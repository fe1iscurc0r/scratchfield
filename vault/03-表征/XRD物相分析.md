# XRD 物相分析

## 原理

X 射线衍射（X-Ray Diffraction），利用 X 射线照射晶体，满足 Bragg 方程时发生相干衍射，形成特征衍射峰。

**Bragg 方程**：2d sinθ = nλ
- d：晶面间距
- θ：入射角
- λ：X 射线波长（Cu Kα ≈ 1.5406 Å）

## 样品要求

- **粉末样品**：研磨过 200-300 目筛，填入样品架压平
- **薄膜样品**：表面平整，基底无干扰峰
- **样品量**：约 0.5-1 g 粉末

## 关键参数

| 参数 | 典型值 |
|------|--------|
| 扫描范围 | 5-80° (2θ) |
| 扫描速度 | 2-5°/min |
| 步长 | 0.02-0.05° |
| 靶材 | Cu Kα（λ=1.5406 Å） |
| 工作电压/电流 | 40 kV / 30-40 mA |

## 碳材料特征峰

| 2θ | 晶面 | 意义 |
|----|------|------|
| ~26° | (002) | 石墨化度，层间堆叠 |
| ~43° | (100) | 面内有序 |
| ~44° | (101) | 面内有序 |
| ~54° | (004) | 高度石墨化 |

- (002) 峰越尖锐 → 石墨化度越高（碳化温度高）
- (002) 峰宽化/位移 → 无定形碳，结构无序

## 数据分析

- **Scherrer 公式**计算晶粒尺寸：
  D = Kλ / (β cosθ)
  - K ≈ 0.89，β 为半峰宽
- **(002) 峰位置**计算层间距 d002
- 比较峰强判断石墨化程度
