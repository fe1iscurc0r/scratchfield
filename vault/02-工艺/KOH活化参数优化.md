# KOH 活化参数优化

## 目标

通过 KOH 活化提高碳材料的比表面积和孔隙结构，制备高比表面积活性炭，用于吸附、电极、吸波等领域。

## 原理

- **造孔反应**：6 KOH + 2 C → 2 K + 3 H2↑ + 2 K2CO3（高温下）
- **刻蚀造孔**：金属 K 蒸汽插入碳层，刻蚀形成微孔
- **K2CO3 活化**：K2CO3 在 800°C 以上分解继续造孔
- **气体逸出**：H2、CO、CO2 逃逸形成孔隙

## 关键参数

| 参数 | 范围 | 最优区间 |
|------|------|----------|
| KOH : 碳质量比 | 1:1 ~ 4:1 | 2:1 ~ 4:1 |
| 活化温度 | 700-900°C | 800°C |
| 保温时间 | 1-2h | 1h |
| 升温速率 | 2-5°C/min | — |
| 气氛 | N2 | 流量 50-100 mL/min |

## 比表面积

| KOH:碳 比 | 比表面积 (m²/g) | 孔径分布 |
|-----------|-----------------|----------|
| 1:1 | 800-1200 | 微孔为主 |
| 2:1 | 1500-2000 | 微孔+介孔 |
| 4:1 | 2000-3000 | 微孔发达 |
| >5:1 | 过活化，孔塌陷 | 介孔增多 |

## 注意事项

1. **腐蚀性**：KOH 强腐蚀，操作需戴防护手套/护目镜，使用镍坩埚或刚玉坩埚
2. **洗涤**：活化产物用 0.1M HCl 酸洗 → 去离子水洗至中性（pH≈7）
3. **干燥**：洗涤后 105°C 真空干燥 12h
4. **安全**：活化过程产生 H2，需保持气体流通，防止积聚
