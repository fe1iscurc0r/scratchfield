# 碳化工艺流程

## 目标

将生物质前驱体（木质素、纤维素、壳聚糖等）在惰性气氛下高温热解，去除非碳元素（O/H/N），转化为富碳固体材料。

## 工艺流程

```
预处理 → 预碳化 → 碳化 → 冷却
```

### 1. 预处理
- 干燥：105°C 烘干至恒重，去除游离水
- 粉碎：过筛 100-200 目，保证受热均匀

### 2. 预碳化（可选）
- 温度：200-300°C
- 作用：稳定结构，减缓后续碳化剧烈失重

### 3. 碳化（核心步骤）
- 温度：400-1000°C
- 气氛：N2 或 Ar（流量 50-200 mL/min）
- 升温速率：2-10°C/min
- 保温时间：1-3h

### 4. 冷却
- 随炉冷却至室温后再取出，防止氧化

## 关键参数

| 参数 | 典型值 | 影响 |
|------|--------|------|
| 升温速率 | 2-10°C/min | 慢升温利于孔隙发育 |
| 碳化温度 | 400-1000°C | 温度越高石墨化度越高 |
| 保温时间 | 1-3h | 延长保温提高结构有序度 |
| 气氛 | N2/Ar | 必须惰性，隔绝氧气 |

## 碳化产率对比

| 前驱体 | 碳化产率 | 原因 |
|--------|----------|------|
| [[木质素]] | 40-50% | 芳香环富碳，热稳定性高 |
| [[壳聚糖]] | 30-40% | 含氮残留，中等失重 |
| [[纤维素]] | 15-25% | 含氧高，糖苷键易断裂 |
