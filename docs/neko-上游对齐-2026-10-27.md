## 四、关于"聊天区空白"——**不是我们该修的**

`/chat` 的消息区在无消息时呈现纯白。核对上游：

| 结构 | 上游 tip 的 `chat.html` | 我们 |
|---|---|---|
| `chat-container`（`display:none`，页面走 react 浮层） | **有** | 有（未改） |
| `react-chat-window-overlay` 等 react 壳 | **有** | 有（未改） |
| `ws-adapter.js` / `electron-page-bridge.js` | **无** | 有（我们加的） |

⇒ 空白消息区来自**上游自己的页面结构**（react 浮层模式 + 空消息区无背景），
我们对 `chat.html` 只追加了 2 个 script 标签，**没有碰布局或样式**。
所以这不该在本仓修；若确属观感问题，应**提给上游**（issue），而不是本地下补丁。
