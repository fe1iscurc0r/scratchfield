## 入选弹药（7 项，全部宽松许可）

### 1. RamanSPy ★191（BSD-3-Clause ✅）· barahona-research-group/RamanSPy

- **语言**: Python（帝国理工 Barahona 组）
- **核心功能**: 积分式 Raman 光谱分析框架——预处理（去噪/基线/cosmic ray 滤除）、
  光谱分解（MCR-ALS/ALS/NMF/PCA/VCA）、机器学习分类回归管线，统一的
  `SpectralContainer` 数据抽象。
- **授粉点**: [源→目标映射] 它的"预处理→分解→ML"三段管线设计与
  `mcpserver/spectra_tools`（轮19 pybaselines 授粉）天然衔接：
  pybaselines 管基线，RamanSPy 的 `preprocessing` 模块管其余前处理与分解层，
  MCR-ALS 分解正是木质素-DES 混合谱解混需要的算法（多组分光谱拆分）。
- 活跃度：2025-11 仍在 push；文档站完整。

### 2. nmrglue ★275（BSD-3-Clause ✅）· jjhelmus/nmrglue

- **语言**: Python（纯 numpy/scipy）
- **核心功能**: NMR 波谱处理的全功能件——时域 FID 处理（FFT/窗函数/相位校正）、
  频域处理、多维谱、Bruker/Varian/Agilent/JEOL 全格式读取。
- **授粉点**: [源→目标映射] 化学表征不只 FTIR/Raman——核磁（木质素结构鉴定的
  金标准 31P-NMR/HSQC）目前是仓里零覆盖。nmrglue 的 `ng.bruker.read` 格式
  读取层可直接进 `mcpserver/spectra_tools` 的 IO 模块；其管线对象式 API
  （process→proc_data）与 sitaware 的 pipeline 思想同构。
- 活跃度：2026-08 仍在 push。

### 3. spectral（SPy）★682（MIT ✅）· spectralpython/spectral

- **语言**: Python
- **核心功能**: 高光谱图像处理老牌库（1998 年起）——ENVI/HDF 等 IO、
  波段运算、分类（SAM/匹配滤波）、无监督（k-means/PCA）、光谱库管理。
- **授粉点**: [源→目标映射] 成像光谱（hyperspectral）是 FTIR 单点谱的
  高维扩展——热蒸发膜层的面扫数据就是 ENVI 格式。SPy 的 `spectral.SpectralLibrary`
  （光谱库持久化 + SAM 距离检索）设计可移植为 lumo 的"标准谱库比对"服务：
  已知物相谱 → 待测谱匹配打分。
- 活跃度：2026-09 仍在 push（30 年生命力的库）。

### 4. lmfit ★1237（BSD-3-Clause ✅，PyPI 元数据确认）· lmfit/lmfit-py

- **语言**: Python
- **核心功能**: 非线性最小二乘拟合的事实标准——`Model` 对象化参数拟合、
  内置上百条谱学线型（Voigt/Gaussian/Lorentzian/…）与峰形模型、
  置信区间估计、多峰复合拟合。
- **授粉点**: [源→目标映射] 光谱定量分析的最后一步永远是"多峰拟合出面积"。
  lmfit 的 `Model + Parameters` 抽象（有界参数/表达式耦合）是
  `spectra_tools` 拟合工具的底层引擎首选；XPS 分析器（如 LG4X）本质
  就是 lmfit 的 GUI 壳——我们直接用内核。
- 活跃度：2026-08 仍在 push。

### 5. xraylarch ★181（MIT ✅，LICENSE 原文确认）· xraypy/xraylarch

- **语言**: Python（芝加哥大学 Newville，与 lmfit 同源生态）
- **核心功能**: X射线吸收谱（XAFS/XANES/EXAFS）分析全管线——
  能量校准、前边/后边背景扣除、EXAFS 拟合（FEFF 路径）、批量批处理。
- **授粉点**: [源→目标映射] 同步辐射表征线（XANES 定价态/配位环境）是
  木质素催化转化的关键表征。larch 的 `pre_edge`/`post_edge`/`autobk`
  三段式 XAFS 预处理管线，模式与 pybaselines 一致——同一个 MCP 工具面
  可以统一挂载两类谱学处理。
- 活跃度：2026-09 仍在 push。

### 6. pymatgen ★1972（MIT ✅，PyPI classifier 确认）· materialsproject/pymatgen

- **语言**: Python（Materials Project 官方）
- **核心功能**: 材料计算事实标准——晶体结构处理、DFT 工作流（VASP/ABINIT 接口）、
  `pymatgen.io` 全格式结构 IO、`pymatgen.symmetry`/`diffraction`（XRD 模拟）/`electronics`。
- **授粉点**: [源→目标映射] "第一性原理谱模拟"维度的落地件：
  `pymatgen.diffraction.xrd.XRDCalculator` 可从 CIF 直接模拟 XRD 谱
  （与实验谱比对定相）；已授粉的 pymatviz（SPEC-19）正好是其可视化伴生件。
  材料线"结构→谱→物性"链条的模拟端补齐。
- 活跃度：2026-08 仍在 push。

### 7. DeerLab ★22（MIT ✅）· JeschkeLab/DeerLab

- **语言**: Python（ETH Jeschke 组）
- **核心功能**: 双电子共振（DEER/PELDOR）EPR 波谱分析——Tikhonov/正则化
  反演距离分布、背景校正、全贝叶斯不确定度。
- **授粉点**: [源→目标映射] 小众但唯一：顺磁表征（自由基/EPR）在
  木质素自聚合机理研究里有用武之地。其"正则化反演 + 不确定度量化"
  的通用设计（不只是 EPR 专用）可借鉴到任何逆问题工具
  （如从 SAXS 反演尺寸分布）。
- 活跃度：2026-05 仍在 push。
