## 0. 结论速览

UC-PSRO 的关键经验：**不要只在理想信道（零丢包）下训练协作策略，而是用「渐进退化的通信课程」让 Agent 学会降级协作**。对 NEKO 多 Agent 的直接迁移是：在训练时把「消息丢包率/带宽」当作课程难度，从 0 单调升至目标恶劣度（如 50% 丢包），让 Agent 学会冗余重传、确认-重试、降级路由等策略，而非在真部署时第一次遇到丢包就失败。

最小原型验证了一条干净的因果链：

- **无课程基线**（在丢包 0% 下训练）：学到「单发即止」，到 50% 丢包时任务成功率仅 ~50%。
- **通信退化课程**（丢包 0%→50% 渐进）：学到「冗余重传」，50% 丢包时成功率 ~87%，**提升 ≥20%**。

## 1. 通信退化课程设计

### 1.1 课程调度

把通信退化指标 `d`（丢包率、带宽上限、延迟抖动的统称）作为课程变量，分阶段单调递增：

```
阶段 0: d = 0.00   （理想信道，学基本协作）
阶段 1: d = 0.10
阶段 2: d = 0.20
阶段 3: d = 0.30
阶段 4: d = 0.40
阶段 5: d = 0.50   （目标恶劣度）
```

每阶段训练到成功率收敛后再进入下一阶段；阶段内用带噪 `d`（上下抖动）避免过拟合单一丢包率。

### 1.2 Agent 可学习的降级协作策略

| 策略 | 适用退化 | 实现 |
|---|---|---|
| 冗余重传（多副本） | 随机丢包 | 同一条消息发 `r` 份 |
| 确认-重试（ACK + 超时重发） | 丢包/延迟 | 收到 ACK 停，超时重发至预算上限 |
| 降级路由（绕开低可信节点） | 局部节点失效 | 结合 A26 信用分重路由 |
| 压缩降载（降信息量） | 带宽受限 | 降低消息粒度/频率 |

原型实现前两者（冗余 + ACK 重试），后两者与 A26 信用账本、R44 协议路由衔接。

### 1.3 训练信号

- 奖励 = 任务成功（+1）− 通信成本（每份副本/重发 × 小惩罚），迫使 Agent 在「可靠」与「省」之间找平衡——这正是 UC-PSRO 从 35%→62% 的关键：不是无脑加冗余，而是学会按信道状况**适当地**降级。
- 用 epsilon-greedy 表格 Q 学习做最小演示（NEKO 真实落地换 PPO/PSRO 的混合策略，本原型只证明「课程」这一杠杆有效）。

## 2. 原型（`tools/comm_degradation_curriculum.py`）

纯标准库，核心对象：

- `Channel(drop_prob)`：`send(copies)` 模拟「发 `copies` 份、每份独立丢包」，成功率 `1 - p^copies`。
- `RedundancyAgent`：在冗余档位 `r ∈ {1..R_MAX}` 上做 epsilon-greedy Q 学习。
- `train(agent, p, steps)`：固定丢包率训练。
- `curriculum_train(agent, ramp)`：丢包 0%→目标值渐进训练。
- `evaluate(agent, p, trials)`：在丢包率 `p` 下统计任务成功率。

运行自测：

```bash
python tools/comm_degradation_curriculum.py
```

## 4. NEKO 落地路径（后续）

1. 把 `Channel` 换成 NEKO 真实消息总线（MQTT-SN/LoRa 网关）的丢包注入层。

3. 训练目标从单对收发扩展到多 Agent 协作任务（如分布式感知共识、编队）。
