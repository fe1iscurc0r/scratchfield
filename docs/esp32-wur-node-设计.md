## 1. 结论先行

MagPie 的核心配方是「**微安级唤醒无线电（WuR）拓宽首触窗口 + 低功耗 RTC 保持相位**」，STM32WL33 实测 11 小时稳定运行。这一架构可移植到 ESP32：常态 WuR + RTC 共 ~10µA 聆听，事件或周期唤醒才启动主控做采样/上报，平均功耗可压到 **≤50µA**（下表给出一份 ~33µA 的预算）。

---

## 2. MagPie 要点（2608.25292）

| 维度 | MagPie 做法 | ESP32 映射 |
|---|---|---|
| 首触窗口 | 微安 WuR 持续监听唤醒信号 | 外部 WuR 芯片（如 AS3933/自制包络检测） |
| 相位保持 | 低功耗 RTC + 32kHz 晶振 | ESP32 ULP + 外部 32.768kHz 晶振 |
| 主控 | 仅唤醒时上电 | ESP32 deep-sleep，RTC 定时唤醒 |
| 结果 | STM32WL33 11 小时稳定 | 目标同量级或更优 |

---

## 3. 架构图（文本）

```
          唤醒信号（网关广播/邻居唤醒）
                    │
                    ▼
        ┌───────────────────────┐
        │  WuR 唤醒无线电（微安级）│  ← 常态监听，首触窗口
        └───────────┬───────────┘
                    │ 唤醒中断（沿触发）
                    ▼
        ┌───────────────────────┐
        │   ESP32（deep-sleep）  │
        │  ┌─────────────────┐  │
        │  │ ULP/RTC 定时器  │◄─┼── 外部 32.768kHz 晶振（相位保持）
        │  │ 相位计数/时间戳 │  │
        │  └─────────────────┘  │
        │  唤醒 → 采样 → TX → 睡 │
        └───────────┬───────────┘
                    │
                    ▼
           传感器（振动/频谱/温度）+ 射频（LoRa/433）
```

- **相位保持**：RTC 由外部 32.768kHz 晶振驱动，deep-sleep 期间持续计数，唤醒后时间戳/相位不丢失，支持 TDMA 类调度（节点按分配时隙唤醒）。
- **WuR**：微安级监听唤醒信号，收到匹配地址才拉高主控；平时主控完全断电。

---

## 4. 唤醒协议

1. **事件唤醒**：网关/邻居发送带节点地址的唤醒帧（OOK 前导 + 地址 + CRC）→ WuR 匹配地址 → 拉中断唤醒主控 → 主控采样并上行。
2. **周期唤醒**：RTC 按 TDMA 时隙定时唤醒，节点在自身时隙采样/上报，其余时隙深睡（相位保持保证时隙对齐不漂移）。
3. **混合**：默认周期稀疏上报（分钟级），WuR 事件触发即时上报（秒级响应），兼顾功耗与实时性。

---

## 5. 功耗预算表（目标 ≤50µA 平均）

| 组件 / 状态 | 电流 | 占空比 | 平均电流 |
|---|---|---|---|
| WuR 唤醒无线电（监听） | 3.0 µA | 100% | 3.0 µA |
| RTC + 32kHz 晶振（相位保持） | 2.0 µA | 100% | 2.0 µA |
| ESP32 deep-sleep（RTC 域） | 5.0 µA | 100% | 5.0 µA |
| 周期采样（1 次/分钟，10ms @ 8mA） | 8 mA | 10ms/60s | 1.3 µA |
| 上行 TX（1 包/分钟，40ms @ 40mA） | 40 mA | 40ms/60s | 26.7 µA |
| **合计** | | | **~38 µA** |

> 结论：~38µA ≤ 50µA，达标。若放宽上报频率（1 包/5 分钟），平均可压到 ~12µA；若改为纯事件驱动（仅 WuR 触发），常态仅 ~10µA。上表按「分钟级周期上报」保守估计。

---

## 6. 落地建议

1. WuR 用现成芯片（AS3933 低频唤醒 / 自制 433MHz 包络检测 + 比较器）做地址匹配。
2. ESP32 用 ULP（超低功耗协处理器）+ 外部 32.768kHz 晶振做相位保持计数。
3. 上行用 LoRa（SX1278）低速率模式，1 包/分钟，40ms 空中时间。
4. 相位保持 + TDMA 时隙调度可复用 R16 的自适应跳频策略。
