## 一、问题陈述

MCU 固件的身份认证若依赖**软件密钥**，密钥可被提取/复制，无法提供"不可克隆"的信任根。IriSig-Spoof（卫星 RF 指纹，97.75% 跨天准确率）和 NICWhisper（网卡电磁侧信道，80.67 Macro-F1）证明：**硬件固有特性（RF 调制特征、EM 辐射）在时域/频域上具有唯一性和鲁棒性**，可作为不可克隆身份。

## 二、指纹提取方案

### 2.1 指纹来源
- **电源管理 IC 噪声**：芯片供电纹波/噪声的固有频谱特征。
- **RF 前端噪声**：射频前端（如 SX1278）的发射/接收链路固有失真特征。

### 2.2 提取流程
```
采集固有噪声（多次采样，跨天/跨温）
  → 时域/频域特征提取（功率谱、调制畸变、EM 辐射模式）
  → 特征稳定化（去环境漂移、归一化）
  → 指纹模板（不可克隆的物理层身份）
```

### 2.3 不可克隆性
- 指纹来自**物理制造差异**，无法被软件复制。
- 提供**固件身份绑定**：固件启动时校验硬件指纹，指纹不匹配即拒绝运行（防固件克隆/刷写到其他设备）。

## 三、稳定性评估

| 指标 | 要求 |
|---|---|
| 跨天稳定性 | 同一设备跨天识别准确率（锚定 IriSig 97.75%） |
| 跨温/跨供电稳定性 | 环境变化下指纹漂移范围 |
| 设备区分度 | 不同设备间指纹的可分性 |
| 抗克隆性 | 软件复制无法通过校验 |

**验收目标**：指纹在"同一设备跨天稳定、不同设备可区分、软件不可克隆"三方面达标。
