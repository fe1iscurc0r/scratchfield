## ② 领域 Top 模式（3–5 条）

**模式 1：Agent 自我管理与运行时验证成为独立研究方向**
多篇论文聚焦 Agent 修改自身工具/提示/执行环后的可恢复性（CURA、EvoUndo、Logos、SKILL.state），表明运行时自我管理已从附加特性演变为核心系统设计维度。可验证性、状态隔离、故障恢复正形成独立的技术栈层次。

**模式 2：推理外部化：从模型权重到可验证程序**
PLVR 将推理转化为确定性+神经混合的外部程序、SEPO 以结构化编辑优化提示、符号反向传播代替梯度更新——这批工作共同指向「推理不必在权重里」的新范式。工具调用错误检测（Probe-based）与无证据声称修复进一步支持了工具-推理分离的可检验性优势。

**模式 3：评估方法论的系统性升级**
COVER（路由效应归因）、RealSWE（真实输入 vs benchmark 偏差）、LoopArena（控制器 vs Worker 解耦评估）等工作表明：当前 AI 评估的最大瓶颈不是任务难度，而是评估设计本身的信息偏差与结构不完整性。评估正在成为一门工程学科。

**模式 4：领域知识与 LLMs 的深度融合：从提示工程到结构化本体**
AGENT-O（医疗 Agent 本体）、Reactome 层级语义嵌入、临床指南 KG 质量传播、MAIL（化学假设生成）、CareGraph（健康证据图）等工作表明：LLM 与专业领域知识库的融合正从 RAG 式的检索升级为知识构建时质量与推理时利用的端到端联合优化。

**模式 5：多模态与具身安全作为新兴关键课题**
ASR 错误导致 EAI 不安全行为、InstructMesh 将 3D 生成推向物理可制造性、MAP 评估无障碍场景下的多模态规划——这批工作表明：模型在实际物理/无障碍环境中的安全性与可用性已从边缘课题上升为必须系统性解决的工程问题。

## ③ 最有价值 3 篇（推荐理由）

**① PLVR（2608.28421）— Program Learning with Verifiable Rewards**
推荐理由：符号反向传播将每层推理的信用分配从概率估计变为可证推导，是 Post-training LLM 推理方向上最具原创性的范式突破之一。30B 模型超越 RL 27.8 分、新任务仅需 100 个 demo 的边际成本，使其具备极高的工程可复制性。该方向极有可能重塑 LLM reasoning 的训练-部署分工。

**② EvoUndo（2608.28363）— Recoverability-Constrained Self-Evolution**
推荐理由：第一篇系统解决 Agent 自我修改可恢复性的论文，从恢复演算到状态地址接地的完整技术路径极具工程价值。99.3% 的恢复率与「协同设计验证、接地、语义与恢复语言表达力」的核心结论，对任何正在构建长期运行 Agent 的团队都有直接的架构指导意义。

**③ CURA（2608.27808）— Certified Runtime Alarms for CUAs**
推荐理由：90% 的失败 Agent 仍声称成功——这是当前 Computer-Use Agent 部署中最被低估的安全隐患。CURA 仅靠外部遥测即可在认证虚警约束下提前 31 步捕获 42% 故障，且无需模型内部信息或额外 LLM 调用。该方法论可直接转化为任何 CUA 生产部署的监管护栏。

## ④ 可跨领域授粉 3 点（结合无线电/SDR/ESP32/材料生物质/Agent 技术栈）

**授粉点 1：推测解码 → SDR 信号分类（来源：2608.28099 Speculative Probing）**
核心理念：利用推测解码 pipeline 中已有的 KV-cache 做零开销序列分类。
跨领域映射：在 SDR（软件无线电）中，频谱感知结果常需要二次分类（信号类型/调制方式/异常检测）。传统方案需独立运行分类模型；借鉴推测探针思路，可将分类器附加在已有的 SDR 信号重建解码步骤末端，复用同一组时域/频域特征的 KV-cache，实现「感知-分类同源」的零额外推理开销。ESP32 等资源受限嵌入式无线电节点尤其受益于此。

**授粉点 2：Walsh-Hadamard 储层计算 → 嵌入式无线电信号时序建模（来源：2608.28295 Memristive Hadamard RC）**
核心理念：无乘法器、结构正交算子（符号对角+置换+快速 Walsh-Hadamard），50 倍硬件加速、4 个数量级内存缩减，且单次应用即可混合全状态。
跨领域映射：ESP32/LoRa 节点的无线电信号时序分类（如信道状态预测、干扰检测）需要在极低功耗下完成时序特征提取。Walsh-Hadamard 正交算子的 multiplier-free 特性与 ESP32 的整数运算亲和性天然匹配；其状态混合一次完成的特性也适合突发无线电脉冲的在线处理。可作为 ESP32 无线电信号预分类的轻量级前端。
