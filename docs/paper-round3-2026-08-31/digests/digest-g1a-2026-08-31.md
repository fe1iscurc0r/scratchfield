## 二、领域 Top 模式（3-5 条共性趋势）

1. **结构化生成与 KV 压缩成为 LLM 推理效率核心战场**：PASK（Parser-Aware KV 持久化）、上下文无关文法 lookahead 解码、SOMTab（注意力分离）等从不同角度压缩推理成本，2026 年的焦点已从训练转向推理部署效率。

2. **基础模型持续微调（Continual FM Fine-tuning）从静态走向动态**：COMPASS、D-TAIA 等将 LLM/FM 适配到过程监控、金融预测等时序领域，核心矛盾是概念漂移下的灾难遗忘与自适应任务边界检测。

3. **物理启发的深度网络与领域知识注入成为突破方向**：QGPINNs（量子图PINNs）、PhyMamba（电池电化学）、EFNO（材料科学迁移）、HALO（超图小波 PDE）、生物启发 groking 等将领域偏置/物理定律嵌入网络结构而非仅靠数据驱动。

4. **信用分配与多智能体 RL 的细粒度化**：VISTA（验证器追溯信用）、VICT（原子证明边）、HARTS（任意树共享前缀差分）等从不同粒度解决长期信用分配问题，驱动 Agent 系统向更复杂任务拓展。

5. **量子机器学习进入可比较经典精度区间**：量子 CNN/LSTM 在高能物理回归任务上用 4 量子比特达经典 CNN 水平，表明近期量子优势可能在特定物理模拟场景先于通用 NLP 出现。

## 三、最有价值 3 篇

### ① 2608.28425 — Euclidean FNOs（EFNO）
**推荐理由**：FNOs 本身是科学计算 ML 的里程碑，但原始 FNOs 无法跨域迁移是其致命缺陷。EFNO 将离散傅里叶模数替换为物理波矢的连续函数，成功在热方程和材料科学交换-相关势任务上跨晶体结构泛化。这对 **射频/天线仿真、SDR 信号传播建模** 等需要在不同频段/几何配置间迁移神经算子的场景有直接价值——训练一个 EFNO 可应用于多种天线阵列拓扑，无需逐个重新训练。

### ② 2608.28276 — PASK（Parser-Aware KV Persistence）
**推荐理由**：LLM Agent 做结构化输出（JSON/SQL/函数调用）时，KV 压缩长期忽视 parser 状态的结构语义。PASK 巧妙利用任务错误敏感度设置保护下界、注意力输出畸变分配残余容量，在 0.33 总 KV 预算下 BFCL 8 项平均领先 17.39pp，吞吐提升 2.2x，TPOT 降低 3.3x。对于 **ESP32 等边缘端部署 LLM**（内存极为有限），这种 parser 感知压缩是把大模型塞进嵌入式设备的关键技术。

### ③ 2608.28306 — VISTA（Verifier-Informed Student-Teacher Adaptation）
**推荐理由**：OPSD（on-policy self-distillation）当前 SOTA 瓶颈是 teacher 分布固定且不对齐问题专用推理。VISTA 核心洞察：用 outcome 验证过的 rollout 样本反向适配 teacher，仅在 top-k KL 散度位置做修正，不引入额外采样。在 Qwen3 1.7B/4B/8B 的 AIME/HMMT 数学任务上平均领先 OPSD 0.6-2.1 分。对 **Agent 工具调用、代码生成、复杂推理** 场景，直接影响模型在工具使用链路上自我纠偏能力——比单独调 teacher 更高效。

## 四、可跨领域授粉 3 点（结合无线电/SDR/ESP32/材料生物质/Agent 技术栈）

### 授粉点 1：PASK 的 parser 感知 KV 思想 → SDR 频谱感知 + ESP32 边缘 LLM 推理
- **来源论文**：2608.28276（`PASK`）
- **来源领域**：LLM 高效推理 / 结构化生成
- **可流向**：ESP32 边缘 AI、SDR 信号解析、射频 Agent
- **潜在用途**：在 ESP32 上跑 LLM 时，KV 内存是瓶颈。PASK 的核心思想是将"结构感知"引入缓存决策——类似地，SDR 信号解析中，不同频段/协议特征（如 LTE 导频、WiFi 前导码）对后续解调的重要性不同，可以设计"协议感知"的特征缓存策略，把关键信道状态信息优先保留在高速缓存中，丢弃低价值噪声特征，实现嵌入式 SDR 的内存-精度权衡优化。
- **移植级别**：设计思想（高度可行，ESP32 有 SIMD 加速器可支持轻量状态追踪）

### 授粉点 2：HALO 超图小波算子 → 材料科学交换-相关势迁移 → 生物质材料频率选择表面
- **来源论文**：2608.27883（`HALO`）+ 2608.28425（`EFNO`）
- **来源领域**：科学计算神经算子 / 计算材料学
- **可流向**：射频超材料设计、生物质基频率选择表面（FSK）、智能天线
- **潜在用途**：HALO 的核心创新是超图提升 + Chebyshev 小波谱滤波器实现任意网格上的稳定多尺度学习。将其迁移到 **生物质基频率选择表面**（如纤维素/木质素复合材料构成的可调 FSS）：超图天然表示单元-邻居-社区的多体耦合，小波多尺度能捕捉从分子振动到宏观电磁响应的跨尺度物理。训练一个 HALO 模型可根据入射波角度/频率预测生物质 FSS 的传输系数，实现低成本可穿戴射频器件的快速设计空间探索。
- **移植级别**：算法移植（需要 PDE 仿真数据，但框架已开源可复用）

### 授粉点 3：VICT 验证器信用追溯 + VISTA 反向 teacher 适配 → Agent 无线电感知-决策闭环
- **来源论文**：2608.28128（`VICT`）+ 2608.28306（`VISTA`）
- **来源领域**：LLM Agent 强化学习 / 细粒度信用分配
- **可流向**：SDR 感知 Agent、认知无线电、IC-705 智能辅助
- **潜在用途**：IC-705 当前依赖手工配置频段/模式，但一个 SDR 感知 Agent 需要：①从频谱感知结果（检测到的信号类型）自动推断下一步操作（切换频段/调制方式）。VICT 提供了一种将验证器内部结构（信号是否满足协议格式？解调是否成功？）映射回各决策步骤的信用分配机制；VISTA 则允许 Agent 的 teacher（规则库/仿真环境）根据真实执行结果反向修正。将两者结合：构建一个"协议验证器驱动的 SDR Agent"，验证器负责检查频谱感知输出的协议一致性，信用追溯驱动策略网络学习哪些感知特征导致正确的调制识别，teacher 适配允许规则库根据实际电离层条件动态调整——形成完整的无线电感知-决策-反馈闭环。
- **移植级别**：架构参考（需构建真实 SDR 数据集与协议验证器，但信用追溯机制可直接对应到信号检测任务）
