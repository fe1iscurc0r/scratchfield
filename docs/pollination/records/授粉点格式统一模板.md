# 授粉点格式统一模板（K05）

> 生成 2026-08-30 ｜ 目标：把 44 份 digest 的授粉点（格式异构）统一为一条可入库的授粉记录。

## 1. 异构现状（抽样）

| digest | 授粉点写法 | 结构字段 |
|--------|-----------|---------|
| g4-3 | `### 授粉点 A：…` | 发现 / 嫁接 / 价值 |
| g9 | `Point 1: … → …` | 无固定字段，段落式 |
| gx-4b | `### 🔌 授粉1：…` | 场景 / 怎么做 / 价值 |
| gx-3b | `1. **无线电/SDR ← …**：…` | 编号列表，`←` 表流向 |
| gx-5c | `### 授粉点 1：…` | `→` 表流向 |

## 2. 统一模板（每点一条）

```
- 编号:      <源>.<N>         # 如 gx-4b.1
- 来源:      <digest 文件> | <涉及的 arXiv ID，多个逗号分隔>
- 流向:      <RF|ESP|材料|Agent|安全|量子|其他>   # 从哪条线流向哪条线
- 用途:      <一句话：这个授粉点要干什么>
- 优先级:    P0|P1|P2
- 原文:      <授粉点原文（截断 300 字）>
```

四个必填字段：**来源 | 流向 | 用途 | 优先级**。

## 3. 迁移脚本

`scripts/pollination_migrate.py`：扫描 `docs/paper-round2-2026-08-30/digests/*.md` → 抽授粉段落 → 按上述模板归一化 → 输出 `授粉点-统一.json` + `授粉点-统一.md`。

- 流向推断：关键词命中（频谱/SDR/无线电→RF；ESP32/嵌入式→ESP；材料/生物质/水凝胶→材料；Agent/LLM→Agent；安全/攻击→安全；量子→量子）。
- 优先级推断：显式 P0/P1/P2 优先；含「直接迁移/直接移植/可抄」→P1；「远期/观察/跟踪」→P2；默认 P2。
- 抽取不到子点时，整段作为单条授粉点兜底。
