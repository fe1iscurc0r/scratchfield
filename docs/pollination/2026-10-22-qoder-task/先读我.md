## 谁来做、怎么拉

- **在本仓里**：`git pull` 后直接读本目录，不需要再要 zip。
- **跑分析**：把 `任务提示词.md` 整段当 prompt，输入指向 `new-papers-2026-10-22.jsonl`。
  有些 IDE 对单文件 >500KB 有索引上限，拆成 4 个 130 条的分片即可（`split -l 130`）。
- **产出交回**：两节 markdown。落盘到 `research/papers/weekly_pollination.md` 末尾（带日期标题），
  同时把这 514 个 base id 追加进 `research/papers/processed_ids.txt` —— **这一步必须做**，
  否则次日 02:00 的 cron 会把同一批再分析一遍。

## 边界

- 无人机/飞控（PX4/ROS2/MavSDK/SLAM）仍暂停：`cs.RO` 那 41 篇只做文献跟踪，不许写成启动项。
- 不许编造数字；每条趋势至少 3 个 arXiv id 支撑，凑不出就降级成"单篇值得看"。
- 不得与 2026-10-22 02:18 那轮的三个授粉点重复（A/B/C 已列在提示词里）。
