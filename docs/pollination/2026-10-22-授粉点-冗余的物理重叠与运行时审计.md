# 授粉点 B · 冗余的物理重叠与运行时审计（10-22 批）

> 工单 274 任务 B。结构固定四段：借鉴点 / 落点 / 难度×收益 / 验收。
> **本文件只出 SPEC，不写实现。**
> 核心命题：**逻辑不相交 ≠ 物理不相交**——两条"互备"链路可以共用同一路市电、同一根天线杆、同一个机房。

| ID | 一句话它做了什么 |
|---|---|
| `cs.NI 2610.27125` | 提出 **illusory resilience**：两条替代路径在 AS/IP 层不相交，却共用同一设施/管道/海底登陆点；定义 **IRI**（隐患加权物理重叠度）来量化这个缺口，并给出**在没有运营商底层地图**时的检测办法 |
| `cs.RO 2610.27726` | 学习型 barrier certificate 的**随时有效（anytime-valid）**运行时监控：用闭环轨迹做序贯假设检验，检测部署期"统计支撑失效"，而不是假设训练期结论永久成立 |
| `cs.CR 2610.28401` | SPECTER：气隙系统的**USB 供电调制**隐蔽外泄信道——发送端只用 USB 电源管理/设备状态操作编码比特，不把载荷放进 USB 数据流；给出三条接收路径 |

## 1. 借鉴点（机制 → 本侧部件 → 档位）

### 1.1 逻辑冗余 vs 物理冗余：用比值戳穿账面冗余（`2610.27125`）

- **机制**：把"路径对"的物理重叠按**隐患**加权求和，得到 IRI；IRI 高说明"名义上两条、实际上一条"。
- **本侧部件**：**名义冗余 vs 真实冗余比值**
  `R = 名义独立度 / (1 + IRI)`：`R > 1` 即"账面冗余是假的"。台架上先算**供电与天线**两类，
  这两类不需要运营商地图就能测（见 1.2）。
- **档位**：**立即**（本地可测，不依赖外部数据）。

### 1.2 共享设施表：五类，字段与填法（`2610.27125`）

- **机制**：物理重叠发生在设施层，所以先把设施显式记录下来，才谈得上算重叠。
- **本侧部件**：下面这张表（§2.1）作为**唯一事实源**；任何"我们有冗余"的结论必须能追到这张表的行。
- **档位**：**立即**（表格 + 现场填一遍）。

### 1.3 运行时审计：阈值该被审计，而不是被信任（`2610.27726`）

- **机制**：学习型安全凭证的有效性会随部署漂移而衰减；作者用**序贯假设检验**做"随时有效"的监控——
  不用固定样本量就能在任意时刻给出有效判据，且能控制误报。
- **本侧部件**：**频谱哨兵阈值漂移审计**。当前做法是"阈值写死 + 超限告警"；改成：
  ① 以标定日的噪声底为原假设；② 每 N 帧做一次序贯检验；③ 检测到漂移时**先标记"阈值失效"再告警**，
  避免"温度升高导致的底噪抬升"被当成"有信号"。
- **样本量与误报代价**：给出表（§2.2），至少两行：`N=32 / 误报率≈1e-2`、`N=128 / 误报率≈1e-3`；
  代价写"每多 1 倍样本，滞后增加多少帧"。
- **档位**：**本周**（纯软件，可在现有哨兵脚本上改）。

### 1.4 诚实边界：IRI 不是通用指标（`2610.27125`，**必须保留**）

- 原文明确：**60 秒级的 BGP 撤路信号通不过校准**，只有**运营商互联足迹**与**海底登陆点**两路可用。
- ⇒ 本侧 SPEC 里 **不得**把 IRI 写成"通用冗余指标"。可行范围仅限：**供电 / 天线杆 / 机房 / 交换机** 四类本地可测项；
  运营商出口一类只能引用公开互联数据，且必须标注"不可用于秒级判断"。
- **档位**：**立即**（作为写作约束，不是待办）。

### 1.5 气隙边界要画到供电与接地（`2610.28401`）

- **机制**：SPECTER 不靠 USB 数据线，而靠**USB 供电调制**外泄 ⇒ 只拔网线、只封数据口的隔离是不完整的。
- **本侧部件**：把"实验室那台只跑仪器的机器"的隔离边界写成三层：
  ① 网络（已做）② **USB/数据口（已做）** ③ **供电与接地（缺）**——第三层要写清：独立回路、共模扼流、
  以及"谁能碰这条回路"。
- **档位**：**本周**（先补文档与检查表，硬件改造排季度）。

## 4. 验收（≥2 个可判定实验）

### 实验 1 · 假冗余能被抓出来（对应 1.1/1.2）

- 做法：构造一对"逻辑上两条、共用同一路市电"的链路，填表并算 `R`。
- 判据：`R > 1` 且报告能**指名共用的那一行**（回路编号）；反向对照：真正独立的两路必须 `R ≤ 1`。

### 实验 2 · 阈值漂移被审计而不是被信任（对应 1.3）

- 做法：恒温下注水抬升噪声底（或人为加衰减），使底噪偏移 +3 dB。
- 判据：审计在 `N=128` 内标记"阈值失效"，**且不产生"有信号"告警**；
  反向对照：真有信号时必须在同一 `N` 内告警（不能因为审计而漏报）。

### 实验 3 · 气隙检查表可判定（对应 1.5）

- 做法：按检查表逐项核"只跑仪器的机器"。
- 判据：三层（网络/USB/供电接地）**每层都有"是/否 + 证据"**；"供电与接地"层未填完即视为整体未通过。
