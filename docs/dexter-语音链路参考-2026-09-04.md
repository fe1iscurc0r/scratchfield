# dexter 语音链路参考报告（Rust 全离线链路）

## 一、端到端链路拆解

唤醒（VAD/wake）→ ASR（Whisper）→ LLM（Ollama 本地推理）→ TTS（Chatterbox）→ 播放，Rust 端编排，全离线。核心是**链路编排 + 资源调度 + 端上部署**，而非 Rust 语言本身。

## 二、与 Python 栈对比

| 维度 | dexter（Rust） | 本项目 Python 栈 |
|------|---------------|-----------------|
| 性能 | 低延迟、低内存 | 开发快、生态丰富 |
| 复杂度 | 构建/依赖管理复杂 | 简单 |
| 部署 | 单二进制，端上友好 | 需 Python 环境 |

## 三、可借鉴设计点（≥3，映射到 Python 栈）

1. **流式级联编排**：ASR 边听边流给 LLM，LLM 边生成边流给 TTS——映射：Python 用生成器/流式接口串联三段，降低首字延迟。
2. **资源调度/降级**：GPU 不可用时自动降 CPU——映射：Python 栈加「设备探测 + 分级降级」开关。
3. **进程隔离 + 重启恢复**：各组件独立进程，崩溃可单点重启——映射：Python 用 subprocess/multiprocessing 隔离 Whisper/Ollama/TTS，避免单点拖垮全链路。

## 四、结论

**仅参考**：链路编排/资源调度/端上部署的工程做法可借鉴（映射见上），不迁移 Rust 语言本身。
