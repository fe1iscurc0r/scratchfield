# pylabrobot 实验自动化 SDK 评估（陆墨材料科研线）

> 2026-09-04 · 88号 M1 · 评估（不写实现、不接真机）
> 上游：PyLabRobot/pylabrobot（GitHub，MIT，★525，硬件无关实验室自动化 SDK）

## 一、抽象层拆解

- 液体处理（移液/分液）、仪器控制、板布局 三块 API 面。
- 数据模型：板（plate）→ 孔（well）→ 移液操作（transfer/mix）的抽象层级。
- 硬件无关：定义「操作语义」，由后端（真机/模拟器）执行，业务代码不感知具体设备型号。

## 二、对照陆墨线现有流程（接入点）

ELN 记录 → 实验执行 → 数据回流。接入点在「实验执行」层：pylabrobot 提供标准化的液体处理/仪器操作抽象，让 ELN 里的实验步骤能转成可执行的操作序列。

## 三、与虚拟实验（Matterix）组合路径

pylabrobot（执行层，虚拟后端可先跑通）→ Matterix（数字孪生仿真）构成「虚拟先行 → 真机执行」路径（见 M2）。

## 四、硬件需求评估

- 无真实工作站：可用**虚拟/模拟后端**纯软件验证流程正确性。
- 未来接真机（移液站/搅拌/温控）：需对应驱动，成本按设备型号评估（硬件无关抽象可平滑切换）。

## 五、结论

**接入（有保留）**：作为「实验自动化」抽象层接入，硬件无关 API 价值高；先虚拟后端验证，真机按需后接。
