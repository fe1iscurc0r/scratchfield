## 1. 项目定位

RFUAV 论文官方基准：**35 种无人机**的 RF 录制原始数据 + 由之生成的频谱信息数据集，
支持「直接在 raw IQ 上做无人机信号检测与识别」。提供 SNR 估计工具（SNREstimation/）、
逐机型属性分析（跳频带宽 FHSBW / 跳频驻留 FHSDT / 频谱特征 FVFPP）。
防御侧价值：无人机 RF 指纹 → 频谱监测告警（「某频段出现无人机遥控/图传特征」）。

## 2. 架构拆解（顶层实测）

```
configs/          # 模型/实验配置
utils/ tools/     # 数据加载/预处理/可视化
SNREstimation/    # SNR 估计（独立小工具）
example/          # 推理示例（inference.py 入口）
abstract/         # 论文图（FSM/FVFPP 等特征示意图）
（数据集本体：raw IQ + 频谱，按机型分卷，README 给出体积/SNR 中位表）
```

要点：
- **raw IQ 与频谱双形态**：既给原始 IQ 也给生成谱——训练/验证可任选输入形态；
  本仓 rf_brain 当前吃 IQ（Phase 4）与谱（Y-04）两条路，正好都能对拍。
- **逐机型属性表**（FHSBW/FHSDT/FVFPP）：把「无人机 RF 指纹」拆成可计算特征，
  是探测告警规则的直接素材。
- **SNR 估计独立成工具**：可单独拿来给本仓哨兵/监测链做信号质量门限。

## 3. 数据集使用边界说明

- Apache-2.0（代码）；**数据集随仓发布**，使用时保留论文引用（README 要求 cite）。
- 用途限定：**探测/识别模型训练与验证**（防御侧）；不得用于生成干扰波形或
  反制载荷研发（本卷铁律 + 用户口径）。
- 数据量大（按机型分卷）：**不整包入本仓**；按需下载子集 + 记录 checksum 与来源。

## 4. 可落地借鉴点（≥3）

1. **无人机 RF 指纹特征三件套**（FHSBW/FHSDT/FVFPP）→ 本仓频谱监测告警规则库
   新增「无人机疑似」规则族（跳频带宽+驻留+谱形），先规则后模型。
2. **SNREstimation 工具**→ 监测链信号质量门限（低 SNR 不告警，降误报）。
3. **raw IQ + 谱双输入对拍**：rf_brain 的 IQ 路径与谱路径用同一数据集互验，
   作为 Phase 4 特征的外部基准（当前只有合成信号自对拍）。
4. **configs 驱动实验**：模型/阈值/特征组合全部配置化，便于复现与消融。

## 5. 防御侧接入判定

- **Apache-2.0 可融合**（代码级借用需保留 NOTICE/版权声明）。
- 接入顺序建议：SNR 工具（独立、小）→ 指纹特征规则 → 分类模型（等 RTL-SDR/
  数据子集到位）；告警出口接 lumo 频谱面板 + ELN 归档。
