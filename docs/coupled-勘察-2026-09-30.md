## 二、事实盘点（2026-09-30 实测）

### 2.1 是什么

`coupled/omnilimb-face/` —— **omnilimb-face 插件**：把 Open-LLM-VTuber 的能力
（免提语音 / barge-in 打断 / Live2D 头像 / TTS+唇形同步 / wake word）封装为
**hermes-agent 插件**（`plugin.yaml`: `name: omnilimb-face`, `version: 0.1.0`,
`author: seanyang1983`, `kind: standalone`，对齐 `hermes_cli/plugins.py` 的 PluginManifest）。

- 上游血统：Open-LLM-VTuber 能力集（`protocol/` 明写 `/client-ws` Open-LLM-VTuber 协议）
- `INTEGRATION-NOTES.md` / `THIRD_PARTY_NOTICES.md` / `release.ps1` / `start.bat` 齐备——
  一个**自带发布链路的独立项目**，只是宿主在陆墨仓里

### 2.2 许可（打包排除的实锤依据）

- `LICENSE` = **GNU AGPL-3.0**
- `COMMERCIAL-LICENSE.md` 并存 → **双许可**（AGPL 或商业二选一）
- 与 CHANGELOG [5.1.5] 边界表、`naga-backend.spec` 黑名单一致：
  "coupled/* standalone 插件（自带 plugin.yaml + 商业许可）不进发布包"——
  AGPL 传染风险 + 商业条款，排除是唯一正确处置，**维持**

4. `scripts/system_governance.py` TOP_MODS 与（若批豁免）ISLAND_EXEMPT

standalone 插件入库再一并正名为 `plugins/`。
