## 差距清单（本轮没找到的）

- 防冻/抗冻水凝胶直接相关开源件：GitHub 近乎荒漠（cryoprotectant 关键词全是 0-1★ 碎片），最大件是 cryodatabase/cryodb（0★ 无 LICENSE TypeScript 网页）——暂缓，下一轮可换 PyPI/HF 角度再探。
- MIT/BSD 的 Pitzer 电解质活度纯 Python 实现**缺位**（pyEQL/pytzer 均 copyleft）——只能走 pyEQL 只读参考 + electrolytedb 数据自算。
- PHREEQC 本体 phreeqc-dev/phreeqc3 是公共领域（USGS 政府作品），无 SPDX 标识；走 Apache-2.0 的 phreeqpython 封装即可，不必拉本体。

## P0 优先级

1. **lvpp/sigma**：直接填 MTL-χ 路径③ 的数据层，COSMO-SAC 纯 Python 可算 γ_木质素模型物/DES。
2. **phreeqpython**：Apache-2.0 OO 封装，适合做 mcpserver handler（与 dwsim agent 同构）。
3. **MPNN-MLP + TSTiNet**：DES 性质 QSAR 数据+基线并入材料 ML 线。
