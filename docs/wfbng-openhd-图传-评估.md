## 一、项目定位

- wfb-ng：raw WiFi 长距离数字图传引擎——视频+遥测双向、AES 加密、FEC 前向纠错、MIMO 分集，无网卡协议栈直通链路。
- OpenHD：图传系统完整方案——OSD 叠加、双向通道、多平台镜像，把 wfb-ng 包成可用系统。

## 二、架构拆解

- 链路层：raw WiFi 帧注入（monitor 模式）绕过 TCP/IP，视频/遥测分通道。
- 可靠性层：FEC（里德-所罗门类）+ 双向重传 + MIMO 天线分集。
- 安全层：AES 加密。
- 应用层：OSD（飞控数据叠加）+ 地面站多平台镜像。

## 三、与本仓对照

本仓图传链路空白（上轮缺口直补正主）；DroneBridge（已立）为对照组，wfb-ng 为引擎级参照，QOpenHD 为地面端配套。

## 四、可落地借鉴点（≥3）

1. **FEC + 双向通道设计**：前向纠错与重传的带宽分配策略，可复用到 LoRa/其他数字链路。
2. **raw WiFi 帧注入架构**：绕过协议栈的链路层直通，是 ESP32-S3 地面站接入点的关键参考。
3. **OSD 叠加方案**：飞控遥测→视频帧叠加的数据管线，可映射到 lumo 地面站 UI。
4. **MIMO 分集**：多天线合并思路（与天线云台线衔接）。
