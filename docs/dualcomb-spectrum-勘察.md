# 双梳宽带频谱感知 · 勘察报告

> 参考 digest：[digest-g5-3b-2026-08-30.md](../paper-round2-2026-08-30/digests/digest-g5-3b-2026-08-30.md)（论文 2608.25378v1 双梳信道化）
> 日期：2026-08-30

---

## 1. 结论先行

双梳光子信道化的物理图景与 SDR 的信道化**高度同构**：光学频率梳齿 ≈ 数字本振 bins，信道化输出 ≈ FFT 结果。这提供了一个「用集成光子学替代高速 ADC + FPGA」的路线，可把实时频谱感知带宽推到 50 GHz+、时间分辨率压到微秒级——当前 rf_brain 的 SDR 前端（RTL-SDR/IC-705 声卡）远达不到。

**结论**：对 rf_brain 是**远期架构参考**而非近期落地项；近期可从三条「软件级启发」入手（见 §4），不必碰光子硬件。

## 2. 双梳信道化要点（2608.25378v1）

| 指标 | 数值 |
|---|---|
| 分析带宽 | 48–52 GHz |
| 时间分辨率 | 微秒级 |
| 频率分辨率 | < 80 MHz |
| 原理 | SBS 泵浦产生光学频率梳 → 步进频率泵浦并行下变频 |

---

## 3. 对比表：双梳光子 vs SDR 信道化

| 维度 | 双梳光子信道化 | SDR 本振扫频 + DDC 信道化 |
|---|---|---|
| 分析带宽 | 数十 GHz | 受 ADC 采样率限制（RTL-SDR 2.4 MHz，IC-705 声卡更窄） |
| 时间分辨率 | 微秒级 | 受 FFT 帧率限制（2–5 fps） |
| 频率分辨率 | < 80 MHz（梳齿间距） | FFT 分辨率（可到 Hz 级） |
| 硬件代价 | 集成光子芯片（SBS 泵浦） | 高速 ADC + FPGA（大带宽时贵且费电） |
| 功耗/延迟 | 低延迟、光域并行 | 数字域并行需大算力 |
| 可重构性 | 泵浦步进频率可重构 | 本振可编程 |
| 成熟度 | 实验室/论文级 | 商品化、成熟 |

---

## 4. 三条可落地启发（软件级，近期可用）

1. **步进频率泵浦 → 多频段并行下变频调度**：双梳「步进泵浦」等价于 SDR 的多本振并行扫频。可在 rf_brain `scanner.py` 实现「多频段并行扫描 + 按活跃度步进」（配合 R24 资源分配），用少量本振覆盖宽频段，优先扫描活跃频段。

2. **梳齿 = 本振 bins → 稀疏信道化**：光子梳齿的稀疏性启示「不必全带宽均匀下变频」，只对活跃梳齿（对应占用频段）下变频。可将 R01 的事件缓存与 R24 的自适应稀疏扫结合，实现「活跃频段密集、闲时稀疏」的信道化。

3. **信道化输出 ≈ FFT → 复用 PFB 多相滤波器组**：双梳输出结构等价于多相滤波器组（PFB）信道化，与 R13（PFB 逆重建）同源。可将 SDR 信道化统一到 PFB 框架，软硬件解耦，为未来光子/数字混合前端预留接口。

---

## 5. 硬件代价 / 带宽收益小结

- **收益**：带宽从 MHz 级 → 50 GHz 级，时间分辨率从百 ms → μs，是数量级提升。
- **代价**：需要集成光子学（SBS 泵浦、光梳源），成本与工程复杂度高，非当前 rf_brain 能负担。
- **定位**：作为「未来高频 SDR 前端」的架构参考，纳入技术雷达观察，待集成光子学成熟后再评估落地。
