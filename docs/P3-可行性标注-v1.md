## 二、许可疑点记录（重要）

1. **stimm：README badge 错标 MIT，LICENSE 实为 AGPL-3.0**。以 `LICENSE` 文件为准 = AGPL-3.0。教训：**许可以 LICENSE 文件为准，不轻信 README badge**。
2. **ainara：双许可（LGPL-3.0 开源 + 商业条款）**。README 明示 "Dual-licensed under LGPL-3.0 and commercial terms"。许可证文件名 `LICENSE_LGPL3.txt`（非标准 `LICENSE`）。LGPL 可吞但**必须标注双许可**，且商业条款下接入需确认非商业用途。
3. **silero_vad_server：GPL-3.0（非 AGPL）**。主仓是 AGPL-3.0，GPL-3.0 非同许可（AGPL 含网络条款，GPL 不含）。可并入（AGPL 是 GPL 超集），但**独立部署场景（VAD 即服务）需评估网络条款差异**。

## 三、逐项可行性标注

### 3.1 flowcat（Apache-2.0，Rust）— 基础设施，观望

- **能否用**：能。原生 Rust 实时语音 agent runtime，电话/WebRTC 呼叫 → VAD/turn-taking → STT·LLM·TTS → 单二进制自托管（VPC 或完全 air-gapped）。
- **运行依赖**：Rust 工具链 + 自己的 VPC/裸机部署。无托管控制面。
- **接入成本**：**高**。独立服务，不融进主仓；与 speech-core（授粉）相比更偏「完整 runtime 产品」，不是库。观望。

### 3.2 stimm（AGPL-3.0，Python）— 融合参考，观望

- **能否用**：能（参考架构）。「Optimistic VUI」——一个 agent 快说、一个 agent 深思，双 agent 实时协作。
- **运行依赖**：Python + LLM。
- **接入成本**：中。授粉点：双 agent 实时协作（快说/深思分工）。许可 AGPL（与主仓同许可，可吞）。

### 3.3 sapphire（AGPL-3.0，Python）— 融合参考，观望

- **能否用**：能（参考产品形态）。「把 AI 变成持久存在」的回家型伴侣框架，语音 + 智能家居控制 + 多年记忆。
- **运行依赖**：Python + LLM + 智能家居硬件。
- **接入成本**：中。授粉点：持久化 persona + 长期记忆的产品形态。AGPL 同许可。

### 3.4 ainara（LGPL-3.0+商业，Python）— 融合参考，观望

- **能否用**：能（参考）。Polaris Orchestrator（50k+ LoC）驱动的「主权 AI Nexus」，客户端侧、大/小 LLM 都支持。
- **运行依赖**：Python + LLM（大模型或本地小模型）。
- **接入成本**：中。授粉点：客户端侧主权架构 + 多 agent 编排。**许可标注：双许可，接入需确认非商业用途**。

### 3.5 silero_vad_server（GPL-3.0，Rust）— 基础设施，观望

- **能否用**：能。VAD 即服务（API server），配合 EchoKit 使用。
- **运行依赖**：libtorch（CUDA/ROCm）+ Rust。
- **接入成本**：中。独立部署。**许可标注：GPL-3.0（非 AGPL），网络条款差异**。我们已有 cascade/aspen 授粉的 VAD 逻辑，此服务器价值有限。

### 3.6 hachimi（MIT，Python）— 融合参考，**最值得关注**

- **能否用**：能（参考）。模块化多进程语音助手：KWS/STT/LLM/TTS 独立进程，**MCP Host（Client 侧）**连接多个 MCP server，barge-in 打断。
- **运行依赖**：Python + 云 API（STT/LLM/TTS）。
- **接入成本**：中。**授粉点：它是 MCP Host/Client，与我们 mcpserver（MCP server 侧）互补**——它演示了「如何编排多个 MCP server + barge-in 打断」，正是陆墨语音层缺的那块。P3 里唯一建议后续升 P2 细读的。

### 3.7 Live2DPet-Enhanced（MIT，JS）— 融合参考，观望

- **能否用**：能（参考）。Electron Live2D 桌宠，截屏感知 + 关键帧视觉记忆 + VOICEVOX 语音。
- **运行依赖**：Electron + Live2D + VOICEVOX + LLM API。
- **接入成本**：中。授粉点：关键帧视觉记忆。**隐私注意：定时截屏送 API**，README 自述不落盘但需信任服务商。

### 3.8 duty-on（MIT，Rust）— 融合参考，观望

- **能否用**：能（参考）。Tauri 2 桌宠，监视 AI IDE（角色看你的编辑器）。
- **运行依赖**：Tauri 2 + Rust + React。
- **接入成本**：低。授粉点：Tauri 2 桌宠最小实现。价值低，纯备选。
