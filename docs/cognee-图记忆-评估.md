# W73-03 cognee 图记忆引擎评估

> 上游：github.com/topoteretes/cognee · Apache-2.0 · 30K★ · Python

## 1. 项目定位

面向 Agent 的开源 AI 记忆平台：跨会话持久记忆 + 自托管知识图谱引擎，把对话/文档转成图记忆。

## 2. 架构拆解

- **图记忆引擎**：实体-关系抽取 → 知识图谱 → 跨会话持久化。
- **event_protocol**：事件流对接，把交互作为事件接入记忆。
- **自托管**：可本地部署知识图谱后端。

## 3. 与本仓对照（cognee vs Graphiti vs 五元组）

| 维度 | cognee | Graphiti（W72-07） | 五元组（summer_memory） |
|---|---|---|---|
| 记忆表示 | 知识图谱 | 时序知识图谱 | 固定五元组 |
| 跨会话 | 持久 + 事件流 | 时序演化 | 需自拼 |
| 部署 | 自托管 | 自托管 | 轻量内嵌 |

## 4. 可落地借鉴点（≥3）

1. **event_protocol 事件流对接**：把交互作为事件流接入记忆，比「全量对话快照」更结构化，可复用到 memory_maas。
2. **图记忆引擎的实体抽取流水线**：自动实体-关系抽取，可作为我们五元组的增强层。
3. **跨会话持久化的统一接口**：cognee 的记忆读写接口可作为 codebase-memory-mcp（W67-05）对照。

## 5. 许可裁定 + 结论

- **许可**：Apache-2.0 → 可借鉴代码。
- **接入建议**：**参考为主**。图记忆引擎能力强，但引入自托管知识图谱是重依赖；优先借鉴「event_protocol 事件流 + 实体抽取」设计，在现有 memory_maas/五元组上增强，而非整体迁入。
