## §7 #400 · WO-271 文件系统边界（⚠️ 29 passed / 3 failed）

### §7.1 失败的三条

| 用例 | 症状 |
|---|---|
| `test_symlink_outside_repo_rejected` | `DID NOT RAISE UnsafePath` |
| `test_junction_redirect_inside_subtree_rejected` | `DID NOT RAISE UnsafePath` |
| `test_preflight_lists_every_violation_not_just_first` | 期望 3 条违规、实际 2 条（少的那条正是链接逃逸） |

### §7.2 根因：**本机 `os.symlink` 返回成功但产出的链接是坏的**

隔离验证（纯 Python，不经 pytest）：

```
链接建成: symlink | os.path.islink: False | 目标文件可达: False
link.resolve(): ...\local\outlink        ← 没有跳到 target
_safe_target('outlink/victim.txt')        → 未被拦，返回 ...\local\outlink\victim.txt
```

⇒ `_mkjunction()` 里 `os.symlink` 没抛异常就 `return`，于是**链接其实没建成**，
后面的"应当被拒"自然不成立。**不是产品漏洞**（那条路径根本没触发），
但**"符号链接逃逸"这一类在本机无法验证**——不能据此宣布 P0-12 的链接分支已覆盖。

### §7.3 建议（两条都便宜）

1. `_mkjunction` 造完链接后**校验一次**：`link.resolve() != link` 或 `(link/'victim.txt').exists()`，
   不成立就 `pytest.skip("本机造不出可用的重解析点")`——这是**平台门控**，不是"用 skip 换绿"。
2. 另加一条**不依赖真链接**的单元测试：直接喂给 `_safe_target` 一个"resolve 结果与请求名不符"的桩
   （monkeypatch `Path.resolve`），把判定逻辑本身钉住。这样即使环境造不出链接，逻辑也有覆盖。

**其余 29 条全过**（词法类：`..`/保留名/NTFS 流/尾点；整批中止；磁盘零动作）——这部分是真覆盖。

## §13 #397 根因追加（2026-10-23 22:0x）—— 是**测试竞态**，不是产品 bug

### §13.1 证据链（四步定位）

| # | 动作 | 结果 |
|---|---|---|
| 1 | 看失败用例的等待条件 | `wait_until(lambda: retry.peek("Yui")["pending"] >= 1)` —— 这个条件**通过了** ⇒ 队列内存里确实进了条目 ⇒ `enqueue` 跑过了 |
| 2 | 全盘搜 sidecar（TEMP + Documents，近 3 分钟） | **文件确实写在期望路径**：`…\pytest-711\…\Yui\memory_settle_retry.json` ⇒ 既不是"写错地方"也不是"没写" |
| 3 | 读 `enqueue()` 顺序 | `entries.append(...)` → `await _save_unlocked()` → `await asyncio.to_thread(atomic_write_json, ...)` ；而测试等到内存 pending 就**立刻** `read_text()` |
| 4 | **对照实验**：等待条件后加 `await asyncio.sleep(0.05)` | "交给待重试队列"日志出现，失败 **2 → 1** |

⇒ 结论：**测试等的是内存信号，读的是磁盘文件**，中间隔着一次 `to_thread` 跳转 ⇒ 必然抢先读到。

### §13.2 定性

**产品侧不是 bug**：`enqueue` 的 docstring 自己写着"入队本身失败也只是让下一次会话结束重发这段，不会丢"
—— 内存先于磁盘是**设计**。**是测试的等待信号选错了**。

### §13.3 给作者的两条修法

| 方案 | 做法 | 评价 |
|---|---|---|
| 1 | 测试 poll "sidecar 存在且 entries 长度达标" | 能过，但把磁盘细节塞进测试；且 `_drive_failing_session_end(harness)` **没有 `store`**，需改 helper 签名（我试过直接写 `_sidecar(store)`，4 条用例立刻 NameError） |
| **2（推荐）** | 产品侧给 `SettleRetryQueue` 加**显式持久化屏障**（`await queue.wait_saved()`），测试等它 | 语义明确、不用 `sleep` 猜时间、将来优雅退出也能复用 |

