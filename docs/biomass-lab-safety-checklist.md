# 木质素 / 水凝胶实验安全清单（W63-04 ChemMCP 落地三件之三）

> 依据 docs/ChemMCP-授粉报告.md P1b：safety_check 思路落到生物质实验安全清单。
> 定位：木质素/水凝胶合成与表征实验的安全检查条目（≥5 条），供实验前 checklist 使用。

## 安全条目

1. **强碱/强酸操作**：木质素解聚常用 NaOH/H₂SO₄，需护目镜 + 耐酸碱手套，酸碱中和在通风橱内进行。
2. **有机溶剂**：二甲基亚砜（DMSO）/二甲基甲酰胺（DMF）/二氧六环等木质素溶剂需防吸入与皮肤吸收，配废液桶分类收集。
3. **交联剂毒性**：水凝胶常用 N,N'-亚甲基双丙烯酰胺（MBAA）/戊二醛等交联剂有神经/皮肤毒性，需称量时戴双层手套。
4. **高温高压**：木质素水热解聚（如 180–250℃ 高压釜）需检查泄压阀，冷却至室温再开盖。
5. **微波/超声辅助**：微波解聚需防爆容器，超声分散需防气溶胶，佩戴听力与呼吸防护。
6. **氧化剂/引发剂**：过硫酸铵（APS）/H₂O₂ 等引发剂需避光低温储存，远离还原剂防自燃。
7. **粉尘与生物质细颗粒**：木质素/纤维素粉体吸入危害，称量在通风橱或配防尘口罩。

## 使用方式

实验前逐条打勾；任一不满足则停止该步操作并上报。本清单为最低安全基线，不替代具体 SOP 与 SDS。
