# 超图小波算子 → 生物质基频率选择表面勘察报告（R64）

> 2026-08-31 · 智能体 16 · 来源：round3 digest-g1a HALO（2608.27883）+ EFNO（2608.28425）
> 状态：勘察（不写实现）

## 一、结论（TL;DR）

HALO 把「超图提升 + Chebyshev 谱小波」用于任意网格上的稳定多尺度 PDE 学习，EFNO 把 FNO 的频谱核参数化为物理波矢的连续函数实现跨域迁移。两者组合对**生物质基频率选择表面**（纤维素/木质素复合材料构成的可调 FSS）多尺度建模可行：超图天然表示单元-邻居-社区的多体耦合，小波多尺度捕捉从分子振动到宏观电磁响应的跨尺度物理，EFNO 让模型在不同频段/几何配置间迁移而不重训。

## 二、建模路径

1. **几何 → 超图**：FSS 周期单元离散化，单元为顶点、相邻耦合为超边、周期性/缺陷为社区超边——比普通图多体耦合表达更强。
2. **超图提升 → 谱小波域**：HALO 的 Chebyshev 多项式在谱域做小波滤波（避免显式拉普拉斯分解，数值稳定），多尺度提取单元内场分布 + 单元间耦合。
3. **波矢参数化（EFNO）**：把传输/反射系数预测核写成入射波矢 k 的连续函数，同一模型覆盖不同入射角/频率。
4. **跨尺度回归**：小波多尺度特征 → 传输系数 S21(f, θ) 预测，快速设计空间探索。

## 三、数据需求

- **电磁仿真数据**：FSS 单元的 S 参数（S11/S21）随频率、入射角、几何参数（单元尺寸/间距/材料介电常数）的扫描——可用 CST/HFSS 或开源 FDTD（如 openEMS）批量生成。
- **生物质材料参数**：纤维素/木质素复合材料的介电常数 ε(f)（通常 1~10，随含水率/密度变化）——需实测或文献标定。
- **跨尺度标签**：微观（分子/纤维取向）→ 介观（复合材料等效 ε）→ 宏观（FSS 传输）的映射数据。

## 四、可落地借鉴点（≥3 条）

1. **超图表达多体耦合**：FSS 的单元-邻居-社区（周期边界/缺陷）用超图比普通图更贴合，可直接复用于 rf_brain 的天线/滤波器拓扑建模。
2. **Chebyshev 谱小波免拉普拉斯分解**：任意网格上稳定的多尺度算子，可迁移到不规则频谱栅格/天线网格的特征提取。
3. **波矢连续参数化（EFNO）**：把频谱核写成 k 的连续函数 → 一个模型覆盖多频段，契合 SDR 跨频段信道/天线迁移（与 R41 跨模拟器迁移同族）。
4. **低介电生物质 FSS 的快速设计**：用低成本纤维素/木质素做可调 FSS，HALO 加速设计空间探索 → 可穿戴/可降解射频器件的快速原型。

## 五、自建门槛

- 依赖 EM 仿真数据生成管线（openEMS/CST），无现成数据时需自建（成本高）。
- 生物质材料 ε(f) 的实测标定是短板，含水率/密度会显著漂移介电常数。
- HALO/EFNO 框架开源可复用，但训练算力与网格生成是主要工程成本。

## 六、离栈度

中。超图小波 + 神经算子是科学计算 ML 的通用工具，与射频/超材料直接相关；但「生物质基 FSS」的具体材料与仿真数据离 rf_brain 现有 ESP32/SDR 栈较远，建议作为「射频超材料」远期方向跟踪，不急于落地。
