## 二、已交付部分（A 的脚本，就绪待跑）

**`tools/paper_reconcile.py`** —— failed.txt 脏账清洗 + 三份输出：

- 对账规则：`failed.txt` 每行 pid ↔ `digests/full/<pid>.md` 存在性比对（已存在的即剔除）
- 分类（写死防漂移）：`content 过短/content=NN` → permanent；`429/502/503/timeout` → active；
  `403` → active（**IP 级 vs 单篇级由调用方单篇探测**，脚本不做网络动作）；
  **未知原因 → active + 原因保留（不静默归类）**
- 三份输出：`failed_active.txt` / `failed_permanent.txt` / `reconcile-report-<date>.md`
  （报告含自洽断言行：总失败 == 已补 + 真缺 + 永久）
- `--check` 退出码 0 = 自洽；`--dry-run` 只打印；数据目录不可达时退出码 2
  并打印本 Blocked 文档指引（**不静默失败**）

**测试**：`tools/tests/test_paper_reconcile.py` **7 例全绿**（解析 2 / 对账 2 / 输出 1 / CLI 2）——
构造数据，零网络。
