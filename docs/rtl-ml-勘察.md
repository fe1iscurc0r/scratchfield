# W67-01 · rtl-ml 勘察（RTL-SDR AI 信号分类器）

> 2026-09-02 · 第二十一期 GitHub 新扫货批 · 勘察（不写实现）
> 上游：TrevTron/rtl-ml（MIT，246★，2026-02 建，Python）

## 一、项目定位

RTL-SDR 软件无线电 + ARM SBC（树莓派类）上的 AI 无线电信号分类：实时抓 IQ/频谱，识别 FM / NOAA 气象卫星 / APRS / FRS 等信号类别。补 rf_brain「规则解调」之外的「AI 盲分类器」侧。

## 二、架构拆解

- 信号采集：RTL-SDR（rtl-sdr/SoapySDR）→ IQ 流 → 频谱图/时频图。
- 模型：CNN（时频图分类，类似 RadioML 路线）。
- 部署：ARM SBC（树莓派）上跑轻量 CNN 推理，实时分类。
- 数据标注：合成信号 + 真实抓包标注（或公开数据集）。

## 三、与本仓对照

| 维度 | rf_brain 规则解调 | rtl-ml |
|------|------------------|--------|
| 方式 | 特征 + 规则（可解释） | CNN 盲分类（不可解释） |
| 覆盖 | GFSK/FSK/OOK 等已知 | FM/NOAA/APRS/FRS 等广谱 |
| 硬件 | IC-705/模拟 | RTL-SDR（需采购） |
| 许可 | 本仓 | MIT（可借鉴） |

## 四、可落地借鉴点（≥3）

1. **时频图 + CNN 盲分类**：频谱图做输入、CNN 分类，可复用到 rf_brain 的 AI 分类分支（补规则解调对未知信号的盲识别）。
2. **RTL-SDR 采集管线**：rtl-sdr → IQ → 时频图的前处理链，是 rf_brain 从「模拟/IC-705」扩展到「RTL-SDR」的现成参考。
3. **信号类别广谱覆盖**：FM/NOAA/APRS/FRS 等多类别，可补 rf_brain 目前偏窄带解调的分类广度。

## 五、卡点判定 + 许可裁定

- **卡点判定**：**未购 RTL-SDR 是采购卡点，非算法卡点**——模型/管线思路清晰，缺的是真实 SDR 前端；无 RTL-SDR 时可用本仓模拟 IQ 源先验证算法侧。
