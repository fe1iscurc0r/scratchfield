## 1. 授粉映射

MAELLE 的核心：把化学反应建模为**电子空间的离散变换**（电子占据向量的重排），而非
生成产物分子图或做启发式图编辑；用**离散流匹配（Discrete Flow Matching, DFM）**建模
这个离散状态空间的连续时间马尔可夫链（CTMC）流动，从而既能预测产物，又能给出机械论解释。

对生物质热解的直接同构：热解的实质是**自由基反应**——键均裂/电子重排（C-C、C-O、
β-O-4 断裂），本质就是电子占据向量的局部重排，与 MAELLE 的建模对象高度一致。

## 2. 最小原型设计

- **电子态**：二元电子占据向量 `e ∈ {0,1}^L`（L=10：2 个「选择子」位 + 8 个反应位点）。
- **反应**：稀疏电子转移（若干位翻转），由反应物前 2 位选择子决定走哪条规则（4 条规则）。
- **模型**：轻量 2 层 MLP 条件生成器，逐位学 `P(产物电子态 | 反应物)`。
- **训练**：逐位交叉熵（对「均匀源 → 产物」线性插值概率路径，其 DFM 目标的闭式最小化点
  等价于逐位交叉熵，见 §3）。
- **采样**：`flow_sample()` 从均匀源出发沿概率路径流向目标分布（CTMC 简化），展示「流」。

## 3. 离散流匹配与本原型的关系（诚实标注）

标准 DFM（Campbell 等）：定义源分布（均匀）到目标分布（产物）的条件概率路径
`p_t(x|x_1) = (1-t)·uniform + t·δ_{x1}`，学习速率矩阵 Q 使模型边际 `p_t^θ` 匹配该路径，
训练目标为对 t 积分的交叉熵。对**逐位 factorized + 均匀源 + 线性插值**这一特例，该积分
的闭式最小化点恰好是逐位交叉熵——因此本原型用逐位交叉熵训练（等价于该 DFM 目标），
`flow_sample` 显式保留「概率路径 + 流动采样」的 DFM 语义。

**非逐字复刻**：本原型未实现完整 CTMC 速率矩阵反演/精确采样（用逐时间步 Bernoulli 近似），
也未做电子占据的全局耦合（逐位 factorized）。上量需换离散扩散/流匹配的标准实现。

## 4. 实测结果（4 规则 × 200 样本，1% 噪声，70/30 划分）

| 指标 | 值 |
|---|---|
| 电子态逐位准确率 | 98.6% |
| **产物全向量精确匹配** | **87.1%**（≥70% 验收线） |
| 流采样 vs argmax 一致性 | ~100% |

## 5. 生物质热解适配路径（验收项）

1. **反应位点重定义**：把「电子占据位」映射到热解的**关键键**（β-O-4 醚键、C-C、糖苷键、
   羟基），L 扩到真实键数；选择子映射到**官能团环境**（酚羟基、甲氧基、脂肪链）。
2. **规则库**：用热解机理文献的**自由基反应规则**（均裂、H 抽取、β-断裂、重排）替换
   合成规则，每规则 = 一个电子重排掩码。
3. **衔接 M16**：M16 的流匹配能量（-log p(residual)）作为**热力学可行性正则**，约束
   产物分布的 OOD 检测；本原型的电子转移预测作为**动力学机理**，两者合成「热解反应网络」。
4. **可解释性**：学习到的逐位翻转权重 = 电子转移的「机理签名」，直接输出「哪个键断、
   电子从哪移到哪」的机械论解释（MAELLE 的核心卖点）。
5. **数据**：真实热解产物分布（ELN `eln-biomass-case.csv` 的 char_yield 是宏观量，
   需补键级反应数据）替换合成数据；无数据时用文献机理 mock 并显式标注。

## 6. 诚实降级

- 合成数据 + 4 条规则是演示粒度；87.1% 是合成场景下的实测值，真实热解键级数据复评。
- 逐位 factorized + 逐时间步 Bernoulli 是简化 DFM，非完整 CTMC 精确采样（§3 已标注）。
- 热解是连续温度场 + 多步自由基链反应，本原型只建模单步电子重排，多步需链式组合。
