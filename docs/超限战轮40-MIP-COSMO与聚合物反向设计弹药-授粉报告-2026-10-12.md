## 四、授粉勘察（阶段 4）

### 4.1 核心数据结构共鸣：「SMILES → 描述符 → 物理/化学性质 → 性能」

#### 范式 A：**sigma-profile + COSMO-SAC 范式**（最值钱——MD/活度系数/分配系数的统一描述符）

- **源域**：分子的 3D 几何结构 → QM 计算（COSMO）→ σ-profile（表面电荷密度直方图，约 50 个 bin）→ COSMO-SAC 方程 → γ 活度系数 → SLE/LLE/VLE/无限稀释活度 → 工艺参数
- **核心数据结构**：σ-profile = 一维分段直方图，分子表面被分成 ~50 个 bin（区间 [-0.025, +0.025] e/Å²），每个 bin 记录面积分数 σ_i。这是**化学热力学最经典的"分子指纹"**，比 ECFP/摩根指纹更物理、更可解释
- **目标域**：
  - **DES（深共熔溶剂）筛选**——木质素/酚类/氯化胆碱/甜菜碱 + HBD/HBA 组合的 γ → 共熔点预测（参考 `Tj-Barrett/mipkit` 的 RDKit + ACPYPE + AutoDock 流水线）
  - **MOF 客体分子吸附**（轮25 弹药已收 zeo++/pymatgen/MAST）—— 用 sigma-profile 替代"截断相互作用"做客体-COSMO-SAC 平衡分配
  - **木质素模型物在水/有机相的分配**（MTL-χ 报告痛点）—— 用 sigma-profile + COSMO-SAC 绕开商业 COSMO-RS 软件，本机算 γ_木质素模型物/水
- **为什么值钱**：
  - **36 万分子 sigma-profile 数据库**（PySCF-Sigmaprofile-COSMO-SAC，CC-BY-4.0 数据 + MIT 代码）= COSMO-SAC 性质预测的"现成弹药库"，无需为每个分子跑 DFT
  - **NIST 基准实现**（usnistgov/COSMOSAC）= 学术+工业对照参考，避免各家算法差异
  - **轮 28 报告里 MTL-χ 路径③「本机无 COSMO 软件」**这个洞可以一次性补上：sigma-profile + COSMO-SAC 纯 Python 可算 γ

#### 范式 B：**MIPkit 数字孪生范式**（最直接对口用户专业线）

- **源域**：目标分子（表位/蛋白）→ 功能单体库（SMILES）→ AutoDock 对接 → 预复合结构 → 聚合模拟 → 复合物 → 再结合模拟
- **核心数据结构**：MIP 复合物 = 「模板分子 + 功能单体阵列（包覆型）+ 交联剂 + 致孔剂」的四元组，每元都是 SMILES/3D 坐标
- **目标域**：
  - **木质素印迹聚合物**（Lignozyme）—— 木质素模型物/酚类（愈创木酚/紫丁香酚/H/G/S 单元）→ 寻找最优功能单体（丙烯酰胺/甲基丙烯酸/乙烯基吡啶）→ 计算合成配方
  - **水凝胶电化学传感器**（轮39 提到）—— 印迹层（MIP）涂覆在水凝胶电极上 → 高选择性检测木质素/酯类/酚类
  - **DES 配方**（圆23+28 一起）—— 把"功能单体库"换成"HBA 库"，"对接"换成"分子动力学溶解度计算"，整套范式可移植到 DES 筛选
- **为什么值钱**：
  - **RDKit + ACPYPE + AutoDock Vina + GNINA** 流水线是**当前最完整的 MIP 计算机辅助设计包**——用户专业线"分子印迹电化学传感器"正好需要这个
  - 1MB 极小代码量、Pytest 完整、LICENSE 是 MIT——读 SPEC 的成本近零

#### 范式 C：**PolyMetriX 聚合物 ML 全栈范式**（补 RadonPy 留下的缺口）

- **源域**：聚合物 SMILES（含重复单元 + 端基）→ polymer graphs 图转换器 → 50+ 特征化器（one-hot/Mordred/descriptors）→ dataset split → ML 训练（XGBoost/RF/NN）→ 物性预测（玻璃化温度 Tg/导热/介电/杨氏模量）
- **核心数据结构**：polymer graph = "重复单元 + 端基 + 连接方式" 的特殊图（不是单体图）
- **目标域**：
  - **木质素 NPs 表面改性**（邵组方向）—— 把 PolyMetriX 的"端基 + 重复单元"建模方式用到木质素结构多样性
  - **水凝胶网络拓扑**（轮20-22 流变+聚合三件套）—— 水凝胶是聚合物网络的特例，polymer graph 建模正好对应
  - **共熔凝胶（DES + 水凝胶）**—— 聚合物基质 + DES 双连续相，PolyMetriX 的 split + featurizer 是 baseline
- **为什么值钱**：
  - **mdk_docs 完整**（mkdocs.yml + docs/index.md + docs/api.md）—— 用户专业线如果未来要做共熔凝胶 ML，PolyMetriX 是零成本起步
  - **PI1M 数据集**（107★ MIT）= 100 万聚合物 SMILES = 用户专业线"轻化工聚合物数据库"建设可参考的数据规模
  - 与已落地的 `RadonPy`（284★ BSD-3）互补：RadonPy 算第一性原理物性，PolyMetriX 做 ML 拟合

#### 范式 D：**RetroAgent Agentic 逆合成**（Agent 编排线 × 分子设计线）

- **源域**：目标分子 SMILES → LLM agent 在结构化记忆（reaction templates × building blocks × known routes）中搜索 → 候选合成路径 + 评分
- **核心数据结构**：反应模板图（Reaction Template = SMIRKS + 上下文）+ 构建块库 + 经验证的反应数据库
- **目标域**：
  - **木质素解聚路径设计**（轮30 已立 LigninGraphs + ligpy）—— 把 RetroAgent 的 agent 编排范式直接套到木质素单体→目标分子
  - **Agent 编排层**（轮14 handoffs）—— RetroAgent 的 "LLM × 结构化记忆" 范式正是 handoffs 原语的应用示范
  - **共熔凝胶合成路径**—— HBA + HBD + 干燥/纯化 → 最优组合 → RetroAgent 范式可移植到"产品选定 → 配方找候选"
- **为什么值钱**：
  - **AGPL-3.0 主仓 + MIT 第三方**——直接融合零许可风险
  - 87KB 极小代码量，**结构化记忆 + LLM 评分**正是 scratchpad Orca 编排的下一级原语
  - 跨域映射到 Lumo material_science（已有 biopred/matchat 预测管线）= 加 "逆合成规划" 能力
