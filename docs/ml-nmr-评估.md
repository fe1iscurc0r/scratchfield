# ML-NMR 化学位移预测评估（M30）

> 工单：M30 ML-NMR 化学位移预测（P2）
> 授粉源：`digest-g5-2-2026-08-30.md` 2608.21313（Machine-Learned NMR Shieldings in Molecular Solids）
> 落点：陆墨（生物质材料固体 NMR 表征）
> 交付：本评估报告（方法 + 数据需求 + 落地路径 + 适用场景 + 3 条落地建议）

## 1. 方法与背景

2608.21313 针对**分子固体的 NMR 化学屏蔽（化学位移）快速估计**：传统屏蔽张量计算依赖
DFT/GIPAW（晶体周期性 NMR 计算），成本高、难以规模化；ML 屏蔽估计器以近 DFT 精度、极低
成本批量预测化学位移，从而支撑「**屏蔽驱动的 NMR 晶体学**」（用预测位移反推/验证晶体结构）。

核心价值：把「算一次固体 NMR 位移要跑一次周期性 DFT」变成「一个 ML 估计器秒出位移」，
让「实测固体 NMR → 候选结构打分」的闭环可行。

## 2. 对陆墨（生物质材料固体 NMR）的适用场景

| 场景 | 适配度 | 说明 |
|---|---|---|
| 纤维素 Iβ/Iα 晶型判别（C4/C6 化学位移） | **高** | 晶型对应的 C4/C6 位移差异小，ML 预测 + 实测比对可辅助晶型归属 |
| 木质素结构单元（G/S/H）归属 | **高** | 芳香环 C/H 位移与甲氧基/酚羟基取代直接相关 |
| 半纤维素/交联度表征 | 中 | 糖苷键构型与取代位点的位移预测 |
| 生物质基材料的候选结构验证（屏蔽驱动晶体学） | 中高 | 有候选结构时，用预测位移打分为实测谱归属 |

**核心判断**：陆墨固体 NMR 的最大痛点不是「不会测」，而是「峰归属难、候选结构打分慢」。
ML 位移估计器正好补这一环——把 DFT 级位移预测成本降数量级，让结构验证闭环可规模化。

## 3. 数据需求

- **训练数据**：目标体系的（晶体结构 → 化学屏蔽/位移）对。分子固体位移估计器通常用
  周期性 DFT（GIPAW）生成训练集；对生物质需覆盖纤维素晶型、木质素低聚物、半纤维素构型。
- **本地数据**：陆墨现有 ELN 是宏观量（`eln-biomass-case.csv` 的 char_yield），**无键级/
  位移级数据**——需补测固体 NMR（¹³C CP-MAS）或从文献/数据库（如 CCP-NC、晶体学库）收集。
- **无数据时**：先用已发布模型（若开源）或合成位移 mock，显式标注（诚实降级）。

## 4. 落地路径

1. **先验证晶型判别**（最小闭环）：纤维素 Iβ/Iα 的 C4/C6 位移是公认指纹，用 ML 估计器
   预测两晶型位移，与陆墨实测 ¹³C CP-MAS 比对，验证「预测位移 vs 实测归属」的一致率。
2. **再扩展木质素归属**：建 G/S/H 结构单元的位移参考集，用 ML 预测辅助芳香区峰归属。
3. **接 M27/M28**：分子 FM 表征（M27）提供结构特征，ML 位移估计器提供位移标签，
   多模态（M28）可把 NMR 位移作为一维模态融合进结构推断。
4. **屏蔽驱动晶体学**：候选结构 → ML 预测位移谱 → 与实测谱匹配打分 → 排序候选。

## 5. 3 条落地建议（验收项）

1. **先借「晶型判别」冷启动**：纤维素 Iβ/Iα C4/C6 位移是文献共识、判别明确，是验证
   ML 位移估计器迁移价值的**最低成本试金石**；跑通后再谈木质素/半纤维素。
2. **位移估计器优先走「已训练模型 + 少样本微调」而非从零训练**：分子固体位移的 DFT 训练集
   昂贵，若论文模型开源则直接迁移（承接 M27 的 FM 迁移思路），用陆墨小样本微调。
3. **把 ML 位移作为「打分器」而非「唯一真值」**：ML 位移用于候选结构排序/预筛，最终归属仍
   以实测谱为准；避免把估计误差当定论（与 M29 的「可解释机理 + 实测闭环」同一原则）。

## 6. 风险与诚实标注

- 2608.21313 的精度/适用体系需以论文全文确认；本评估基于摘要的方向性判断。
- 分子固体位移的「近 DFT 精度」在生物质（氢键强、构象多样）上可能退化，需专门验证。
- 陆墨当前无位移级数据，落地前需补测或借外部数据；短期只能 mock 验证链路。
