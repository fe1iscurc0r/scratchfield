# Pilot 浏览器控制轻量路径评估

> 2026-09-04 · 87号 T2 · 评估（不写实现）
> 上游：TacosyHorchata/Pilot（GitHub，MIT，★32，Chrome 扩展 + MCP server）

## 一、架构拆解

Chrome 扩展（在浏览器内）↔ MCP server（本地）↔ agent。数据流：agent 通过 MCP 发指令 → MCP server 转给 Chrome 扩展 → 扩展操作真实标签页（复用已登录会话）。

## 二、与 browser-use 对比

| 维度 | Pilot | browser-use |
|------|-------|-------------|
| 路线 | Chrome 扩展 + MCP | 无头/自动化驱动 |
| 已登录会话复用 | ✅（真实浏览器） | ⚠️（需重登或注入） |
| 能力边界 | 标签页/URL/点击/填表 | DOM/点击/填表/更多 |
| 部署复杂度 | 低（装扩展+起 MCP） | 中（环境/驱动） |
| 稳定性 | 依赖扩展+浏览器 | 较成熟 |

## 三、适用场景结论

**接入（补充路径）**：作为 browser-use 之外的轻量补充，用于「复用用户已登录会话」场景（免重登/免无头初始化）。不替代 browser-use 主路径。
