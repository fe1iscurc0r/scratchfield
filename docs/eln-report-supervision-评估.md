## 1. 授粉映射

R-Super 的核心：医学影像的**文字报告**（放射科医生写的「肿瘤数量/大小/位置」）天然携带
与像素掩码等价的监督信息，可**直接作为弱监督信号**约束分割模型，从而大幅降低对昂贵像素
掩码的依赖（50 个掩码即可 +15% F1）。

对陆墨的同构：ELN 实验记录 / 表征报告（FTIR、质谱、SEM、TGA、产率记录）天然携带与
「材料真值」等价的约束——这些报告是**已经存在、零额外标注成本**的间接标注。核心洞察：
**把「实验者写下的结构化结论」编译成可微损失，替代稀缺的原子级/像素级直接标注。**

## 2. 标注来源清单（验收项）

| 来源（ELN/报告字段） | 携带的监督信息 | 可约束的模型 | 监督形式 |
|---|---|---|---|
| TGA/热重报告（失重%、char_yield、起始分解温度）| 热稳定性/成炭率 | 热解动力学/势基准 | 回归约束（M32 数据）|
| FTIR 报告（峰位/官能团归属）| 官能团存在性 | 结构/描述符模型 | 分类约束（接 M33）|
| 质谱/GC-MS 报告（m/z、产物种类）| 热解产物分布 | 反应机理（M29）| 分布约束 |
| SEM 报告（形貌描述：孔径/纤维直径/致密度）| 微结构几何 | 形貌/结构模型 | 几何约束 |
| 产率/收率记录 | 反应选择性 | 反应预测 | 回归约束 |
| XRD 报告（晶型/结晶度）| 相/结晶度 | 结构/晶型判别 | 分类约束（接 M30）|
| 元素分析（C/H/O/N 含量）| 元素组成 | 组分模型 | 回归约束 |
| 合成配方/条件记录 | 自变量（组分/温度）| 组分-性能闭环 | 输入特征（M05）|

**现状缺口**：陆墨现有 ELN（`eln-biomass-case.csv`：lignin/temp→char_yield）是**结构化数值**，
已可直接作回归监督；但 FTIR/SEM/XRD 的**文字报告**尚未结构化，需先做「报告 → 字段」解析
（见 §3 数据流）。

## 3. 数据流设计（验收项）

```
ELN 实验记录 / 表征报告（PDF/文本/表格）
        │  ① 报告结构化：LLM 或规则解析 → 监督字段（peak/质量损失/孔径/产物种类）
        ▼
间接标注字段（弱监督信号，零新增标注成本）
        │  ② 信号编译：字段 → 可微损失
        │      - 数值字段 → 回归损失（MSE）
        │      - 类别字段（官能团有/无）→ 交叉熵
        │      - 几何/分布字段 → 约束损失（数量/大小/位置，R-Super 同款）
        ▼
材料模型（势/描述符/反应/结构）训练
        │  ③ 少量直接标注（DFT 参考 / 掩码）兜底关键样本
        ▼
预测 + 回写 ELN（闭环，接 M05）
```

关键点：**字段级的「可微损失编译」是 R-Super 迁移的落点**——把「报告里的一句话结论」
变成对模型输出的数值约束，而非把它当作普通文本特征。

## 4. 落地路径

1. **先吃现有结构化数据**：`eln-biomass-case.csv`（lignin/temp→char_yield）直接用回归监督，
   验证「ELN 字段 → 模型」链路（最小闭环，接 M32/M33 预测案例）。
2. **报告结构化**：把陆墨历史 FTIR/SEM/XRD 报告解析成字段（LLM 抽取或规则模板），
   建「间接标注库」。
3. **字段 → 损失编译**：对「热重失重%/产物分布/官能团有无」三类字段各做一条损失路径，
   约束对应模型（M29/M33/M32）。
4. **少量直接标注兜底**：用 DFT 参考（M32）或手动掩码对「报告监督覆盖不到的歧义样本」
   补强，R-Super 已证明 50 个直接标注即可显著增益。

## 5. 风险与诚实标注

- 文字报告存在**噪声/口径不一**（不同人写法不同），结构化解析是主要工程成本；
  R-Super 在医学影像的「报告→约束」迁移到材料报告需先验证字段抽取准确率。
- 报告监督是**弱监督**，模型受「报告覆盖不到的信息」限制（如 FTIR 报告不写峰强度定量）。
- 本评估是方向性设计，未落地实测；短期以 `eln-biomass-case.csv` 结构化字段冷启动最稳妥。
