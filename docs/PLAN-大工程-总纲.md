## 二、现状判断（冷眼看）

1. **NEKO 是巨人**：130 万行框架（含前端/插件/测试），但记忆层(48912)评估后缺混合检索/索引卡/会话血统——**大而不精**
2. **mcpserver 是枢纽**：80 文件 1.35 万行，架构清晰（三表注册/白名单/adapters）——**这是全系统的底座**
3. **rf_brain 是雏形**：仅 844 行，Phase1-4 只是解调链骨架——**潜力最大，代码量最少**
4. **Lumo 是业务层**：2208 行，接 academic 16 后是科研工作台——**专业价值最高**
5. **学术库 545M 躺着**：16 项许可全核，MODEL_INTERFACE 未写——**最肥的肉没动**

## 三、结论：三大方向本质是一件事

- NEKO = **人机交互壳**（桌宠/伴侣/前端）
- mcpserver = **能力总线**（MCP 工具调度）
- rf_brain = **物理感知层**（无线电）
- Lumo = **领域应用层**（材料科研）

**合起来 = 一个"全栈智能体"**：感知（射频）→ 认知（记忆/决策）→ 行动（MCP 工具）→ 应用（科研/生活）
