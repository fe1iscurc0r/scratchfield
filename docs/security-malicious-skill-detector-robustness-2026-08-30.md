# S12 恶意技能检测器跨源鲁棒性改进

## 一、问题陈述

MaliciousSkillBench（2608.19901）揭示 learned 恶意技能检测器的核心缺陷：**Source-Disjoint（跨源）评估下宏 F1 骤降 20+ 点**。检测器在"训练过的来源"上表现好，换成"没见过的来源"就崩溃——过拟合了已知恶意来源的表面特征，而非学到"什么是恶意技能"的跨源不变特征。

## 二、复现骤降

1. 接入 MaliciousSkillBench（13 来源 / 7,539 恶意技能）。
2. 按 Source-Disjoint 划分：训练来源 ≠ 测试来源。
3. 对比 matched（同源）与 disjoint（跨源）的宏 F1，复现 20+ 点骤降。

## 三、跨源泛化改进设计

1. **语义级特征**：从"表面 token 匹配"转向"恶意意图语义特征"（指令注入、越权、数据外泄等行为语义），这些特征跨来源稳定。
2. **行为/效果分析**：不只看技能文本，还要看技能**执行效果**（是否会触发危险工具调用、越权、外泄）——效果是跨来源不变的本质特征。
3. **数据增强**：跨来源的对抗训练 / 域泛化（domain generalization），让检测器对未见来源鲁棒。
4. **来源无关的规范化**：把技能规范化为统一表示（行为图/能力图），消除来源表面差异。

## 四、复测方案

改进后，在 Source-Disjoint 下复测宏 F1，对比：
1. **基线**（learned 检测器，F1 骤降 20+）；
2. **本改进**（语义 + 行为效果 + 域泛化）。

**验收目标**：Source-Disjoint 宏 F1 相对基线显著回升（骤降幅度收敛到可接受范围）。
