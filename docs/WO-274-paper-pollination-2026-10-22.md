## §1 一句话主张（三份各一句）

| SPEC | 一句话主张 |
|---|---|
| A 嵌入式 agent 实验台 | **先把"事实怎么量出来"写进表，再谈 agent 调参**——否则 agent 优化的是一套它从没在目标硬件上见过的成本结构 |
| B 冗余的物理重叠与运行时审计 | **逻辑不相交 ≠ 物理不相交**：先用设施表算"名义/真实冗余比"，再谈可靠性；阈值要**被审计**，不是被信任 |
| C 生物质值级溯源账本 | **一个数字只有在原始文件与抽取方法都可追时才成立**；NaN 也必须留证据，否则等于没做 |

**SPEC C**
