## 二、授粉映射（源→目标域）

### 金果1：chemics + ugropy → 物性估算 MCP（P0，立即可做）

- **源**：`chemics/`（209⭐ MIT）= 单位换算 + 热力学性质 + 传递系数；`ugropy/`（36⭐ MIT）= UNIFAC 基团贡献法（分子 SMILES → 活度系数）
- **共鸣**：邵老师课题（木质素 NPs → 碳化 → 超级电容）涉及多元体系活度系数/相平衡估算——DES 溶剂混合物（氯化胆碱/尿素/醇）、生物油组分（酚类/水/酸）。现有 CoolProp（轮28）管纯物质，chemics+ugropy 管**多元混合物**，链条互补。
- **落点**：`tools/property_estimator.py`（ugropy UNIFAC 物性估算 + chemics 单位换算）→ MCP 化；`mcpserver/` 独立 handler
- **验收**：`python tools/property_estimator.py --smiles "CCO.O" --property acentric_factor` 出合理数值；与 CoolProp 纯物质数据交叉校验

### 金果2：Chemical-Thermodynamics → 闪蒸计算 MCP（P1）

- **源**：`flash/`（Rachford-Rice 闪蒸）+ `eos/`（PR/SRK/VDW）+ `activity/`（NRTL/UNIQUAC 活度系数）
- **共鸣**：生物油提质/酚类分离涉及**液液萃取 + 精馏**的相平衡计算——闪蒸是这些单元操作的基础模型。与 ugropy（基团贡献）形成「闪蒸算法 + 物性方法」组合。
- **落点**：`tools/flash_calc.py`（Rachford-Rice 求解器 + EOS 选择器）→ MCP 化；与 ugropy 联用做 DES 溶剂-生物油体系相图
- **验收**：`python tools/flash_calc.py --system ethanol-water --type LL` 出液液分层数据；乙醇-水 NRTL 参数校验

### 金果3：PyJutulDarcy + PRESTO → 多相流/渗流仿真参考（P1）

- **源**：PyJutulDarcy（SINTEF 2025，MIT，JutulDarcy.jl 的 Python wrapper）+ PRESTO（UFPE 2017，MIT，IMPEC/全隐式有限差分）
- **共鸣**：活性炭孔结构（轮36）→ 气体吸附/解吸 → **多孔介质渗流**是介观尺度的合理延伸。两者均为油藏模拟工具，但孔隙尺度物理（达西定律 + 相对渗透率）可迁移至活性炭孔道建模。
- **落点**：融合参考（学术包，不并入主仓）；提取渗流方程框架作为 `references/porous-flow-physics.md`
- **验收**：读 `pyjutuldarcy/*.py` 提取核心方程（达西定律 + 相对渗透率 + 毛管压力），附行号引用

### 金果4：differential-evolution-optimization → 过程优化 MCP（P1）

- **源**：`de.py`（MIT，56⭐）：纯 Python 微分进化实现，无依赖
- **共鸣**：生物质过程优化（热解温度/停留时间/催化剂配比）是典型**黑箱多目标优化**——DE 比网格搜索效率高 10-100 倍。与轮35 dwsimopt（流程模拟黑箱优化）互补：dwsimopt 负责流程级，DE 负责参数级。
- **落点**：`tools/process_optimizer.py`（DE 包装 + 约束处理）→ MCP 化；可与 Chemical-Thermodynamics 联用做最优化闪蒸条件
- **验收**：`python tools/process_optimizer.py --func schwefel --dim 10 --maxiter 500` 收敛至全局最优邻域（误差<1%）

### 金果5：UNIFAC_Method → UNIFAC 活度系数教学参照（P2）

- **源**：`unifac.py`（8⭐ MIT）：UNIFAC 矩阵组装 + Pxy 相图绘制
- **共鸣**：ugropy 已含 UNIFAC，但 UNIFAC_Method 的 Pxy 图绘制逻辑是**教学可视化**的好样本。源代码约 300 行，可作为 ugropy 的可视化补充层。
- **落点**：学术包参考；提取 `plot_pxy.py` 作为木质素-酚类-水体系相图可视化模板
- **验收**：读源码确认基团矩阵和 Pxy 求解逻辑完整
