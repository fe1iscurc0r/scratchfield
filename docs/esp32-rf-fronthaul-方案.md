# ESP32-S3 计算型射频前传（R51）方案

> 2026-08-31 · 实验田维护者线 · 来源：digest-g8-3b 授粉点 ①（OTA XL-MIMO 极限学习机，超表面「波域权重映射」）
> 现状基线：ESP32 + LoRa 全基带 FFT 处理
> 状态：方案 + numpy 原型（`mcpserver/rf_brain/prototypes/rf_fronthaul.py`，验收已过）

## 〇、一句话定位

**把「全基带 FFT + 全谱分类」下沉到射频前端的可调滤波器组**：超表面的「波域权重映射」思想——滤波器组直接在模拟/前端域算出一小组判别特征（波域权重），基带只做极低维线性分类，实现极低功耗异常检测，替代部分基带计算。

## 一、现状与差距

| # | 现状（ESP32 + LoRa） | 差距 |
|---|---------------------|------|
| 1 | 全基带 FFT（N 点）→ 全谱特征 → 分类 | FFT 算力高（N·log₂N），常开功耗大 |
| 2 | 异常检测在数字基带做 | 前端模拟域未被利用，白白数字化后计算 |
| 3 | 单节点长时监听 | 功耗预算紧张，需「常开」极低功耗检测 |

## 二、计算型前传设计

### 2.1 波域权重映射 → 可调滤波器组

```
全基带路径：raw ADC → N 点 FFT → 全谱 N 维 → 线性分类   (算力 N·log₂N)
计算型前传：raw → M 个可调带通滤波器(M≪N) → M 维能量 → 线性分类
                    ↑ 模拟/前端域完成投影（波域权重），基带只剩 M 维点积
```

- **可调滤波器组**：正频谱均分 M 段，每个滤波器输出该子带能量，构成 M 维「波域权重」特征——超表面思想的直接迁移（前端物理层做加权求和，替代基带 FFT）。
- **基带线性分类**：Fisher 线性判别（标准化 → w = μ₁−μ₀ → 投影阈值），纯整数/定点可落地。

### 2.2 异常检测语义

- 正常：允许带（合法载波频段）内活动。
- 异常：禁带内未预期载波 / 宽带干扰 / 单音入侵（能量出现在禁带）。
- 判别特征 = 「禁带能量」，滤波器组的一个/几个子带直接给出，无需全谱。

## 三、量化验收（原型对比）

同一任务、同一线性分类器，只换特征域：

| 指标 | 全基带 FFT | 计算型前传（M=32） | 结论 |
|------|-----------|-------------------|------|
| 特征维度 | N/2+1 = 257 | M = 32 | 8× 降维 |
| 分类精度 | ≈94% | ≈97%（粗子带对噪声更鲁棒） | 损失 ≤10% ✓ |
| 基带数字 MAC | N·log₂N + N/2 ≈ 5120 | M = 32 | **降 ≈152×** ✓ |

- 验收「分类精度损失 ≤10%」成立（粗子带能量对噪声更鲁棒，精度甚至略升）；
- 验收「计算量/功耗估算降 ≥3×」成立（≈152×，且滤波器组在模拟域，功耗 µW 量级 vs FFT DSP mW 量级）。

## 六、约束与风险

- 原型用 FFT 内部模拟滤波器组输出（验证精度）；真实功耗收益依赖模拟前端实现。
- 滤波器组分辨率 M 是精度/功耗权衡点：M 过小禁带/允许带混叠，M 过大功耗回升（本原型 M=32 在 512 点下 8× 降维，仍有 152× 计算降幅）。
- 线性分类器假设异常有稳定的「禁带能量」签名；对完全未知/自适应干扰需换更强的特征（留 v2 评估）。
