## 二、A 子路由化（P0）

- `main.ts`：`/config/:tab(model|memory|audio|notifications|agent)?`——子页可直达/可分享
- **命名漂移修掉**：`terminal` key → `audio`（label 是「音画配置」，key 却是 terminal）；牵连仅 4 处（type/默认值/tabs/v-show），无外部引用
- **兼容**：存量 `?tab=terminal` 链接 → `onMounted` 内 `router.replace('/config/audio')`；无参 `/config` 等价旧行为（默认 audio）
- **切换即写 URL**：`watch(activeTab)` → `router.replace('/config/<tab>')`
- **命令面板索引**（`navigation.ts`）：5 个子页条目，keywords 各 ≥8 个**中文意图词**（从用户会搜什么出发）：

## 三、B 设置内搜索（P0，「更好找」核心）

实现（零新增依赖，未上 fuse.js——设置项量级 <200 原生够）：

1. `ConfigItem` 加 `searchKeys?: string[]` prop + `data-search-text`（name+description+searchKeys 小写拼接）——**DOM 层过滤，零侵入既有 30+ 个调用点**
2. ConfigView 顶部搜索框：输入即触发
   - **跨 tab 扫描**：`v-show` 隐藏的 tab 块仍在 DOM → `querySelectorAll('[data-config-item]')` 天然可搜
   - **当前 tab 过滤**：不匹配项 `display:none`
   - **跨 tab 命中列表**：显示「命中 N 项（跨 M 个设置页）」+ 每项标注所属页
   - **点击跳转**：切到所属子页 → `scrollIntoView` → 高亮 2 秒（`.config-item-highlight`）
   - **空结果**：显式「无匹配「xxx」」+ 清空按钮（**不静默**）
3. 验收项「搜索 live2d 跨 tab 命中」：live2d 命中音画配置页的 Live2D 相关项（音画页 keywords 已含 live2d）✓

## 四、D ConfigView 拆分——部分完成 + 边界说明

**已完成**：`src/views/config/MemoryTab.vue`（记忆连接设置页，含专属 script：memoryStats/testResult/isCloudMode/similarityPercent/testConnection/accordionMemory——6 个符号仅服务本块，已核验无跨块共享）。ConfigView 净减 119 行（diff -121/+2，搬移为主）。notifications 块**本已是独立组件**（`NotificationSettingsPanel`）。

**未完成**：model 块（216 行）/ audio 块（254 行）未拆。

**原因（实测，非借口）**：
1. 这两块的符号依赖**远多于 memory**——model 块涉及 `gatewayBusy`/`llmUsesGateway`/`useCloudGateway`/模型定价（`inputPrice`/`outputPrice`/`modelPricing`）/自定义 Live2D 模型管理/更新检查（`checkForUpdate`/`handleCheckUpdate`）/多组常量（`PROVIDER_OPTIONS`/`MODEL_OPTIONS`/`ASR_PROVIDERS`/`TTS_VOICES`/`API_FORMAT_OPTIONS`）——其中多个符号**跨块共享**（如 CONFIG、llmUsesGateway 音频页也用）
2. 搬移这些符号 = 要么写一堆 props/emits（模板更复杂），要么提取 composables（**是重构不是搬移**）
3. **验收标准内在矛盾**：工单要求「ConfigView ≤200 行」+「纯搬移不重构逻辑」——script 段 443 行必须留下支撑模板，纯搬移做不到 200 行；要达 200 行则必须大规模提 composable（重构），违反另一条要求

**建议**：立专门工单「ConfigView composables 化」——把模型/音频逻辑按域提取 `useModelConfig`/`useAudioConfig` composable（前者含定价与网关状态机，后者含 Live2D 与 ASR/TTS），届时不只 200 行可达，测试面也更清晰。本卷不做，避免「重构冒充实测面收窄」的风险。
