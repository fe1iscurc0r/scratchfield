## 入选候选（6 项）

### 1. pvlib-python ★1668（BSD-3-Clause ✅）· pvlib/pvlib-python

- **语言**: Python（NREL 主导，光伏领域事实标准）
- **核心功能**: 太阳辐照建模全链——晴空模型（Ineichen/DirInt）、太阳位置天文算法（SPA）、
  大气衰减、辐照分解（GHI→DNI/DHI）、入射角与光谱修正。
- **授粉点**: [源→目标映射] 太阳能蒸发的第一性输入是**到达蒸发面的真实辐照**：
  `pvlib.location.Location.get_clearsky()` + `solarposition.get_solarposition()`
  给出任一坐标/时刻的入射功率与角度——这是水凝胶蒸发模型（1 sun 标定 vs 真实日变化）
  的边界条件发生器。仓里 sitaware 已有地理/时序数据线，pvlib 补"太阳资源层"，
  蒸发效率曲线（kg/m²·h vs kW/m²）直接消费其输出。
- 活跃度：2026-09 仍在 push（社区基金会维护）。

### 2. CoolProp ★1070（MIT ✅）· CoolProp/CoolProp

- **语言**: C++ 核心 + Python 绑定（Windows 轮子齐全）
- **核心功能**: 200+ 流体的输运与热力学物性（IAPWS-95 水物性的工业级实现）——
  水/水蒸气的焓、熵、粘度、导热、表面张力、汽化潜热，全温压区间。
- **授粉点**: [源→目标映射] 蒸发能量核算的核心查表件：汽化焓 h_fg(T) 与表面张力 σ(T)
  是水凝胶蒸发速率模型（Hertz-Knudsen / 热限制模型）的两个温度依赖参数。
  与轮19 的 thermo（ChEDL，混合物/相平衡向）**分工明确**：CoolProp 管"水侧高精度
  单质物性"（IF97 后继），thermo 管"DES 混合物"——两者互补不重复。
  `PropsSI('H','T',320.,'Q',1,'Water')` 一行拿 47°C 饱和汽焓。
- 活跃度：2026-09 仍在 push。

### 3. OpenPNM ★539（MIT ✅）· PMEAL/OpenPNM

- **语言**: Python
- **核心功能**: 孔隙网络模型（PNM）——把多孔介质（水凝胶就是）抽象为
  孔-喉拓扑网络，模拟毛细输运、渗透、扩散、蒸发干燥锋面。
- **授粉点**: [源→目标映射] 水凝胶蒸发的介观层：凝胶孔隙率/孔径分布 →
  PNM 网络 → 水分输运阻力 → 蒸发面盐析/干涸预测。其
  `openpnm.network.Cubic` + `StokesFlow`/`FickianDiffusion` 算法组
  直接对应"水凝胶内部水迁移"的模型骨架；导师方向里"木质素 NPs
  调控孔结构→蒸发性能"的构效关系正好需要这层模拟能力。
- 活跃度：2026-07 仍在 push。

### 4. PyMieSim ★38（MIT ✅）· MartinPdeS/PyMieSim

- **语言**: Python（NumPy 向量化）
- **核心功能**: Lorenz-Mie 散射快速计算——均匀/核壳球体的消光/散射/吸收截面
  与散射角分布，粒径-折射率-波长全参数扫描。
- **授粉点**: [源→目标映射] 光热转换的"吸收层设计"环节：纳米颗粒
  （碳基/金纳米棒/半导体）在太阳光谱（400-2500nm）的**吸收截面**决定
  光热转换效率上限。PyMieSim 一行算出给定粒径分布的 spectral
  absorption——与轮19 pybaselines（光谱后处理）拼成
  "设计→表征→验证"闭环。向量化实现适合批量粒径扫描（MCP 工具
  `np_absorption(distribution, wl_range)` 一发）。
- 活跃度：2026-09 仍在 push。

### 5. block-DDA_Py ★（MIT ✅）· NobuhiroMoteki/block-DDA_Py

- **语言**: Python（NumPy/SciPy）
- **核心功能**: 块状离散偶极近似（block-DDA）——非球形粒子（多孔碳/团聚体/
  不规则形貌）的光散射求解器，Mie 的"任意形状"扩展。
- **授粉点**: [源→目标映射] 真实光热材料不是理想球——木质素碳化 NPs
  是不规则团聚体。Mie（球假设）给量级，DDA 给形状修正。
  block-DDA 算法（Moteki 组，大气光学顶刊常客）的"块状并行"设计
  让消费级机器也能跑微米级团聚体。小星数但学术血统纯正（AGU/JQSRT 系）。
- 活跃度：2026-07 仍在 push。

### 6. hydrogels（debeshmandal）★9（MIT ✅）· debeshmandal/hydrogels

- **语言**: Python
- **核心功能**: 凝胶模拟的输入生成工具——水凝胶有限元仿真（FEBio/Abaqus 向）
  的网格与参数生成器，含溶胀-力学耦合算例模板。
- **授粉点**: [源→目标映射] 仓里 SOAX 管"凝胶图像量化"，缺"凝胶仿真
  前处理"。此件小而具体：把 Flory-Rehner 参数（χ、交联密度、网链分子量）
  转成仿真输入卡——正好是"实验测得的溶胀比 → 反演交联密度 → 生成
  力学仿真模型"管线的中段。9★ 但功能精确、许可干净、体量小适合整体借设计。
- 活跃度：2023 停更——生成器类工具无运行时腐化风险。
