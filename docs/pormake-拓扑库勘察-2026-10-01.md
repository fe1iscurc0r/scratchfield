## 一、拓扑数据库的存储格式（实测 `src/pormake/database/`，3277 文件）

| 位置 | 格式 | 内容 |
|---|---|---|
| `database/topologies/RCSR_topology.zip` | **zip 包**（810 KB） | **RCSR 数据库**（Reticular Chemistry Structure Resource）——8000+ 抽象拓扑网 |
| `database/topologies/*.cgd`（zip 内） | `.cgd` 文本 | Systre 标准格式（CRYSTAL/EDGE 块描述周期网）——**拆包后为 pickle 缓存加速重载**（`database.py` docstring 实证：「abstract nets as .cgd files (cached as .pickle)」） |
| `database/bbs/*.xyz` | XYZ | **构建单元**（building blocks）——3277 个文件里的主体 |

`Database` 类（`src/pormake/database.py`）是**名字解析层**：`topo_dir`/`bb_dir` 可自定义
（支持用户自有库），默认指向打包目录——「按短名请求组件而非文件路径」。

## 二、组装 API 签名（实测 `src/pormake/topology.py` + `builder.py`）

```python
class Topology:                     # 抽象网（节点=构建单元位点，边=键）
    def get_node_type(self, i)      # 位点类型
    def get_edge_type(self, i)      # 边类型
    def get_neighbor_indices(self, i)
    def get_edge_length(self, i)

class Builder:
    def build_by_type(self, topology, node_bbs, edge_bbs=None, **kwargs)
    def build(self, topology, bbs, permutations=None, **kwargs)
```

组装流水线：`Database` 按名取 `Topology` + `BuildingBlock` →
`Builder.build(topology, bbs)` → 组装出 MOF 框架。

## 三、「逆向按目标孔径生成候选结构」可行性段

**可行，路径**：RCSR 数据库的每个 net 携带**顶点配位数/边长/孔径信息**（经
`Topology.get_edge_length` 等可读）——「给目标孔径 D」→ 筛选拓扑（edge_length
缩放后孔径 ≥D 的 net 集）→ `Builder.build` 生成候选 → porespy（本仓已接入）做
孔径分布复核。**工程量**：拓扑筛选器（读 RCSR 元数据）+ 孔径换算（BB 尺寸影响）——
建议作为后续卷的独立任务（需先有 BB 尺寸数据）。

## 四、拓扑条目样例（真实引用）

**条目样例的诚实声明**：`RCSR_topology.zip`（810 KB）**未下载解包**（工单硬约束
「勿整仓 clone GB 级仓库」的同类纪律——zip 属打包数据，本卷只勘察结构）。以下为
**真实可引用的片段**：

1. `database.py` docstring 原文：「containing abstract nets as `.cgd` files (cached as
   `.pickle` for fast reloading) and molecular building blocks as `.xyz` files」
   ——即每条拓扑 = 一个 `.cgd`（Systre 格式：`CRYSTAL NAME/GROUP/NODE/EDGE` 块）+
   pickle 缓存。
2. `.cgd` 的 Systre 标准格式（公开规范，RCSR 导出即此格式）：

```
CRYSTAL
  NAME <net 名>
  GROUP P1
  NODE 1 <元素> <坐标×3>
  ...
  EDGE <节点1> <节点2>
  ...
END
```

3. `Topology` 的节点/边访问 API（`get_node_type/get_edge_type/get_neighbor_indices/
   get_edge_length`）——即组装器消费的拓扑语义面。

> 若需真实 `.cgd` 条目样例：解包 `RCSR_topology.zip` 任取一个（如 `pcu.cgd`）即可——
> 属一次性动作，建议在落地施工卷（若立项）时顺带完成并归档样例。
