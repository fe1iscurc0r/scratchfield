# SPEC-20 · PCB 两方案提示词（LoRaCanary 底板）

> 用户二选一：①插接版（成功率最高，先跑通）②直焊版（紧凑手感好，难度高）。
> 共同事实：I2C SDA=GPIO8/SCL=GPIO9，BME280 地址 0x76（SDO 接地），SDA/SCL 4.7k 上拉 3.3V；SPI NSS=10 SCK=12 MOSI=11 MISO=13 RST=4 DIO0=2；SX1278 只吃 3.3V；USB-C 5V→TP4056(PROG 1.2k)→18650+，SS34 肖特基隔离→主控 5V；AMS1117 VOUT→3V3 轨；底层铺地，天线区净空。

---

## 方案① 插接版提示词（复制给嘉立创 AI）

```
【项目】LoRa 环境感知节点底板 LoRaCanary v1-插接版。2 层板 60×50mm。
【器件】ESP32-S3 SuperMini 排母(2×17pin 2.54mm)、SX1278 Ra-01 模块排母(2×4pin)、BME280 芯片直焊(LGA8)、SSD1306 OLED 排母(4pin)、AMS1117-3.3 直焊(SOT-223)、TP4056 直焊(ESOP-8)、USB-C 母座、18650 电池座、BOOT/RST 按钮。
【连接】I2C：GPIO8=SCL 9 总线接 BME280(0x76,SDO 接地)+OLED，4.7k 上拉；SPI：NSS=10 SCK=12 MOSI=11 MISO=13 RST=4 DIO0=2；SX1278 只接 3.3V；USB-C 5V→TP4056(PROG 1.2k)→18650+，经 SS34→SuperMini 5V；AMS1117 VIN 接 5V 隔离后，VOUT→3V3 轨。
【布局】电源区左下；SX1278 右上角天线朝板边净空≥5mm 底部禁铜；I2C 总线右侧；3V3 走线≥0.5mm；底层铺地；四角 M3 孔；排母朝上。
【输出】DRC 0 错误，中文注释，给 BOM。
```

## 方案② 直焊版提示词（复制给嘉立创 AI）

```
【项目】LoRa 环境感知节点底板 LoRaCanary v1-直焊版。2 层板 80×60mm，全部直焊无排母。
【器件】ESP32-S3-MINI-1 邮票孔模组直焊（自带 Flash/晶振）、SX1278 芯片直焊(QFN-28)、BME280 芯片直焊(LGA8)、SSD1306 OLED 4pin 焊盘直焊(FPC 座可选)、AMS1117-3.3 直焊(SOT-223)、TP4056 直焊(ESOP-8)、USB-C 母座、18650 电池座、SX1278 用 32MHz 晶振+12~15pF 负载电容、RF 匹配元件（串感+并容，参考模块公版，天线端留测试焊盘）。
【连接】I2C/SPI 同上；SX1278 RF 地分离，RF 部分单点回主地；USB-C 5V→TP4056→18650，SS34 隔离→模组 5V；AMS1117→3V3 轨。
【布局】SX1278 芯片右上角，RF 走线 50Ω 控制+天线伸出板边≥8mm；匹配元件紧贴芯片引脚；晶振贴 SX1278 晶振脚短走线；模拟/数字地分区；其余同方案①。
【输出】DRC 0 错误；标注 RF 匹配测试点；中文注释；BOM 含晶振/射频件。
```

## 两版差异与建议

- ① 成功率高（90%+），先跑全链路；插接松动可接受
- ② 板子耐用，但 SX1278 焊芯片必须先抄公版 RF 匹配电路（whycan SX1278-STM8S 透传模块有完整原理图，参考案例清单里），别让 AI 编 LC 值；天线端留测试焊盘，距离不满意可调
- **推荐路径**：PCB 设计时把 SX1278 位置做成"芯片焊盘 + 8pin 模块位"双兼容（二选一焊接，丝印标注），①跑通后无缝升级②，只重打一次样
