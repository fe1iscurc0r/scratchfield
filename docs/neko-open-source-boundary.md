# NEKO 开源版权边界（W65-04）

> 来源 docs/zhuomianling-授粉报告.md · 桌宠 pet-id 隔离 + 版权边界

## 边界「不包含」项（≥5）

1. **不包含** 任何第三方桌宠的二进制/资源文件（只做 pet-id 目录约定 + 映射结构参考）。
2. **不包含** 上游闭源桌宠的源代码（只参考「事件映射结构」，不抄代码）。
3. **不包含** 受版权保护的角色形象/立绘/配音素材（用自绘或开源替代）。
4. **不包含** 未经授权的品牌名称/logo 作为默认桌宠名（默认用中性名）。
5. **不包含** 网络下载的未授权模型权重（pet 记忆/表情默认走本地开源模型）。
6. **不包含** 从商业桌宠反编译的协议字段（表情协议用 `<<expression>>` 自有约定）。

## 实现

`tools/pet_profile.py`：`pet_dir(pet_id)` 隔离目录 + 事件映射（加载/点击/拖拽 → 动作）。
