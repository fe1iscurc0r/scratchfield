# W73-06 记忆文件格式（memoryfields）评估

> 上游：calpaterson.com/memoryfields.html（HN 190p/93c）· 许可待核（网页，未明确开源许可）

## 1. 项目定位

把 agent 记忆做成**文件格式**：人、程序、agent 三方都能读写同一份记忆文件，记忆即文件、文件即记忆，跨工具可移植。

## 2. 架构拆解

- **文件即记忆**：记忆以标准化文件格式落盘，三方（人/程序/agent）可读写。
- **标准化**：格式定义清晰，便于跨工具交换。

## 3. 与本仓对照（memoryfields vs 五元组）

| 维度 | memoryfields | 五元组（summer_memory） |
|---|---|---|
| 形态 | 文件格式（三方可读写） | 结构化五元组 |
| 可移植 | 高（文件交换） | 中（需序列化） |
| 人可读 | 高 | 中 |

## 4. 可落地借鉴点（≥3）

1. **「文件即记忆」的可移植性**：记忆以人可读文件落盘，便于人工审查与跨工具迁移——可借鉴到我们记忆文件落盘 + yjs_sync（W63-01）。
2. **三方可读写**：人/程序/agent 三方共享同一格式，减少「agent 记忆是黑盒」的问题。
3. **格式标准化**：定义清晰的记忆文件 schema，可作为我们记忆序列化格式的对照。

## 5. 许可裁定 + 结论

- **许可**：网页无明确开源许可 → **许可待核**，参考设计不抄实现。
- **结论**：参考「文件即记忆 + 三方可读写」设计，与现有五元组 + 记忆文件落盘兼容；值得在记忆序列化格式上做对照。
