# 单液滴声悬浮实验台设计（工单 265 · P0-5）

> 目的：给轮47 的 PBM 提供**无壁成核**边界条件——液滴悬在空中，成核不受容器壁影响。
> 本文件是**设计文档**，不含第三方硬件设计文件（许可边界见 §7）。

---

## §1 为什么用声悬浮

| 需求 | 声悬浮能满足的原因 |
|---|---|
| 无壁成核 | 液滴不与任何固体接触，消除壁面异相成核 |
| 可观测 | 液滴悬停不动，可长时间光学/热学测量 |
| 可控制 | 通过**相位**与**频率**调节位置与刚度 |
| 代价 | 声流扰动、蒸发、局部加热（§6 逐条给对策） |

## §2 三要素（本设计的核心参数）

### §2.1 换能器间距

驻波由**换能器 + 反射板**形成（单换能器反射式，比双换能器对置更省件）。

- 空气中 40 kHz ⇒ `λ = c/f = 343/40000 = 8.575 mm`
- 相邻**声压节点**间距为 `λ/2 = 4.29 mm`
- 取间距 `d = n·λ/2`，推荐 `n = 5`（d ≈ **21.4 mm**）或 `n = 6`（d ≈ **25.7 mm**）
- 理由：`n` 太小则反射板靠近换能器近场（声场未成形）；`n` 太大则声压梯度变小、悬浮刚度下降。
  `n = 5~6` 是"近场已过、刚度还够"的折中。
- 装配精度：**±0.2 mm**（≈λ/40）。偏移会让节点偏离设计高度并降低刚度。

### §2.2 频率

| 频率 | λ | λ/2 | 适合液滴直径 | 备注 |
|---|---|---|---|---|
| 25 kHz | 13.7 mm | 6.86 mm | 1.5–4 mm | 刚度低但声压要求低，适合大水珠 |
| **40 kHz** | **8.575 mm** | **4.29 mm** | **0.5–2 mm** | **本设计选型**（器件最普及） |
| 60 kHz | 5.72 mm | 2.86 mm | 0.3–1 mm | 需更高声压，换能器贵 |

选型理由：40 kHz 换能器（Langevin 型）市售最便宜、驱动最容易；
液滴直径需满足 `D ≪ λ`（重力与声辐射力的平衡区），0.5–2 mm 落在 8.575 mm 的 1/4 以内。

驱动：**单频连续波**（CW），频率稳定度需 `Δf/f < 1e-4`；
扫频会移动节点位置，只用于寻找共振（找到后必须锁定）。

### §2.3 相位解算（phase_alignment）

**这是全台架最容易被忽略、也最决定成败的一步。** 目标：让**声压节点**恰好落在
设计的悬浮高度 `z_target` 上，且（双换能器方案下）两侧激励同相。

单换能器反射式：节点位置由 `d` 与频率共同决定，`phase_alignment` 退化为"频率锁定 + 间距校准"。

双换能器对置式（需要更高声压或更强调控时）：两路驱动的相对相位 `Δφ` 决定合成驻波的节点位置：

```
z_node(Δφ) = z_0 + (Δφ / 2π) · (λ/2)
```

**相位解算流程（phase_alignment 标准步骤）**：

1. 用微型麦克风（1/8"）沿轴向以 0.3 mm 步距扫描，记录声压幅值 `|p(z)|`；
2. 找 `|p(z)|` 的极小点（即声压节点），记录实际 `z_node_meas`；
3. 按 `Δφ = 2π·(z_target − z_node_meas)/(λ/2)` 计算需要补的相位；
4. 写入信号源的通道间相位偏移，重复步骤 1–2 验证偏差 `|z_target − z_node| < 0.2 mm`；
5. 锁定相位与频率，记录到台架日志（温度变化会使 `c` 漂移 ≈ 0.6 %/K，需定期复校）。

> 实测坑：`Δφ` 的符号取决于两路通道的接线极性；若扫出来节点**朝反方向**移动，
> 说明某一路反相，先把极性统一再算相位。

## §3 悬浮力与稳定性预估

### §3.1 radiation force 的量化

Gor'kov 势（驻波场、小液滴 `D ≪ λ`）：

```
U = (4π/3)a³ · [ f₁·⟨p²⟩/(3ρ₀c₀²) − f₂·(ρ₀⟨v²⟩/2) ]
f₁ = 1 − ρ₀c₀²/(ρ_p c_p²)，  f₂ = 2(ρ_p − ρ₀)/(2ρ_p + ρ₀)
```

轴向 **radiation force** `F_z = −∂U/∂z`，在节点附近近似为线性恢复力 `F_z ≈ −k_z·(z − z_node)`。

水/空气：`ρ₀ = 1.2 kg/m³`、`c₀ = 343 m/s`、`ρ_p = 998`、`c_p = 1500`
⇒ `f₁ ≈ 1.0`、`f₂ ≈ 1.0`（水在空气中的强声学反差，是能悬浮的根本原因）。

### §3.2 悬浮所需声压（量级估算）

平衡条件 `F_z > m·g`。对 `D = 1 mm` 水滴（`m ≈ 5.2e-7 kg`）：

- 所需声压幅值量级 **≈ 2–3 kPa**（对应声强 ≈ 25 mW/cm²）
- 常见 40 kHz Langevin 换能器 + 反射板在 21 mm 间距下可达 **5–15 kPa** ⇒ 余量 2–5 倍

### §3.3 刚度与稳定性

- 轴向刚度 `k_z ∝ p_ac² / (ρ₀ c₀²) · (2π/λ)²`：声压越高越硬
- 横向：驻波场在横向形成 Bessel 型势阱，只要液滴偏离轴心 < 0.3 mm 就有回正力
- **失稳模式**：① 声流（acoustic streaming）把液滴往下游推 —— 对策：降低驱动幅度并用
  低频方波调制打断定常流场；② 液滴蒸发导致质量减小、被推到更高节点 —— 对策：控湿腔体；
  ③ 加热（≈数十 K 局部升温）—— 对策：脉冲驱动（占空比 < 50 %）。

## §5 验收判据（本台架"做成了"的标准）

| # | 判据 | 测法 |
|---|---|---|
| A1 | 液滴悬停 ≥ 60 s 不掉 | 视频计数 |
| A2 | 节点位置偏差 < 0.2 mm | 麦克风扫描 + `phase_alignment` 复核 |
| A3 | 液滴直径可重复性 ±5 % | 相机测径，连续 20 滴 |
| A4 | 悬浮高度可调 ≥ 3 个节点（≈12.9 mm 范围） | 改变频率或相位 |
| A5 | 环境温度漂移 < 1 K/10 min | 传感器记录（避免热成核干扰） |

## §6 与轮47 PBM 的接口

- 输入：无壁条件下的**成核诱导时间**分布（同一过饱和度下重复 ≥ 30 次）
- 输出格式：`{T, S, t_ind [s], droplet_mm, run_id}` → 进 PBM 的成核项 `J(S,T)`
- 注意：声场本身会**促进**空化/成核（这是已有文献结论），所以必须做**声压对照实验**
  （同一液滴在 0 / 50 % / 100 % 声压下各测一组），否则会把"声致成核"误判成"均相成核"。
