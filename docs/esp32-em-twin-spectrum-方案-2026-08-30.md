## 〇、一句话定位

**用"物理先验（多径/窄带稀疏）+ 压缩感知稀疏重建"替代整段频谱测量：在 433MHz 主场，用少量观测恢复底噪画像、识别干扰、判定多径，给 rf-brain 决策和信号分类当预处理层。**

## 一、勘察点定义与论文来源（诚实标注）

### 1.1 "电磁孪生稀疏重建"= 两个可拆开的学术构件

| 构件 | 含义 | 落到 433MHz |
|---|---|---|
| **物理引导无线世界模型** | 把多条信道/频谱观测聚合成一个固定大小的"环境嵌入"，作为任务无关先验 | 每个架台点/每频段建一张"RF 指纹卡"，下游任务（干扰识别/多径判定）共享 |
| **稀疏重建（压缩感知 CS）** | 物理先验（时延簇少、窄带干扰少）→ 频域/时延域稀疏 → 用欠采样观测恢复完整频谱 | 用 SX1278 稀疏统计量 / RTL-SDR 短时 IQ 恢复 433MHz 环境图景 |

| "电磁孪生"论文 | 即 **Channel2World**（arXiv:2608.17544，Hyung-Joo Moon 等，eess.SP，2026-08） | 本仓已有实现草稿 + `radio_brain/channel2world/`（Sionna 数据生成 + model 骨架） |

**Channel2World 核心（三句话）**：MIMO 信道是"对同一传播环境的局部 RF 观测"；用 Set-Transformer/Perceiver 把变长多径参数聚合成固定大小的"无线世界嵌入"（Kz=16 latent × Dm=128）；context-query 自监督预训练，冻结编码器后下游零微调。**红线**：原文是 7GHz MIMO 基站侧（4×8 阵列 + ray-tracing），用户没有 MIMO 基站硬件，**直接照抄无意义**，价值在"环境级表征 + 物理先验 + 自监督"这个范式。

**稀疏重建补强（经典 CS，未逐一查原文，标"经典方法"）**：压缩感知奠基（Candès/Romberg/Tao 2006；Donoho 2006）、OMP（Pati 1993）、稀疏信道/时延-多普勒估计。这些是公开成熟方法，用于把"物理先验→稀疏重建"这条腿补上——Channel2World 只给了"环境嵌入"，没给"从欠采样观测恢复频谱"这一步，而这一步正是本单要的"频谱后处理"。

## 二、映射到 ESP32-S3 433MHz 现实：能做什么 / 不能做什么

### 2.1 硬约束（不变量）

| 约束 | 值 | 来源 |
|---|---|---|
| 主场频段 | 433MHz（大连），微波段不可用 | 工单铁律 |
| 发射功率 | 433MHz ≤100mW | 工单铁律 |
| LoRa 单包 | ≤120B，帧头 0xD0CC + CRC-16 MODBUS | `docs/SPEC-20-v1.5-...` |
| 在手硬件 | ESP32-S3 SuperMini + SX1278×2 + NEO6M；IC-705(日版) + 泉盛 UV-K6；**RTL-SDR 未购** | 工单铁律 |
| SX1278 能给的 | 包级 RSSI（dBm）、解调后 SNR、CRC 通过/失败、Fei（频偏估计） | `firmware/dcp_lora/sx1278_lora.cpp` + datasheet |

### 2.2 关键判断：SX1278 统计量 vs 需要 SDR 前端

**SX1278 是窄带 LoRa 收发器，不是频谱仪。** 它只能给"这一包信号"的统计量，给不出宽带频谱，更给不出 IQ 原始观测——而"稀疏重建"的数学对象就是 IQ/能量观测。所以：

- **SX1278 统计量能做**：环境底噪画像（RSSI 时间序列的均值/方差/峰度）、干扰粗分类（连续波 CW 干扰 vs 脉冲干扰 vs 底噪抬升，靠 RSSI/SNR/CRC 时序特征）、弱多径间接指示（SNR 抖动 + 频偏 Fei 抖动）。
- **SX1278 做不了**：宽带频谱稀疏重建、真正的多径时延簇分离（需要 IQ 做 FFT/ESPRIT/MUSIC/CS）、精确干扰源频点定位（需要扫频或宽带接收）。

一句话：**"稀疏重建"这条腿，SX1278 喂不饱，必须加 IQ 前端；"物理先验→粗画像/粗分类"这条腿，SX1278 现在就够。**

### 2.3 三个能落地的频谱后处理任务（按依赖排序）

| 任务 | 输入 | 输出 | 物理先验 | 前置条件 |
|---|---|---|---|---|
| A. 底噪画像 | SX1278 RSSI 时序 | 底噪均值/方差/昼夜漂移/异常抬升 | 底噪平稳 + 稀疏异常 | 无（零采购） |
| B. 干扰粗分类 | RSSI+SNR+CRC 时序特征 | NORMAL/CW干扰/脉冲干扰/底噪异常 | 干扰是稀疏窄带成分 | 无（零采购） |
| C. 多径判定 + 稀疏频谱重建 | RTL-SDR IQ（或 IC-705 IQ） | 多径簇数/时延谱/干扰频点 | 时延域稀疏 + 频域稀疏 | **RTL-SDR（未购）** |

## 五、处理流程（档B 核心算法，伪代码级，不写完整固件）

1. **采集**：RTL-SDR 短时 IQ 快照（1s），中心频 433.92MHz，采样率 1MS/s（够 433MHz 主场 ±500kHz 观察窗，覆盖 LoRa SF7/BW125 一次传输）。
2. **粗谱**：直接 FFT（1024/2048 点）得到能量谱，找峰值（干扰候选 + 本场 LoRa 信号）。
3. **稀疏重建**：把观测建模为 `y = A x + n`，`x` 是频域/时延域稀疏向量，`A` 是部分观测矩阵；用 **OMP**（正交匹配追踪，简单、可解释、云服纯 Python 可写）从欠采样/含噪观测恢复 `x`，物理先验 = 干扰数 K、多径簇数 L 都小。
4. **特征**：恢复出的频谱 → 峰均比、带宽、K 个频点、时延谱 L 个簇 → 归一化 8 维特征（复用 `elm_lut` 特征范式）。
5. **模型**：轻量 **ELM-LUT**（参考 `firmware/elm_lut/`：8 维特征 → 32 隐节点 → 3 类，tanh 256 项 8-bit LUT，纯整数 MAC+查表，LUT 与 float 精度差 0.67%）。云端用 float 版训练，边缘用 LUT 版部署（只做粗分类，不做稀疏重建——稀疏重建在云端，ESP32 跑不动也不该跑）。
6. **环境嵌入**：档B 稳定后，把每架台点的"稀疏频谱特征"喂给 Channel2World 的环境编码器（已有 `radio_brain/channel2world/model/encoder.py` 骨架），产出"RF 指纹卡"。

## 六、模型选择（为什么是 ELM-LUT 而不是 CNN/Transformer）

| 模型 | 理由 | 部署位置 |
|---|---|---|
| **ELM-LUT**（首选） | 无梯度训练（岭回归解析解），激活函数 LUT 化，纯整数、无浮点无 libm；已在 `firmware/elm_lut` 交付并编译验证（flash 21%/RAM 6%，LUT 路径 76 指令 0 乘除） | 边缘（ESP32 粗分类） |
| OMP（稀疏重建核心） | 可解释、云服纯 Python/NumPy 即可、无需训练 | 云端 |
| Channel2World 编码器 | 环境级表征，任务无关，冻结后零微调；已在 `radio_brain/channel2world` 有骨架 | 云端（ESP32 不跑 Transformer） |

**诚实标注**：ELM-LUT 现有模板是"收包频谱特征→3 类（NORMAL/NOISE/BAD_FRAME）"，本单要把它**改造成"环境频谱特征→底噪/CW干扰/脉冲干扰"**，输入特征从"收包字节流特征"换成"RSSI/频谱稀疏重建特征"——训练数据需重新生成（真实 RF 分布未验证，现有模板是合成 mock）。

## 九、诚实降级清单（真机验证前不声称"已实测"）

1. 所有采集参数（1MS/s、1024 FFT、干扰数 K、多径簇数 L）为**估算/经验值**，未在 433MHz 大连环境实测。
2. SX1278 底噪画像的 RSSI 标定（-110~-95dBm 区间）需真机 STAT 回读校准（见 `firmware/README.md` §6 第 2 条）。
3. ELM-LUT 现有精度（93.33%）来自**合成 mock 数据**，真实 RF 环境分布未验证。
4. RTL-SDR 8bit 动态范围有限，强干扰下需外加可调衰减；多径时延分辨率受 1MS/s 采样率限制（时延分辨 ≈1µs ≈ 300m 光程差），仅能判"多径簇数"量级，不能做厘米级时延。
5. IC-705 日版频段受限，433MHz 段是否可发射/接收需用户核对执照与频段，本单默认 RTL-SDR 为接收前端（不涉及发射）。

## 十、真机验证点（用户实测）

1. **底噪画像**：SX1278 上电发 `STATUS`，静置 10 分钟记录 `rssi_dbm` 序列，算均值/方差，确认无信号时 -110~-95dBm。
2. **干扰粗分类**：在 433MHz 附近放一台已知 CW 信号源（UV-K6 低功率 + 假负载）vs 无干扰，观察 RSSI/SNR 时序特征能否分出两类。
3. **档B 稀疏重建**：RTL-SDR 采 1s IQ，跑 FFT 看是否出现 UV-K6 载波谱线，再用 OMP 从 1/4 欠采样恢复该谱线（定性验证 CS 有效）。
4. **多径判定**：移动 SDR 位置 / 靠近金属反射面，观察时延谱簇数变化。
