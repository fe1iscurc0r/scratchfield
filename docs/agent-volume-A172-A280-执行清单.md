## 1. 重点 A 线单（优先，深度评估）

### A204 AgenticRag-R1（RL agentic RAG）
- **方法拆解**：把 RAG 的「检索→读取→写入记忆栈」建模为 RL 的**细粒度动作空间**，配**层级即时奖励**（动作级即时反馈 + 任务级最终奖励），而非只在最终答案给稀疏奖励；记忆栈作为可读写的外部状态，支撑多跳长时推理。
- **可借鉴点（≥3）**：
  1. NEKO 的 RAG 检索链改为可 RL 的动作序列，用动作级即时奖励缓解多跳推理的奖励稀疏；
  2. 记忆栈「读/写」显式建模，直接对接 A216 的记忆阶段化风险设防；
  3. 层级奖励与 A214 A²Agent 的动作级信用分配同构，可合并为一个「动作级信用 + 层级奖励」的 RL 骨架。

### A179 Hydra（离散潜变量导航世界动作模型）
- **方法拆解**：用**离散潜变量**表示导航世界状态与动作，做世界-动作联合建模，预测导航的下一步状态/动作。
- **可借鉴点（≥3）**：
  1. 离散潜空间量化友好，适配端侧/嵌入式的导航决策部署；
  2. 「世界模型 + 动作模型」联合，可迁移到 rf_brain 的频谱环境感知-决策闭环（呼应 A30）；
  3. 与 G2 的显式记忆图导航（A186 CGFM-Nav）互补：Hydra 给潜世界、CGFM 给显式地图。

### A264 One Policy Is Enough（单策略超越树搜索）
- **方法拆解**：单 RL 策略在化学工具调用编排上**击败 MCTS/树搜索**，核心结论是「搜索并非必要」——良好的奖励设计 + 简洁策略即可，且省算力。
- **可借鉴点（≥3）**：
  1. 复杂工具编排用单策略替代树搜索，显著降推理算力；
  2. 工程启示：奖励设计 > 搜索空间，优先投资奖励塑造而非复杂搜索；
  3. 与 A204/A206/A214 的 RL 主线一致，可统一为「RL 优先于搜索」的工具编排范式。

### A268 语言驱动 QD 操作（机器人技能自举）
- **方法拆解**：LLM **自主推断适应度函数与多样性函数**，做 Quality-Diversity（QD）优化，输出多样的运动原语档案，免任务专属提示/人工调参。
- **可借鉴点（≥3）**：
  1. LLM 自推断适应度/多样性 → 免人工设计的技能自举，降低技能获取成本；
  2. 「多样运动原语档案」是可复用的技能库，与 NEKO 技能目录（SkillForge 系）方向一致；
  3. QD 的「多样性」维度对抗过拟合单一解，适合需要鲁棒动作库的具身场景。

### A216 记忆阶段化效用-风险权衡（记忆投毒剖面）
- **方法拆解**：把 agent 记忆生命周期分为**写入/管理/检索**三阶段，各阶段暴露不同的投毒风险剖面——写入是注入点、管理是持久化、检索是激活点，效用与风险在各阶段权衡。
- **可借鉴点（≥3）**：
  1. NEKO 记忆系统按三阶段设防：写入时来源校验、管理时审计、检索时溯源门控；
  2. 与 A09 记忆投毒防护、A221 工具知识抽取防御互补，构成「结构化记忆防御」框架；
  3. 阶段化风险剖面可作为记忆系统的威胁建模模板，逐阶段配检测指标。

## 4. 跨组可复用结论

1. **RL 替代搜索/编排**（A204/A214/A264/A206）——细粒度动作信用 + 层级奖励，用简洁 RL 策略替代 MCTS/树搜索，省算力。
2. **世界模型 + 记忆统一**（A179/A186/A219/A230/A272）——显式记忆图 + 世界模型是长时 agent 的共同底座。
3. **安全按阶段/结构设防**（A216/A215/A218/A221）——记忆三阶段投毒剖面、影响≠授权、工具知识抽取，都需要结构化防御而非事后检测。
