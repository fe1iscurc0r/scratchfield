## 2. 最小可行闭环建议（对齐现实硬件）

**目标闭环（天选7 全仿真，零新硬件）**：
```
Gazebo 铁路/道路世界（railway_world 复用）
   → PX4 SITL（offboard 模式）
   → 避障决策节点（本仓自研：障碍距离契约 + 反应式速度指令）
   → 状态估计输入（SITL 真值代替 VIO，接口按 Kimera 契约定义）
   → 回归断言：障碍前 N 米减速/停（pytest + rosbag 回放断言）
```
步骤：
1. **契约先行**（无仿真也可做）：写 `obstacle_distance` 与 `pose/vel` 两个数据契约
   文档 + Python dataclass + 单测（本仓 research/ 或 firmware 主机侧）。
2. **SITL 床**：天选7 装 PX4 SITL + Gazebo Harmonic，导入 railway_world（MIT 仓资源）。
3. **反应式控制器**：规则版（距离阈值→速度档），单测覆盖阈值边界；DDPG 留研究线。
4. **状态估计替换点**：SITL 真值 →（未来）VIO/光流，接口不变（Kimera 契约）。
5. **无深度相机现实的对冲**：单目已知尺寸估距 + LoRa 测距写入同一占据层
   （W97-01 借鉴点 3 的占据距离场），真机阶段再补深度相机。
