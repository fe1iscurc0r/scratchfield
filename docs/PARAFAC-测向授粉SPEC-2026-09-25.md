## 1. 结论先说

**PARAFAC（三线性分解）能在纯软件层做窄带测向**，本仓已给出可运行的最小验证：
`tools/parafac_doa_sim.py`，纯 numpy、无硬件依赖、自带自检断言。

实测（本机 `.venv`，numpy 2.4.6）：

| 场景 | 结果 |
|---|---|
| 双源（真值 −20°/+25°，SNR 20 dB） | 估计 −20.02°/+25.02°，**RMSE 0.020°** |
| 三源（−30°/0°/+30°，SNR 20 dB） | **RMSE 0.144°** |
| SNR 扫描（10 次试验均值） | −5 dB: 0.515° → 20 dB: 0.012°，**单调收敛** |

> 这些数字是"算法自洽"的证明，**不是**实测精度——真实精度取决于阵列标定与硬件相位一致性，见 §4。

## 2. 方法：为什么这么构造张量（含两个踩过的坑）

### 2.1 张量构造（空间平滑，固定全局参考）

```
Y[m, τ, s] = (1/T) Σ_t  X[s+m, t] · conj(X[0, t+τ])          → 形状 [Ms, lags, S]
期望值      = Σ_k (1/M)·e^{jπ(s+m−1)sinθ_k} · ρ_k^τ
```

三模各自带**逐源多样性**：阵元维 `e^{jπm·sinθ}`、时延维 `ρ_k^τ`（源的时间相关）、子阵移位维 `e^{jπs·sinθ}`。
Kruskal 条件 `k_A+k_B+k_C ≥ 2K+1` 对 K 个不同角度成立 ⇒ **分解唯一** ⇒ DOA 可辨识。

两路独立反解（阵元维 A 与子阵维 C 都是 `e^{jπ(·)sinθ}` 型）取均值降方差，**两路一致性本身就是自检**：
实测两者差 0.02°；若差很多，说明分解没落到真解。

### 2.2 坑一：Khatri-Rao 参数顺序必须匹配 C-order 展平

`Y.reshape(M,-1)` 的列索引是 `l*N+n`（**最后一维最快**），不是 `l+n*L`。写错时即便用真值初始化，
单步更新也会把残差打到 ~1.0。三个 mode 的正确配对：`kr(B,C)` / `kr(A,C)` / `kr(A,B)`。
（已写成脚本内注释，含"单步残差检验"这个定位手法。）

### 2.3 坑二：**不能用「时间子块」当第三模**（会导致分解非唯一）

最初的构造是 `Y[m, τ, n]`（n = 时间子块）。问题：块的互相关期望**与块号无关**（只差估计噪声）
⇒ 第三模近似 rank-1 ⇒ Kruskal 条件差 1 ⇒ **分解非唯一**，估出的角度是任意混合。
实测后果：10 个随机种子 RMSE 从 1.9° 到 15° 乱跳，多起点也救不回来。
换成**空间平滑**（子阵移位）后才稳定 —— 这是本次最重要的一条结论。

## 3. RAM 瓶颈与阵列基线（RTL-SDR 实测路径）

### 3.1 采样率与带宽

| 项 | RTL-SDR（R820T2 级） | 说明 |
|---|---|---|
| 可用瞬时带宽 | 2.4 MS/s（稳定）；3.2 MS/s 需掉样 | 窄带测向足够 |
| 复采样率 | 2.048 MS/s（常用） | 与 `lags` 维配合：τ 上限 ~几十 μs |
| ADC 位深 | 8 bit | **动态范围是主要短板**：强邻道会压死弱目标 |

对 433/2.4G 干扰排查：建议先降到 **1.024 MS/s** 提高 SNR，再按需升带宽。

### 3.2 阵列与基线

- **阵元数**：≥4（脚本默认 10 是仿真值；实测 4 元 ULA 也能分辨 2 源，分辨力 ∝ 基线/波长）
- **基线**：半波长间距（433 MHz → 34.6 cm）是无模糊上限；间距 > 半波长会出现**栅瓣模糊**，
  需用非均匀阵列或加先验才能解
- **只做接收**：RTL-SDR 无收发切换，无法做真正的 ISAC 泄漏度量（那需要收发同源，见 §5）

### 3.3 标定（不做这步，仿真精度没有意义）

1. **相位一致性**：同一信号等分到各通道（功分器），测各通道相位偏差并记录为标定表
2. **电缆长度差**：每根馈线长度差直接变成相位误差；用已知源（或矢网）测相位斜率
3. **时钟**：多通道要么共用同一采样时钟（推荐），要么 GPSDO/NTP 同步（见频谱制图 SPEC 未决项）
4. **复测**：标定后重跑「已知方位角源」的实测，与脚本的 `--sweep-snr` 对照

## 4. 脚本用法

```bash
python tools/parafac_doa_sim.py --simulate                # 双源自测（含自检断言，失败非零退出）
python tools/parafac_doa_sim.py --simulate --sources 3    # 三源
python tools/parafac_doa_sim.py --sweep-snr               # 10 次试验/档，看 RMSE 收敛
python tools/parafac_doa_sim.py --simulate --antennas 4 --snapshots 512   # 模拟 RTL-SDR 小阵列
```

纯 numpy（本仓 `.venv` 自带 numpy 2.4.6）；**不引入 scipy 或任何新依赖**（供应链铁律：本脚本零新增）。

## 5. 与 ISAC 泄漏度量的关系（能力边界）

本脚本只做**测向**。工单提到的 ISAC 泄漏度量需要**收发同源**（发射泄漏到接收链路的自干扰评估）：

- 用 **IC-705 发射 + RTL-SDR 接收**：可做"泄漏功率随频率/功率档位"的曲线，但两机不同源，
  只能测**量级**，不能测相位一致的泄漏矢量
- 要测泄漏矢量需要同一本振的收发链路（SDR 收发一体机或专用耦合器 + 矢网），**本仓无此资产**

⇒ 结论：**ISAC 泄漏这条线在本仓只能做到"功率量级曲线"，矢量级泄漏度量需额外硬件**（如实记录，不硬凑）。
