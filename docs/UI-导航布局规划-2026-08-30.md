# UI 导航布局规划（PanelView 收纳改版）

日期：2026-08-30
范围：scratchpad/frontend · PanelView.vue + 路由复用
状态：规划稿（待拍板 3 项 → 转 Trae 工单）

---

## 一、背景

首页现有 7 个硬按钮 + 2 个本地应用启动，但 15 个路由只有 7 个入口，
ELN / 语音ELN / 数据 / 论文 / 频谱（/radio）等路由存在但无入口。
继续平铺加按钮会臃肿，需做导航收纳。

## 二、目标布局

```
娜杰日达（大图标 /chat）
记忆云海   知识▸   技能工坊
悬浮球    射频大脑▸  终端设置
枢机集市   外设▸
```

- 第一行：娜杰日达（不动）
- 第二行：记忆云海（不动）、**知识▸**（收纳）、技能工坊（不动）
- 第三行：悬浮球（不动）、**射频大脑▸**（收纳）、终端设置（不动）
- 第四行：枢机集市（不动）、**外设▸**（收纳）

## 三、改动清单

### 1. 知识▸（原"知识库 MatChat"按钮改造）
- 收纳：MatChat（/knowledge）、ELN（/eln）、语音ELN（/voice-eln）、数据（/data）、论文（/papers）
- 单击直达 MatChat；点 ▸ / 长按展开二级菜单
- 二级菜单 5 项，带图标

### 2. 射频大脑▸（原"频谱"入口上位 + 收纳 hamlog）
- 收纳：频谱（/radio）、无线电日志（hamlog 本地应用，从外设迁入）
- 单击直达 /radio 频谱（主战场）；▸ 展开二级
- hamlog 迁移：仅改调用位置，`launchLocalApp('hamlog')` 逻辑原样保留，
  启动中 disabled 状态照旧

### 3. 外设▸
- 迁出 hamlog 后仅剩 NEKO
- 待拍板：(a) 保留外设容器，为未来本地应用留位；(b) 改为 NEKO 独立按钮
- 倾向 (b)：一容器一应用浪费层级，未来有新增再加回

### 4. 旅行（/model → TravelView.vue）
- 标签"旅行"、路径 /model、组件 TravelView 三处语义对不上，且长期无入口
- 本轮：按钮不进布局，路由暂留（防误删）
- 待拍板：是否连路由一起删除

### 5. 不动项
记忆云海、技能工坊、悬浮球、终端设置、枢机集市

## 四、交互统一

- 两个收纳按钮行为一致：单击进主入口，▸/长按展开二级
- 二级用 Popover 弹出（带图标，≤5 项），不做新页面、不做 tab
- 待拍板：Popover vs 抽屉
