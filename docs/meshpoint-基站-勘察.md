# W67-03 · meshpoint LoRa 基站勘察（开源 LoRa 网关侧）

> 2026-09-02 · 第二十一期 GitHub 新扫货批 · 勘察（不写实现）
> 上游：KMX415/meshpoint（AGPL-3.0，281★，2026-03，Python）

## 一、项目定位

开源 LoRa 基站/网关：树莓派 + SX1302/SX1303 集中器芯片，实现多信道 LoRaWAN/LoRa 网关。与 LoRaCanary（节点侧）互补，补「网关/基站侧」。

## 二、架构拆解

- 硬件：树莓派 + SX1302/SX1303 集中器（多信道并发收发）。
- 软件：Python 网关栈（集中器驱动 → 包解析 → 上行/下行调度）。
- 多信道：SX130x 支持 8 个并发解调信道 + 1 个下行，覆盖大范围节点。

## 三、与本仓对照

| 维度 | LoRaCanary（节点侧） | meshpoint（网关侧） |
|------|---------------------|---------------------|
| 角色 | 节点上报 | 网关集中接收/下发 |
| 硬件 | ESP32 + SX127x | 树莓派 + SX1302/1303 |
| 多信道 | 单信道 | 8 信道并发 |
| 许可 | 本仓 | AGPL-3.0（只参考） |

## 四、可落地借鉴点（≥3）

1. **SX1302/1303 集中器架构**：多信道并发解调 + 下行调度，是 LoRaCanary 从「单节点」扩到「多节点网关」的硬件选型参考。
2. **网关栈分层**：集中器驱动 → 包解析 → 上行/下行调度的分层，可借鉴到 LoRaCanary 网关侧（现 `tools/loracanary_gateway.py`）的扩展。
3. **多节点并发接入**：8 信道并发，对应 LoRaCanary 多节点上报的容量扩展。

## 五、与 LoRaCanary 网关对接路径

- LoRaCanary 网关（`tools/loracanary_gateway.py`，433MHz 单信道）→ 若要扩多节点并发，参考 meshpoint 的 SX130x 多信道架构；但 433MHz 与 LoRaWAN 频段/协议不同，需评估「SX130x 是否支持 433 集中」。
