# QOpenHD + LiveVideo10ms 评估（图传地面端 UI + 低延迟解码）

> 2026-09-08 · 卷80 W79-06 · 评估（不写实现）
> 上游：OpenHD/QOpenHD（GPL-3.0，★282）+ Consti10/LiveVideo10ms（LGPL-3.0，★100）

## 一、项目定位

- QOpenHD：图传官方地面站 App（视频显示 + OSD 叠加 + 遥控通道）。
- LiveVideo10ms：安卓 10ms 级低延迟视频解码（双缓冲管线）。

## 二、架构拆解

- QOpenHD：视频流接收 → OSD 叠加 → 显示 + 遥控上行。
- LiveVideo10ms：解码管线 + 双缓冲延迟方法论（解码-渲染流水线化）。

## 三、与本仓对照

lumo 移动端图传控制界面形态参考；解码管线/双缓冲延迟方法论是核心借鉴。

## 四、可落地借鉴点（≥3）

1. **OSD 叠加层抽象**：遥测数据→屏幕叠层的独立渲染层，可映射到 lumo 图传 UI。
2. **双缓冲低延迟管线**：解码与渲染分离、丢弃旧帧策略（10ms 级延迟方法论）。
3. **地面站双向通道**：视频下行 + 遥控上行的会话模型。

## 五、许可裁定

QOpenHD GPL-3.0（只参考设计）；LiveVideo10ms LGPL-3.0（动态链接可用）。接入判定：QOpenHD 仅参考 UI 形态；LiveVideo10ms 解码方法论可借鉴。
