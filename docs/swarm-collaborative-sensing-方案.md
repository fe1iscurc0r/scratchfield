---

## 1. 结论先行

多 ESP32/SDR 节点构成**去中心化频谱感知网络**，节点只与邻居交换信息、不做中心融合，用共识算法合并多节点感知结果，**去中心、抗单点**。核心选型：**ADMM 共识**（精度高、可证收敛）+ **评分/多数表决**（低功耗节点 1bit 量化兜底）。

---

## 2. 共识算法选型

| 算法 | 原理 | 适用 | 通信量 | 精度 |
|---|---|---|---|---|
| **ADMM 共识** | 邻域交换 + 拉格朗日对偶迭代 | 连续值融合（功率/占用概率） | 中 | 高（可证收敛） |
| **D-MAP / D-EKF** | 分布式最大后验 / 分布式卡尔曼 | 目标跟踪、动态状态 | 中 | 高 |
| **Gossip 平均** | 随机邻居两两平均 | 稀疏图、鲁棒 | 低 | 中（慢收敛） |
| **多数/评分表决** | 1bit 量化 + 费雪信息加权 | 低功耗节点、占用判定 | 极低 | 中 |

**推荐组合**：占用/功率用 ADMM 共识（连续值）；告警/事件判定用评分表决（1bit + 费雪加权，容忍低功耗节点）；移动目标用 D-EKF。

---

## 3. 共识流程（去中心）

```
每节点：本地感知（WHT 特征 → 1bit 量化 / 功率估计）
   │
   ▼ 只与邻居交换
每轮：x_i ← 本地观测 + Σ(邻域) 共识变量   （ADMM 迭代 / gossip 平均）
   │
   ▼ 收敛判定（相邻轮差异 < ε）
全局地图 = 各节点共识后的本地视图合并（无需中心）
   │
   ▼ Agent 层基于共享地图做功率控制/信道分配
```

- **抗单点**：任一节点故障不影响全局（邻居图连通即可）。
- **隐私**：只交换共识变量，不上传原始频谱（与 R27 本地推理、R32 语义传输一致）。

---

## 4. 模拟计划

1. 建 N 节点随机几何图（邻接矩阵），每节点对「频谱占用图」做带噪声的本地观测。
2. 实现三种共识：ADMM、gossip 平均、多数表决。
3. 指标：
   - 收敛速度（迭代次数 vs N）
   - 共识误差（各节点最终估计与真值的 MSE）
   - 抗单点（随机删节点后的容错）
   - 通信量（消息数）
4. 场景：静态占用图 + 动态目标（D-EKF）+ 节点故障注入。
