## PF022 · 采样端内嵌压缩（CS-SAR 前端模拟）

**源论文**：2608.28847 CS-SAR ADC
**迁移机制**：压缩感知内嵌进采样网络（伪随机极性调制 + 电荷域累加），一个测量值编码多个时域样本。
**落地**：Rademacher ±1 测量矩阵 + OMP 稀疏恢复 + NCC 评估。
**实测**：k-稀疏点目标 NcT=8/4/2 恢复 NCC 全 1.0（论文 NcT=4 保 0.98 达标）。

## PF012 · FIREQ 精密波形控制架构

**源论文**：2608.29399（FIREQ）
**迁移机制**：
1. **确定性事件时序**——I/Q 生成拆成离散事件，时间戳用样本索引（时钟拍）而非浮点时间，杜绝边生成边漂移；同配置两次构建逐样本一致（已验证）
2. **模块化 I/Q 生成**——tone / 2-FSK / chirp / silence / marker 五类生成器，调度器只负责拼装时间轴
3. **依赖感知配置**——事件可声明 `depends_on`，调度器校验依赖序、解析依赖根，把参数扫描裁剪到依赖根事件（对应 FIREQ 减少参数扫描开销）
4. **流式频谱读出**——分帧滑动窗口功率谱（全 FFT 正频率段），供瀑布图/检测消费

**接口**：
```python
sched = WaveformScheduler(sample_rate=1e6)
schedule = sched.build([
    WaveformEvent(EventType.TONE, 2000, {"freq_hz": 100e3, "amplitude": 1.0}),
    WaveformEvent(EventType.FSK, 4000, {"freq0": 100e3, "freq1": 110e3,
                                        "bit_rate": 2e4, "seed": 3, "amplitude": 1.0}),
    WaveformEvent(EventType.CHIRP, 2000, {"f0": 90e3, "f1": 130e3, "amplitude": 0.8}),
    WaveformEvent(EventType.SILENCE, 1000),
])
agg = StreamingSpectrum(1e6).aggregate(schedule.iq)   # 流式频谱聚合
```

**验证**：CLI 输出——总样本 9000（9ms）、事件时间戳 [0,2000,6000]、流式频谱 69 帧、峰值频点 101.6kHz、确定性重建一致 True。

## PF050 · 乘法免费特征提取器

**源论文**：日报 cs.SD Keyword Spotting
**迁移机制**：SDR/ESP32 边缘端做信号分类（KWS/频谱指纹/调制识别）时，FFT 的复数乘法是 MCU 功耗/周期大户。落地一套**零乘法**特征管线（全部只依赖加减、符号比较、计数、阈值）：

- **WHT 系数谱**（Walsh-Hadamard，纯加减蝶形 O(N log N)，系数仅 ±1）
- **零交叉率 ZCR**（符号翻转计数）
- **过零间距统计**（相邻过零样本距均值/方差）
- **峰值计数 / 峰均比**（比较 + 加减）
- **sign 量化指纹**（分块符号占比）

输出 38 维固定特征向量，直接喂质心/kNN/线性分类器。分类器内置 z-score 标准化避免量纲悬殊。

**验证**：4 类合成信号（noise=0.25）分类精度 **90.6%** vs FFT 对照 **100%**——仅差 6 个百分点换取零乘法。无噪声时 100% 持平。
