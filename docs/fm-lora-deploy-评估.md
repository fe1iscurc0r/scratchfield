# K27 DINOv2-LoRA 紧凑模型部署范式 评估

> 来源：round3 digest-g2a 2608.28207（DINOv2-LoRA 糖尿病视网膜分类：预训练大模型 + LoRA 微调 4M 参数级实用精度）
> 交付：评估报告（本文档）。

## 1. 范式

"Foundation Model + LoRA"：冻结预训练大模型主干，只训练 **LoRA 低秩适配器**（rank r，
参数量 ~ r×d×2），在**数据稀缺的垂直场景**以 ~4M 参数级获得 SOTA/竞争性精度。核心是
**主干复用 + 低秩增量**，把微调成本从"全量亿级"降到"千万级可训练参数"。

## 2. 选型矩阵

| 维度 | 选项 | 权衡 |
|---|---|---|
| 主干 | DINOv2 / CLIP / 领域小 ViT | 大主干精度高但边缘推理贵；领域小主干更轻 |
| LoRA rank r | 4 / 8 / 16 / 32 | r 大拟合强但参数多；4M 级对应 r≈8–16 |
| 量化 | FP16 / INT8 / INT4 | 边缘必量化，INT8 精度损失可控 |
| 部署目标 | ESP32 端侧 / 陆墨边缘 / 云端 | 端侧需蒸馏/剪枝后 <1M 参数 |
| 任务 | 分类（热解产物/材料/频谱事件） | 单头分类最易落地 |

## 3. 部署路径

1. **预训练主干 + LoRA 微调**（云端）：冻结主干，LoRA 在垂直数据上微调（4M 级参数）。
2. **LoRA 合并（merge）**：`W' = W + B·A`，把低秩增量合并回主干权重 → 推理无额外分支开销。
3. **量化**：INT8 量化（PTQ）→ 边缘推理；4M 级参数 INT8 ≈ 4 MB，可落 ESP32-S3 外扩 PSRAM。
4. **蒸馏（可选）**：若需 <1M 参数端侧，用合并后的模型蒸馏到小 ViT/MLP（对齐 K14 LVSSM
   蒸馏思路）。
5. **端侧部署**：ESP32（外扩 PSRAM + NPU/定点 DSP）或陆墨边缘推理，对齐 `tools/elm_train.py`
   的定点/查找表推理风格。

## 4. 对自有工具链的适配结论

- **适配度高**：DINOv2-LoRA 的"主干复用 + 低秩微调 + merge + 量化"路径可直接套到
  陆墨/ESP32 的材料识别、频谱事件分类等垂直任务，4M 级参数在 INT8 下 ~4 MB 可边缘部署。
- **关键改造点**：① 提供 LoRA merge + PTQ 量化脚本；② 端侧推理对齐 elm_train 的定点
  风格（把 merge 后权重转定点/查找表）。
- **不引新依赖**：LoRA 为两低秩矩阵乘，numpy 即可原型；推理侧复用现有定点管线。

## 5. 结论

FM+LoRA 是自有工具链"低成本垂直精度"的主流落地范式；建议以"预训练主干（云端）+ LoRA
微调 + merge + INT8 量化 + 定点端侧推理"为默认路径，与 K14 蒸馏形成"LoRA 微调 → 蒸馏 →
定点"的完整紧凑部署链。
