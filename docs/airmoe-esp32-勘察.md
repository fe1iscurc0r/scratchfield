## 1. 结论先行

AirMoE 把「MoE 推理的专家分布到多设备 + 空中计算（AirComp）波形叠加聚合」结合，绕开正交多址上行瓶颈。映射到 ESP32 传感网：每个节点跑一个「专家」（本地信号处理模型：频谱检测/调制识别），网关用**空中聚合**直接叠加各节点结果，替代逐节点上传。**可行性：中高**——适合 ESP32-NOW/LoRa 这类广播型短距链路，但需解决同步与信道失真。

---

## 2. AirMoE 要点（2608.22932）

| 维度 | AirMoE 做法 | ESP32 传感网映射 |
|---|---|---|
| 专家分布 | MoE 专家放各设备 | 各节点跑本地检测/识别专家 |
| 聚合 | AirComp 波形叠加（同频同时） | ESP32-NOW 广播叠加 / LoRa 同频聚合 |
| 两时间尺度 | 快时功率控制 + 慢时专家放置 | 快时功率控制 + 慢时专家(节点)选择 |
| 收益 | 绕过正交上传瓶颈 | 多节点一次聚合，省上行时隙 |

---

## 3. 聚合协议设计

1. **慢时间尺度（专家放置）**：网关按节点能力/信道质量/能耗预算，选择参与本轮聚合的专家子集（节点），周期性（秒级）更新。
2. **快时间尺度（功率控制）**：各节点对本地结果加权（权重由信道/置信度决定），以**对齐的功率**同步发射，网关收到的是**空中叠加的和**（AirComp），直接得到聚合结果。
3. **同步与校准**：网关广播同步帧 + 参考导频，节点校准相位/增益后对齐叠加；网关按叠加结果 + 扰动感知误差度量做鲁棒融合。

---

## 4. 能耗对比（估）

| 方案 | 上行方式 | 时隙/能耗（N 节点） | 说明 |
|---|---|---|---|
| 正交上传（逐节点） | 时分 TDMA | N 个时隙，N×能量 | 逐节点独享时隙 |
| 空中聚合（AirComp） | 同频叠加 | 1 个时隙，N×能量(功率对齐) | 一次叠加聚合 |
| 本地独立（无聚合） | 各算各 | 0 上行，但精度受限 | 无协作 |

> AirComp 的核心收益是**时延/频谱效率**（1 个时隙聚合 N 节点，而非 N 个时隙），能耗量级相当但频谱占用降 N 倍；适合高密度、低速率传感网（如频谱占用上报）。

---

## 5. 落地建议

1. 专家 = 轻量 int8 频谱检测/调制识别（复用 R05/R38 的定点化产物）。
2. 物理层用 ESP32-NOW（免连接广播）或 LoRa 同频 Chirp 叠加做 AirComp。
3. 慢时专家放置复用 R24 资源分配 / R16 跳频的活跃度信息。
4. 扰动感知误差度量：网关对叠加结果的噪声/失真建模，异常节点剔除。
