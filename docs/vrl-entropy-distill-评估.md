# W73-09 VRL + 熵引导蒸馏评估（Agent 自学习）

> 上游：arXiv 2609.01597（VRL 自然语言反馈）+ 2609.01567（熵引导 VLM 蒸馏）· 论文（参考方法）

## 1. 项目定位

两条 Agent 自学习路线：①VRL——用**自然语言作为 Agent 改进反馈通道**（log→feedback→policy）；②熵引导蒸馏——**按不确定性（熵）选择性查询云端教师**，把知识蒸馏到本地策略，省带宽省电。

## 2. 架构拆解

- **VRL**：执行 log → 自然语言反馈 → 策略更新（自然语言作为 RL 奖励信号）。
- **熵引导蒸馏**：本地策略对不确定样本（高熵）才查询云端教师，确定样本本地作答。

## 3. 与本仓对照

| 维度 | 上游 | 本仓 |
|---|---|---|
| 自学习 | 自然语言反馈 + 熵引导蒸馏 | orchestration + W72-10 SLM 路由 + K40 端上推理 |

## 4. 可落地借鉴点（≥3）

1. **自然语言反馈作为改进通道**：把 log 转成自然语言反馈驱动策略改进，可作为 orchestration 的自改进层。
2. **熵引导选择性蒸馏**：本地不确定才问云端，确定本地作答——端上省带宽省电，与 W72-10 SLM 路由互补。
3. **log→feedback→policy 管线**：端上推理的自学习闭环，可作为 K40 端上推理的改进机制。
