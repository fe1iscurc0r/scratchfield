## 一、架构拆解（README 实读）

- 单网关多通道：Discord/iMessage/Slack/Teams/Telegram/WhatsApp 等 20+ 渠道，One Gateway（README.md:18）。
- 状态/记忆/凭证本地化 + 模型与 agent harness 可插拔（README.md:20）。
- 会话/工具/事件/渠道连接由 Gateway 本地控制面统一管（README.md:70-72）。
- 安全模型：入站消息按不可信输入对待，DM 渠道配对需人工 approve（README.md:79）；工具沙箱化（README.md:81）。
