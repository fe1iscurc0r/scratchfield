## 一、m3gnet：材料图网络（晶体/周期体系）

### 1. 能预测什么

- 晶格/晶体结构的形成能、带隙、弹性模量等 DFT 可导属性；
- 作为 DFT 代理：晶体结构松弛（relaxation）+ 属性预测；
- 核心是 3-body（三体）相互作用的图网络，专长**周期/晶体体系**（比 chemprop 更贴晶体）。

### 2. 与 chemprop（已在池）的关系

| 维度 | chemprop | m3gnet |
|------|----------|--------|
| 对象 | 分子图（有机小分子） | 周期晶体图（无机/晶体材料） |
| 强项 | 分子性质、有机/生物分子 | 晶体形成能、带隙、结构松弛 |
| 三体相互作用 | 弱（主要是成对消息） | ✅ 3-body 显式建模 |
| 对生物质（无定形/纤维素/木质素） | ✅ 分子层面适用 | ⚠️ 晶体专长，对无定形适用性有限 |

**结论：互补而非重叠**——chemprop 管「分子/有机」，m3gnet 管「晶体/无机」；二者共同覆盖材料线的分子端与晶体端。

### 3. 结论：**接入（有保留）**

- 接入价值：晶体材料（电解质/催化剂/电极）的属性预测与结构松弛后端。
- 保留：对**无定形生物质**（纤维素/木质素）适用性有限——m3gnet 是晶体图网络，无定形体系需转成近似晶体或用 chemprop 分子路径，此点**标待评估**，不硬接入。

## 二、MDCrow：LLM 驱动分子动力学

### 1. 是什么

LLM agent 驱动 MD 模拟：自然语言描述 → 自动生成模拟配置（力场/温度/时长）→ 执行 MD → 分析结果。抽象层设计把「模拟」封装成 agent 可调用的工具链。

### 2. 与陆墨 Agent 化愿景的关系

- 同构于「Agent 驱动科研」：把 MD 模拟做成 agent 可编排的工具，与陆墨线「材料科研 AI agent」愿景一致。
- 抽象层可借鉴：模拟配置的自然语言 → 参数映射 → 执行 → 分析的四段式，可作为陆墨材料 agent 的「模拟后端」蓝图。

### 3. 结论：**仅参考（对齐愿景，不立即接入）**

- 参考价值：其「LLM→模拟配置→执行→分析」抽象层设计，可直接借鉴到陆墨材料 agent 的模拟后端。
- 不立即接入：依赖成熟 MD 引擎（OpenMM/GROMACS）+ LLM 编排，与现有材料 ML 栈（Ollama/chemprop）不在同一层，先作蓝图登记。

## 三、结论汇总

| 项目 | 结论 | 理由 |
|------|------|------|
| m3gnet | **接入（有保留）** | 晶体/无机属性预测，与 chemprop 互补；无定形生物质适用性待评估 |
| MDCrow | **仅参考** | LLM 驱动模拟抽象层，对齐愿景但依赖重，先作蓝图 |
