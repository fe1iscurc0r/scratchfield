## 二、核心数据结构共鸣（附源行号）

1. **力分解三件套**：源把蛇每步位移拆为外力求和——`AddExternalForce`（:539，图像梯度）与 `AddStretchingForce`（:551，顶点间距保持）汇入 `ComputeRHSVector`（:532）线性系统；本探针 `snake_step` 以「拉伸 + 弯曲 + gamma×梯度」三力叠加的显式形式复刻同一分解，拉伸力用 rest-length 形式（间距>静息长吸引、<静息长排斥），对应源 Resample（:73）保持顶点均匀的意图。
2. **种子初始化走梯度场**：源 `InitializeSnakes`（:438）先 `ScanGradient` 找脊线再生成候选蛇；本探针 `trace_ridge` 的逼近态沿梯度行走，且用「梯度方向翻转=越过脊线」判定切入贴脊态（沿切线行走）——把源的「先检测后沿丝方向生长」压缩为两态种子行走。
3. **网络拓扑=交叉点+端点**：源 `junctions.cc:75-80` 从蛇端点位（`(*it)->position()`）收集交叉点；本探针 `network_stats` 用 8 邻域环交叉数（cn）分类端点/段点/交叉点，是同一拓扑语义在像素骨架上的稳健近似。
4. **参数集中命名**：源 `multisnake.cc:254-255` 用 `stretch-factor` 名称路由到 `Snake::set_stretch_factor`；本探针对应参数命名为 `rest_len`/`alpha` 并在 docstring 说明映射，保留语义可追溯。

- 难度：★★★（蛇模型力平衡 + 脊线追踪两态 + Zhang-Suen 细化，纯 numpy 无形态学库，约 200 行）
- 收益：★★☆（凝胶/SDR 荧光纤维网络量化通道从零打通；骨架统计可直接复用于其它图像网络分析）

## 四、借鉴点清单（≥3）

1. 蛇演化力模型的三力分解（外部图像力/拉伸力/弯曲力）与静息长度保距——借鉴自 `snake.cc:539/551`。
2. 梯度扫描初始化 + 「方向翻转即越脊」的脊线贴行两态机——借鉴自 `multisnake.cc:438/667` 的初始化-演化两段流程。
3. 交叉点/端点拓扑统计（交叉数分类）——借鉴自 `junctions.cc:75-80` 的拓扑语义。
4. 参数命名与源保持一致（stretch-factor → rest_len），便于回查对照——工程习惯借鉴。
