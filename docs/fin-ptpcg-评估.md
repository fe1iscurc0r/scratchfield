## 1. 项目定位

论文《基于 Fin-BERT 的中文金融领域事件抽取方法》（CNKI）官方代码：
在 PTPCG（跨句触发词语义图）基础上加 Fin-BERT 编码器。附可视化交互页面与

要点：
- **跨句触发词语义图**（PTPCG 核心）：文档级事件抽取里跨句证据的组织方式——
  对材料文献 EE（实验记录跨句因果）有方法学参考价值。

  材料领域可照此做「Mat-BERT」路线评估（本仓已有材料文献语料）。

## 3. 领域迁移评估（金融 → 通用/材料）

| 维度 | 金融（Fin-PTPCG） | 材料（本仓目标） |
|---|---|---|
| 触发词跨句 | 强需求（新闻叙事） | 强需求（实验记录因果链） |
| 领域编码器 | Fin-BERT（公开） | 无公开 Mat-BERT → 需自训或换通用中文 BERT |
| 标注 schema | 金融事件类型 | 需自定义（工艺/表征/性能事件） |
| 数据量 | 万级新闻 | 本仓 ELN/文献千级 → 小样本路线（few-shot） |

结论：**方法学可迁移（跨句图 + 领域编码器范式），代码不融合（无 LICENSE）**；
材料 EE 优先走 DeepKE + 小样本，跨句图作 P2 研究项。
