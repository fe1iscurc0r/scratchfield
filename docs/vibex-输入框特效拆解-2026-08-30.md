## 一、结论

VibeX 主输入框（.main-prompt）的特效不是单一效果，是 7 层叠出来的：
极光光斑 + 玻璃拟态容器 + 打字光标 + Logo 辉光 + 背景星空 + 流星雨 + shimmer。

## 二、核心：极光输入框

### 1. 玻璃拟态容器

```css
.main-hero-intro .main-prompt {
  min-height: 72px;
  border-radius: var(--radius-input);
  background: linear-gradient(#ffffff13,#ffffff0b), #07080ad6; /* 半透明白渐变叠深色底 */
  backdrop-filter: blur(18px) saturate(145%);                  /* 毛玻璃 + 提饱和 */
  box-shadow:
    inset 0 0 0 1px #ffffff17,   /* 1px 白描边 */
    inset 0 1px #ffffff14,       /* 顶部内高光 */
    0 32px 110px #00000085,      /* 大投影悬浮感 */
    0 0 70px #1d9bf012;          /* 蓝色外发光 */
}
```

### 2. 极光光斑（伪元素 + CSS 变量动画，灵魂）

```css
.main-hero-intro .main-prompt::before {
  content: "";
  z-index: -1;                   /* 特效层在内容下方 */
  position: absolute;
  top: -1px; bottom: -1px; left: -1px; right: -1px;
  background:
    radial-gradient(circle at var(--prompt-x,18%) var(--prompt-y,18%),
      #72c7ff29, transparent 34%),                          /* 移动的蓝色光斑 */
    linear-gradient(115deg, transparent 0%, #ffffff17 34%, transparent 58%); /* 斜扫光带 */
  opacity: .72;
  animation: 7s ease-in-out infinite alternate mainPromptAurora;
}

/* 关键：动画的是 CSS 变量，不是元素位置 */
@keyframes mainPromptAurora {
  0% { --prompt-x: 14%; --prompt-y: 18%; filter: hue-rotate(0); }
  to { --prompt-x: 84%; --prompt-y: 72%; filter: hue-rotate(12deg); }
}
```

精妙点：
- 光斑位置由 `--prompt-x / --prompt-y` 两个 CSS 变量驱动，keyframes 里直接动画变量
- 伪元素只写一次 `circle at var(...)`，一套 keyframes 同时驱动光斑移动 + 色相漂移
- 7s 慢速 ease-in-out alternate 来回扫，hue-rotate 12° 产生极光流动感
- 实际是双层伪元素（一层 #72c7ff 蓝、一层 #7bd7f6 青）叠出双色极光

## 四、可复用技巧（三条）

1. **CSS 变量动画**：keyframes 里动画自定义属性（--prompt-x 等），一套 keyframes 驱动多个渐变层，比动画 transform/opacity 更灵活
2. **玻璃拟态三件套**：backdrop-filter blur + 半透明白渐变底 + inset 白描边/高光，成本低效果好
3. **伪元素 z-index:-1 + 绝对定位撑满**：特效层与内容层分离，互不干扰

## 五、复用建议

- hamlog 仪表盘输入框 / PanelView 搜索框可用同一套极光输入框风格
