# W70-06 · RS41ng 评估（无线电探空仪固件）

> 2026-09-02 · 第二十四期三榜单扫描批 · 勘察/评估（不写实现）
> 上游：mikaelnousiainen/RS41ng（GPL-2.0，190★，C，2026-08-29 活跃）

## 一、项目定位

Vaisala RS41 / Graw DFM-17 无线电探空仪（气象探测气球载荷）的**自定义固件**：替换原厂固件，支持业余频率发射遥测（温度/气压/湿度/GPS 定位），供业余无线电/气象爱好者追踪与自组探空。GPL-2.0、C 语言、活跃维护。

## 二、架构拆解

- 硬件抽象：RS41/DFM-17 主控（STM32 类）+ 射频前端 + 传感器（温湿压/GPS）。
- 遥测编码：气象数据打包 → 数字调制 → 业余频段（如 70cm）发射。
- 协议：支持多种下行编码（RS41 原生/DFM 格式 + 自定义），GPS 定位上报。
- 低功耗：探空仪电池续航、周期性遥测。

## 三、与本仓对照

| 维度 | rtl_433 哨兵（W66-04） | RS41ng |
|------|------------------------|--------|
| 角色 | 接收/解码（SDR 侧） | 发射/固件（载荷侧） |
| 频段 | 433/868 等 ISM | 业余频段（70cm 等） |
| 协议 | rtl_433 解码库 | RS41/DFM 原生 + 自定义 |
| 许可 | （已有） | GPL-2.0（只参考不融合） |

结论：**互补**——rtl_433 做「接收解码哨兵」，RS41ng 提供「发射端遥测协议」参考，二者可拼成「自组探空 + 地面解码」闭环。

## 四、可落地借鉴点（≥3）

1. **遥测帧编码设计**：气象数据（温湿压/GPS）打包 → 调制 → 业余频段发射，可借鉴到 SDR 哨兵的气象遥测**发射/解码**帧结构。
2. **业余频段合规发射**：RS41ng 支持业余频率，其「占空比/频率合规」约束可借鉴到本仓 LoRa 发射侧的法规遵循。
3. **探空仪遥测解码类别**：RS41/DFM 协议解码可补 rtl_433 的气象遥测类别（目前哨兵偏消费类传感器），扩展 SDR 哨兵的气象探测覆盖。

## 五、互补判定 + 许可裁定（已修正）

- **互补判定**：与 rtl_433 哨兵互补——RS41ng 补「气象探空遥测」的发射端协议与解码类别，不重复 rtl_433 已覆盖的消费类传感器。
