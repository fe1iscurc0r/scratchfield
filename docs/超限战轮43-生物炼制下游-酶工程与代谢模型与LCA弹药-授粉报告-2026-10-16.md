## §5 · 核心数据结构共鸣（最值钱的 3 处）

1. **CataPro 的输入三元组 `(蛋白序列, 底物 SMILES, 条件)` → 输出 `(kcat, Km, kcat·Km⁻¹)`**
   这与我们已有的**化学式解析**（ChemFormula → `{H:2,S:1,O:4}`）是同一类「字符串 → 结构化数值」问题，但维度更高：化学式是无条件常量，酶参数是**依赖序列+底物+条件的函数值**。这意味着授粉不是「再加一个解析器」，而是**给现有语料加一件「函数式条目」的新数据形态** —— 这是本轮最值钱的结构发现。
2. **memote 的 `model → test suite → 通过-不通过 报告`**
   与 `scripts/anti_hallucination_guard.py` 的 `report → FAIL 与 WARN` 是**同构闸门**：都是「拿一个可执行的不变量集合去审计一个产物」。区别只在被审对象（GEM vs 报告）。可直接抄它的分层设计（consistency / annotation / stoichiometry 分组）。
3. **metaGEM 的「MAG → GEM → 群落互作矩阵」链**
   与拉工单流程的「候选 → 分类 → 落点矩阵」结构同源：**都是把非结构化的原始集合（基因组 / 候选仓库）压成结构化的关系矩阵**。价值在于它的**中间产物全部落盘为可复算的中间格式**（MAG 表、GEM sbml、互作 tsv）—— 这正是我们工单台账想要的「每步可复核」特性。
