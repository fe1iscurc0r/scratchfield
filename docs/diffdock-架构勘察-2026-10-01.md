## 一、扩散 pose 迭代精化的 pipeline

```
输入                          扩散精化（T 步反向扩散）                    输出
─────────                    ────────────────────────────              ─────────
蛋白: .pdb 或序列             平移(translation)                          最终 pose
（无结构时 ESMFold 折叠）  →   旋转(rotation)      ──→ 置信度模型      →  (pose + confidence)
配体: SMILES/.sdf/.mol2       扭转角(torsion angles)                     排名
        │                            ↑↓ N 步迭代去噪
        └── 图网络编码（蛋白口袋 + 配体构象图，e3nn 等变图网络）──┘
```

**迭代精化范式**（与轮24 KG-RAG 迭代检索的同构性）：两者都是
「**粗候选 → 多步"评分-修正"循环 → 收敛解**」——DiffDock 从随机 pose 出发经
T 步反向扩散逐步精化（每步用等变图网络预测平移/旋转/扭转的更新量）；
KG-RAG 从粗检索出发经多轮"检索-重排-补充查询"精化上下文。**差异**在状态空间
（连续几何 vs 离散文档集合）与收敛判据（置信度 vs 检索分数饱和），范式同源——
若做统一的"迭代精化调度器"（工单卷174 的 `--decide` 方向），两者可作为同一
抽象的两个实例。

**推理入口（实测）**：
```
python -m inference --config default_inference_args.yaml \
    --protein_ligand_csv data/protein_ligand_example.csv --out_dir results/...
```
配体输入：SMILES 或 RDKit 可读的 `.sdf/.mol2`；蛋白输入：`.pdb` 或氨基酸序列
（无结构时自动经 **ESMFold** 折叠——无需实验结构即可对接，重要能力）。

## 三、打分差异表（DiffDock vs dockstring vs AutoDock Vina）

| 维度 | **DiffDock**（生成式） | **dockstring**（Vina 封装基准） | AutoDock Vina（经典经验） |
|---|---|---|---|
| 输出 | pose（坐标）+ 置信度（−log conf） | **docking score**（Vina affinity，kcal/mol） | 同 Vina score |
| 方法 | 扩散生成 pose（无物理力场） | AutoDock Vina 打分函数 | 经验打分函数 + 局部搜索 |
| 依赖 | PyTorch + e3nn + **GPU 推荐** + 权重 ~GB | vina 可执行/Python 绑定（CPU 即可） | CPU 即可 |
| 对刚性蛋白 | 无需已知结合位点（盲对接能力，DiffDock-L 显著提升） | 需指定口袋（或全表面） | 需指定口袋 |
| 速度 | 数秒~数十秒/复合体（GPU） | 秒级/配体（CPU） | 秒级/配体 |
| 适用 | **无已知口袋** / 蛋白无结构（ESMFold）| **基准打分标尺**（benchmark 数字可比） | 传统虚拟筛选 |

## 四、「小分子-木质素酶对接」落点评估

- 木质素降解酶系（漆酶/过氧化物酶类）**多有实验结构或同源模型**——dockstring 的
  Vina 打分路径（CPU、秒级）**先做基准**：3 个木质素衍生单体（香草醛/阿魏酸/丁香酸）
  × 2~3 个靶点的 score CSV（卷169-B）
- DiffDock 的价值在**盲对接**（酶结构未知时 ESMFold 折叠 + 生成 pose）——
  **无 GPU 时标注待真机**（工单允许），报告先行
- **双引擎组合**：DiffDock 出 pose（几何）→ dockstring/Vina 打分（能量）→
  交叉验证（pose 评分一致性是 pose 质量的经典校验）
