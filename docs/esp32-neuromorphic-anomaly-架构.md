# ESP32 神经形态异常检测 · 架构文档

> 来源工单：R11 · 分组 group1-无线电
> 参考 digest：[digest-gx-1-2026-08-30.md](../paper-round2-2026-08-30/digests/digest-gx-1-2026-08-30.md)（授粉点 3 · 论文 18341 Loihi 2 神经形态 autoencoder）
> 日期：2026-08-30

---

## 1. 结论先行

Loihi 2 神经形态 autoencoder 的核心不是「换硬件」，而是**「无事不计算」的事件驱动范式**（动态能耗仅 0.04 mJ/sample，比 CPU/GPU 低两个数量级）。这一范式可移植到 ESP32-S3，但**无需真正的脉冲神经网络**——用「事件触发 + 稀疏自编码器 + SIMD 定点」即可拿到大部分收益，且能跑在现成硬件上。

**推荐形态**：ESP32-S3 + 事件触发门控 + 稀疏 autoencoder（int8 定点 + SIMD），异常时唤醒全精度重判，常态只跑稀疏前向。

---

## 2. Loihi 2 范式要点（18341）

| 维度 | Loihi 2 做法 | ESP32 等价物 |
|---|---|---|
| 事件驱动 | 仅在有事件时计算 | 阈值触发：谱帧变化量 < ε 则跳过推理 |
| 稀疏激活 | 脉冲稀疏 | 稀疏权重 + ReLU 稀疏激活 |
| 低功耗 | 0.04 mJ/sample | int8 定点 + SIMD，避免浮点 |
| 异常检测 | autoencoder 重建误差 | 稀疏 autoencoder 重建误差 |

---

## 3. 架构设计

```
频谱帧 x ∈ R^N（R01/R03 输出）
        │
   [事件门控]  ‖x - x_prev‖ < ε 且无事件 → 跳过（省电 90%+）
        │ 通过
   [编码器]  1D-CNN/MLP，int8 定点，稀疏激活 → 潜码 z ∈ R^d（d≪N）
   [解码器]  对称重建 x̂
        │
   [异常分]  e = ‖x - x̂‖²  →  e > 阈值 → 异常（唤醒全精度重判）
```

- **稀疏自编码器**：单隐层（或 1D-CNN），权重 ≥ 80% 稀疏（剪枝），ReLU 激活天然稀疏。
- **事件驱动**：连续帧间差异小则直接复用上一帧结论，不重算。
- **推理引擎**：int8 对称量化 + ESP32-S3 的 SIMD（ESP32-S3 有 Vector 扩展指令集）。

---

## 4. 推理复杂度估算

以输入频谱 N=128、潜码 d=16、单隐层 autoencoder（W: 128→16→128）为例：

| 项 | 计算量 | 备注 |
|---|---|---|
| 编码器 MACs | 128×16 = 2048 | 每帧 |
| 解码器 MACs | 16×128 = 2048 | 每帧 |
| 总 MACs/帧 | ~4096 | 忽略激活/偏置 |
| 稀疏（80% 剪枝后） | ~820 | 稀疏权重跳过 |
| int8 SIMD | ~820/16 ≈ 52 条 SIMD 指令 | 16×int8/指令 |
| 事件门控命中率 | 90%+ 帧直接跳过 | 常态省 10× |

**结论**：常态每帧 < 100 条指令量级，可满足 ≤10Hz 频谱监测的实时性，功耗较全浮点 DNN 低 1~2 个数量级。

---

## 5. 与 DNN 对比表

| 维度 | 全浮点 DNN autoencoder | ESP32 神经形态范式（本设计） |
|---|---|---|
| 参数精度 | fp32 | int8 |
| 权重密度 | 100% | ≤20%（剪枝稀疏） |
| 常态计算 | 每帧全量 | 事件门控跳过 90%+ |
| MACs/帧 | ~8192（fp32） | ~820（int8 稀疏） |
| 功耗 | 高（浮点 + 全量） | 低（定点 + 稀疏 + 事件） |
| 异常召回 | 高 | 相当（重建误差等价） |
| 硬件要求 | 需加速器 | 现成 ESP32-S3 |

---

## 6. 落地建议

1. 离线训练密集 autoencoder（PC），剪枝 + int8 量化 → 稀疏 int8 权重表。
2. ESP32-S3 上实现稀疏 int8 前向 + SIMD，事件门控复用上一帧结论。
3. 异常分阈值离线标定（纯噪声数据），超阈唤醒全精度重判/上报。
