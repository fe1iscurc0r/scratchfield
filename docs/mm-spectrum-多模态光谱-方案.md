# MM-Spectrum 多模态光谱→结构推断 · 方案（M28）

> 工单：M28 MM-Spectrum 多模态光谱→结构（P1）
> 授粉源：`digest-g1-4-2026-08-30.md` 2608.27286（MM-Spectrum: Multimodal Multi-spectral Molecular Structure inference）
> 落点：陆墨（生物质/水凝胶结构表征）
> 交付：本方案 + 原型 `tools/mm_spectrum_fusion.py`（特征拼接基线，pytest 2 用例全绿）
> 验收：合成光谱数据集结构推断准确率 ≥70% —— 实测 **融合 100%，单模态 19~21%**

---

## 1. 目标

用红外(IR)+质谱(MS)+NMR 三模态联合推断未知分子结构。核心价值在「互补」：
IR 提供官能团信息、MS 提供分子量/碎片、NMR 提供原子连接性——任一单模态都只给
部分线索，融合后才能唯一确定结构。这正是生物质/水凝胶组分表征（纤维素/木质素/
半纤维素及其衍生物）的痛点。

## 2. 方法（特征拼接基线）

```
IR 谱 ──离散成 N 个 bin 强度向量──┐
MS 谱 ──离散成 N 个 bin 强度向量──┼─→ 拼接 (3N 维) ─→ 线性 softmax 分类 → 结构类
NMR 谱 ──离散成 N 个 bin 强度向量─┘
```

- **离散化**：每模态谱按波数/m/z/ppm 分成 N 个 bin，取峰强度（或归一化强度）为特征。
- **融合**：特征拼接（最简基线，证明「融合优于单模态」即可；后续可换轻量注意力融合）。
- **分类**：线性 softmax（numpy 手写，无外部依赖），输出结构类标签。

## 3. 合成数据与诚实标注

无真实谱数据，用合成 surrogate（显式 mock）：每类分子编码为 3-bit 结构签名
（IR 编码 bit0、MS 编码 bit1、NMR 编码 bit2），每模态谱 = 一个强峰 + 底噪。真实
IR 波数（O-H~3300、C=O~1700 等）/ MS m/z / NMR ppm 峰位可直接替换 bin 位置，
方法链路不变。

## 4. 实测结果（8 类结构，softmax，70/30 划分）

| 模态 | 准确率 |
|---|---|
| IR 单模态 | 21.4% |
| MS 单模态 | 19.8% |
| NMR 单模态 | 19.3% |
| **三模态融合** | **100%**（≥70% 验收线） |

单模态 ~20% 对应「只能解出 1 bit、在 4 个候选里瞎猜」的上限；融合后 3 bit 全解出，
8 类全分离 → 100%。证明了多模态互补的必要性。

## 5. 落地路径

1. **真实谱替换**：用陆墨实测 IR/MS/NMR 谱替换合成 bin，训练同一个拼接+softmax 管线。
2. **融合升级**：特征拼接 → 轻量注意力/门控融合（弱模态锚定主模态，见 g1-4 授粉点 ③
   strong-modality collapse 教训），但先以拼接基线锁住「融合有用」的结论。
3. **结构粒度**：从「结构类标签」扩展到「子结构/官能团多标签」，输出可解释的结构片段。
4. **与 M27 协同**：分子 FM 的表征可作为第四模态或拼接后特征，进一步提精度。

## 6. 诚实降级

- 精度是**合成谱**上的结果，真机以实测谱复评；8 类为演示粒度，真实结构空间更大。
- 线性 softmax 是最简分类器，未做谱预处理（基线校正/归一化/峰对齐），真实数据需补。
- 特征拼接是基线，不主张其优于更复杂融合；本原型用于证明「多模态互补」这一前提成立。
