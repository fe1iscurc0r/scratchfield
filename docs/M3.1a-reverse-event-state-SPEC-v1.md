## 〇、一句话定位

让 NEKO → 陆墨的反向事件从「只审计」变成「产生状态感知」，供陆墨下次对话时参考。**全程零 LLM 调用**（纯逻辑分流，token 零开销）。

## 一、背景与边界

### 现状
反向端点 `lumo_event.py` 已打通：6 类事件（`user_input` / `asr_result` / `tts_start` / `tts_end` / `user_action` / `error`）收到后完成「时效校验 + event_id 去重 + 审计日志」，但第 4 步 `[TODO M3.1] 投递到陆墨决策回路` 至今空置（`lumo_event.py:207`）。

### 本 SPEC 做什么 / 不做什么

| 做 | 不做 |
|----|------|
| 事件分流（按类型，纯逻辑） | 主动搭话时机决策（M3.1b，需 LLM） |
| 用户状态快照存储（短时，内存态） | 实际切纯文本降级动作（涉及 NEKO 侧配置） |
| error 事件降级标记 | 改 message_manager 持久化结构 |
| 状态快照注入下次对话（environment_snapshot） | 任何 LLM 调用 |

**关键原则：非侵入旁路**。不改 `lumo_event.py` 现有的校验/去重/审计逻辑，只在第 4 步 TODO 位置追加分流调用。

## 二、架构设计

```
NEKO 事件 → lumo_event.py（已有：校验+去重+审计）
                    ↓ [第4步新增]
              事件分流器（无 LLM）
              ├── 状态类（5 类）→ lumo_state.update()
              ├── error       → lumo_state.mark_error()
              └── 无 LLM 调用，零 token

下次对话时：
lumo_proxy.py → lumo_state.get_snapshot(session_id)
             → build_context_supplement(environment_snapshot=快照文本)
             → 注入 tier4 prompt
```

### 组件清单

| 组件 | 文件 | 类型 | 说明 |
|------|------|------|------|
| 状态存储 | `apiserver/routes/lumo_state.py` | 新建 | 内存态 LumoStateStore，TTL 清理 |
| 事件分流 | `lumo_event.py` 第 4 步 | 修改 | 追加 5 行左右分流调用 |
| 快照注入 | `lumo_proxy.py` | 修改 | 查快照 → 传 environment_snapshot |

## 三、施工步骤

### 步骤 1：新建 `apiserver/routes/lumo_state.py`

```python
"""NEKO 反向事件 → 用户状态快照（短时，内存态，零 LLM）。

与 message_manager 解耦：状态快照是「最近几分钟用户在 NEKO 侧做了什么」的
短时感知，不需要跨重启持久化，因此独立内存 dict + TTL 清理。
"""
from __future__ import annotations

import time
from dataclasses import dataclass, field
from typing import Optional

# 快照 TTL：超过此秒数的状态视为过期，get_snapshot 返回空串
_STATE_TTL_SECONDS = 600  # 10 分钟
# 注入文本里 user_input/asr_result 的截断长度（控 token）
_TEXT_SNIPPET_LEN = 120


@dataclass
class LumoState:
    last_user_input: Optional[str] = None       # 最近用户输入文本（截断）
    last_user_input_at: Optional[float] = None
    last_action: Optional[str] = None           # 最近 UI 操作（switch_character/stop_playback/...）
    last_action_at: Optional[float] = None
    tts_interrupted: Optional[bool] = None      # 最近一次 TTS 是否被打断
    last_error: Optional[str] = None            # "severity:error_type"
    last_error_at: Optional[float] = None

    def _fresh(self, ts: Optional[float]) -> bool:
        return ts is not None and (time.time() - ts) <= _STATE_TTL_SECONDS

    def render(self) -> str:
        """渲染为注入 environment_snapshot 的文本；全部过期返回空串。"""
        lines: list[str] = []
        if self._fresh(self.last_user_input_at) and self.last_user_input:
            lines.append(f"- 最近输入：「{self.last_user_input}」")
        if self._fresh(self.last_action_at) and self.last_action:
            lines.append(f"- 最近操作：{self.last_action}")
        if self.tts_interrupted is not None and self._fresh(self.last_error_at if self.tts_interrupted else self.last_action_at):
            lines.append("- 语音：上次播放被用户打断")
        if self._fresh(self.last_error_at) and self.last_error:
            lines.append(f"- 身体状态：{self.last_error}（已上报异常）")
        if not lines:
            return ""
        return "【NEKO 侧用户状态】\n" + "\n".join(lines)


class LumoStateStore:
    """进程内快照存储，key = session_id。非线程安全，仅在 asyncio 单线程下使用。"""

    def __init__(self) -> None:
        self._states: dict[str, LumoState] = {}

    def _get(self, session_id: str) -> LumoState:
        return self._states.setdefault(session_id, LumoState())

    def update(self, session_id: str, event_type: str, payload: dict) -> None:
        """按 event_type 分流更新状态。无 LLM，纯字段写入。"""
        st = self._get(session_id)
        now = time.time()
        if event_type == "user_input":
            text = (payload.get("text") or "")[:_TEXT_SNIPPET_LEN]
            st.last_user_input = text
            st.last_user_input_at = now
        elif event_type == "asr_result":
            # 与 user_input 冗余，只在 voice 来源时补一条（confidence 低不覆盖）
            if (payload.get("confidence") or 0) >= 0.5:
                text = (payload.get("text") or "")[:_TEXT_SNIPPET_LEN]
                st.last_user_input = text
                st.last_user_input_at = now
        elif event_type == "user_action":
            st.last_action = payload.get("action") or payload.get("detail")
            st.last_action_at = now
        elif event_type == "tts_end":
            if payload.get("interrupted"):
                st.tts_interrupted = True
        elif event_type == "tts_start":
            st.tts_interrupted = False
        # error 走 mark_error，不在此分支

    def mark_error(self, session_id: str, severity: str, error_type: str) -> None:
        st = self._get(session_id)
        st.last_error = f"{severity}:{error_type}"
        st.last_error_at = time.time()

    def get_snapshot(self, session_id: str) -> str:
        st = self._states.get(session_id)
        if not st:
            return ""
        return st.render()

    def gc(self) -> None:
        """清理 TTL 过期条目，防内存无界增长。可挂到低频定时器或懒触发。"""
        cutoff = time.time() - _STATE_TTL_SECONDS
        stale = [k for k, v in self._states.items()
                 if not (v._fresh(v.last_user_input_at) or v._fresh(v.last_action_at)
                         or v._fresh(v.last_error_at))]
        for k in stale:
            del self._states[k]


# 模块级单例（与 message_manager 单例同风格）
_state_store = LumoStateStore()


def get_state_store() -> LumoStateStore:
    return _state_store
```

## 四、关键假设与 fallback

### 假设 1：neko_session == 陆墨 session_id
正向调用（`lumo_proxy` 的 `request.session_id`）与反向推送（`lumo_event` 的 `neko_session`）是同一个 NEKO 会话 ID。

**验证方法**：curl 打 `lumo_event` 时带一个已知 session_id，再调 `lumo_proxy` 用同 ID，观察快照是否命中。

**fallback**：若验证不符，则在 `lumo_state.py` 加一个 `neko_session → lumo_session` 别名映射（内存 dict），由 `lumo_proxy` 首次调用时登记。SPEC 初版先按「同 ID」实现，验证失败再补映射。

### 假设 2：状态快照不需要跨重启
快照是「最近 10 分钟」的短时感知，重启丢失可接受。若未来需要跨重启，再迁入 message_manager 持久化（不在本 SPEC 范围）。

## 五、已知限制（诚实标注）

1. **不触发主动搭话**：本 SPEC 只让陆墨「感知」，不「主动开口」。主动搭话时机决策（M3.1b）需 LLM 参与，另行 SPEC。
2. **降级只标记不切换**：`error` 事件打标记、注入提示，但**不实际切换纯文本模式**——那需要改 NEKO 侧 provider 配置，超出本 SPEC。
3. **单进程内存态**：状态存内存，多实例/重启即丢。当前部署是单机单实例（蓝图 v1.1 决策 D6），可接受。
4. **`tts_interrupted` 的 TTL 借用**：`render()` 里 `tts_interrupted` 用 `last_action_at` 或 `last_error_at` 做新鲜度判断（无独立时间戳），够用但不精确。若要精确，`LumoState` 加 `tts_interrupted_at` 字段。

## 六、测试用例（云服可直接跑，纯 Python）

在 `apiserver/routes/` 下临时脚本或 `python -c` 验证：

```python
# 1. 状态更新 + 渲染
from apiserver.routes.lumo_state import get_state_store, _STATE_TTL_SECONDS
s = get_state_store()
s.update("s1", "user_input", {"text": "帮我查一下木质素水凝胶", "confidence": 1.0})
s.update("s1", "tts_end", {"interrupted": True})
s.mark_error("s1", "fatal", "tts_engine_down")
snap = s.get_snapshot("s1")
assert "木质素" in snap and "打断" in snap and "fatal:tts_engine_down" in snap
print("PASS 1:", snap)

# 2. TTL 过期 → 空串
import time
s2 = get_state_store()
s2.update("s2", "user_action", {"action": "stop_playback"})
s2._states["s2"].last_action_at = time.time() - _STATE_TTL_SECONDS - 1
assert s2.get_snapshot("s2") == ""
print("PASS 2: TTL 过期返回空串")

# 3. error 与状态互不污染
s3 = get_state_store()
s3.mark_error("s3", "warn", "asr_retry")
assert "asr_retry" in s3.get_snapshot("s3")
print("PASS 3: 错误标记生效")
```
