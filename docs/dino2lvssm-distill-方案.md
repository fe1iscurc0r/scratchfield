# DINOv2 → LVSSM 跨架构蒸馏 · 方案（K14）

> 工单：K14 DINOv2→LVSSM 跨架构蒸馏（P1）
> 授粉源：`digest-g2-4b-2026-08-30.md` 蒸馏授粉点（DINOv2 教师 → 轻量状态空间模型学生，带门控双向选择扫描块，4.45M 学生保留 98.3% 精度）
> 落点：`tools/dino2lvssm_distill.py`（离线教师 logit 蒸馏骨架，可跑通）
> 验收：方案含参数量/内存/精度预算表；骨架可跑通 logit 蒸馏流程 —— 已跑通（损失 0.0183→0.0015）

---

## 1. 目标

把大型预训练视觉模型（DINOv2）的知识，经**离线 logit 蒸馏**迁移到轻量异构模型
（LVSSM：轻量视觉状态空间模型，SSM 混合 CNN），落到 ESP32-S3 端侧推理。参考指标：
4.45M 学生保留 98.3% 教师精度。

## 2. 蒸馏管线

```
离线阶段（主机）:
  冻结教师 DINOv2(ViT) ──前向──> 软 logits（温度 T 软化）
  学生 LVSSM(4.45M) ──前向──> logits
  L = KL( softmax(teacher/T) ‖ softmax(student/T) ) × T²
  → 反向传播更新学生（教师不更新）

部署阶段（ESP32-S3）:
  学生 int8 量化 → 仅前向推理（无教师、无反向）
```

骨架 `tools/dino2lvssm_distill.py` 已实现该闭环：`Teacher`（冻结 CNN 占位，可替换为真实
DINOv2 的 `forward` 语义）→ `distill_loss`（Hinton KL）→ `LVSSM`（patch 嵌入 + 门控双向
选择扫描块 + 分类头）。

演示升级为「有信号教师 → 精度保留」：教师先在合成 4 类任务（全亮/全暗/白噪声/中灰）上
预训练到 **100% 测试精度**，冻结后经 logit 蒸馏，学生 LVSSM 蒸馏后精度 **100%（保留率 1.00）**，
蒸馏损失 6.08→0.76。`--full`（width=384，1.28M 参数）同路径可跑（扫描逐时间步离散化，内存
有界，不再物化 (B,L,D,S) 大张量）。

## 3. 学生架构（LVSSM）

- **Patch 嵌入**：图像 → 非重叠 patch → 线性嵌入到 `D` 维。
- **门控双向选择扫描块**（`SelectiveScan`）：对角状态矩阵 `A`（对数空间学习、负初始化保稳定）、
  输入相关的 `B/C/Δ`（「选择」）、SiLU 门控 `z`；正反各扫一次取均值（双向）。
- **残差 + LayerNorm + 全局平均池化 → 分类头**。

这是对论文「带门控双向选择扫描块」的工程简化（机制一致、非逐字复刻）。

## 4. 预算表（参数量 / 内存 / 精度）—— 验收项

| 模型 | 参数量 | 权重内存（int8） | 权重内存（fp32） | 精度（ImageNet 参考） | 说明 |
|---|---|---|---|---|---|
| DINOv2 ViT-S（教师） | 22M | 22 MB | 88 MB | 基线 100% | 只做离线软目标 |
| DINOv2 ViT-B（教师） | 86M | 86 MB | 344 MB | 基线（更高） | 可选更强教师 |
| **LVSSM 学生（论文参考）** | **4.45M** | **4.45 MB** | 17.8 MB | **98.3%** | 目标部署形态 |
| 骨架 small（本仓，4 类演示） | 98K | 0.10 MB | 0.39 MB | — | CPU 秒级演示 |
| 骨架 full（本仓，width=384，4 类演示） | 1.28M | 1.28 MB | 5.11 MB | — | 同代码路径更大规模 |

**ESP32-S3 可行性判定**：
- 4.45M 学生 int8 权重 ≈ 4.45 MB，落在 ESP32-S3 外部 PSRAM（8/16 MB）内；**必须 int8 量化**，
  fp32（17.8 MB）超出常见 PSRAM 配置。
- 推理内存峰值 ≈ 权重 + 激活（激活随分辨率缩放，低分辨率 64×64 输入时 < 1 MB）。
- 计算：SSM 扫描为顺序依赖，ESP32-S3 用 ESP-DL/ESP-NN int8 加速「线性层 + patch 嵌入」，
  扫描循环在低 token 数（≤256）下可实时（约十 ms/帧量级），逐帧视觉任务可行、视频流需分块。

## 5. 与既有工程衔接

- 独立工具，不侵入 `mcpserver`/`frontend`；后续可作为 `mcpserver/rf_brain` 的视觉感知前处理
  或独立端侧视觉节点接入。
- 与 K15（AI 生成 RTL）互补：K15 解决「端侧视觉加速器怎么来」，本项解决「端侧视觉模型怎么轻」。

## 6. 诚实降级与未验证项

- 骨架教师是「冻结小 CNN 占位」，未加载真实 DINOv2 权重；软目标分布与真实教师不同，但蒸馏
  机制、损失、更新路径完全一致——真实教师替换 `Teacher.forward` 即可。
- 98.3% 是论文参考值，本骨架未复现到该精度（需真实数据集 + 完整训练）；预算表按论文给出，
  骨架 `--full` 为 1.28M 的同路径演示。骨架在合成 4 类任务上已量化「教师 100% → 学生 100%」保留，
  证明蒸馏机制可保留精度，但该任务远简单于 ImageNet。
- 选择性扫描用循环实现（可读性优先），未做并行/关联扫描优化；上量前需换 selective-scan 内核。
  已修正原始骨架「预计算 (B,L,D,S) 中间量致大 batch 内存爆炸」的问题（改为逐时间步离散化）。
