# 隐私语义通信勘察报告（R61）

> 2026-08-31 · 智能体 12 · 来源：digest-g3-2 2608.21773v1（Privacy Preserving Semantic Communications in Wireless Edge Networks）
> 状态：勘察（不写实现）

## 一、结论（TL;DR）

语义通信「传高层语义而非原始比特」本身就有隐私红利——原始数据不必离开设备。2608.21773 进一步把**隐私保护机制显式化**：本地特征提取 + 语义特征加密/扰动，在无线边缘网络里实现「可用的语义 + 可控的隐私」。对 R32（频谱语义传输）的补充：R32 只解决「压缩传输频谱状态」，R61 解决「传输语义时不泄露敏感原始信息」——即语义传输的隐私层。

## 二、隐私机制

- **本地特征提取**：原始频谱/传感数据在设备端提炼成语义特征（事件/变化/类别），原始序列不出域——天然最小化泄露面。
- **语义加密**：对语义特征（latent）做加密/置换，信道窃听者即使截获也无法还原原始数据。
- **差分隐私扰动**：对语义特征注入校准噪声，防止「语义特征反推原始数据」的成员推断攻击。
- **隐私-效用权衡**：扰动强度与语义保真度成反比，按场景调隐私预算 ε。

## 三、边缘场景适配

- 窄带 LoRa 上行：语义压缩本身已大幅降字节（R32 的带宽节省），加密/扰动只加少量开销。
- 端侧算力：特征提取用轻量模型（R39 乘法免费特征、R51 计算型前传可复用），加密用对称密码（AES）成本可忽略。
- 网关侧：解密 + 语义解码，恢复「频谱状态」而非原始 IQ——恰好是 rf_brain 决策层需要的抽象层级。

## 四、可落地隐私设计（≥3 条）

1. **原始数据不出端**：rf_brain 频谱语义传输改为「端侧提取事件/占用/异常特征，只传特征」——天然防窃听者拿到原始 IQ（承接 R32，加隐私约束）。
2. **语义层差分隐私**：对频谱语义特征加校准噪声（Laplace/Gaussian），量化「特征 → 原始数据」的反推难度，给 ε 预算。
3. **对称加密语义载荷**：语义特征 AES-CCM 加密（mesh_layer 已有 AES-CCM 组件可复用），窃听者拿到密文也无效。
4. **最小化原则**：只传「变化/重要事件」而非全谱（与 R32 的语义压缩一致），传输面即隐私面。

## 五、自建门槛

- 差分隐私的 ε 与频谱语义的保真度权衡需实测标定，无真机时只能给理论预算。
- 端侧特征提取模型需与决策层 schema 对齐（FeatureVector 抽象已有，但语义特征维度需新定义）。
- 加密在 LoRa 帧长约束下需控制 payload 膨胀（语义特征已压缩，加密 tag 增量可控）。

## 六、离栈度

中。语义通信 + 差分隐私 + 对称加密都是可直接落地的通用技术，与 rf_brain 的频谱语义传输（R32）强相关；不依赖特殊硬件。
