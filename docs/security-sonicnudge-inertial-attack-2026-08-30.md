# S11 惯性攻击传感器安全（SonicNudge）

## 一、问题陈述

SonicNudge（2608.25319）开辟了**低层惯性误差攻击面**：用超声波共振扰动陀螺仪，产生传感器偏置，经**估计器-控制器耦合**放大为无人机的受控物理位移。攻击链路：超声波共振 → 陀螺仪偏置 → 卡尔曼滤波估计器偏差 → 控制器基于偏差决策 → 受控位移。该攻击**不依赖导航 spoofing**，颠覆了"有 IMU 就有可靠姿态"的安全假设。

## 二、攻击路径分析

1. **传感器层**：超声波共振注入陀螺仪偏置（物理层攻击，无信号注入）。
2. **估计器层**：卡尔曼滤波把偏置当真实状态，估计器输出被污染。
3. **控制器层**：控制器基于偏差估计做决策，放大为物理位移。
4. **影响面**：任何含 IMU 的嵌入式系统（无人机、ESP32+MPU6050 的 SDR 节点、设备）都受影响。

## 三、防护建议

1. **多传感器一致性校验**：多传感器（IMU 多轴、磁力计、气压计）投票 + 异常检测，防止单一 IMU 偏置污染感知。
2. **估计器鲁棒性**：在卡尔曼滤波中引入偏置异常检测，识别"传感器读数与物理模型不一致"的情况。
3. **声学屏蔽/检测**：物理层屏蔽超声波，或增加声学异常检测。
4. **控制器安全边界**：控制器对"状态估计突变"设安全边界，超出即降级/悬停，防止偏差被放大为位移。
