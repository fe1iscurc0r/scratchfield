## 1. 函数与集合

### 1.1 邻域（后面极限全靠它）

- 点 a 的 δ 邻域：`U(a, δ) = {x | |x − a| < δ}`，即开区间 `(a−δ, a+δ)`
- **去心邻域**：`0 < |x − a| < δ`，把中心点挖掉
- 为什么重要：极限讨论的就是"x 无限靠近 a 但 **不等于** a"时的行为

### 1.2 函数的分类

| 类型 | 形式 | 要点 |
|---|---|---|
| 显函数 | y = f(x) | 直接给出 |
| 隐函数 | F(x, y) = 0 | 不一定能解出 y |
| 分段函数 | 分区间给表达式 | 符号函数 sgn x、取整函数 [x] |
| 狄利克雷函数 | 有理点取 1，无理点取 0 | 处处不连续，画不出图 |

- **取整函数 [x]**：不超过 x 的**最大整数**。`[3.1] = 3`，`[−3.1] = −4`。**不是四舍五入**。

### 1.3 五大基本初等函数

幂函数、指数函数、对数函数、三角函数、反三角函数。

**初等函数** = 基本初等函数经**有限次四则运算 + 有限次复合**得到。
（分段函数一般不是初等函数，但个别能合并成初等函数——老师特意提醒过这个误解。）

### 1.4 定义域：三类题型，考试必考

| 题型 | 方法 | 例子 |
|---|---|---|
| 具体函数 | 解不等式组（分母≠0、根号内≥0、对数内>0） | — |
| 复合函数 f(g(x)) | 把 g(x) **代回 f 的定义域区间** | f 定义域 [0,1] → 0 ≤ 3x ≤ 1 → x ∈ [0, 1/3] |
| 抽象函数 | 同上，但只给区间不给表达式 | 同左 |

- 三角函数求定义域：先在一个**周期**内解，再按周期性扩到全体
- 老师说的"123456 条规则"，指的是课上总结的定义域限制清单（分母、偶次根号、对数真数、tan、arcsin/arccos、零次幂底数）

### 1.5 求函数表达式（考查概率 >90%）

已知 `f(g(x))` 求 `f(x)`：**换元**，令 `t = g(x)`，解出 `x = g⁻¹(t)`，代回。
例：`f(1/x) = x² + 1 + x` → 令 `t = 1/x`，`x = 1/t` → `f(t) = 1/t² + 1 + 1/t`。

**函数相等**的判据：定义域相同 **且** 对应法则相同。（考试不考，了解）

## 2. 数列极限

### 2.1 定义（ε-N 语言）

`lim(n→∞) xₙ = a`  ⇔  对任意 ε > 0，存在正整数 N，当 n > N 时，`|xₙ − a| < ε`。

- 这里的 N **由 ε 解出来**，不是随便取的
- 证明题的标准动作：给定 ε → 解不等式找 N → 验证

### 2.2 四个性质（含反例，最爱考反例）

| 性质 | 内容 | 反例/陷阱 |
|---|---|---|
| **有界性** | 收敛 ⇒ 有界 | 有界 ⇏ 收敛：`(−1)ⁿ⁻¹` |
| **唯一性** | 极限唯一 | — |
| **保号性** | 极限 >0 ⇒ 从某项起 xₙ >0 | 是**局部**保号，不是整体 |
| **子列** | 母列收敛 ⇒ 子列收敛且同极限 | 子列收敛 ⇏ 母列收敛 |

- 逆否：**无界 ⇒ 发散**
- 但**发散 ⇏ 无界**（`(−1)ⁿ⁻¹` 发散但有界）——这两个方向别搞反

### 2.3 割圆术（理解"无限逼近"的源头）

刘徽："割之弥细，所失弥少；割之又割，以至于不可割，则与圆合体而无所失矣。"
思想：**用已知逼近未知**。这是极限概念的直观来源，不是考点，但能帮你理解 ε-N。

## 3. 函数极限

### 3.1 两种变化过程，两套语言

| 过程 | 语言 | 定义 |
|---|---|---|
| x → x₀ | **ε-δ** | ∀ε>0, ∃δ>0, 当 `0 < |x−x₀| < δ` 时 `|f(x)−A| < ε` |
| x → ∞ | **ε-X** | ∀ε>0, ∃X>0, 当 `|x| > X` 时 `|f(x)−A| < ε` |

**核心区别（老师反复强调）**：
- 数列只有 `n → +∞` 一个方向，所以是 `n > N`
- 函数 `x → ∞` 要**同时管正负两个方向**，所以必须是 `|x| > X`，不能只写 `x > X`

### 3.2 去心邻域为什么必须去心

`0 < |x − x₀|` 排除了 x = x₀。

推论：**f 在 x₀ 有没有定义，与极限是否存在无关。**
例：`sin x / x` 在 x=0 无定义，但极限是 1。

### 3.3 左右极限

`lim(x→x₀) f(x) = A` ⇔ 左极限 = 右极限 = A。

分段函数在分界点、含绝对值、含 `e^(1/x)` 或 `arctan(1/x)` 的题，必须分左右。

同理：`x → ∞` 的极限存在 ⇔ `x → +∞` 与 `x → −∞` 的极限都存在且相等。

### 3.4 渐近线

| 类型 | 判定 | 形式 |
|---|---|---|
| 水平 | `lim(x→∞) f(x) = a` | y = a |
| 铅直（垂直） | `lim(x→x₀) f(x) = ∞`（左/右任一方向即可） | x = x₀ |

例：`2 + 1/x` → 水平 y = 2；`1/(x−1)` → 铅直 x = 1。

## 4. 无穷小与无穷大

### 4.1 定义（这里有个高频误区）

🔴 **课堂原话"无穷小是绝对值小于 1 的变量"不严谨**，严格定义是：

> 在自变量的某个变化过程中，若 `lim f(x) = 0`，则称 f(x) 为该过程中的**无穷小**。

- 无穷小是**变量**，不是数；说"无穷小"必须带上**变化过程**
- 唯一的常数无穷小是 **0**
- `−10000` 不是无穷小（它不趋于 0）

### 4.2 无穷大

> 对任意 M > 0，在该过程中总有 `|f(x)| > M`，则称 f(x) 为**无穷大**。

- 无穷大本质是**极限不存在**，"= ∞" 只是约定写法
- 无穷大也是变量，不是"很大的数"

### 4.3 三条关系

1. 无穷小的倒数 = 无穷大（0 除外）
2. 无穷大的倒数 = 无穷小
3. `lim f(x) = A` ⇔ `f(x) = A + α`，其中 α 是无穷小

### 4.4 运算性质（判断题常考）

- 有限个无穷小的**和**、**积**仍是无穷小
- **有界函数 × 无穷小 = 无穷小** ← 最常用
  - 例：`lim(x→∞) (sin x)/x = 0`
  - 套路：先把式子拆成「有界 × 无穷小」

⚠️ 注意：无穷小 **÷** 无穷小 是未定式，不能直接说等于 0 或 ∞。

## 5. 极限计算 · 五类套路

### 5.1 抓大除小（∞/∞ 型多项式分式）

分子分母同除以最高次幂，只留最高次项。

例：`(n³+…)/(3n³+…) → 1/3`

**老师要求：必须写出"抓大除小"的过程**，不能直接写答案——步骤分。

### 5.2 裂项相消（母积子差）

分母是两项乘积、分子是这两项的差 → 拆成 `1/小 − 1/大`，中间项全部抵消。

**系数不匹配先凑**：需要 2 就乘 1/2 再补回来。

### 5.3 有理化（∞−∞ 型，含根号）

分子有理化：乘共轭 `√A + √B`，把 ∞−∞ 转成 0/0 或 ∞/∞。

### 5.4 待定系数法

例：`lim(x→∞) [√(x²+x+1) − (ax+b)] = 0`，求 a, b。

有理化后分子为 `(1−a²)x² + (1−2ab)x + (1−b²)`。
极限为 0 且分母是一次 → 分子二次项、一次项系数都必须为 0：

```
1 − a² = 0 → a = 1（取正，保证 √ ~ ax）
1 − 2ab = 0 → b = 1/2
```

🔴 **纪要记的是 b = 2，代入验算不成立**。正确应为 **a = 1, b = 1/2**。以自己代入验算为准。

### 5.5 直接代入 / 有界×无穷小

- 连续点直接代
- `0 × 有界` 型 → 直接判 0（如 `(sin x)/x` 在 x→∞）

## 6. 两个重要极限

### 6.1 第一个：`lim(x→0) sin x / x = 1`

**适用条件**：x → 0，且分子 `sin(□)` 与分母 `□` **完全一致**。

不一致就配凑/换元：
```
sin(2x)/x = 2 · sin(2x)/(2x) → 2
```
老师的话："**我拿给你什么，我就得补回什么**"——引入的系数必须补回。

### 6.2 第二个：`lim(x→∞) (1 + 1/x)^x = e`

等价形式：`lim(x→0) (1+x)^(1/x) = e`

**适用条件**：底数 → 1，指数 → ∞（1^∞ 型）。

### 6.3 单位圆推导 sin x / x = 1（老师要求掌握图形）

单位圆中设圆心角 x（弧度），比较三个面积：

```
S△AOD < S扇形AOB < S△OAB
(1/2)sin x < (1/2)x < (1/2)tan x
→ sin x < x < tan x
→ 1 < x/sin x < 1/cos x
→ cos x < sin x/x < 1
x→0 时 cos x→1，由夹逼得 sin x/x → 1
```

## 7. 两个收敛判据

### 7.1 夹逼准则

若 `g(x) ≤ f(x) ≤ h(x)`，且 `lim g = lim h = A`，则 `lim f = A`。

- 从**某一项起**满足即可，前面有限项不影响
- 难点在**放缩尺度**：放太大极限超 A，缩太小极限低于 A，都失效
- 典型：`n` 项和、开 n 次方、`sin x/x`

### 7.2 单调有界准则

**单调 + 有界 ⇒ 收敛**。两个条件缺一不可。

- 单调增 + 有上界 → 收敛到上确界
- 单调减 + 有下界 → 收敛到下确界

## 8. 无穷小比较

### 8.1 定义（设 α、β 是同一过程的无穷小，α ≠ 0）

| 条件 | 称法 | 记号 |
|---|---|---|
| `lim β/α = 0` | β 是 α 的**高阶**无穷小 | β = o(α) |
| `lim β/α = ∞` | β 是 α 的**低阶**无穷小 | — |
| `lim β/α = C ≠ 0` | β 与 α **同阶** | — |
| `lim β/α = 1` | β 与 α **等价** | α ~ β |
| `lim β/α^k = C ≠ 0` | β 是 α 的 **k 阶**无穷小 | — |

🔴 **纪要 2.4 写"x·sin(1/x) 是 x 的低阶无穷小"是错的**：`x·sin(1/x)/x = sin(1/x)` 极限**不存在**（在 ±1 间震荡），属于**无法比较**，不是低阶。同一份纪要前面 2.2 自己写了"无法比较"，前后矛盾——以"无法比较"为准。

### 8.2 等价无穷小代换定理

`α ~ β` ⇔ `β = α + o(α)`

证明（两方向）：
- 必要：`(β−α)/α = β/α − 1 → 1 − 1 = 0`
- 充分：`β/α = (α + o(α))/α = 1 + o(α)/α → 1`

### 8.3 必背 8 条（x → 0）

```
sin x ~ x
tan x ~ x
arcsin x ~ x
arctan x ~ x
1 − cos x ~ x²/2
e^x − 1 ~ x
ln(1 + x) ~ x
(1 + x)^α − 1 ~ αx
```

**推广**：把 x 换成任何 `φ(x) → 0`，公式仍成立。如 `sin(3x) ~ 3x`、`ln(1+x²) ~ x²`。

### 8.4 代换的三条铁律

1. **只能换乘除因子**，加减项不能直接换
2. 乘积中可换任意一个或几个因子
3. 加减型要先变形（提公因式、通分、有理化）凑成乘积

经典反例：`lim(x→0) (x − sin x)/x³`
若把 sin x 换成 x，分子变 0，答案错。
正确处理：`x − sin x` 是 x 的**三阶**无穷小，`x − sin x ~ x³/6`，所以极限 = **1/6**。

🔴 **纪要记的"极限为 1/2"是错的**（1/2 是 `(1−cos x)/x²` 的答案，两题被混了）。这条务必以教材/自己验算为准。
