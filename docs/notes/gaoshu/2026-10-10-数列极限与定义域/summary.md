## 二、课堂内容

### 2.1 函数定义域复习

- 回顾上节课内容，涉及**反三角函数**（主要是反正弦）与**复合函数**求定义域的方法。
- 复合函数求定义域的核心思路：将复合函数中的**新复合变量代换成原来的变量**来解决。
- 教师以具体例题演示：已知 **f(x) 的定义域为 [0,1]**，求 **f(3x)** 的定义域。
  - 解法：将 **3x** 代入原定义域范围，即 **0 ≤ 3x ≤ 1**，解得 **0 ≤ x ≤ 1/3**。
- 涉及三角函数时，需先在其**一个周期**上求解满足条件的范围，再根据**周期性**扩充到整个实数范围。

### 2.2 抽象函数定义域

- **抽象函数**定义：没有具体表达式的函数，称为抽象函数。
- 作业第二页给出了抽象函数求复合后定义域的例题，方法为将复合变量直接替换原变量。
- 教师强调：抽象函数求定义域是**常见考点**，需重点掌握。

### 2.3 考试题型与分值分布

- 本课程考试类型为**五道选择题、五道填空题**，各占 **3分**，合计 **30分**。
- **填空题第一题**通常考查**求函数定义域**，属于高频考点。
- 教师提醒：已知函数表达式求定义域时，需遵循之前总结的 **123456 条规则**。

### 2.4 函数相等与函数表达式

- **函数相等**的判断条件：**对应法则相等**且**定义域相等**。
- 教师说明：函数相等这类题**考试不考**，了解即可，作为后续学习工具使用。
- **求函数表达式**是另一类重要题型，考查概率高达 **90%以上**。
  - 已知 **f(g(x))** 的表达式，求 **f(x)**：通过换元法，令中间变量替换，求出反函数后再代入计算。
  - 已知特殊点求函数值：直接将特殊点代入表达式计算。

### 2.5 初等函数概念

- 五大基本初等函数：**幂函数、指数函数、对数函数、三角函数、反三角函数**。
- **初等函数**定义：由基本初等函数经过**有限次四则运算**或**有限次复合**所得到的函数。
- 初等函数是主要研究对象；**分段函数**通常不属于初等函数。
- 教师提醒：学习数学时认知范围在不断扩大，不能用小学或中学的旧概念限制大学数学的理解。

### 2.6 数列极限概念的引入

- 从有限数列（如 **1 到 100**）出发，指出有限数列无法构成极限讨论的对象，**数列极限针对无穷数列**。
- 引入中国古代**割圆术**：
  - 刘徽用正多边形逼近圆，边数越多，正多边形面积越接近圆的面积。
  - 经典语句：**“割之弥细，所失弥少；割之又割，以至于不可割，则与圆合体而无所失矣。”**
  - 刘徽约在 **公元 220 年** 完成相关工作，并对《九章算术》进行了修正与全面评估。
  - 祖冲之与其子利用**牟合方盖**（两个垂直相交的圆柱体）逼近球体，用于求体积。
- 割圆术的核心思想：**用已知去逼近未知**，即用有棱角的正多边形逼近圆。

### 2.7 数列极限的数学定义

- 数列由**无穷多个元素**组成，每个元素对应数轴上的一个点，依次取 **x₁, x₂, x₃, …**。
- 有些数列当 **n 无限增大**时，**xₙ 会无限接近于某一个确定的数**；有些则不会（如 **-1, 1, -1, 1** 交替出现的数列）。
- 示例：数列 **xₙ = n/(n+1)**，当 n 趋于无穷大时，分子分母相比无穷大，**1 的影响趋于零**，数列无限接近 **1**，但永远达不到 1。
- 讨论数列极限的两个核心问题：
  1. 判断数列**是否有极限**（是否无限趋近于某个确定值）。
  2. 若有极限，**极限值是多少**。
- 教师指出：“无限接近”和“无限增大”是模糊的文字概念，需要用**数学语言**精确表达。
  - “n 无限增大”用 **n → ∞** 表示。
  - “xₙ 无限接近 a”用 **|xₙ - a|**（距离）趋于零来表示。

## 三、课中难点

### 3.1 难点/疑点

- 学生对**抽象函数**求定义域的方法理解不到位，不清楚如何将复合变量替换回原变量。
- 对“**无限接近**”这一直观概念如何转化为**精确数学语言**存在困惑。
- 对数列极限中“**永远达不到但无限接近**”这一特性理解有难度。

### 3.2 解决方案

- 教师以 **f(x) 定义域为 [0,1] 求 f(3x) 定义域** 为例，演示替换过程：将 **3x** 代入原定义域，解不等式 **0 ≤ 3x ≤ 1**。
- 通过**割圆术**的动态演示（正四边形→正六边形→正八边形→…），直观展示“边数越多越接近圆”的过程，帮助学生建立“无限接近”的直观感受。
- 用 **|xₙ - a|** 表示 xₙ 与 a 的距离，将“无限接近”转化为**距离趋于零**的数学表述。

## 六、课后洞察

### 6.1 模型思维

- 本课体现了从**直观感知**到**精确数学定义**的建模路径：割圆术中“越割越接近圆”是直观感知，数列极限中“|xₙ - a| 趋于零”是精确数学语言。学习中应先建立直观理解，再追问如何用数学符号精确表达。

### 6.2 可视化比喻

- 数列极限就像**用正多边形逼近圆**：边数越多，多边形越像圆，但永远不可能完全重合。极限值就是这个“永远达不到但无限接近”的目标。同理，**n/(n+1)** 这个数列，n 越大，值越接近 1，但永远不等于 1。

### 6.3 潜在启发

- **个人层面**
  - 学习新概念时，先找到历史源头或直观例子，再理解精确数学定义。
  - 用“小本本”记录每日目标，完成一项勾掉一项，用已知的现在逼近未知的未来。
- **学习/教研层面**
  - 讲极限概念时，先用割圆术等历史案例建立直观，再引入数学语言定义。
  - 强调“无限接近”与“永远达不到”的区别，帮助学生突破认知难点。

### 6.4 举一反三

1. 将“用已知逼近未知”的极限思想迁移到**函数极限**学习，理解 x → x₀ 时函数值的趋近过程。
2. 将“|xₙ - a| 趋于零”的判断方法应用于**数列收敛性判断**，用距离定义验证极限是否存在。
3. 将“变量替换求定义域”的方法迁移到**复合函数求值域**，先确定内层函数范围再求外层函数范围。

## 七、术语解释

- **反三角函数（概念）**：三角函数的反函数，主要包括反正弦、反余弦等。重要性：中。
- **复合函数（概念）**：由两个或多个函数复合而成的函数，求定义域时需将复合变量替换回原变量。重要性：高。
- **抽象函数（概念）**：没有具体表达式的函数，仅给出抽象符号关系。重要性：高。
- **初等函数（概念）**：由基本初等函数经有限次四则运算或复合得到的函数。重要性：中。
- **分段函数（概念）**：在不同定义区间内表达式不同的函数，通常不属于初等函数。重要性：中。
- **数列极限（概念）**：当 n 无限增大时，数列 xₙ 无限接近某个确定值的性质。重要性：高。
- **割圆术（方法）**：刘徽提出的用正多边形逼近圆以计算圆面积的方法，体现极限思想。重要性：高。
- **牟合方盖（概念）**：两个垂直相交的圆柱体公共部分，祖冲之父子用它逼近球体求体积。重要性：低。
- **九章算术（专有名词）**：中国古代数学著作，无具体作者，是历代数学家智慧结晶。重要性：中。

## 八、加深印象

**问：复合函数求定义域的核心方法是什么？**

- 将复合函数中的新复合变量代换成原来的变量，代入原定义域范围求解。

**问：已知 f(x) 定义域为 [0,1]，求 f(3x) 的定义域？**

- 令 **0 ≤ 3x ≤ 1**，解得 **0 ≤ x ≤ 1/3**。

**问：函数相等的判断条件是什么？**

- **对应法则相等**且**定义域相等**。

**问：求函数表达式的常用方法是什么？**

- 用**换元法**，令中间变量替换，求出反函数后再代入计算。

**问：什么是初等函数？**

- 由基本初等函数经过**有限次四则运算**或**有限次复合**所得到的函数。

**问：割圆术中刘徽的经典语句是什么？**

- **“割之弥细，所失弥少；割之又割，以至于不可割，则与圆合体而无所失矣。”**

**问：数列极限讨论的两个核心问题是什么？**

- 判断数列**是否有极限**；若有极限，**极限值是多少**。

**问：如何用数学语言表达“xₙ 无限接近 1”？**

- 用 **|xₙ - 1|** 表示 xₙ 与 1 的距离，当 n 无限增大时，**|xₙ - 1| 趋于零**。

**问：数列 xₙ = n/(n+1) 的极限是多少？**

- 当 n 趋于无穷大时，**xₙ 无限接近 1**，但永远达不到 1，所以极限为 **1**。
