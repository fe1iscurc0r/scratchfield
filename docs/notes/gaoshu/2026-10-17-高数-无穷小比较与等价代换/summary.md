## 二、课堂内容

### 2.1 无穷小的回顾与引入

- 教师先回顾无穷小的概念：**无穷小是一个绝对值小于1的变量，不是一个数**，它依赖于某个变化过程（如 X 趋于零）。
- 举例说明同一过程中的多个无穷小：当 X 趋于零时，**X、X 的平方、Sin X** 都是无穷小。
- 教师指出 **X 的平方乘以 Sin（X 分之一）** 也是无穷小，因为它是**无穷小乘以一个有界变量**，结果仍为无穷小。
- 教师提问：既然都是无穷小，**哪一个更小、趋于零的速度更快**？由此引出无穷小比较的必要性。

### 2.2 无穷小比较的直观例子

- 教师通过三个比值例子说明无穷小趋于零的**速度差异**：
  - **X 的平方 比 X**：极限为 0，说明 **X 的平方 比 X 更快趋于零**。
  - **Sin X 比 X**：极限为 1（重要极限），说明 **Sin X 与 X 趋于零的速度大致相同**。
  - **X 乘以 Sin（X 分之一）比 X**：极限不存在（因 Sin（X 分之一）在负一到一之间震荡），说明**这两个无穷小无法比较**。
- 教师总结：不同无穷小趋于零的速度不同，需要建立严格的比较定义。

### 2.3 无穷小比较的定义

- 设 **阿尔法、贝塔** 是同一过程中的两个无穷小，且 **阿尔法 不等于零**，则：
  - **高阶无穷小**：若 **贝塔 比 阿尔法** 的极限等于 0，则称 **贝塔 是 阿尔法 的高阶无穷小**，记作 **贝塔 等于 小 O（阿尔法）**。
  - **低阶无穷小**：若 **贝塔 比 阿尔法** 的极限等于无穷，则称 **贝塔 是 阿尔法 的低阶无穷小**。
  - **同阶无穷小**：若 **贝塔 比 阿尔法** 的极限等于常数 C（C 不等于 0），则称 **贝塔 与 阿尔法 是同阶无穷小**。
  - **等价无穷小**：若上述常数 **C 等于 1**，则称 **贝塔 与 阿尔法 是等价无穷小**，记作 **阿尔法 波浪线 贝塔**。
- 教师提醒：波浪线记号在后续**线性代数**中含义不同，需注意区分。
- **K 阶无穷小**：若 **贝塔 比 阿尔法 的 K 次幂** 的极限等于常数 C（C 不等于 0，K 大于 0），则称 **贝塔 是 阿尔法 的 K 阶无穷小**。

### 2.4 定义的应用与例题

- 教师用课堂前面的例子回扣定义：
  - **X 的平方 是 X 的高阶无穷小**，因为两者比值的极限为 0。
  - **Sin X 与 X 是等价无穷小**，因为两者比值的极限为 1。
  - **X 乘以 Sin（X 分之一）是 X 的低阶无穷小**，因为比值极限不存在（震荡）。
- 教师补充一个例子：**X 的平方 是 X 的二阶无穷小**（K 等于 2 的情形）。

### 2.5 等价无穷小代换定理

- **定理内容**：**贝塔 与 阿尔法 是等价无穷小的充要条件是：贝塔 等于 阿尔法 加上 阿尔法 的高阶无穷小**。
- **必要性证明**（等价推出表达式）：
  - 已知 **贝塔 与 阿尔法 等价**，即 **贝塔 比 阿尔法** 的极限为 1。
  - 构造 **贝塔 减 阿尔法 比 阿尔法**，拆开后第一部分极限为 1，第二部分为减 1，整体极限为 0。
  - 因此 **贝塔 减 阿尔法 是 阿尔法 的高阶无穷小**，即 **贝塔 等于 阿尔法 加上 阿尔法 的高阶无穷小**。
- **充分性证明**（表达式推出等价）：
  - 已知 **贝塔 等于 阿尔法 加上 阿尔法 的高阶无穷小**。
  - 将 **贝塔 比 阿尔法** 代入，得到 **1 加上 高阶无穷小 比 阿尔法**，极限为 **1 加 0 等于 1**。
  - 因此 **贝塔 与 阿尔法 是等价无穷小**。

### 2.6 常用等价无穷小公式

- 当 **X 趋于 0** 时，以下等价关系成立（教师要求**课后默记**）：
  - **Sin X 与 X 等价**
  - **Tangent X 与 X 等价**
  - **Arc Sin X 与 X 等价**
  - **Arc Tangent X 与 X 等价**
  - **1 减 Cos X 与 二分之一 X 的平方 等价**（由二倍角公式推出）
  - **E 的 X 次方 减 1 与 X 等价**
  - **Ln（1 加 X）与 X 等价**
  - **（1 加 X）的阿尔法次方 减 1 与 阿尔法 X 等价**
- 教师给出**拓展形式**：若 **Five 是趋于零的无穷小**，则上述公式中的 **X 均可替换为 Five**，例如 **Sin（Five）与 Five 等价**、**E 的 Five 次方 减 1 与 Five 等价**、**Ln（1 加 Five）与 Five 等价**。

### 2.7 等价代换在极限计算中的应用

- 教师通过例题演示等价代换的简化作用，核心思路是**将复杂因子替换为简单等价量**，从而简化极限计算。
- 例题：求 **X 趋于 0 时，（X 减 Sin X）比 X 的立方** 的极限。
  - 第一步：判断为 **0/0 型**，需消去零因子。
  - 第二步：分子提出 **Tangent X**，括号内为 **1 减 Cos X**。
  - 第三步：利用 **二倍角公式**，将 **1 减 Cos X** 化为 **2 倍 Sin 的平方（二分之 X）**。
  - 第四步：利用 **重要极限** 和 **等价代换**，将分子分母分别化简。
  - 第五步：最终极限为 **二分之一**。
- 教师强调：该例题同时证明了 **X 减 Sin X 是关于 X 的三阶无穷小**。
- 教师提醒等价代换的**使用条件**：
  - 若分子分母是**若干个因子的乘积**，可对其中**任意一个或几个因子**做等价代换。
  - **加减项不能直接做等价代换**，只能对乘除因子使用。

## 三、课中难点

### 3.1 难点/疑点

- 学生对 **无穷小比较中比值极限不存在** 的情形感到困惑，不理解为何此时“无法比较”。
- 学生对 **等价无穷小代换定理的证明过程**（必要性与充分性）理解有难度。
- 学生对 **等价代换只能用于乘除因子、不能用于加减项** 的规则容易混淆。
- 学生对 **K 阶无穷小** 中 K 的取值与判断方法不够清晰。

### 3.2 解决方案

- 教师通过 **X 乘以 Sin（X 分之一）比 X** 的例子说明：因 **Sin（X 分之一）在负一到一之间震荡**，比值极限不存在，故两个无穷小**无法比较大小**。
- 教师分两步证明等价代换定理：先证必要性（从等价推出表达式），再证充分性（从表达式推出等价），每一步都拆解极限运算过程。
- 教师反复强调：**等价代换只针对乘除因子**，加减项不能直接替换；若遇到加减结构，需先提取公因子或变形为乘积形式。
- 教师通过例题演示 **K 阶无穷小** 的判断：将 **贝塔 比 阿尔法 的 K 次幂** 取极限，若极限为非零常数，则 K 即为阶数。

## 四、课中要点

- **无穷小是变量，不是数**，其绝对值小于 1，依赖于具体变化过程。
- 无穷小比较的核心是**比值极限**：极限为 0 是高阶，极限为无穷是低阶，极限为非零常数是同阶，极限为 1 是等价。
- **等价无穷小代换定理**：贝塔 与 阿尔法 等价的充要条件是 **贝塔 等于 阿尔法 加上 阿尔法 的高阶无穷小**。
- 常用等价无穷小公式（X 趋于 0 时）：**Sin X 与 X 等价**、**Tangent X 与 X 等价**、**1 减 Cos X 与 二分之一 X 的平方 等价**、**E 的 X 次方 减 1 与 X 等价**、**Ln（1 加 X）与 X 等价**。
- 等价代换的**适用条件**：只能用于**乘除因子**，**加减项不可直接代换**。
- 等价代换的作用是**简化极限计算**，将复杂因子替换为简单等价量，且不改变原极限值。

## 六、课后洞察

### 6.1 模型思维

- 本课体现了从**直观比较**到**严格定义**的数学建模路径：先用具体例子感受无穷小趋于零的速度差异，再通过**比值极限**这一统一标准建立高阶、低阶、同阶、等价的严格定义，最后用**等价代换定理**将定义转化为可操作的极限计算工具。学习中应先建立“比较标准”，再追问“标准背后的数学结构”。

### 6.2 可视化比喻

- 无穷小比较就像**赛跑**：不同的无穷小是速度不同的运动员，比值极限就是“谁先到达终点”的判据。极限为 0 表示分子“跑得更快”，极限为无穷表示分母“跑得更快”，极限为 1 表示两者“齐头并进”。等价代换则像**换跑鞋**——只要保证最终成绩不变，就可以把复杂的“跑鞋”换成简单的“跑鞋”，让计算更轻松。

### 6.3 潜在启发

- **个人层面**
  - 学习新概念时，先通过具体例子建立直观感受，再理解严格定义，能降低抽象难度。
  - 遇到复杂计算时，先观察结构是否为“乘除因子”，再决定是否使用等价代换。
- **学习/教研层面**
  - 讲无穷小比较时，应先用比值例子打破“都是无穷小”的直觉，再引入定义。
  - 用“赛跑”“换跑鞋”等生活化比喻，可帮助不同基础的学生同时建立直观与规范。

### 6.4 举一反三

1. 将“比值极限判断比较”的思路迁移到**函数增长速度比较**，用极限判断不同函数趋于无穷的快慢。
2. 将“等价代换只用于乘除因子”的规则迁移到**其他极限计算方法**（如洛必达法则、泰勒展开）的适用条件判断。
3. 将“K 阶无穷小”的概念迁移至**无穷大比较**，用类似比值方法判断不同无穷大的阶数。

## 七、术语解释

- **无穷小（概念）**：绝对值小于 1 的变量，不是一个数，依赖于变化过程。重要性：高。
- **高阶无穷小（概念）**：若贝塔 比 阿尔法 的极限为 0，则贝塔 是 阿尔法 的高阶无穷小，记作贝塔 等于 小 O（阿尔法）。重要性：高。
- **低阶无穷小（概念）**：若贝塔 比 阿尔法 的极限为无穷，则贝塔 是 阿尔法 的低阶无穷小。重要性：高。
- **同阶无穷小（概念）**：若贝塔 比 阿尔法 的极限为非零常数，则两者为同阶无穷小。重要性：高。
- **等价无穷小（概念）**：若贝塔 比 阿尔法 的极限为 1，则两者为等价无穷小，记作阿尔法 波浪线 贝塔。重要性：高。
- **K 阶无穷小（概念）**：若贝塔 比 阿尔法 的 K 次幂 的极限为非零常数，则贝塔 是 阿尔法 的 K 阶无穷小。重要性：中。
- **等价代换（方法）**：在极限计算中，将复杂因子替换为等价无穷小，仅适用于乘除因子，不适用于加减项。重要性：高。
- **重要极限（概念）**：Sin X 比 X 在 X 趋于 0 时的极限为 1，是判断等价无穷小的基础。重要性：高。
- **二倍角公式（方法）**：用于将 1 减 Cos X 化为 2 倍 Sin 的平方（二分之 X），是推导等价公式的关键工具。重要性：中。

## 八、加深印象

**问：什么是无穷小？**

- 无穷小是绝对值小于 1 的变量，不是一个数，它依赖于某个变化过程。

**问：如何判断两个无穷小谁更小？**

- 通过**比值极限**判断：极限为 0 是分子高阶，极限为无穷是分母高阶，极限为非零常数是同阶，极限为 1 是等价。

**问：高阶无穷小的记号是什么？**

- 若贝塔 是 阿尔法 的高阶无穷小，记作 **贝塔 等于 小 O（阿尔法）**。

**问：等价无穷小的充要条件是什么？**

- 贝塔 与 阿尔法 等价的充要条件是 **贝塔 等于 阿尔法 加上 阿尔法 的高阶无穷小**。

**问：X 趋于 0 时，1 减 Cos X 与什么等价？**

- 与 **二分之一 X 的平方** 等价，由二倍角公式推出。

**问：等价代换的使用条件是什么？**

- 只能用于**乘除因子**，加减项不可直接代换；若分子分母是若干因子的乘积，可对其中任意一个或几个因子做等价代换。

**问：X 趋于 0 时，（X 减 Sin X）比 X 的立方 的极限是多少？**

- 极限为 **二分之一**，同时说明 **X 减 Sin X 是关于 X 的三阶无穷小**。

**问：为什么 X 乘以 Sin（X 分之一）与 X 无法比较？**

- 因为 **Sin（X 分之一）在负一到一之间震荡**，比值极限不存在，故无法判断大小关系。
