## 二、课堂内容

### 2.1 邻域与集合

- 以 **A 为中心**，**德尔塔为半径** 定义邻域，记作 **U(A, 德尔塔)**。
- 邻域表示所有满足 **A - 德尔塔 < X < A + 德尔塔** 的点的集合，即开区间 **(A - 德尔塔, A + 德尔塔)**。
- 去心邻域：将中心点 **A 去掉**，即 **A - 德尔塔 < X < A + 德尔塔 且 X ≠ A**。
- 教师强调：**邻域是描述函数局部性质的重要工具**，后续学习极限与连续时会反复使用。

### 2.2 函数概念与分类

- **显函数**：直接用自变量表达因变量，关系明确，如 **Y = F(X)**。
- **隐函数**：以方程形式给出 X 与 Y 的关系，如 **F(X, Y) = 0**，不一定能直接用 X 表示 Y。
- **分段函数**：在不同区间上有不同表达式的函数，如**符号函数**，只能取特定值，图像在不同区间呈现不同形态。
- **取整函数**：表示不超过 X 的最大整数，如 **[3.1] = 3**，注意**不是四舍五入**，取整后结果永远小于等于原数。
- **狄利克雷函数**：有理数点取 1，无理数点取 0，图像无法用连续曲线描绘，是典型的**间断函数**。
- 教师指出：**大多数函数是连续的**，图像是光滑曲线，但也存在**特别间断**的函数，如狄利克雷函数。

### 2.3 基本初等函数

- 五大基本初等函数包括：**幂函数、指数函数、对数函数、三角函数、反三角函数**。
- **幂函数**：形如 **Y = X^A**。
- **指数函数**：形如 **Y = A^X**。
- **对数函数**：形如 **Y = LOG_A(X)**。
- **三角函数**：包括**正弦、余弦、正切、余切、正割、余割**。
- **反三角函数**：三角函数的反函数，如反正弦、反余弦等。
- 教师强调：**这五类函数是构成一切初等函数的基础**。

### 2.4 初等函数与复合函数

- **初等函数**：由**基本初等函数**经过**有限次四则运算**和**有限次复合运算**所得到的函数。
- 示例：**指数函数与对数函数的组合**，如 **Y = A^(LOG_A(X))**，属于复合函数。
- 教师指出：**分段函数看似分段，实际上可能能合并为一个初等函数**，这是初学者容易误解的地方。
- **复合函数**：将一个函数的变量表达式代入另一个函数的变量中，如将 **X+3** 代入原变量 **X**，得到新的函数表达式。

### 2.5 定义域求解

- 教师强调：**定义域求解是重要考点**，需要特别注意。
- 求解定义域时，需将**变量表达式代入原有变量**，再解不等式。
- 教师提示：教材 **15页** 的**第一题**和**第三题**均为求定义域的题目，需按 PPT 上的要求完成。

## 三、课中难点

### 3.1 难点/疑点

- 学生对**隐函数与显函数的区别**存在疑问，教师提问“你认为区别在哪里”。
- 学生对**分段函数与初等函数的关系**感到困惑，不理解为何分段函数有时能合并为一个函数。
- **狄利克雷函数**的图像无法直观画出，学生难以理解其性质。

### 3.2 解决方案

- 教师解释：**显函数**直接用自变量表达因变量，关系明确；**隐函数**以方程形式给出，不一定能分离变量。
- 教师指出：**分段函数看似分段，实际上可能能合并为一个初等函数**，需要具体分析。
- 教师通过**有理数点与无理数点**的取值差异，说明狄利克雷函数的图像为何无法用连续曲线表示。

## 六、课后洞察

### 6.1 模型思维

- 本课体现了从**具体到抽象**的建模路径：先建立**邻域**这一局部工具，再引入**函数**的多种分类，最后通过**基本初等函数**的组合构建**初等函数**体系。学习中应关注**分类标准**，如显函数与隐函数的区别在于能否直接用自变量表达因变量。

### 6.2 可视化比喻

- **邻域** 就像以某点为中心的**圆形范围**，德尔塔是半径，去心邻域则是去掉圆心后的范围。**分段函数** 像**不同路段限速不同**的道路，每段有各自的规则，但整体仍是一条路。

### 6.3 潜在启发

- **个人层面**
  - 学习新概念时，先明确**分类标准**，再理解各类别的区别与联系。
  - 遇到抽象函数（如狄利克雷函数），可借助**特殊点取值**辅助理解。
- **学习/教研层面**
  - 讲解函数分类时，应先用**显函数与隐函数**的对比建立直觉，再引入分段函数。
  - 用**基本初等函数**的组合演示初等函数的构建过程，帮助学生理解复合运算。

### 6.4 举一反三

1. 将**邻域**的概念迁移到**极限与连续**的学习，理解局部性质如何影响整体。
2. 将**显函数与隐函数**的区分迁移到**参数方程**与**极坐标方程**的识别。
3. 将**基本初等函数组合**的思路迁移到**复合函数求导**，先识别内层与外层函数。

- 由**基本初等函数**经过**有限次四则运算**和**有限次复合运算**得到。
