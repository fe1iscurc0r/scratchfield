# 答案

## A 组

**1. 错。** 无穷小是**极限为 0 的变量**，不是数。−10000 不趋于 0，不是无穷小。唯一的常数无穷小是 0。

**2. 半个错。** 前半对（收敛 ⇒ 有界），后半错。反例 `(−1)ⁿ⁻¹`：有界但发散。

**3. 错。** 逆否命题是"无界 ⇒ 发散"，反过来不成立。反例仍是 `(−1)ⁿ⁻¹`：发散但有界。

**4. 错。** 反例 `(−1)ⁿ⁻¹`：奇数项子列 → 1，偶数项子列 → −1，两个子列都收敛，但母列发散。只有当**所有**子列都收敛到同一值，才能推母列。

**5. 错。** 极限讨论的是 x→x₀ 但 x≠x₀ 的过程，与该点是否有定义无关。例：`sin x/x` 在 0 无定义，极限为 1。

**6. 错。** `= ∞` 是**极限不存在**的一种写法（无界发散），不是极限存在。

**7. 错。** 等价代换只能用于**乘除因子**，`x − sin x` 是减法，不能换。换了分子变 0，答案错。正确：`x − sin x ~ x³/6`，极限 = 1/6。

**8. 错。** `x·sin(1/x) / x = sin(1/x)`，极限不存在（在 ±1 间震荡）。二者**无法比较**，既不是高阶也不是低阶。

## B 组

**9.** 抓大除小：分子 2n³，分母 3n³ → **2/3**

**10.** 分子 `n(n+1)/2`，除以 n² → **(1/2)(1 + 1/n) → 1/2**

**11.** `sin(3x)/x = 3 · sin(3x)/(3x) → 3 · 1 = ` **3**

**12.** `1 − cos x ~ x²/2` → **1/2**

**13.** `e^(2x) − 1 ~ 2x` → **2**

**14.** 有理化：`(x²+x−x²)/(√(x²+x)+x) = x/(√(x²+x)+x)`
分子分母同除 x：`1/(√(1+1/x)+1) → 1/2`
答案 **1/2**

**15.** `tan x − sin x = sin x(1/cos x − 1) = sin x · (1−cos x)/cos x`
`~ x · (x²/2) / 1 = x³/2` → 极限 **1/2**
（这题和 12 题答案相同，但过程不同——注意区分它和 `(x−sin x)/x³ = 1/6`）

## C 组

**16.** 对任意 ε>0，要使 `|1/n − 0| = 1/n < ε`，只需 `n > 1/ε`。
取 `N = ⌈1/ε⌉`，则当 n > N 时 `1/n < ε` 恒成立。故极限为 0。

**17.** 对任意 ε>0，要使 `|(2x+1) − 3| = 2|x−1| < ε`，只需 `|x−1| < ε/2`。
取 `δ = ε/2`，则当 `0 < |x−1| < δ` 时，`|(2x+1)−3| = 2|x−1| < 2δ = ε`。证毕。

**18.** 因为极限研究的是 x **无限靠近但不等**于 x₀ 时的趋势。
若允许 x = x₀，函数在该点的取值 f(x₀) 会干扰判断；去心后，"有没有定义""定义成什么"都不影响极限是否存在。这也是"可去间断点"能补定义的原因。

**19.**
单位圆中设 ∠AOB = x（0 < x < π/2），比较三块面积：

```
S△AOD = (1/2)·sin x
S扇形AOB = (1/2)·x
S△OAB = (1/2)·tan x
```

由包含关系：`S△AOD < S扇形AOB < S△OAB`

```
(1/2)sin x < (1/2)x < (1/2)tan x
→ sin x < x < tan x
→ 同除 sin x：1 < x/sin x < 1/cos x
→ 取倒数：cos x < sin x/x < 1
```

x→0 时 cos x → 1，两端都趋于 1，由**夹逼准则**得 `sin x/x → 1`。
（x<0 时由偶函数性质同理。）

**20.**
- `f(3x)`：`0 ≤ 3x ≤ 1` → **x ∈ [0, 1/3]**
- `f(x−1)`：`0 ≤ x−1 ≤ 1` → **x ∈ [1, 2]**

方法：把括号里的整体代回 f 的定义域区间，再解不等式。
