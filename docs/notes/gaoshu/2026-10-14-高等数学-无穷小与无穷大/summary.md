## 二、课堂内容

### 2.1 函数极限的定义复习

- 函数在某点 x₀ 的极限：当 x 趋近于 x₀ 时，f(x) 与常数 A 的差的绝对值可以任意小，即 **|f(x) - A| < ε**。
- 左极限与右极限：x 从左侧趋近 x₀ 得到左极限，从右侧趋近 x₀ 得到右极限；**函数在 x₀ 处极限存在的重要条件是左极限与右极限都存在且相等**。
- x 趋于无穷大时的极限：对任意给定的正数 ε，存在正数大 X，当 **|x| > 大 X** 时，恒有 **|f(x) - A| < ε**，则称 x 趋于无穷大时 f(x) 以 A 为极限。
- 教师强调：x 趋于无穷大既包含 **正无穷大**，也包含 **负无穷大**。

### 2.2 无穷小的定义与辨析

- 定义：在自变量的某个变化过程中，若函数的极限为 **0**，则称该函数为 **无穷小**。
- 教师强调：**无穷小不是很小很小的数**，而是 **无限接近于 0 的变量**；可以正向趋近 0，也可以负向趋近 0，不限定正负。
- 无穷小一定是 **针对自变量在某个变化过程中** 而言的，不是天生就是无穷小；**唯一的常数无穷小只有 0**。
- 反例辨析：
  - x - 1 在 x 趋于 1 时，极限为 0，此时 x - 1 是无穷小。
  - 1/x 在 x 趋于无穷大时，分母无限大，取倒数后无限接近 0，因此 1/x 是 x 趋于无穷大时的无穷小。
  - 1/(1+x) 在 x 趋于负无穷大时，分母趋于负无穷大，取倒数后趋于 0，因此它是 x 趋于负无穷大时的无穷小；但在 x 趋于正无穷大时同样成立。
  - 负 100、负 10000 等虽然数值很小，但 **不是无穷小**，因为它们并不无限接近于 0，反而离 0 越来越远。
- 教师总结：**判断无穷小的唯一标准是极限是否为 0**，与数值大小无关。

### 2.3 函数与极限的关系：f(x) = A + α

- 若 f(x) 在某个变化过程中以 A 为极限，则 f(x) 与 A 的差是一个 **极限为 0 的变量**，即无穷小 α。
- 结论：**f(x) = A + α**，其中 α 是无穷小。
- 教师说明：f(x) 并不等于 A，但可以看作 **A 加上一个无穷小量**；该结论直观，证明过程不必过多展开。

### 2.4 无穷大的定义与辨析

- 定义：对任意给定的正数大 M，在自变量的某个变化过程中（如 |x| > 大 X，或 x 落入 x₀ 的取心邻域），函数 f(x) 的绝对值总能大于大 M，则称 f(x) 为 **无穷大**。
- 教师用比喻解释：无穷大就是 **“锁不住、封不住”**，不管给定多大的范围，函数总能超越出去。
- 无穷大是 **极限不存在的一种典型情形**：正常极限存在时，函数应与某个常数的差的绝对值小于 ε；而无穷大是比任意给定的数还要大，因此极限不存在。
- 记号说明：极限等于无穷大只是一种 **约定俗成的写法**，并不代表极限存在，本质上仍是 **极限不存在**。
- 无穷大也不是 **很大很大的数**，而是 **变量**；除 0 之外，无穷大和无穷小一样，都是在某个变化过程中的变量。

### 2.5 无穷大与无穷小的关系

- 关系一：**无穷小的倒数是无穷大**（除 0 之外）。
- 关系二：**无穷大的倒数是无穷小**。
- 应用：要证明一个函数在某个变化过程中是无穷小，只需证明它的倒数是无穷大；反之亦然。
- 教师举例：x 趋于无穷大时，1/x² 是无穷小，因为 x² 是无穷大；1/x² 可以看作 1/x 与 1/x 两个无穷小的乘积。

### 2.6 无穷小的运算性质

- **有限个无穷小的乘积仍是无穷小**：如 1/x² 是 1/x 与 1/x 两个无穷小的乘积；1/x¹⁰ 是 10 个 1/x 相乘，结果仍是无穷小。
- **有限个无穷小的和仍是无穷小**：相当于有限个趋于 0 的量相加，结果仍趋于 0。
- **有界函数与无穷小的乘积是无穷小**：
  - 例：x 趋于无穷大时，sin x 是有界函数（|sin x| ≤ 1），1/x 是无穷小，因此 **(sin x)/x 是无穷小**。
  - 教师强调：解题时先把函数拆成 **有界函数 × 无穷小** 的形式，再下结论。

### 2.7 水平渐近线与铅直渐近线

- **水平渐近线**：若 x 趋于无穷大时，f(x) 趋于常数 a，则 **y = a** 是函数的水平渐近线。
  - 例：x 趋于无穷大时，2 + 1/x 趋于 2，因此 **y = 2** 是水平渐近线。
- **铅直渐近线**：若 x 趋于某常数 x₀ 时，f(x) 趋于无穷大，则 **x = x₀** 是函数的铅直渐近线。
  - 例：x 趋于 1 时，1/(x-1) 趋于无穷大，再加常数 2 仍趋于无穷大，因此 **x = 1** 是铅直渐近线。
  - 从左侧趋近 1 或从右侧趋近 1，只要满足趋于无穷大，均可判定为铅直渐近线。

## 三、课中难点

### 3.1 难点/疑点

- 学生容易误认为 **无穷小就是很小很小的数**，把负 100、负 10000 等也当作无穷小。
- 学生容易混淆 **无穷小与无限小**，误以为“无限小下去”就是无穷小。
- 学生对 **无穷大是极限不存在** 这一结论感到困惑，因为记号上写的是“等于无穷大”。
- 学生对 **x 趋于无穷大时 sin x 与 1/x 乘积** 的极限判断存在困难，不清楚如何拆分函数。

### 3.2 解决方案

- 教师用反例纠正：负 100、负 10000 虽然数值很小，但离 0 越来越远，不是无穷小；**无穷小必须无限接近于 0**。
- 教师强调：**判断无穷小的唯一标准是极限是否为 0**，与数值大小无关；无穷小一定是针对自变量某个变化过程而言的变量，**唯一常数无穷小只有 0**。
- 教师说明：无穷大是 **极限不存在的一种典型情形**，“等于无穷大”只是约定俗成的写法，不代表极限存在。
- 教师示范拆分方法：把 (sin x)/x 拆成 **sin x（有界函数）× 1/x（无穷小）**，利用“有界函数与无穷小的乘积是无穷小”直接下结论。

## 四、课中要点

- **无穷小是极限为 0 的变量**，不是很小很小的数；唯一常数无穷小只有 0。
- 无穷小一定是 **针对自变量在某个变化过程中** 而言的，不是天生就是无穷小。
- **f(x) = A + α**：函数以 A 为极限，等价于函数等于 A 加上一个无穷小量。
- **无穷大是极限不存在的一种典型情形**，“等于无穷大”只是约定俗成的写法。
- **无穷小的倒数是无穷大，无穷大的倒数是无穷小**（除 0 之外），可用于证明函数是无穷小或无穷大。
- **有限个无穷小的和与乘积仍是无穷小**；**有界函数与无穷小的乘积是无穷小**。
- x 趋于无穷大时 f(x) 趋于常数 a，则 **y = a 是水平渐近线**；x 趋于 x₀ 时 f(x) 趋于无穷大，则 **x = x₀ 是铅直渐近线**。

## 六、课后洞察

### 6.1 模型思维

- 本课体现了从 **直观感觉** 到 **严格定义** 的建模路径：无穷小与无穷大不能靠“很小很小”“很大很大”的直觉判断，而必须用 **极限是否为 0** 或 **是否能被任意大数超越** 来严格刻画。学习中应优先建立 **“变化过程 + 极限结果”** 的框架，再判断具体函数属于哪一类。

### 6.2 可视化比喻

- 无穷大就像 **“锁不住的人”** ：不管给定多大的范围（大 M），函数总能超越出去，无法被限制在某个罩子里。无穷小则像 **“无限逼近 0 的游标”** ：它不断靠近 0，但始终是变量，不是固定的数。两者的核心都在于 **变化过程**，而不是某个静止的数值。

### 6.3 潜在启发

- **个人层面**
  - 学习新概念时，先找出旧直觉的局限（如“很小就是无穷小”），再理解严格定义为什么更可靠。
  - 遇到抽象概念，可借助“锁不住”“无限逼近”等生活化比喻辅助理解。
- **学习/教研层面**
  - 讲无穷小与无穷大时，应先用反例打破“很小/很大”的直觉定势，再引入极限定义。
  - 用“有界函数 × 无穷小”的拆分方法教学，可帮助学生快速判断复杂函数的极限。

### 6.4 举一反三

1. 将“判断无穷小看极限是否为 0”的思路迁移到 **数列极限** 判断，用定义验证数列是否趋于 0。
2. 将“无穷小的倒数是无穷大”应用于 **分式函数极限** 分析，先判断分母是否为无穷小，再确定整体极限。
3. 将“有界函数与无穷小的乘积是无穷小”迁移至 **三角函数与分式组合** 的极限计算，如 (cos x)/x 在 x 趋于无穷大时的极限。

## 七、术语解释

- **无穷小（概念）**：在自变量的某个变化过程中，极限为 0 的变量；唯一常数无穷小只有 0。重要性：高。
- **无穷大（概念）**：在自变量的某个变化过程中，函数绝对值总能大于任意给定的正数，是极限不存在的一种典型情形。重要性：高。
- **极限（概念）**：函数在某点或某变化过程中趋近的常数，是判断无穷小与无穷大的基础。重要性：高。
- **左极限与右极限（概念）**：x 从左侧或右侧趋近某点时函数的极限；两者都存在且相等是极限存在的必要条件。重要性：中。
- **取心邻域（概念）**：x₀ 附近但不包含 x₀ 本身的邻域，用于描述 x 趋于 x₀ 的变化过程。重要性：中。
- **有界函数（概念）**：函数值被限制在某个有限范围内的函数，如 sin x；有界函数与无穷小的乘积是无穷小。重要性：高。
- **水平渐近线（概念）**：x 趋于无穷大时 f(x) 趋于常数 a，则 y = a 是水平渐近线。重要性：中。
- **铅直渐近线（概念）**：x 趋于某常数 x₀ 时 f(x) 趋于无穷大，则 x = x₀ 是铅直渐近线。重要性：中。

## 八、加深印象

**问：判断无穷小的唯一标准是什么？**

- 在自变量的某个变化过程中，函数的 **极限是否为 0**；与数值大小无关。

**问：负 100、负 10000 是无穷小吗？**

- 不是。它们虽然数值很小，但离 0 越来越远，并不无限接近于 0。

**问：唯一的常数无穷小是什么？**

- 只有 **0**。除 0 之外，其他函数都是在某个变化过程中才是无穷小。

**问：函数 f(x) 以 A 为极限，可以写成什么形式？**

- **f(x) = A + α**，其中 α 是无穷小量。

**问：无穷大是极限存在还是不存在？**

- 无穷大是 **极限不存在的一种典型情形**；“等于无穷大”只是约定俗成的写法，不代表极限存在。

**问：无穷小与无穷大的倒数关系是什么？**

- **无穷小的倒数是无穷大，无穷大的倒数是无穷小**（除 0 之外）。

**问：x 趋于无穷大时，(sin x)/x 的极限是多少？为什么？**

- 极限为 **0**。因为 sin x 是有界函数，1/x 是无穷小，**有界函数与无穷小的乘积是无穷小**。

**问：如何判断水平渐近线和铅直渐近线？**

- x 趋于无穷大时 f(x) 趋于常数 a，则 **y = a 是水平渐近线**；x 趋于 x₀ 时 f(x) 趋于无穷大，则 **x = x₀ 是铅直渐近线**。
