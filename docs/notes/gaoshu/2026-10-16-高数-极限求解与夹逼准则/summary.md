## 二、课堂内容

### 2.1 数列极限求解：抓大除小

- 适用题型：**分子分母均为多项式**，且当 **n 趋于无穷大** 时，只需关注**最高次项**。
- 以第一、二、四小题为例：分子为 **n 的三次方**，分母为 **3n 的三次方**，抓大除小后极限为 **1/3**。
- 教师强调：抓大除小时，**不能直接写 1/3**，必须写出“抓大除小”的步骤，说明丢弃低次项的依据。
- 核心结论：**抓大除小** 是求解 **∞/∞ 型** 多项式分式极限的首选方法。

### 2.2 数列极限求解：无穷小替换与裂项相消

- 适用题型：**n 趋于无穷大** 时，数列通项呈现**无穷小量**，需通过**恒等变形**转化为可求极限的形式。
- 常用方法：**裂项相消**，核心特征是**母积子差**，即分母为两项乘积，分子为这两项的差。
- 典型例题：第六小题，分母为相邻两项乘积，裂项后**中间项全部抵消**，只剩首项与尾项。
- 教师强调：裂项时若分子与分母因数的差**不成比例**，需先**凑系数**（如缺 2 就乘 1/2），再裂项。
- 易错提醒：**多项和的极限必须打括号**，漏掉括号会导致后续符号错误，意义完全改变。

### 2.3 函数极限求解：无穷小替换与有界函数

- 第一题：**x 趋于某值** 时，直接代入即可求解。
- 第二题：利用**有界函数乘以无穷小仍为无穷小** 的性质，如 **|sin x| ≤ 1**，可直接判定极限为 0。
- 教师强调：**有界性判断** 是处理 **0 × 有界** 型极限的关键步骤，不可跳过。

### 2.4 函数极限求解：待定系数法

- 第九题：表达式为 **√(x² + x + 1) − (ax + b)**，当 **x 趋于无穷大** 时呈 **∞ − ∞ 型**。
- 处理思路：**分子有理化**，将 ∞ − ∞ 型转化为 **0/0 或 ∞/∞ 型**。
- 有理化后，分子为 **(x² + x + 1) − (ax + b)²**，展开并整理：
  - **二次项系数**：1 − a²
  - **一次项系数**：1 − 2ab
  - **常数项**：1 − b²
- 因原式极限为 0，且分母最高次项为一次，故**分子最高次项次数必须低于分母**，即**二次项系数与一次项系数均为 0**。
- 解得：**a = 1，b = 2**。
- 教师强调：**待定系数法** 的关键是**先判断极限类型**，再通过**最高次项次数对比**确定系数条件。

### 2.5 夹逼准则：数列形式

- 核心思想：若 **Yₙ ≤ Xₙ ≤ Zₙ**，且 **lim Yₙ = lim Zₙ = A**，则 **lim Xₙ = A**。
- 角色分配：**Xₙ 是主角**（待求极限），**Yₙ 和 Zₙ 是工具**（用于夹逼）。
- 适用条件：**从某一项起** 满足不等式即可，前面有限项不影响结论。
- 教师比喻：夹逼准则如同**环境对人的影响**——身边人都在学习，自己也会被带动；身边人都在打游戏，自己容易被同化。因此要**主动选择志同道合者**，远离消极环境。

### 2.6 夹逼准则：函数形式与单位圆推导

- 函数形式：若 **g(x) ≤ f(x) ≤ h(x)**，且 **lim g(x) = lim h(x) = A**，则 **lim f(x) = A**。
- 应用难点：**放大与缩小的尺度必须精准**——放得太大，极限可能超过 A；缩得太小，极限可能小于 A，都会失效。
- 典型应用：**x 趋于 0 时，sin x / x 的极限**。
- 推导过程（单位圆法）：
  - 画**单位圆**，设圆心角 **∠AOB = x**（弧度制）。
  - 在单位圆中构造三个图形：**三角形 AOD、扇形 AOB、三角形 OAB**。
  - 面积关系：**三角形 AOD 的面积 < 扇形 AOB 的面积 < 三角形 OAB 的面积**。
  - 用三角函数表示各面积：
    - 三角形 AOD 面积 = **1/2 · sin x**
    - 扇形 AOB 面积 = **1/2 · x**
    - 三角形 OAB 面积 = **1/2 · tan x**
  - 由面积关系得：**sin x < x < tan x**。
  - 同除以 sin x（x > 0 时）：**1 < x / sin x < 1 / cos x**。
  - 取倒数：**cos x < sin x / x < 1**。
  - 当 **x 趋于 0** 时，**cos x 趋于 1**，由夹逼准则得：**lim (sin x / x) = 1**。
- 教师强调：**单位圆 + 面积关系** 是推导该重要极限的直观方法，必须掌握图形构造与三角函数对应关系。

## 三、课中难点

### 3.1 难点/疑点

- 学生对**抓大除小** 的书写规范不清晰，容易直接写结果而省略步骤。
- 学生对**裂项相消** 中“母积子差”的识别不熟练，遇到系数不匹配时不知如何凑系数。
- 学生对**待定系数法** 中“最高次项次数对比”的理解有困难，不清楚为何二次项和一次项系数必须为 0。
- 学生对**夹逼准则** 中“放大与缩小的尺度”把握不准，容易放得过大或缩得过小。
- 学生对**单位圆法推导 sin x / x 极限** 的图形构造与面积关系感到抽象。

### 3.2 解决方案

- 教师强调：抓大除小时**必须写出步骤**，说明丢弃低次项的依据，不能直接写结果。
- 教师讲解裂项时，先识别**母积子差**，再检查分子与分母因数的差是否成比例，缺多少就**凑多少**（如缺 2 就乘 1/2）。
- 教师通过**展开有理化后的分子**，逐项对比系数，明确**极限为 0 意味着分子最高次项次数低于分母**，从而确定系数条件。
- 教师用**环境比喻**解释夹逼准则：放大缩小要像选择环境一样**精准**，太大或太小都会失效。
- 教师通过**单位圆图形**，逐步构造三角形与扇形，用**面积关系**推导不等式，再取极限。

## 六、课后洞察

### 6.1 模型思维

- 本课体现了**从特殊到一般** 的解题建模路径：先掌握**抓大除小、裂项相消** 等具体技巧，再上升到**夹逼准则** 这一通用工具。学习中应先**识别极限类型**，再选择对应方法，最后**验证条件是否满足**。

### 6.2 可视化比喻

- **夹逼准则** 就像**选室友**：你夹在两个人中间，如果两边的人都优秀（极限为 A），你也会被带动变得优秀；如果两边的人都在打游戏，你很难独善其身。**放大与缩小** 就像选择环境——太宽松（放大过头）或太严格（缩小过头）都无法达到目标，必须**精准匹配**。

### 6.3 潜在启发

- **个人层面**
  - 解题时先**判断极限类型**，再选择方法，避免盲目套用。
  - 订正错题时，**逐项检查细节**（括号、符号、系数），比重新做一遍更有效。
- **学习/教研层面**
  - 讲夹逼准则时，可先用**生活化比喻**（环境对人的影响）建立直觉，再引入数学形式。
  - 用**单位圆图形** 推导重要极限，比纯代数推导更直观，适合视觉型学习者。

### 6.4 举一反三

1. 将**抓大除小** 迁移到**函数极限** 中 **x 趋于无穷大** 的多项式分式，同样只看最高次项。
2. 将**裂项相消** 迁移到**级数求和**，通过裂项抵消中间项，快速求部分和。
3. 将**夹逼准则** 迁移到**数列收敛性证明**，构造两个收敛于同一极限的数列夹住目标数列。

## 七、术语解释

- **极限（概念）**：当自变量趋于某值或无穷大时，函数或数列无限逼近的固定值。重要性：高。
- **抓大除小（方法）**：求 ∞/∞ 型多项式分式极限时，只看分子分母最高次项，忽略低次项。重要性：高。
- **无穷小替换（方法）**：将无穷小量通过恒等变形转化为可求极限的形式。重要性：高。
- **裂项相消（方法）**：将分式拆成两项差，使中间项抵消，只剩首尾项。核心特征是**母积子差**。重要性：高。
- **待定系数法（方法）**：通过展开并对比系数，确定未知参数的方法。重要性：中。
- **夹逼准则（定理）**：若 Yₙ ≤ Xₙ ≤ Zₙ 且 lim Yₙ = lim Zₙ = A，则 lim Xₙ = A。重要性：高。
- **单位圆（概念）**：半径为 1 的圆，用于三角函数定义与极限推导。重要性：中。
- **重要极限（结论）**：lim (sin x / x) = 1（x 趋于 0），由夹逼准则与单位圆面积关系推导。重要性：高。

## 八、加深印象

**问：抓大除小适用于什么类型的极限？**

- 适用于 **∞/∞ 型** 的多项式分式极限，只看分子分母最高次项。

**问：裂项相消的核心特征是什么？**

- **母积子差**，即分母为两项乘积，分子为这两项的差。

**问：裂项时系数不匹配怎么办？**

- 先凑系数，缺多少就乘多少（如缺 2 就乘 1/2），再裂项。

**问：多项和的极限为什么必须打括号？**

- 漏掉括号会导致后续符号错误，意义完全改变。

**问：待定系数法中，极限为 0 意味着什么？**

- 意味着分子最高次项次数低于分母，因此二次项和一次项系数必须为 0。

**问：夹逼准则的适用条件是什么？**

- 从某一项起满足 Yₙ ≤ Xₙ ≤ Zₙ，且两边极限相等为 A，则中间极限也为 A。

**问：如何用单位圆推导 lim (sin x / x) = 1？**

- 构造三角形 AOD、扇形 AOB、三角形 OAB，由面积关系得 sin x < x < tan x，取倒数后由夹逼准则得极限为 1。

**问：夹逼准则中放大和缩小的尺度为什么必须精准？**

- 放得太大，极限可能超过 A；缩得太小，极限可能小于 A，都会失效。
