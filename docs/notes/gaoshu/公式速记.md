# 公式速记（考前 10 分钟看这一页）

## 一、8 条等价无穷小（x → 0）

```
sin x      ~ x
tan x      ~ x
arcsin x   ~ x
arctan x   ~ x
1 − cos x  ~ x²/2
e^x − 1    ~ x
ln(1 + x)  ~ x
(1 + x)^α − 1 ~ αx
```

**推广**：x 换成任何 →0 的 φ(x) 照样成立。

**用法**：只能换**乘除因子**；加减要先变形。

## 二、两个重要极限

```
lim(x→0)  sin x / x = 1
lim(x→∞)  (1 + 1/x)^x = e
lim(x→0)  (1 + x)^(1/x) = e
```

## 三、三套定义语言

| 场景 | 写法 |
|---|---|
| 数列 n→∞ | ∀ε>0, ∃N, n>N ⇒ \|xₙ−a\|<ε |
| 函数 x→x₀ | ∀ε>0, ∃δ>0, 0<\|x−x₀\|<δ ⇒ \|f(x)−A\|<ε |
| 函数 x→∞ | ∀ε>0, ∃X>0, \|x\|>X ⇒ \|f(x)−A\|<ε |

**记忆钩子**：数列单向（n>N），函数双向（\|x\|>X）。

## 四、数列四性质（记反例）

```
收敛 ⇒ 有界          有界 ⇏ 收敛   ((−1)ⁿ⁻¹)
无界 ⇒ 发散          发散 ⇏ 无界   ((−1)ⁿ⁻¹)
母列收敛 ⇒ 子列收敛  子列收敛 ⇏ 母列收敛
极限唯一
保号性：局部保号（从某项起）
```

## 五、无穷小 / 无穷大

```
无穷小 ⇔ 极限为 0（是变量，不是数）
唯一常数无穷小 = 0
无穷大 ⇔ 极限不存在（"=∞" 是约定写法）
无穷小的倒数 = 无穷大（0 除外）
无穷大的倒数 = 无穷小
f(x) = A + α  (α 是无穷小) ⇔ lim f = A
有界 × 无穷小 = 无穷小
```

## 六、无穷小比较

```
β/α → 0      β 是 α 的高阶，β = o(α)
β/α → ∞      β 是 α 的低阶
β/α → C≠0    β 与 α 同阶
β/α → 1      β 与 α 等价，α ~ β
β/α^k → C≠0  β 是 α 的 k 阶
```

等价 ⇔ `β = α + o(α)`

## 七、渐近线

```
水平：lim(x→∞) f(x) = a        → y = a
铅直：lim(x→x₀) f(x) = ∞       → x = x₀
```

## 八、五类解法速查

| 题型 | 方法 | 口诀 |
|---|---|---|
| ∞/∞ 多项式 | 抓大除小 | 只留最高次，**写步骤** |
| 分母两项乘积、分子两项差 | 裂项相消 | 母积子差，缺系数先凑 |
| ∞−∞ 含根号 | 有理化 | 乘共轭 |
| 待定系数 | 有理化 + 次数对比 | 极限为 0 → 高次项系数为 0 |
| 0×有界 | 直接判 0 | 先拆成「有界 × 无穷小」 |
| n 项和 / 开 n 次 | 夹逼 | 放缩要精准 |
| 递推数列 | 单调有界 | 单调 + 有界，缺一不可 |

## 九、老师反复强调的 6 句话

1. 无穷小是**变量**，不是"很小的数"
2. "= ∞" 不是极限存在，是**不存在**
3. 等价代换**只能用于乘除**，加减不行
4. 抓大除小**必须写过程**，不能直接给答案
5. 换元后**极限过程要同步转换**
6. 配凑时**引入的系数必须补回来**
