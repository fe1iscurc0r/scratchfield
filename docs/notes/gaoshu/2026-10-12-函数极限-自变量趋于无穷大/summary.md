## 二、课堂内容

### 2.1 从数列极限到函数极限的类比引入

- 教师回顾数列极限的 **ε-N语言**：只需让小 **n > 大N**，即可保证数列从某项开始无限接近常数 **A**。
- 教师指出：数列极限只需往一个方向跑（n 趋于正无穷），而函数极限中自变量 **x** 要趋于无穷大，必须**同时往正、负两个方向跑**。
- 因此，不能只要求 **x > X**，而应要求 **|x| > X**，这样既能保证 **x > X**（往正方向跑），也能保证 **x < -X**（往负方向跑）。
- 教师强调：这是函数极限与数列极限的**核心区别**，也是本节课的关键理解点。

### 2.2 ε-X语言定义函数极限

- 教师给出 **自变量趋于无穷大时函数极限的 ε-X语言** 定义：
  - 对任意给定的 **ε > 0**，存在 **大X > 0**，当 **|x| > 大X** 时，有 **|f(x) - A| < ε** 恒成立。
  - 此时称 **f(x) 当 x 趋于无穷大时以常数 A 为极限**。
- 教师解释：**大X** 的作用是划定一个范围，保证从这个范围之外的所有 x 都满足 **|f(x) - A| < ε**。
- 教师补充：**|f(x) - A| < ε** 是函数值无限接近常数 **A** 的**充要条件**，即函数值落入以 A 为中心、宽度为 **2ε** 的带状区域内。
- 教师指出：**大X** 的取值由 **ε** 决定，**ε 越小，大X 通常需要取得越大**，这与数列极限中 **N 随 ε 变化** 的逻辑一致。

### 2.3 趋于正无穷与趋于负无穷的极限

- 教师分别给出两种单侧无穷极限的条件：
  - **x 趋于正无穷**：存在 **大X**，当 **x > 大X** 时，有 **|f(x) - A| < ε**。
  - **x 趋于负无穷**：存在 **大X**，当 **x < -大X** 时，有 **|f(x) - A| < ε**。
- 教师强调：**x 趋于无穷大** 的极限存在，等价于 **x 趋于正无穷** 和 **x 趋于负无穷** 两个方向的极限都存在且相等，这与数列极限中**左极限与右极限**的讨论思路类似。

### 2.4 几何直观理解

- 教师借助图形说明：常数 **A** 对应一条水平线，**|f(x) - A| < ε** 意味着函数图像落入以 A 为中心、上下各 **ε** 的两条水平线之间的**带状区域**。
- 函数图像并非从一开始就落入带状区域，而是从某个 **大X** 之后才开始落入；**大X 取得越大**，带状区域之外的函数图像部分越少。
- 教师对比指出：与趋于某一点 x₀ 时的 **δ** 不同，**大X** 是向两边延伸的，而 **δ** 是向 x₀ 两侧收缩的，二者方向相反。

### 2.5 水平渐近线与竖直渐近线

- 教师引出**水平渐近线**概念：当 **x 趋于无穷大**（或趋于正无穷、负无穷）时，若 **f(x) 趋于常数 A**，则直线 **y = A** 称为函数的**水平渐近线**。
- 判断水平渐近线的方法：只需考察 **x 趋于无穷大** 时函数的极限值，极限值对应的水平直线即为水平渐近线。
- 教师引出**竖直渐近线**概念：当 **x 趋于某个常数 x₀** 时，若函数值趋于无穷大（不存在且趋于无穷），则直线 **x = x₀** 称为函数的**竖直渐近线**。
- 竖直渐近线的三种情况：**x 趋于 x₀**、**x 趋于 x₀ 的左极限**、**x 趋于 x₀ 的右极限**，任一方向函数值趋于无穷，即可判定 **x = x₀** 为竖直渐近线。
- 教师建议：将**水平渐近线**与**竖直渐近线**两个定义**对比着放一起看**，便于区分记忆。

## 三、课中难点

### 3.1 难点/疑点

- 学生容易混淆**数列极限的 ε-N语言**与**函数极限的 ε-X语言**，不清楚为何函数极限要加**绝对值**。
- 学生对**大X**与**ε**的关系理解不透彻，不清楚为何 **ε 越小，大X 越大**。
- 学生对**水平渐近线**与**竖直渐近线**的判断条件容易混淆。

### 3.2 解决方案

- 教师通过类比讲解：数列极限只需 **n > N** 保证一个方向，函数极限需 **|x| > X** 同时保证正负两个方向，这是二者**本质区别**。
- 教师借助几何图形说明：**ε** 决定带状区域的宽度，**ε 越小** 带状区域越窄，函数图像需要更晚（即更大的 **大X**）才能落入其中。
- 教师建议将**水平渐近线**（x 趋于无穷，y 趋于常数）与**竖直渐近线**（x 趋于常数，y 趋于无穷）**对比记忆**，并分别考察左、右两个方向。

## 四、课中要点

- **ε-X语言** 是自变量趋于无穷大时函数极限的严格数学定义，核心条件是 **|x| > 大X** 时 **|f(x) - A| < ε**。
- 函数极限与数列极限的核心区别：数列只需 **n > N** 单方向跑，函数需 **|x| > X** 保证正负两个方向都满足。
- **大X** 由 **ε** 决定，**ε 越小，大X 越大**，与数列极限中 **N 随 ε 变化** 的逻辑一致。
- **x 趋于无穷大** 的极限存在，等价于**正无穷**与**负无穷**两个方向的极限都存在且相等。
- **水平渐近线**：x 趋于无穷大时 f(x) 趋于常数 A，则 **y = A** 为水平渐近线。
- **竖直渐近线**：x 趋于某常数 x₀ 时函数值趋于无穷，则 **x = x₀** 为竖直渐近线。

## 六、课后洞察

### 6.1 模型思维

- 本课体现了**从特殊到一般**的数学建模路径：数列极限只考虑单方向延伸，函数极限则需同时考虑正负两个方向，通过引入**绝对值**将单方向条件推广为双方向条件。学习中应关注新概念与旧概念的**差异点**，差异往往是理解新概念的关键。

### 6.2 可视化比喻

- 函数极限的 **ε-X语言** 可以类比为**划定活动范围**：常数 A 是目标位置，**ε** 是允许的偏差范围，**大X** 是“从某个距离之外开始”的门槛。只要 x 离原点足够远（超过大X），函数值就一定能落在目标附近的允许范围内，就像从远处看一座建筑，离得越远越能看清它的整体轮廓。

### 6.3 潜在启发

- **个人层面**
  - 学习新概念时，先找出它与旧概念的**区别**，再理解为什么需要新的定义方式。
  - 遇到抽象定义，可借助**几何图形**辅助理解，将符号语言转化为直观图像。
- **学习/教研层面**
  - 讲解函数极限时，应先用数列极限作类比，再突出**绝对值**这一关键差异。
  - 用**水平渐近线**与**竖直渐近线**对比教学，可帮助学生同时建立两类渐近线的判断框架。

### 6.4 举一反三

1. 将 **ε-X语言** 的“双方向”思路迁移到**偶函数**的判断，理解为何偶函数只需考察 x > 0 一侧。
2. 将**水平渐近线**的判断方法应用于**分式函数**，通过求 x 趋于无穷大的极限快速确定渐近线。
3. 将**竖直渐近线**的判断方法迁移至**有理函数**，通过找分母为零的点确定可能的竖直渐近线位置。

## 七、术语解释

- **ε-X语言（概念）**：自变量趋于无穷大时函数极限的严格定义，对任意 ε > 0，存在大X > 0，当 |x| > 大X 时 |f(x) - A| < ε。重要性：高。
- **ε-N语言（概念）**：数列极限的严格定义，对任意 ε > 0，存在正整数 N，当 n > N 时 |aₙ - A| < ε。重要性：高。
- **自变量趋于无穷大（概念）**：x 同时向正无穷和负无穷两个方向延伸，用 |x| > 大X 表示。重要性：高。
- **绝对值（概念）**：用于表示 x 到原点的距离，在函数极限中保证正负两个方向都满足条件。重要性：高。
- **水平渐近线（概念）**：x 趋于无穷大时 f(x) 趋于常数 A，则直线 y = A 为水平渐近线。重要性：中。
- **竖直渐近线（概念）**：x 趋于某常数 x₀ 时函数值趋于无穷，则直线 x = x₀ 为竖直渐近线。重要性：中。
- **常数A（概念）**：函数极限的目标值，函数值无限接近的常数。重要性：高。

## 八、加深印象

**问：函数极限的 ε-X语言 与数列极限的 ε-N语言 核心区别是什么？**

- 数列极限只需 **n > N** 保证单方向延伸，函数极限需 **|x| > 大X** 同时保证正负两个方向都满足条件。

**问：为什么函数趋于无穷大的极限要用 |x| > 大X 而不是 x > 大X？**

- 因为 x 趋于无穷大意味着同时向正无穷和负无穷两个方向跑，只用 x > 大X 只能保证正方向，无法覆盖负方向。

**问：大X 与 ε 之间是什么关系？**

- 大X 由 ε 决定，ε 越小，带状区域越窄，函数图像需要更远的位置才能落入，因此大X 需要取得越大。

**问：x 趋于无穷大的极限存在需要满足什么条件？**

- x 趋于正无穷和 x 趋于负无穷两个方向的极限都存在且相等。

**问：什么是水平渐近线？如何判断？**

- 当 x 趋于无穷大时 f(x) 趋于常数 A，则直线 y = A 为水平渐近线，只需考察 x 趋于无穷大时的极限值。

**问：什么是竖直渐近线？如何判断？**

- 当 x 趋于某常数 x₀ 时函数值趋于无穷，则直线 x = x₀ 为竖直渐近线，需考察 x 趋于 x₀ 时函数是否趋于无穷。
