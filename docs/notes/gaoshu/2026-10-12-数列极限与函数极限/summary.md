## 二、课堂内容

### 2.1 数列极限定义回顾

- 数列 {Xₙ} 收敛于 a 的含义：当 n 趋于无穷大时，Xₙ 与 a 的距离无限接近，即对任意给定的正数 ε，存在正整数 N，当 n > N 时，有 |Xₙ - a| < ε。
- 关键点：**大 N 是由 ε 的表达式表示出来的**，即根据函数特性由 ε 解出不等式来找大 N。
- 证明极限存在的核心步骤：**验证大 N 选得对不对、求出来对不对**，这是上节课用定义证明极限存在的核心。

### 2.2 数列极限的四个性质

- **性质一：有界性**
  - 收敛数列必有界。
  - 逆否命题：**无界的数列必定发散**。
  - 注意两个不成立的逆命题：
    - 有界的数列不一定收敛，反例：**(-1)ⁿ⁻¹** 数列来回波动。
    - 发散的数列不一定无界，反例：**(-1)ⁿ⁻¹** 数列发散但有界。
- **性质二：唯一性**
  - 收敛数列的极限一定是唯一的，不可能同时等于两个不同的值。
- **性质三：保号性**
  - 注意是**局部保号**而非整体保号，即从大 N 开始往后的绝大多数项符号一致。
- **性质四：子列与原数列（母列）的关系**
  - 原数列（母列）收敛，则子列必收敛。
  - 反过来，**子列收敛时母列未必收敛**，反例仍为 **(-1)ⁿ⁻¹** 数列。
  - 子列与母列不仅敛散性一致，**极限值也相同**。

### 2.3 函数极限的引入

- 数列极限中 n 趋于无穷大只有**一个变化方向**（正无穷方向）。
- 函数极限中自变量 x 的变化过程更复杂，分为两类：
  - **x 趋近于有限值 x₀**。
  - **x 趋近于无穷大**（包括正无穷和负无穷两个方向）。
- 以 **f(x) = x²** 在 x 趋近于 1 时为例：从左侧（x 比 1 略小）和右侧（x 比 1 略大）同时向 1 靠拢，函数值也随之向极限值靠拢。

### 2.4 函数极限的 ε-δ 定义

- 用数学语言描述“两个无限接近”，需要两个关键量：
  - **ε**：任意给定的正数，表示函数值与极限值之间允许的误差。
  - **δ**：由 ε 确定的正数，表示自变量 x 与 x₀ 的接近程度。
- 定义表述：设函数 f(x) 在 x₀ 的某个去心邻域内有定义，A 为常数。若对任意给定的正数 ε，总存在正数 δ，当 **0 < |x - x₀| < δ** 时，有 **|f(x) - A| < ε**，则称函数 f(x) 在 x 趋近于 x₀ 时以 A 为极限。
- 与数列极限的类比：数列中的**大 N** 对应函数中的**δ**，数列中“n > N”对应函数中“0 < |x - x₀| < δ”。

### 2.5 去心邻域的含义

- 定义中要求 **0 < |x - x₀|**，即 x ≠ x₀，表示 x 落入 x₀ 的**去心邻域**。
- 原因：当 x = x₀ 时，函数值就是 f(x₀) 本身，无需讨论极限。
- 重要推论：**函数在 x₀ 点有没有定义，与极限是否存在无关**。即使函数在 x₀ 处没有定义，也可以求该点的极限。
- 去心邻域包含 x₀ 的**左右两侧**，因此极限存在必须保证从左侧和右侧两个方向趋近时函数值都趋近于同一常数。

### 2.6 函数极限的几何解释

- 当自变量 x 落入 x₀ 的 δ 去心邻域时，函数值 f(x) 与 A 的差绝对值小于 ε，即所有函数值落入以 A 为中心、宽度为 2ε 的带状区域内。
- **δ 越小，带状区域越狭窄**，函数值越无限接近 A。
- 教师建议：**画图理解几何解释效果很好**，是掌握 ε-δ 定义的重要辅助手段。

### 2.7 简单函数的极限证明示例

- **例一：常函数 f(x) = C**
  - 对任意 ε > 0，|C - C| = 0 < ε 恒成立，故极限为 C。
- **例二：f(x) = x 在 x 趋近于 x₀ 时**
  - 对任意 ε > 0，取 δ = ε，当 0 < |x - x₀| < δ 时，|x - x₀| < ε 成立，故极限为 x₀。
- **例三：f(x) = x² 在 x 趋近于 1 时**
  - 目标证明 |x² - 1| < ε。
  - 因 x 趋近于 1，可先限定 x 的范围（如 x 与 1 的距离小于某值），再放大 |x + 1| 的上界。
  - 最终取 δ 为两个限制条件中**较大的那一个**，保证两个条件同时成立。

## 三、课中难点

### 3.1 难点/疑点

- 数列极限与函数极限中“控制变量”的对应关系容易混淆：数列用**大 N**，函数用**δ**。
- 去心邻域中 **x ≠ x₀** 的条件不易理解，学生容易疑问“为什么求极限要把 x₀ 点去掉”。
- 用 ε-δ 定义证明 **f(x) = x²** 在 x 趋近于 1 时的极限时，如何放大 |x + 1| 并确定 δ 的取值是难点。
- 函数极限存在要求**左右两侧同时趋近**，学生容易忽略“两侧”这一前提。

### 3.2 解决方案

- 教师通过类比讲解：数列中“n > N”是往后无限延伸，函数中“0 < |x - x₀| < δ”是限定在一个范围内，两者本质都是“找到一段范围使误差可控”。
- 教师强调：x = x₀ 时函数值就是 f(x₀) 本身，没有讨论极限的必要，因此定义中采用**去心邻域**。
- 对于 x² 的证明，教师给出处理思路：先限制 x 的取值区间，再对 |x + 1| 进行放大，最后取两个限制条件中较大的 δ 值，保证不等式同时成立。

## 四、课中要点

- 数列极限四性质：**有界性、唯一性、保号性、子列关系**，其中保号性是局部保号而非整体保号。
- 有界数列不一定收敛，发散数列不一定无界，反例均为 **(-1)ⁿ⁻¹**。
- 子列收敛推不出母列收敛，但母列收敛则子列必收敛且极限相同。
- 函数极限中自变量变化分为 **x 趋近于有限值 x₀** 与 **x 趋近于无穷大** 两类。
- ε-δ 定义的核心：**δ 由 ε 确定**，当 x 落入 x₀ 的去心邻域时，函数值与极限值的误差小于任意给定的 ε。
- 去心邻域意味着 **x ≠ x₀**，函数在该点有无定义不影响极限存在与否。
- 极限存在必须保证**左右两侧趋近**时函数值都趋近于同一常数。

## 六、课后洞察

### 6.1 模型思维

- 本课体现了从**离散到连续**的推广路径：数列极限研究离散变量 n 的变化，函数极限研究连续变量 x 的变化。两者的定义框架一致（任意给定误差 → 找到控制范围 → 误差可控），只是控制变量从**大 N** 换成了 **δ**。学习中应抓住“误差可控”这一核心思想，再对比两种情形的差异。

### 6.2 可视化比喻

- ε-δ 定义就像**射箭打靶**：A 是靶心，ε 是允许的脱靶范围（环数要求），δ 是瞄准时的稳定范围。只要你的瞄准点落入靶心附近的 δ 范围内，箭的落点就一定在 ε 环数内。δ 越小，要求瞄准越精确；ε 越小，对精度的要求越高。

### 6.3 潜在启发

- **个人层面**
  - 学习新概念时，先回顾旧概念的框架，再找新旧之间的对应关系，能大幅降低理解难度。
  - 遇到抽象定义时，尝试画出几何示意图，将符号语言转化为直观图像。
- **学习/教研层面**
  - 讲函数极限时，应先复习数列极限的定义与性质，再通过类比引入 δ，帮助学生建立知识迁移。
  - 用“射箭打靶”等生活化比喻辅助理解 ε-δ 语言，可降低初学者的畏难情绪。

### 6.4 举一反三

1. 将“数列极限四性质”的思考方式迁移到**函数极限的性质**学习中，逐一验证有界性、唯一性、保号性在函数情形下是否成立。
2. 将“δ 由 ε 确定”的证明思路应用于**函数极限的证明题**，先放大目标表达式，再反解 δ 的取值。
3. 将“左右两侧趋近”的要求迁移到**分段函数极限**的判断中，分别计算左右极限并比较是否相等。

## 七、术语解释

- **数列极限（概念）**：当 n 趋于无穷大时，数列 Xₙ 无限接近常数 a，则称数列收敛于 a。重要性：高。
- **函数极限（概念）**：当自变量 x 按某种方式变化时，函数值 f(x) 无限接近常数 A，则称 A 为函数在该变化过程中的极限。重要性：高。
- **收敛（概念）**：数列或函数的极限存在，即无限接近某个确定常数。重要性：高。
- **发散（概念）**：数列或函数的极限不存在。重要性：高。
- **有界（概念）**：数列或函数的值域被限制在某个有限范围内。重要性：中。
- **无界（概念）**：数列或函数的值域超出任何有限范围。重要性：中。
- **保号性（概念）**：收敛数列从某项开始，各项符号与极限值的符号保持一致。重要性：高。
- **子列（概念）**：从原数列中按原顺序抽取无穷多项构成的新数列。重要性：中。
- **ε-δ 语言（方法）**：用任意正数 ε 和存在正数 δ 来严格定义函数极限的数学语言。重要性：高。
- **去心邻域（概念）**：点 x₀ 的邻域中去掉 x₀ 本身后的集合，即满足 0 < |x - x₀| < δ 的 x 的集合。重要性：高。

## 八、加深印象

**问：收敛数列是否一定有界？**

- 是，收敛数列必有界。逆否命题为：无界的数列必定发散。

**问：有界的数列是否一定收敛？**

- 不一定。反例为 **(-1)ⁿ⁻¹**，它在 1 和 -1 之间来回波动，有界但发散。

**问：子列收敛能否推出母列收敛？**

- 不能。子列收敛时母列未必收敛，反例仍为 **(-1)ⁿ⁻¹**，其奇数项子列和偶数项子列分别收敛于 1 和 -1，但母列发散。

**问：函数极限定义中，δ 与 ε 是什么关系？**

- δ 是由 ε 确定的正数。给定任意 ε > 0，总存在对应的 δ > 0，使得当 x 落入 x₀ 的 δ 去心邻域时，|f(x) - A| < ε 成立。

**问：为什么函数极限定义中要求 x ≠ x₀？**

- 因为当 x = x₀ 时，函数值就是 f(x₀) 本身，无需讨论极限。去心邻域保证了极限讨论与函数在该点是否有定义无关。

**问：函数极限存在需要满足什么方向条件？**

- 必须保证从 x₀ 的左侧和右侧两个方向趋近时，函数值都趋近于同一常数 A，即左右极限存在且相等。

**问：常函数 f(x) = C 在 x 趋近于 x₀ 时的极限是什么？**

- 极限为 C。因为对任意 ε > 0，|C - C| = 0 < ε 恒成立，无需限制 x 的范围。

**问：证明 f(x) = x² 在 x 趋近于 1 时极限为 1，关键步骤是什么？**

- 先对 |x² - 1| = |x - 1| · |x + 1| 进行放大，限制 x 的范围使 |x + 1| 有上界，再取 δ 为两个限制条件中较大的值，保证 0 < |x - 1| < δ 时 |x² - 1| < ε 成立。
