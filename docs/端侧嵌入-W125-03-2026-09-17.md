# 端侧嵌入（卷125 W125-03 · 2026-09-17）

记忆/检索的 embedding 从「云端 API」改成「**本地优先**」：省 token、降延迟、离线可用。
参考 OpenSquilla 的 on-device embeddings 思路，自研实现（不引代码）。

## 选型（调研结论）

| 候选 | 体积 | 维度 | 中文 | 许可 | 结论 |
| --- | --- | --- | --- | --- | --- |
| `BAAI/bge-small-zh-v1.5` | ~95MB | 512 | 好（中文检索常用基线） | MIT | **采用**：仓库自带、memclaw/graphrag 已在用，零新增依赖 |
| `text2vec-base-chinese` | ~400MB | 768 | 好 | Apache-2.0 | 备选：体积 4 倍，收益不明显 |
| `paraphrase-multilingual-MiniLM` | ~470MB | 384 | 一般 | Apache-2.0 | 不选：中文弱于 bge-small-zh |

体积/维度是实际加载值（`local_embedder.stats()` 里可查）。模型目录沿用 `rag.embedding_engine`
的缓存路径，首次加载后常驻内存（懒加载，只有真正用到 embedding 才加载）。

## 行为

```
mode=auto（默认） ─┬─ 本地 bge-small-zh（LRU 缓存命中 → 直接返回）
                   └─ 本地不可用/编码失败 → 云端 OpenAI 兼容 /embeddings 回退
mode=local        ── 只用本地；不可用返回 None（调用方决定降级，不偷偷走云端）
mode=cloud        ── 只用云端
```

- **LRU 缓存**：`sha256(text)` → 向量，默认 512 条（`embedder.cache_size`，改配置即时生效）
- **统计**：`local_calls` / `cloud_calls` / `fallbacks` / `cache.hits` / `cache.misses`
- **不阻塞检索**：本地与云端都不可用才返回 None；单个文本失败不影响同批其它文本

## 接线

| 调用点 | 改动 |
| --- | --- |
| `rag/rag_service.py`（文档入库 embedding） | 走 `local_embedder.embed`，失败回退原引擎 |
| `mcpserver/material_science/graphrag/vector_index.py`（图谱向量索引） | 同上 |

> 云端「远程记忆服务」(`remote_mem.query_memory`) 是远端自己算 embedding，本项不改它；
> 迁移点是「检索侧 embedding 也走 `local_embedder`」，已在 README 记录，未做的不假装做。

## 实测（真实模型，512 维）

```
相关(材料带隙 vs DFT算带隙): 0.627
无关(材料带隙 vs 午饭):     0.178
本地调用: 3  缓存命中: 3（第二次同样的 3 条文本）云端: 0  回退: 0
```

相关句相似度明显高于无关句，且第二次调用全部命中缓存 —— 本地路径确实在跑，缓存确实生效。

## 节省估算口径

```python
estimate_saved_tokens(texts, cloud_price_per_1k=0.02)
# tokens ≈ 字符数 / chars_per_token（默认 4；中文可调小到 1.5）
# cloud_cost_estimate = tokens / 1000 × cloud_price_per_1k
```

即：**本地算一次 = 省一次云端 embedding 调用**。示例（3 条短文本，32 字符）：token ≈ 8，
按 $0.02/1K 计 ≈ $0.00016 —— 单条微不足道，但文档入库动辄上千块，
`tokens ≈ 字符数/4` 的线性放大下就是实打实的量（这也是本项目 RAG 入库量级下的主要节省点）。

## 配置（`config.json` 的 `embedder` 段）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `mode` | `auto` | auto / local / cloud |
| `cache_size` | `512` | 向量 LRU 条数（0 表示关缓存前请先看容量语义：目前最小值 1） |
| `cloud_api_base` / `cloud_api_key` / `cloud_model` | 空 | 云端回退端点；留空依次回退 `embedding.*` → `api.*` |

## 回滚

`embedder.mode=cloud` 即回到云端；或删 `local_embedder.py` 与两处接线
（`rag_service`、`vector_index`），它们都会回退到原来的 `rag.embedding_engine`。
