## §0 · 一句话

轮 47 把颗粒层的三块地基铺好了（个体 DEM / 群体 PBM / 取向张量），但**它要输入 PSD，要标定成核核，而这两样在浓悬浮液里都测不出来**——光学粒径法必须把样品稀释几个数量级（多次散射限制），纸浆、黑液、木质素浆料这种原浓体系根本进不了激光粒度仪。

轮 48 换一个传"介质"：**声**。声波在浓悬浮液里能穿透、能带着颗粒的黏性/热/散射损失走出来；同一套声学通道，往上走是**作用层（空化强化预处理）**，往下走是**监测层（声发射/阵列声源成像）**。

一句话：**45 管图怎么读，46 管设备怎么烂，47 管颗粒怎么生怎么长，48 管这套东西怎么在闭着眼睛的情况下被"听见"。**

## §4 · 跨域授粉核心：反问题同构（射频频谱 ↔ 声谱）

这是本轮最值钱的一句话：**我不是从零学声学，我是把已经调了二十几轮的射频反演算子，换一个传播介质。**

| 射频/频谱侧（已有积累） | 声学侧（本轮要建） | 数学共鸣 |
|---|---|---|
| 功率谱估计（Welch / 多窗） | 衰减谱 α(f) 提取 | 同一把 FFT + 窗函数 + 相干平均 |
| 导向矢量 + 协方差矩阵 + DBF 零陷 | `acoular.SteeringVector` + DAMAS/CLEAN-SC/CMF | 完全同构（导向矢量与介质无关） |
| 正则化反卷积 / 稀疏先验 | Tikhonov 0/1/2 阶 + L 曲线选 λ（`attomo`） | 同一条病态反演链 |
| 射线追踪 / 大气折射修正 | `attomo.compute_forward_op` 射线路径矩阵 | 同一套几何声学 |
| CFAR 检测 + 门限标定 | AE 事件拾取（AIC / 阈值 / timepicker） | 同一套虚警-漏警权衡 |
| 干扰对消 / 相干源抑制 | CLEAN-SC / CMF 的相干源去相关 | 同一个协方差矩阵修正技巧 |

**唯一的物理不对称，也是声学的价值所在**：

- 光散射法（激光衍射 / DLS）在浓体系里被**多次散射**打死，必须稀释几个数量级 → **测的不是原浓体系**；
- 声波波长远大于分子、与颗粒同尺度，能穿过高固含量浆料，衰减里同时携带**黏性损失（∝ f² 量级）、热损失、散射（Rayleigh 区 ∝ f⁴ 量级）**；
- 因此 `α(f)` 的**幂律指数随粒径变化**：细颗粒被黏性/热吸收主导（低频段陡），粗颗粒进入散射区（高频段陡）。**宽带测一条 α(f)，本质上是在做一次"粒径的频谱指纹识别"**。

> 落点一句话：**PBM 需要时间片上的 PSD，光学法给不了原浓的 PSD，声学法能——代价是要自己写正向算子（ECAH 类模型）并标定。**

**建成的模块（拟）**：

```
acoustics/
  atten_forward.py    # PSD + 物性 → α(f) 正向算子（ECAH：黏性/热/散射三项叠加）
  atten_inverse.py    # α(f) → PSD 的 Tikhonov/L 曲线反演（骨架取自 attomo）
  cavitation_dose.py  # 驱动波形 → 气泡 RP 解 → 声发射谱（骨架取自 apecss）
  source_map.py       # 阵列数据 → 声源图像（骨架取自 acoular）
  ae_features.py      # AE 命中 → 频域/时域特征（vallenae + MistrasDTA 双格式入口）
```

**非侵入旁路**：以上全部独立可运行，只**读** PBM/DEM 的输入输出，不改主流程（与轮 47「不改现有写路径」同纪律）。
