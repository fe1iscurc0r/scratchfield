## 1. 优先级 6 单（工单指定，深挖）

### 1.1 Monroe Molecular FM（2608.18982，第七批 M40 / 第六批 M44）
- **核心**：81M 参数的分子 + 量子化学预训练 PFN（Prior-data Fitted Network），下游任务适应，
  活性悬崖（activity cliffs）预测新 SOTA。
- **方法拆解**：预训练 PFN 在「分子 SMILES/图 + 量子化学标签」上做 in-context/少样本适配，81M 参数
  覆盖多任务（性质预测/活性悬崖），替代逐任务训练。
- **对陆墨借鉴**：① 活性悬崖（结构相似但活性剧变）对生物质组分-性能预测是核心难点，Monroe 的
  少样本悬崖检测可迁移；② 承接 M09 UBio-MolFM（同为预训练分子 FM），Monroe 偏「性质/活性」，
  UBio-MolFM 偏「动力学/势能」，两者互补；③ 81M 参数需云端推理，边缘走蒸馏（接 M34）。
- **验收**：评估报告（本报告 §1.1）+ 借鉴点 3 条 ✅。

### 1.2 UBio-MolFM（2608.18623，第六批 M42 / 前批 M09）
- **核心**：预训练量子化学 FM，单模型 DFT 精度、10⁵ 原子规模，覆盖离子传导/膜渗透/金属识别。
- **说明**：已在 M09 完成勘察（规模/算力评估表 + 云边协同路径）。本卷为「补充 M36」扩编，
  不重复铺开；补充结论：与 Monroe 分工——UBio-MolFM 管「电子结构/动力学」，Monroe 管「性质/活性悬崖」。
- **验收**：承接 M09 已交付，本单补充分工说明 ✅。

### 1.3 电解质分子设计（2608.16364，第六批 M43 / 前批 M31）
- **核心**：锂电电解液「腈中心 + 醚辅助」motif 层级——平衡电子稳定性与 Li⁺ 溶剂化。
- **说明**：已在 M31 完成评估（方法拆解 + 生物质基电解质适配：骨架天然醚氧配位 + 需吸电子基接枝）。
  本卷补充：与 Monroe/UBio-MolFM 衔接——用分子 FM 预筛「稳定核心 + 配位基」候选，再 motif 提炼。
- **验收**：承接 M31 已交付，本单补充衔接路径 ✅。

### 1.4 压卡分子晶体动力学（2608.22091，第六批 M38）
- **核心**：barocaloric（压卡）分子晶体的有序-无序相变，是固态制冷有前景的机制。
- **对陆墨借鉴**：① 压卡效应（压力驱动的相变熵变）对生物质基相变储能材料有类比价值；② 有序-无序
  相变建模可复用 M06（量子储层/软物质非平衡）与 M29（离散流匹配电子重排）的思路；③ 分子晶体的
  取向自由度 → 相变熵，可迁移到纤维素/木质素的构象自由度相变研究。
- **验收**：评估报告 + 借鉴点 3 条 ✅。

### 1.5 聚合物玻璃力学（2608.19790，第六批 M39，"A molecular perspective on the…"）
- **核心**：从分子视角理解聚合物玻璃的力学（玻璃化、脆韧、屈服）——分子尺度机制到宏观力学。
- **对陆墨借鉴**：① 生物质聚合物（纤维素/木质素）与合成玻璃在「分子堆积 + 链动力学」上同构，
  玻璃力学框架可迁移；② 承接 M02（TIP 热力学势→水凝胶相变）的「分子动力学→相变」路线；
  ③ 玻璃化转变的分子机制可指导水凝胶/木质素材料的增韧设计。
- **验收**：评估报告 + 借鉴点 3 条 ✅。

### 1.6 近晶液晶玻璃（2608.20543，第六批 M40）
- **核心**：模型近晶液晶分子（itraconazole）气相沉积制备玻璃，呈现高度有序的近晶-like 堆积。
- **对陆墨借鉴**：① 气相沉积调控「有序-无序」堆积，对生物质薄膜/涂层的有序化制备有借鉴；② 近晶
  有序（层状堆积）与纤维素微纤丝的取向有序同构；③ 玻璃中「冻结的近晶有序」可类比木质素芳香环
  的 π-π 有序堆积。
- **验收**：评估报告 + 借鉴点 3 条 ✅。
