# 大工程规划 · 第二部分：三大方向路线图

## 方向 A：rf_brain 射频大脑（物理感知层）

**愿景**：从"解调链雏形"成长为"自主频谱认知系统"

| 阶段 | 内容 | 代码量 | 依赖 |
|------|------|--------|------|
| P5 | 自主闭环：扫描→检测→LLM选解调→解码→反馈 | ~800行 | 无 |
| P6 | 多协议解码器库（APRS/PSK31/DTMF...） | ~1500行 | P5 |
| P7 | IC-705 USB 音频输入抽象 | ~300行 | 真机 |
| P8 | 频谱数据库 + 信号档案 | ~600行 | P6 |
| P9 | LoRa mesh 组网运营（MeshRadio 整合） | ~1000行 | P5 |
| P10 | MUSIC 测向阵列（doa.py 整合） | ~800行 | 硬件阵列 |
| P11 | 业余频段合规白名单强化 | ~300行 | 持续 |
| P12 | 实时频谱 UI（前端） | ~1000行 | P8 |

**远期**：全自主频谱监测站——自动发现新信号、自动分类、自动归档，配合 IC-705/UV-K6 做真实通联验证。

## 方向 B：Lumo 科研工作台（领域应用层）

**愿景**：从"科研 agent"成长为"材料科学家数字助手"

| 阶段 | 内容 | 代码量 | 依赖 |
|------|------|--------|------|
| P1 | academic 16 融合（MODEL_INTERFACE×16） | ~2000行 | 无 |
| P2 | graphify GraphRAG（图谱+向量检索） | ~800行 | graphify 已装 |
| P3 | duckdb 分析工作台 | ~600行 | duckdb 已装 |
| P4 | 科研写作管线（综述→实验→分析→论文） | ~1000行 | P1-P3 |
| P5 | 材料数据自动采集（文献→结构化） | ~800行 | P2 |
| P6 | 实验设计与仿真（PyXtal/FEMcy/tespy 联动） | ~1200行 | P1 |
| P7 | 结果可视化（graphify HTML/科学绘图） | ~600行 | P4 |
| P8 | 论文产出辅助（nature-skills 整合） | ~800行 | P4 |

**远期**：Lumo 成为"从文献调研到论文初稿"的全流程助手，服务于生物质能源与材料专业（木质素→水凝胶→太阳能蒸发方向）。

## 方向 C：NEKO 记忆层 + 授粉落地（认知层）

**愿景**：从"大而不精"到"记忆即服务"

| 阶段 | 内容 | 代码量 | 依赖 |
|------|------|--------|------|
| P1 | 混合检索 RRF + index_cards + 会话血统 | ~800行 | 无 |
| P2 | compaction 升级（branch-summarization） | ~400行 | P1 |
| P3 | 后台静默写入 + 记忆过期 | ~500行 | P1 |
| P4 | nuwa 上游同步（FIDELITY+scripts） | ~400行 | 无 |
| P5 | 流程层 skills 三件套 | ~600行 | 无 |
| P6 | 记忆即服务 API（供全系统调） | ~500行 | P1-P3 |

**远期**：记忆层成为全系统共享底座——NEKO/rf_brain/Lumo 共用一套记忆 API（会话血统+混合检索+索引卡）。
