## 〇、两勘察点合并结论（一句话）

**先做勘察点 1（频谱稀疏重建），它贴着 rf-brain / LoRaCanary / 哨兵网格主线、且"档A"零采购立即可做；勘察点 2（近场探头）更独立、研究向，且 ESP32 内置 ADC 有硬短板，降级为"档A 验证信号可达性"后再决定是否深挖。**

## 一、两勘察点横向对比

| 维度 | 勘察点 1：电磁孪生稀疏重建 | 勘察点 2：NICWhisper 近场探头 |
|---|---|---|
| 目标 | 433MHz 环境感知（底噪/干扰/多径）→ 频谱后处理 | 设备网络活动 → 电磁泄漏指纹 |
| 与主线关系 | **强**：直接喂 rf-brain 决策 + LoRaCanary 帧可靠性判断 + 哨兵网格网关质量 | **弱**：独立研究向，与 LoRaCanary/哨兵无直接复用 |
| 现在能做的部分 | **档A 底噪画像 + 干扰粗分类（零采购，SX1278 统计量 + ELM-LUT）** | 粗粒度"活动有无/强度"（磁棒+运放+ADC，~¥60 材料） |
| 卡点 | 档B/C 稀疏重建需 **RTL-SDR（未购）** | ESP32 ADC ENOB/带宽 + 无商用探头，复现论文精度需外置 ADC/SDR |
| 采购成本 | 档A ¥0；档B ≈¥130–200 | 起步 ≈¥60–120；复现论文 ≈¥数百（商用探头） |
| 算法成熟度 | 高（CS/OMP 经典 + 已有 Channel2World 骨架） | 中（论文是预印本，无同行评审） |
| 可行性 | **部分能做 → 采购后完整** | **部分能做（粗）→ 完整需换硬件** |

| 顺序 | 动作 | 依赖 | 成本 | 产出 |

| **P2（低成本验证）** | 09-02 档A：磁棒探头 + 运放 + ESP32 ADC 验证"能否采到 75–200kHz 包络" | 材料 ≈¥60–120 | ¥60–120 | 判断 NICWhisper 方向是否值得深挖 |

## 五、真机验证步骤（合并，按顺序）

1. **底噪基线**：SX1278 上电 `STATUS`，静置 10 分钟记录 `rssi_dbm`，确认 -110~-95dBm（09-01 档A）。
2. **干扰对照**：UV-K6 低功率 + 假负载在 433MHz 附近发射 CW，观察 SX1278 RSSI/SNR 时序能否区分（09-01 档A）。
3. **稀疏重建**：RTL-SDR 采 1s IQ → FFT 见 UV-K6 谱线 → OMP 从 1/4 欠采样恢复（09-01 档B）。
4. **多径**：移动 SDR / 靠近反射面，看时延谱簇数变化（09-01 档B）。
5. **探头可达性**：磁棒贴网卡/ESP32 自身，示波器看 75–200kHz 包络；再上 ESP32 ADC 看信号是否 > 底噪 10dB（09-02 档A，Go/No-Go）。
6. **粗分类**：目标设备空闲 vs 压测，频谱能量差异是否显著（09-02 档A）。
