## 2. 对照表：木质素 NPs / 共熔凝胶的哪类物性用什么预估

| 目标物性 | 物理含义 | 可用生态/方法 | 现阶段可行性 |
|---|---|---|---|
| **χ 参数**（Flory-Huggins 交互） | 溶剂-木质素相容性、相分离/溶胀驱动 | `vendor/polykin`（活度系数族：Flory-Huggins/NRTL/UNIQUAC）+ 小超胞 MLIP 能量差 | ✅ 可从 polykin 起步（本轮已接入 vendor） |
| **玻璃化转变 T_g** | 共熔凝胶的力学/热稳定窗口 | MLIP-MD 比容-温度扫描（慢）；或 `martignac` 工作流做 CG 粗粒化近似 | ⚠️ 计算量大，建议先 CG 后 MLIP |
| **扩散系数 D** | 小分子在凝胶网络中的输运（水下电子线的关键） | MLIP-MD 均方位移；介观可用 `vendor/DPDsim`（非键合近似） | ✅ DPD 起步 → 关键体系上 MLIP |
| **界面/表面羟基密度** | NPs 表面化学（关联 FTIR 表征） | 小超胞 DFT + MLIP 富集采样 | ⚠️ 需先有 M1 数据（见路线图） |
| **结合/吸附亲和力** | 添加剂-木质素相互作用初筛 | **Boltz-2**（MIT，代码与权重均已实测可商用） | ✅ 候选体系粗筛的首选入口 |

## 3. 流程：计算初筛 → 实验验证（文本版）

```
[候选体系清单]  ← 本节 §4 的 10 个
      │
      ├─(1) 廉价粗筛：拓扑/物性经验规则 + polykin 热力学估算        ← 分钟级
      │        剔除明显不相容/不可成药体系
      │
      ├─(2) 亲和力/结构初筛：Boltz-2（结构 + 结合亲和力联合建模）    ← 小时级（单卡）
      │        产出：候选-配体相互作用排序 + 结构合理性
      │
      ├─(3) 介观验证：DPDsim（非键合近似）跑网络连通性/输运趋势      ← 小时~天
      │        产出：D、孔洞/网络演化趋势
      │
      ├─(4) 高精度：小超胞 MLIP 主动学习闭环（见卷151 路线图 M1~M3） ← 周级
      │        产出：χ、界面能、关键反应路径能垒（带测试集误差）
      │
      └─(5) 实验验证（用户已确认的课题组方向）：合成 → FTIR/流变/溶胀
               判据：计算排序与实验排序的**秩相关**（不要求数值一致）
```

**每层都要留数字**：粗筛给排序、Boltz-2 给分数、DPD 给趋势、MLIP 给误差区间、实验给秩相关。
**没有数字的层不许写"已验证"**。

## 4. 首批 10 个候选体系（可起点，非最终结论）

按"木质素 NPs × 共熔凝胶/水凝胶 × 水下电子"这条线铺开，覆盖 5 个方向、每方向 2 个：

| # | 体系 | 方向 | 首选方法 |
|---|---|---|---|
| 1 | 碱木质素 / 水（χ 基线） | 相容性基线 | polykin |
| 2 | 碱木质素 / 氯化胆碱-乙二醇（DES） | 共熔凝胶溶剂 | polykin + Boltz-2 |
| 3 | 木质素磺酸盐 / 水-甘油 | 增塑/保湿 | polykin |
| 4 | 木质素 NPs / PVA 水凝胶网络 | 网络力学 | DPDsim → MLIP |
| 5 | 木质素 NPs / PAAm 共熔凝胶 | 低温抗冻 | DPD → MLIP |
| 6 | 木质素 NPs / 明胶-甘油 | 可拉伸离子导体 | DPD → MLIP |
| 7 | 木质素模型二聚体（β-O-4）/ 水 | 连接键能基准 | 小超胞 MLIP（M1 起） |
| 8 | 木质素模型三聚体（β-O-4/β-β）/ 离子液体 | 降解路径 | MLIP 主动学习 |
| 9 | 木质素 NPs 表面（羟基化）/ 水 | 界面润湿 | MLIP 界面 |
| 10 | 木质素 NPs / 导电高分子（PEDOT:PSS） | 水下电子电极 | Boltz-2 + MLIP |

> 选体系的原则：**每方向留一个"最容易算"的和一个"最像真实体系"的**，
> 便于对照出"近似到底损失了多少"。
