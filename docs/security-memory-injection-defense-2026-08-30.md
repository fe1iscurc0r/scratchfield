## 一、问题陈述

InjecMEM（2608.23471）揭示一种更隐蔽的记忆攻击：**仅需一次交互、无需读写内存**，即可对 LLM Agent 的记忆系统注入**定向偏移**。攻击者用梯度优化对抗命令，让记忆系统产生定向偏移，且这些命令**跨模型迁移**（对多个模型都有效）。记忆持久化因此成为新的持久化攻击面——不是"注入一条假事实"，而是"让整个记忆系统朝攻击者想要的方向偏移"。

## 二、攻击模型（复现）

1. **目标**：对记忆系统注入定向偏移（如让 Agent 系统性地偏向某个偏好/立场/决策）。
2. **手段**：梯度优化出一次交互的对抗命令（无需反复读写内存）。
3. **特性**：跨模型迁移——对抗命令对不同模型同样有效。

## 三、防御机制

1. **写时对抗检测**：对写入记忆的内容做对抗性检测（识别梯度优化的对抗命令特征，而非仅语义注入）。
2. **记忆基线校验**：定期校验记忆分布的偏移量，检测"系统性定向偏移"（而非单条注入）。
3. **来源分级**：与 A09 互补——低信任来源的写入不改变记忆分布权重。
4. **偏移回滚**：检测到定向偏移时，回滚到攻击前的记忆基线。
5. **跨模型鲁棒性**：由于对抗命令跨模型迁移，防御不应依赖单一模型的语义判断，需引入独立检测器。
