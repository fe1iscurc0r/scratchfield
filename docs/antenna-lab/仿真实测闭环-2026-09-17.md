# 天线仿真 ↔ 实测闭环（卷122 W122-04 · 2026-09-17）

仿真结论要能和实测对账才有意义。本文定义两边字段的映射与对账流程，
上承卷118 W118-03「无相位天线测量方案」（降采样测量 → 方向图补全），
下接卷122 W122-03 的仿真报告字段。

## 字段对账表

| # | 仿真侧字段（`summary.json`） | 实测侧字段（W118-03 方案） | 对账方式 |
| --- | --- | --- | --- |
| 1 | `resonance_mhz`（谐振频率） | 扫频实测回波损耗最低点频率 | 偏差 >1% → 修正振子长度（仿真给方向，实测给量） |
| 2 | `s11_min_db`（谐振点 S11） | 实测最小回波损耗 dB | 差 >6dB → 检查馈电/巴伦/接地（仿真不含馈线损耗） |
| 3 | `bandwidth_hz` / `bandwidth_ratio` | 实测 -10dB 带宽 | 相对带宽比对；仿真偏窄常见于网格过粗 |
| 4 | `zin_at_resonance`（Zin 实部/虚部） | 矢量网络分析仪实测 Zin | 实部偏差 >30% → 优先怀疑仿真网格（见 README 标定缺口） |
| 5 | 增益 dBi（方向图峰值） | 实测增益（参考天线替换法） | 仿真通常乐观 1~3dB；用差值做相对校准 |
| 6 | 前后比 / 波束宽度 | 实测方向图切片 | 形状比对（更看「瓣形一致」而不是绝对峰值） |
| 7 | 模型文件头（类型/频率/尺寸/网格假设） | 实物尺寸/环境（高度、地面、附近金属） | **必须逐项核对**：环境差异常是偏差主因 |

## 对账流程

```
仿真（gen_model → sim_run → analyze_result）
   ├─ summary.json + report.md 归档 docs/antenna-lab/results/<job_id>/
   ↓
实测（卷118 W118-03：云台 + 降采样 → 方向图补全）
   ├─ 实测数据落同一 job_id 目录（实测摘要 JSON，原始数据不进 git）
   ↓
对账（本文件表格逐项填）
   ├─ 偏差在容差内 → 结论可采信，更新档案状态为「仿真+实测一致」
   ├─ 谐振偏移 → 按「实测定长度、仿真定拓扑」迭代
   └─ 增益偏差 → 先排除环境（地面/馈线），再考虑网格加密复算
```

## 档案目录规范

```
docs/antenna-lab/
├── 仿真实测闭环-2026-09-17.md      # 本文（字段对账与流程）
└── results/
    ├── README.md                   # 索引：job_id / 类型 / 结论 / 实测状态
    └── <job_id>/
        ├── summary.json            # 仿真分析摘要（进 git）
        ├── report.md               # 可读报告（进 git）
        ├── measurement.json        # 实测摘要（有实测后进 git）
        └── raw/                    # 原始输出（HDF5/PNG/日志）——**不进 git**
```

**git 纪律**：只入库 `summary.json` / `report.md` / `measurement.json` 与索引；
原始仿真输出与图片放 `<user_data>/antenna-lab/results/`（本地）或 http_share，**不进仓**。

## 用户入口（对话里怎么用）

1. 「帮我仿真一个 14MHz 的 Moxon」→ `gen_model(antenna_type=moxon, freq_mhz=14.05)`
2. 「跑一下」→ `sim_run(model_path=...)`（本机 OpenEMS；无环境时 `dry_run` 走状态机）
3. 「结果怎么样」→ `analyze_result(job_id=...)`（无输出时可用 `synthetic=True` 跑通链路，报告会标注合成）
