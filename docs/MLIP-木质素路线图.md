# MLIP 木质素路线图 — 轮23 授粉点③：小数据 MLIP → 木质素 NPs 分子模拟

> 来源：卷151 任务C（2026-09-23 晨增量轮授粉点）· 落盘：砚 · 状态：**路线图（未开工）**

## 1. 为什么走 MLIP，而不是纯经典力场

课题组方向（木质素 NPs → 水凝胶/共熔凝胶 → 水下电子）的瓶颈是**木质素结构的无序性**：
经典力场对 β-O-4/β-β/5-5 等连接键的断裂能、以及 NPs 表面羟基密度给不出可信数字；
第一性原理（DFT）算得准但**超胞一大就跑不动**。MLIP 正好卡在中间：**DFT 精度、接近 MD 的速度**。

## 2. 小数据策略（本路线的核心，不是"数据不够就等"）

| 手段 | 做法 | 预期收益 |
|---|---|---|
| 小超胞起步 | 先建 20~50 原子小超胞（单连接键模型 + 少量显式水），DFT 标定 | 训练集可在本机/单卡产出的量级 |
| 迁移学习 | 用公开 MLIP 基础模型（MACE/NequIP 系）作初始化，再小数据微调 | 把"从零训练"降级为"微调" |
| 主动学习/富集 | 用当前模型跑 MD → 挑不确定度高的构型回灌 DFT → 重训（迭代 3~5 轮闭环） | 每一份 DFT 算力都花在模型最不懂的地方 |
| 结构先验富集（**Boltz-2 早期富集**） | 先用 Boltz-2 类结构预测给出候选构型/界面排布，**筛掉明显不合理的构型**再进 DFT | 减少无效 DFT 采样（这是工单点名的"早期富集"） |

**关键判断**：小数据 MLIP 的成败不在模型大小，而在**采样点是否落在关键自由度上**（连接键断裂路径、表面质子转移）。富集 = 把采样预算花在这几处。

## 3. 里程碑（每步都有可判定的产出）

| 里程碑 | 产出 | 判定 |
|---|---|---|
| M1 基准超胞 | 20~50 原子模型的 DFT 数据集（能量/力） | 训练/验证集落盘，能量 MAE 有数字 |
| M2 首个 MLIP | 微调后的势函数文件 + 推理脚本 | 在 M1 验证集上力 MAE 达标（阈值待定，需先看数据） |
| M3 闭环 | 主动学习 1 轮（挑构型→DFT→重训） | 第 2 代模型在同一测试集上优于第 1 代 |
| M4 应用 | 木质素 NPs 表面/界面的 MD 轨迹与性质统计 | 与实验（FTIR/流变）可对照的量至少 1 个 |

## 5. 验证边界（本机能做到哪一层）

- **能在本机做**：小超胞 DFT 数据（视算力）、模型微调、推理、主动学习闭环脚本、MLIP vs DFT 的误差评估
- **本机做不了 / 需外部资源**：大体系长时间 MLIP-MD（需 GPU 集群）、Boltz-2 权重获取（需确认许可与获取渠道 —— **未核实，先不写进依赖**）
- **不许含糊**：MLIP 精度必须用**留出测试集**报数字；没有数字之前不许写"已达到 DFT 精度"
