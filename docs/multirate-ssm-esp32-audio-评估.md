# K23 多速率 SSM→ESP32 音频 DSP 评估

> 来源：round3 digest-g7 2608.28472（Multirate SSM PDM：多速率状态空间模型端到端脉冲密度调制处理）
> 原型：`tools/multirate_ssm_pdm.py` · 测试：`tools/test_multirate_ssm_pdm.py`（5 passed）
> 关联：K14 LVSSM 蒸馏、R67 多速率 SSM PDM（共享设计）

## 1. 目标与结论

ESP32 的 PDM 数字麦克风输出 1-bit 高速率（如 1–3 MHz）位流。多速率 SSM 的关键是：
**高速率段只做轻量抗混叠（CIC 箱平均 = 状态空间累加链）并降采样**，把昂贵的一阶
状态空间特征提取挪到**低速率段**。结论：**适配可行**——用极简参数（每级 2 标量）在
ESP32 内存预算内完成 PDM→PCM→特征。

## 2. 原型方法

```
模拟信号 x(t)
   │ pdm_encode（一阶 Σ-Δ）           ← 1-bit PDM 位流（±1，高速率）
   ▼
CIC 箱平均（decim 个累加器）         ← 多速率 SSM 高速段：抗混叠 + 降采样
   │ 降采样 decim×
   ▼
一阶 SSM 低通（低速率）              ← 特征提取（状态 = 1 标量/级）
   ▼
低速率包络/特征
```

## 3. 预算对比（FS=100 kHz，decim=200 → 500 Hz；原型 `budget()` 实测）

| 维度 | 单速率 SSM | 多速率 SSM |
|---|---|---|
| 特征 SSM 运行速率 | 100 kHz（全速率） | 500 Hz（低速率） |
| 状态缓冲（每通道，1 s） | ~400 KB | ~2.8 KB |
| 参数（每级） | 2 标量 | 2 标量（高段为 CIC 累加器） |
| 内存占比（多/单） | — | **0.007×** |
| PDM→PCM 重建 SNR | — | **> 30 dB**（原型实测） |

要点：单速率把特征 SSM 放在全 PDM 速率跑，1 s 状态缓冲 ~400 KB，超过 ESP32 片上
RAM（~320 KB）；多速率把特征降到 500 Hz，状态降到 ~2.8 KB，轻松落地。

## 4. ESP32 可行性

- **精度**：一阶 Σ-Δ + 200× 过采样 CIC（sinc¹）重建 SNR > 30 dB；**二阶 Σ-Δ + sinc²
  可达 ~75 dB**（`pdm_encode2` + `cic_decimate(order=2)`，原型实测），高阶调制需配高阶
  CIC 才能兑现噪声整形收益。音频/传感场景一阶已够用，高保真场景用二阶。
- **内存**：多速率状态 ~KB 级，适配 ESP32-S3（512 KB SRAM）与经典 ESP32（320 KB）。
- **算力**：CIC 段只做累加（无乘法），低速率 SSM 每级 2 标量 → 满足 ESP32 双核 DSP 预算。

## 5. 落地建议

与 K14 LVSSM 蒸馏衔接：低速率段的"一阶 SSM 特征"可替换为蒸馏后的 LVSSM，形成
"PDM→CIC→蒸馏 SSM"端到端链；与 R67 共享 CIC 前端设计，避免重复实现。
