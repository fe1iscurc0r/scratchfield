## 三、顺带发现：venv 系统性损伤（本机环境，不进仓）

排查中发现 **WorkBuddy safe-delete shim 对 venv 的持续性损伤**（两类）：

| 损伤类型 | 实测 | 修复 |
|---|---|---|
| dist-info 缺 METADATA | **31 个包**（docling 全家桶、affine_gaps、fluids、h5py…） | 批量 `uv pip install --reinstall <31 个>` |
| 包目录被掏空（.py 全删） | `thermo` 目录仅剩 1 个 JSON | `--reinstall thermo` |

⚠️ 该损伤会在**每次 uv install 时新增**（本轮修复后仍有 14 个新损伤）——不阻碍 import
（METADATA 只服务 uv 的元数据查询），但会让后续 `uv pip install` 报
`Failed to read metadata ... os error 2`。**运维建议**：遇到该报错直接
`--reinstall` 报错包即可（已记入环境依赖清单）。
