## 3. 跨组可复用结论

1. **「时序/多模态 → 异常检测」的 LLM Agent 范式**是 SDR 频谱监测的统一骨架（G1）。
2. **可微仿真 + 数字孪生 + 世界模型**是「免测绘/自校准/预测式」无线链路的共同底座（G3）。
3. **确定性门控/写时筛查/来源分级**贯穿安全与标定（G6/G7），与既有 skill_gate/ROPE 起源门控同向。
