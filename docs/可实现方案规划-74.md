## 2. 待落地方案（按 P0→P2）

### P0-1 Accept-Markdown 中间件（已完成原型，待接入）
- **目标**：给文档站/MCP 服务加 `Accept: text/markdown` 支持，agent 抓取省 token。
- **路径**：`tools/accept_markdown.py` 的 `serve()` 接入 apiserver/web 中间件；HTML→Markdown 用更完整转换器（如 markdownify）替代极简正则版。
- **验收**：`curl -H "Accept: text/markdown"` 返回 markdown；HTML 默认不变。

### P0-2 LightRAG 轻量图索引（已完成原型，待接 rag/）
- **目标**：rag/ 检索引擎加「实体-关系轻量图」层，多跳问答用图检索补充向量检索。
- **路径**：`tools/lightrag_graph.py` 的 `LightGraphIndex` 接入 rag/ 引擎；实体抽取用现有 NLP 或规则替换启发式。
- **验收**：多跳问答命中率较纯向量检索提升；图索引开销可控。

### P1-1 multiplierless DFT 端上落地（已完成原型，待接 rf_brain）
- **目标**：ESP32-S3 上无乘法 DFT 近似，省乘法器。
- **路径**：`tools/multiplierless_dft.py` 的量化旋转因子思路移植到 rf_brain 频域前端（C++ 镜像，复用 elm_train.py 的定点导出思路）。
- **验收**：量化 DFT 相对标准 DFT 误差可控（<阈值），MAC 数降。

### P1-2 skill_gate 权限内核增强（W73-08/12）
- **目标**：模型↔shell 之间加确定性权限最小化层 + 运行时 skill 行为监控。
- **路径**：扩展 `tools/skill_gate.py`：①动作先过权限校验再达 shell；②skill 行为监控（Defense-as-Skill）。
- **验收**：伪造来源注入成功率降；正常调用通过率 ≥90%（复用 A34 ROPE 口径）。

### P1-3 记忆写入授权审计（W73-10 MutMem）
- **目标**：记忆写入/变异需可验证授权，防篡改。
- **路径**：`mcpserver/memory_maas` 增加写入授权（HMAC 起源 + 三阶段审计），对应 A216 记忆三阶段投毒剖面。
- **验收**：未授权写入被拒；授权写入通过。

### P2-1 图记忆/事件流对接（W73-03 cognee）
- **目标**：memory_maas 增加 event_protocol 事件流对接 + 实体抽取增强。
- **路径**：把交互作为事件流接入记忆；实体抽取用现有 NLP。
- **验收**：跨会话 recall 提升；不引入自托管 Neo4j 重依赖。

### P2-2 依赖漏洞图谱化（W73-10 Athena）
- **目标**：third-party-code-audit 增加依赖漏洞知识图谱。
- **路径**：依赖 → 漏洞 CVE 建 KG，图谱化追踪。
- **验收**：漏洞影响面可图谱化查询。

### P2-3 态势面板数据源清单（W73-05 Shadowbroker）
- **目标**：sentinel_intel 增加合规数据源清单（ADS-B/AIS/震情等，AGPL 只参考不融合）。
- **路径**：数据源清单 + 接入 sentinel_intel。
- **验收**：合规数据源可聚合查询。

## 3. 不建议落地（许可/定位）

| 项 | 原因 |
|---|---|
| URH（GPL）、Shadowbroker（AGPL） | 传染性许可，只参考设计不抄代码 |
| AutoProber 类硬件飞针 | 离栈 + 非商用许可 |
| 全量 GraphRAG / Neo4j | 重依赖，轻量图索引已够用 |

## 4. 通用纪律

- 安全类只写防御；硬件类标「待真机」；GPL/AGPL 只参考设计。
- 原型 numpy/stdlib 够用；显式 `git add` 分项 commit；验收指标可量化。
