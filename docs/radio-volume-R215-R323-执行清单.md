## 4. 跨组可复用结论

1. **信道建模从「实测」转向「先验 + 生成」**（R275 遥感、R265 扩散生成、R287 亚 6GHz 辅助）——LoRaCanary/rf_brain 部署前可用遥感/生成式先验免现场测量。
2. **通信-感知一体化（ISAC）**（R235/R301/R307）——波形同时承载通信与感知，是可复用方向。
3. **多任务 + 不确定度加权**（R229）——调制识别/解调可合并为单一多任务头，用同方差不确定度加权损失。
