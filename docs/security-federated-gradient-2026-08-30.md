## 一、问题陈述

联邦学习让各方在不共享原始数据的前提下协作训练，但**梯度本身可被反演攻击**（gradient inversion）——攻击者从共享梯度重构出私有训练数据。对材料实验数据（生物质材料、催化剂性能数据）的分布式 AI 训练，这是直接威胁：各方不愿共享原始实验数据，但梯度却可能泄露这些数据。

AEGIS（三通道梯度隔离）、FedGuard-DC（隐私保护联邦负载预测）正在解决梯度反演与模型投毒问题。

## 二、梯度保护方案

1. **梯度隔离**：借鉴 AEGIS，把梯度按通道隔离（如 attention 嵌入梯度、其他层梯度分通道处理），限制反演攻击可利用的信息。
2. **差分隐私梯度**：梯度加噪，平衡隐私与模型精度。
3. **鲁棒聚合**：借鉴 FedGuard-DC，聚合阶段过滤异常/恶意梯度，防模型投毒。
4. **梯度裁剪**：裁剪大梯度，减少单一样本对梯度的贡献泄漏。

## 三、威胁模型

| 威胁 | 说明 | 防护 |
|---|---|---|
| 梯度反演 | 从梯度重构原始材料数据 | 梯度隔离 + 差分隐私 |
| 模型投毒 | 恶意方注入毒梯度 | 鲁棒聚合 |
| 成员推断 | 推断某样本是否参与训练 | 差分隐私 + 裁剪 |
