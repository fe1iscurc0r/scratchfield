## 1. 优先级 5 单（工单指定，深挖）

### 1.1 M164 非晶 LiTaCl₆ 固态电解质弹性（2608.29404）
- **核心**：非晶卤化物固态电解质 LiTaCl₆ 的弹性性质——力学与离子传输/界面稳定性的耦合。
- **对陆墨借鉴**：① 固态电解质「力学-离子传输」耦合对生物质基凝胶电解质同样关键（接 M31 离子导体）；
  ② 非晶相弹性（vs 晶态）的可压延/界面贴合是软包电池关键，可迁移到柔性水凝胶电解质；③ 力学表征
  方法（弹性模量→界面应力）可复用到生物质基固态电解质评测。
- **验收**：评估 + 借鉴 3 条 ✅。

### 1.2 M195 MOF 增强自发泡多孔摩擦电材料（2608.31019）
- **核心**：HKUST-1（MOF）增强自发泡多孔摩擦电材料——MOF 抑制孔塌陷 + 吸附水分子，抗湿度稳定性提升。
- **对陆墨借鉴**：① MOF/生物质杂化（纤维素-MOF）可借鉴「骨架增强多孔 + 湿度管理」双功能；② 自发泡多孔
  结构 + 摩擦电（能量收集）对生物质基可穿戴能源器件有直接类比（接 M112 能量收集）；③ 抗湿度稳定性是
  生物质材料（天然亲水）的核心痛点，MOF 吸湿调控思路可迁移。
- **验收**：评估 + 借鉴 3 条 ✅。

### 1.3 M182 聚合物膜张拉整体逆设计（2608.30501）
- **核心**：LCD 光罩单面 UV 固化嵌入刚性杆的聚合物膜张拉整体（tensegrity），误差仅 1-2%。
- **对陆墨借鉴**：① 「刚性杆嵌入柔性膜」的力学增强策略可迁移到纤维素/水凝胶膜增强；② 单面 UV 固化
  的低成本逆设计工艺，对生物质基薄膜/涂层的图案化制备有借鉴；③ 张拉整体（受拉稳定）是轻质高强结构
  设计范式，可指导水凝胶支架力学设计。
- **验收**：评估 + 借鉴 3 条 ✅。

### 1.4 M167 锌电池固态/准固态电解质系统分类（2608.29586）
- **核心**：锌电池固态/准固态电解质系统分类，揭示「水活度 vs 离子传输」的内在权衡。
- **对陆墨借鉴**：① 锌电池水系电解质与生物质水凝胶离子导体的「水活度-传输」权衡同构（接 M31）；
  ② 系统分类框架可复用为陆墨电解质选型矩阵；③ 准固态（凝胶）路线天然契合生物质基水凝胶电解质。
- **验收**：评估 + 借鉴 3 条 ✅。

### 1.5 M161 胶体-聚合物混合物热力学相行为（2608.29124）
- **核心**：从径向分布函数（RDF）直接预测胶体-聚合物混合物热力学相行为的液体理论框架。
- **对陆墨借鉴**：① RDF→相行为框架可迁移到木质素/纤维素胶体分散、水凝胶相分离；② 承接 M21（熵与
  Frenesy 非平衡语言）的平衡热力学互补；③ 相行为预测可指导生物质基胶体/乳液的稳定性调控（接 M18 乳液）。
- **原型**：`tools/colloid_polymer_phase.py` + pytest（RDF→结构因子→等温压缩率 S(0)→spinodal 阈值；
  实测 S(0) 随耗散强度单调上升 -0.668→15.482，相分离阈值 ≈4.0）。
- **验收**：评估 + 借鉴 3 条 + 原型 pytest 2 用例全绿 ✅。
