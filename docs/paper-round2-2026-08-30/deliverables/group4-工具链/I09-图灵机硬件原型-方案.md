# I09 图灵机硬件原型（教学）方案

> 来源：`digest-gx-4a-2026-08-30.md` 授粉点 ② ｜ 优先级 P2 ｜ 落点：ESP

## 方案对象

- **2608.24742**《Design and Empirical Characterization of a Hardware-Realized Turing Machine with Automated Card-Based Programming》：完整硬件图灵机 = **Arduino Mega + ESP32-CAM 光学读卡 + NEMA17 马达**，**flood-fill 自适应阈值（75%→90%）**读打孔卡，end-to-end 验证。

## 光学读卡方案（授粉点 ② → 嵌入式 Agent 执行引擎）

1. **读卡**：ESP32-CAM 拍摄打孔卡 → flood-fill 自适应阈值（75%→90%）二值化 → 识别孔位 → 解码为图灵机转移规则。
2. **执行**：Arduino Mega/ESP32 按转移规则驱动 NEMA17 步进马达（读写头位移）。
3. **定位**：作为嵌入式 Agent 执行引擎的教学/原型平台——用物理卡片承载「指令」，光学读回，闭环执行。

## 接线/代码方案（草案）

- ESP32-CAM（OV2640）→ 打孔卡图像采集 + 二值化（阈值自适应）。
- NEMA17 + A4988/DRV8825 驱动 → 读卡头步进。
- 主控（Arduino Mega 或 ESP32 双核）→ 状态机执行转移表。
- 可行性：单帧打孔卡识别 + 有限状态机，ESP32 算力足够；风险在光学识别的抗环境光稳定性。

## 结论

P2：可行性成立（参考实现已验证 end-to-end）；作为教学/原型平台备选，待有「物理指令卡片」教学需求时启动。当前不投入。
