# I08 NeuralNexus 开源机械臂勘察

> 来源：`digest-gx-3b-2026-08-30.md` 授粉点 ② ｜ 优先级 P2 ｜ 落点：ESP

## 勘察对象

- **2608.22799**《NeuralNexus Arm》：开源 **6-DOF 机械臂**，**STM32H743 + 混合步进驱动**（板上 TMC2209 推挽 + 外部 CL57T/DM542 开漏），**2 kHz 中断固件**，**Web Serial 浏览器控制**，附带可复现的硬件失败模式文档。

## 评估（作参考平台）

- **价值**：ESP32/嵌入式 + 机器人栈可直接照抄的完整蓝本——中等扭矩机械臂的省成本标配（板上轻驱动 + 外部大电流开漏驱动分档）。
- **可复用点**：① 混合驱动架构（TMC2209 推挽 + CL57T/DM542 开漏）；② 2kHz 中断固件结构；③ Web Serial 无桌面依赖的浏览器控制；④ 失败模式文档（降低复现踩坑）。

## 复现清单

1. STM32H743 主控 + 6 轴混合步进驱动（TMC2209 板上 + CL57T/DM542 外部大电流）。
2. 2kHz 定时器中断步进脉冲固件。
3. Web Serial 上位机（浏览器 → 串口控制）。
4. 硬件失败模式文档（按仓库 README 逐项核对）。

## 结论
