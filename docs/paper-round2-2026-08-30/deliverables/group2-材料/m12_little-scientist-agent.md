# M12 设计：Little Scientist Agent → 材料实验自动设计

> 来源：digest-g7-1-2026-08-30.md（授粉点 1/3：The Little Scientist 的 Kuhn Agent 范式转换机制 + MCTH 冻结黑盒搜索）
> 验收：Agent 流程文档 + 一个端到端案例

## 1. 科学循环 Agent 架构

Little Scientist 的核心是让 LLM Agent 走完整科学方法循环，并在局部最优处注入"范式转换"打破路径依赖。映射到材料实验自动设计：

```
┌─────────────────────────────────────────────────────┐
│ 1. 提出假设  H: "组分 X 提升热稳定性"                 │
│ 2. 设计实验  D: 选定组分/工艺/表征手段                │
│ 3. 执行+验证 E: 运行实验(或仿真) → 数据 → 检验 H       │
│ 4. 更新知识  K: 更新材料-性能模型（冻结黑盒 surrogate） │
│ 5. 范式转换  P: 若收敛到局部最优 → 注入跨域灵感重提 H   │
└─────────────────────────────────────────────────────┘
        ↑___________________________|
```

- **冻结黑盒**（MCTH 思路）：把训练好的材料-性能 surrogate 作为"冻结算子"，Agent 用 MCTS/搜索在组分空间探索，无需每次重训模型。
- **范式转换**（Kuhn 机制）：当 surrogate 反复收敛到同一局部极值时，注入跨尺度/跨领域"反向假设"（如从"优化组分"切换到"优化工艺/界面"），强制探索新的 latent 空间区域。

## 2. 端到端案例（生物质热稳定性优化）

**目标**：最大化纤维素/木质素复合物的热解温度 T。

1. **提出假设 H1**："提高木质素占比能提升热稳定性"（先验常识）。
2. **设计实验**：Agent 选 5 组木质素占比 20%–60% 的配方，调用 surrogate（或真实热重分析 TGA）测热解温度。
3. **验证**：数据表明木质素占比在 40% 附近 T 达到峰值，继续增加反而下降——H1 部分成立。
4. **局部最优**：围绕 40% 反复微调，T 提升趋缓，Agent 判定进入局部最优。
5. **范式转换**：注入跨域灵感（"聚合物网络刚度而非单组分比例主导热稳定性"），重提假设 H2："交联/氢键网络刚度是主控变量"。Agent 转向设计交联密度/氢键给体-受体比的新实验。
6. **突破**：沿 H2 方向找到 T 显著更高的配方，跳出 H1 的局部最优。

## 3. 落地要点

- **不确定性感知**：当多个 surrogate 预测器不一致时，保留备选假设而非单点输出（MCTH 的 cross-expert 共识/分歧）。
- **成本**：范式转换注入是"探索 vs 利用"开关，需设定触发条件（如连续 N 轮收益 < ε）避免过早切换。

## 4. 建议的最小实现

用 LLM 编排 + sklearn surrogate + 一个实验执行器（TGA 实测或 MD 仿真）即可搭出最小闭环；范式转换用规则触发（收敛检测）+ LLM 生成跨域假设。
