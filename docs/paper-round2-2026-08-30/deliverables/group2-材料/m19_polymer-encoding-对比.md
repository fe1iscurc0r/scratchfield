# M19 聚合物编码策略对比 → 木质素 NPs 结构-性能建模（有源版）

> 来源已补齐：Wang & Wang. *Polymer Genome in the Age of Artificial Intelligence*, arXiv:2608.20979（复旦高分子科学系 王颖组）。
> 验收：编码对比表 + 推荐

## 1. 论文核心主张

编码策略的选择必须与**数据可用性、预测目标、结构复杂度**三者对齐——这正是"选编码而非盲目堆模型"的严谨表述。

## 2. 三类编码 + 适用场景（论文 Table 1 + 总结）

| 编码策略 | 代表 | 优势 | 局限 | 适用场景 |
|---|---|---|---|---|
| 指纹 | Morgan(RDKit) / Polymer Genome / PolyBERT | 快、可解释、**数据稀缺时反超 GNN** | 难编码聚合度/共聚序列/组成分布 | 快速性质预测、小样本 |
| 图 | 2D(GCN/GAT) / 3D(EGNN/IGNN) | 捕捉拓扑/键连/局域作用 | 需特征工程、要大数据 | 结构-性质自动提取、节点级预测 |
| 序列 | SMILES / BigSMILES / one-hot | 灵活、语义深度、兼容 NLP/Transformer | 要大数据、难表达重复单元序列 | 复杂多组分、整合外部信息 |

## 3. 论文的明确结论（直接对应工单要求）

- **"under data-scarce conditions, fingerprint-based encoding can outperform deep learning (GNN)"**——数据稀缺时指纹编码优于深度图网络。
- 编码选择准则（原文原话概括）：
  - 快速性质预测 + 数据稀缺 → **指纹**；
  - 需自动提取结构-性质关系 / 节点级预测 → **图**；
  - 需灵活整合多样外部信息 → **序列**。
- **共聚物编码是开放难题**（组成复杂、序列可变、重复单元不确定）。
- 不确定性量化同样关键：单指标 MAE/R² 不够；ensemble 在分布内稳健，Bayesian/boosting 在分布外更优。

## 4. 映射到木质素 NPs

木质素 NPs 结构异质（多分散粒径、分支拓扑、β-O-4 键型分布），难度接近"共聚物/多组分"那一档。据此推荐：

1. **数据稀缺起步 → 指纹 + 物理描述符**（粒径、ζ 电位、交联度、疏水度）作主编码——与论文"指纹在数据稀缺时最优"一致。
2. **数据充足 + 要深层结构-性质关系 → 图/序列**（但要面对木质素 NPs 无明确重复单元的编码难题）。
3. **附带**：用 ensemble 做分布内预测，用 Bayesian 方法覆盖分布外；报告不确定性而非只看 R²。

## 5. 一句话推荐

**先指纹/物理描述符跑通基线，数据量和结构先验允许了再上图/序列；编码选对，浅模型即可逼近深模型。**
