# M08 勘察：DPA4C 通用分子势 → 10⁵ 原子生物质 MD

> 来源：digest-g5-1a-2026-08-30.md 授粉点 C（源自 2608.19041v2 DPA4C 通用 ML 分子势）
> 验收：勘察 + 部署方案（含性能预估表）

## 1. DPA4C 架构要点

DPA4C 属"通用 ML 分子势"：用图神经网络/等变网络拟合 DFT 级别的势能面，训练数据覆盖多元素/多化学环境，目标是**量子精度 + 经验势速度**，支持 10⁵ 原子规模。授粉点 C 强调其 `Nano` 变体可压缩部署到 MCU/加速器，实现现场实时能量最小化或 MD。

## 2. 对生物质 MD 的适配性

| 维度 | 评估 |
|---|---|
| 元素覆盖 | 纤维素/木质素为 C/H/O 体系，DPA4C 通用势需确认含 C/H/O 的完整训练覆盖 |
| 化学环境 | 氢键、糖苷键、芳香环（木质素）是关键；需验证氢键方向性与芳环 π 作用 |
| 规模 | 10⁵ 原子 ≈ 数万单体链，满足纤维素微纤丝+木质素基质的中尺度模型 |
| 精度 | DFT 级精度对热解键断裂、氢键重排等反应事件有优势 |

## 3. 部署方案

1. **力场适配**：用 C/H/O 的 DFT 参考集（糖类/酚类小分子 + 二聚体扫描）微调或验证 DPA4C 的氢键/糖苷键/芳环描述能力。
2. **体系构建**：纤维素微纤丝（Iβ 晶型）+ 木质素低聚物 + 半纤维素，周期边界。
3. **热解/溶胀模拟**：NVT/NPT MD，升温程序观察热解键断裂顺序；或水合溶胀观察网络膨胀。
4. **嵌入式延伸**（授粉点 C 的落地方向）：将训练好的 Nano 变体量化部署，做现场催化水解路径快速筛选。

## 4. 性能预估表（量级估算）

| 体系规模 | 力场 | 单步耗时 | GPU 吞吐 (ns/day) | 精度参考 |
|---|---|---|---|---|
| 10³ 原子 | 经典 (CHARMM/OPLS) | ~1 ms | ~100 | 经验 |
| 10⁴ 原子 | DPA4C (单 GPU) | ~10 ms | ~10 | DFT 级 |
| 10⁵ 原子 | DPA4C (多 GPU) | ~100 ms | ~1 | DFT 级 |
| 10⁵ 原子 | DPA4C Nano (边缘) | ~1 s | ~0.01 | 量化近似 |

> 数值为量级估算，实际依赖硬件与势的具体实现；正式部署前需用目标体系 benchmark 校正。

## 5. 风险与建议

- **风险**：通用势对糖苷键/氢键这类强各向异性作用的迁移精度需专门验证；反应性热解（键断裂）可能超出"近平衡"势的适用范围，需要反应势或主动学习补点。
- **建议**：先做 10³ 原子基准（纤维素 Iβ 晶格参数、氢键网络 vs DFT/实验），验证精度后再扩展到 10⁵ 原子生产模拟。
