# R44 轻量协议路由器 — 方案

> 来源分组：group1-无线电（第二批）· 授粉点：2608.25277v1 Routed Graph Handoff
> 状态：✅ 原型 + 测试落地 · 文件：`tools/protocol_router.py` / `tools/test_protocol_router.py`

## 1. 目标与验收

NEKO/LoRa 网关部署轻量协议路由器：在**结构化通信**（状态同步 / 频谱分配 / 功率控制）
与**自然语言指令**之间自适应选择传输格式，目标 **≥3× 通信字节压缩**，且**任务成功率不降**。

## 2. 授粉点迁移

原论文用 155 token 的 LLM 路由器在"依赖图 vs 自然语言"之间做选择，3.2× 压缩无精度损失。
本方案把路由器降级为**规则式**（无需 LLM，适配 ESP32 级网关）：

| 原论文机制 | 本方案对应 |
|---|---|
| 依赖图结构表示 | 三套定长二进制 schema（struct 打包） |
| 自然语言表示 | UTF-8 原文透传（带 fallback 头字节 255） |
| 自适应选择 | 键集合 + 取值范围校验 → 命中 schema 走二进制，否则自然语言 |

## 3. 消息 schema

| 类型 | 字段 | struct 格式 | 载荷字节 |
|---|---|---|---|
| state_sync（状态同步） | node_id(u8), freq_hz(u32), seq(u16) | `<BIH` | 8 |
| spectrum_alloc（频谱分配） | node_id(u8), freq_hz(u32), bandwidth_hz(u32) | `<BII` | 10 |
| power_ctrl（功率控制） | node_id(u8), power_dbm(i8), timeslot(u16) | `<BbH` | 5 |

首字节为类型标识（1/2/3），255 表示自然语言回退。

## 4. 路由决策（规则式）

1. 输入为 `str` → 直接自然语言透传。
2. 输入为 `dict`：键集合与该 schema 字段**完全一致**、且所有值落在取值范围 →
   编码为紧凑二进制。
3. 否则（未知字段 / 值超范围 / 类型不符）→ 自然语言回退，JSON 序列化保留语义。

## 5. 压缩率

压缩率 = 自然语言（JSON）基线字节数 / 二进制字节数：

| 示例消息 | JSON 基线 | 二进制 | 压缩率 |
|---|---|---|---|
| power_ctrl（node=7, -10dBm, slot=3） | 43 B | 5 B | **8.6×** |
| state_sync（node=7, 433.92MHz, seq=1234） | 51 B | 8 B | **6.4×** |
| spectrum_alloc（node=7, 125kHz 带宽） | 64 B | 10 B | **6.4×** |

均 ≥3×，由 `tools/test_protocol_router.py::test_compression_at_least_3x` 锁定。

## 6. 任务成功率不降

- 结构化消息：二进制往返 `encode → decode` 逐字段无损还原。
- 自然语言 / 模糊消息：原文逐字节透传（`decode_nl` 还原一致）。
- 收端统一入口 `ProtocolRouter.decode()`：按载荷首字节自动分发结构化 / 自然语言，
  无需调用方预先知道格式（`test_decode_auto_dispatch_roundtrip` 覆盖）。
- 混合批次成功率 = 100%（`test_mixed_batch_success_rate_100` 覆盖）。

## 7. 验收结论

8/8 测试通过：压缩 ≥3×、结构化无损往返、自然语言无损回退、decode 自动分发、
混合批次成功率 100%。
