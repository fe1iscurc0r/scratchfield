# A28 Memory Is Communication — 记忆-信号边界方案

> 来源：digest-g1-1 2608.17053（Memory Is Communication：记忆-信号边界框架，有界 Agent 信息预算最优分配）
> 原型：`tools/memory_comm_budget.py` · 测试：`tools/test_memory_comm_budget.py`（5 passed）

## 1. 框架

把"记忆"和"通信"统一看成**同一笔有界信息预算的两种去向**：

- **记忆**：把信息存进自己的状态，只服务自己（每 agent 各存各的，成本 O(agent 数 × 信息量)）。
- **通信**：把信息广播出去，一条广播服务所有接收方（接收不计入各 agent 预算，成本 O(1) 换 O(agent 数) 收益）。

结论（记忆-信号边界）：**共享/公共信息应走通信，私有/独占信息应走记忆**。

## 2. 最小原型（确定性协作任务模拟）

- `C` 个共享事实 + 每 agent `P` 个私有事实；每 agent 有 `budget` 个槽位，`comm_slots` 用于广播共享事实，其余记忆。
- 观察按 round-robin 分区：每 agent 直接看到约 `C/n_agents` 个共享事实，全体并集才覆盖全部 → 必须靠通信补全。

## 3. 结果（C=12, n_agents=4, P=6, budget=9）

| 策略 | 通信槽 | 记忆槽 | 平均掌握率 | 任务成功率 |
|---|---|---|---|---|
| 朴素（全记忆） | 0 | 9 | 0.50 | 0% |
| 最优（通信补共享） | 3 | 6 | 1.00 | 100% |

最优分配较朴素基线**成功率提升 +100%**（≥10% 验收），根因即"共享走通信、私有走记忆"。

## 4. NEKO 落点建议

NEKO 记忆系统里，把"写入本地记忆" vs "对外广播/同步给其它 agent/前端"视作同一预算的两条路径：
- 需要多端一致的公共事实（如频道占用、共享上下文）→ 走通信/同步，不重复本地存；
- 各 agent 独占的任务/环境状态 → 走本地记忆。

预算分配调度器可直接复用 `optimal_comm_slots()` / `budget_scan()` 的结论，不重造记忆存储轮子
（对齐 `summer_memory` / NEKO memory 的既有写入路径与 provenance 约定）。
