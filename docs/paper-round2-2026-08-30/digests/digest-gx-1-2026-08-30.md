## 三、本组最有价值 3 篇

1. **16227 语义分裂学习自适应不等差错保护（cs.IT）**：无线边缘推理中 latent 表征的可靠性差异受信息论驱动；该文把 MI 梯度作为任务相关性代理，实现完全数据驱动的 UEP 功率分配——实测在 IoT 传感数据上全面优于 EEP 和固定 UEP，且 ranking 稳定可迁移。**对 ESP32 SDR 无线电栈的感知-通信联合设计有直接参考价值：发射端就能按语义重要性不等保护，而不仅是等强纠错。**

2. **17703 Dijkstra Oracle 在线随机最短路径导航可证保证（cs.RO）**：移动机器人在未知成本地图+随机障碍下需安全导航；该文证明 Dijkstra 在非负 reduced cost 条件下仍是精确规划引擎，并提出 DORA 算法仅用固定次数 shortest-path oracle 调用即可保持安全与效率。**对 ESP32 机器人导航：在资源极受限下用 Dijkstra 替代完整 Value Iteration，有严格理论保障。**

3. **18341 神经形态声学异常检测 Loihi 2 低功耗（cs.NE）**：在 Intel Loihi 2 上运行 autoencoder 声学异常检测，动态能耗仅 0.04 mJ/sample，比 CPU/GPU 低两个数量级；干净/噪声条件下 AUC 均超基线。**对 ESP32 无线电异常检测：声学而非电磁，但自监督 autoencoder +  neuromorphic 计算范式可迁移到 ESP32 端侧异常频谱检测。**

## 四、可跨领域授粉 3 点

1. **Dijkstra Oracle 精确条件（17703，cs.RO）→ ESP32 机器人导航/无线电调度**：Reduced-cost 非负条件保证 Dijkstra 精确性；这相当于「在什么先验下贪心 = 全局最优」的轻量判据。可流向 esp32-robot 或 LoRa 调度——资源极低时直接替代 Dyna-Q / Value Iteration，省内存省算力。**潜在用途**：ESP32 轮式机器人实时路径重规划、LoRa 网关动态频道分配。

2. **信息驱动 UEP（16227，cs.IT）→ ESP32 SDR 感知通信一体化**：MI 梯度驱动不等差错保护的思路可迁移到「感知-通信一体化」场景：把信道状态信息的语义重要性（rate-distortion tradeoff）映射到发射功率/调制阶数，ESP32 上可实现端侧自适应频谱管理。**潜在用途**：软件无线电的动态频谱分配、ESP32 + CC1101 的自适应跳频策略。

3. **神经形态 Loihi 2 autoencoder（18341，cs.NE）→ ESP32 声学/振动监测**： neuromorphic 计算的「事件驱动 + 低功耗」范式核心是「不在无事时计算」；可把 autoencoder 换成 1D-CNN autoencoder 在 ESP32 上做频谱异常检测（如FCC 频谱监测、无人机声学故障诊断）。**潜在用途**：ESP32 + MEMS 麦克风的端侧机器健康监测、LoRa 无人机声纹识别。
