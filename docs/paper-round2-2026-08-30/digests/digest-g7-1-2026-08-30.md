## 第二部分：Top 模式 3-5 条

### 模式 1：基础模型 + 适应（Adaptation / Fine-tuning）
**贯穿全文的核心主线。** 无论是蛋白结构预测、RNA 设计、抗体工程还是酶预测，"预训练大模型 + 任务适配"已全面渗透。本组论文中：MCTH 用 MCTS 适配折叠模型做共设计，AAMFM 用 Cal-DPO 微调抗体模型，DegradeQuery 用对比学习适配 PROTAC，Molexar 用 SFT 适配分子生成，DynaMode 用扩散适配构象动力学。**趋势：从"训练一个新模型"转向"设计适配策略"**，包括提示工程、少样本微调、对比微调、贝叶斯适配等多条技术路径。

### 模式 2：多模态 / 跨尺度信息融合
蛋白-RNA-DNA-配体多模态联合建模（G7_17381 MultiStructRNA，MCTH），结构 + 序列 + 药效团联合条件生成（Molexar、JEDEL），多层网络视角（muxvizpy）均反映同一趋势：**单一数据模态已触及瓶颈，跨模态/跨层信息整合是突破点。** 尤其值得注意：本组中 3 篇明确使用 graph network / chain-of-thought reasoning 对多模态信息建模（GNN、Transformers、几何深度学习）。

### 模式 3：可解释性 / 可解释-by-design
AlphaFunctor（范畴论）、TCR-SRIM（接触原型）、scDNM-VAE（符号门控）、BRMSD（贝叶斯权重）、CAL（代数描述符）均体现：**不是先建黑盒再事后解释，而是在架构设计阶段就内嵌可解释性**。这种范式在生物网络、合成生物的电路设计中尤其有价值，因为监管和安全性要求必须能审计每个决策节点。

### 模式 4：不确定性 / 贝叶斯 / 概率建模
Bayesian Last Layer、BRMSD、共进化感知的 ASR (2606.27942)、DegradeQuery 对比学习、PML 持续流形、SF-Cluster 挫折感知采样——**贝叶斯/不确定性量化全面渗透**。这与模式 1 直接相关：少样本、标签缺失、噪声数据环境下，不确定性建模是可靠预测的前提。

### 模式 5：动态系统 / 时序 / 扰动推理
tSymPerturb（时序症状网络干预）、The Little Scientist（LLM Agent 科学方法论循环）、CMS（神经 ODE 训练）、HIPNO（血流动力学推断）、DynaMode（构象动力学生成）、SF-Cluster（构象采样）——**从静态预测走向动态干预推理是明确方向**。包括：构象态空间预测、干预最优控制、分支过程灭绝概率、eDNA 随机偏微分方程等。
