qLDPC 码从理论走向系统级实现——ONEX 框架将中性原子 2D 规划分解为最优 1D 子问题（20164），从组件拆解构造深度最优校验电路（19917），RL 把 Trotter 误差当纠错资源（20139），fan-out 并行对数深度压缩（20250），对抗噪声容错定理超越局域随机假设（16857）。配套光控超导 qubit 实现 99.9%+ 门保真度（19602）与 100 比特纠缠检测（20170），显示 2026 年 NISQ→FTQC 过渡期强工程化取向。

**2. 量子-经典混合 ML 双向渗透（quant-ph + mtrl-sci）**
量子为 ML 提供归纳偏置（QGP 回归 19306、量子储层 00139、病原 QML 28655），ML 反过来为量子降维（ML 压缩子空间 QSCI 20585、QGT 预条件 RNN-NQS 18065、分布式 VQE 19824）。物理引导 ML 在 NV 磁强计（19582）与分子力场（19532）上验证物理一致性——"混合工作流"已成量子-材料双向渗透的主流叙事。

**3. 铝磁（altermagnet）材料家族持续爆发（mtrl-sci）**
对称性分类学精细化：反自旋 Laue 群完整分类 21 组（19056）+ 缺陷几何可在 2D 铝磁中选择极性/反常霍尔相（17788）+ Ti₂X₂Y 新谷材料（19734）+ Tc₂O 镜面陈绝缘体（19725）。加上薄膜外延生长进展（α-MnTe 17513）——无净磁化自旋劈裂从对称性预言全面进入"可加工、可调控"阶段。

**4. ML 驱动的材料发现/模拟全流程自主化（mtrl-sci）**
主动学习 MBE（17742）<20 次迭代找到 Fe₃Sn 稳定窗口；JANUS 神经采样器三阶量级减少评估（19116）；硬碳钠电高速筛选超 800 mAh/g（17716）；主动学习框架自动分辨 SPM 测量位置与协议（09104）；主动学习相场建模预测界面断裂（19031）——"ML 即第三范式"从单点工具走向闭环自主实验。

**5. 软物质多尺度建模与实验精准对接（soft + stat-mech）**
热响应微凝胶溶剂通量理论（19884）桥接连续介质与分子尺度；等变 3D 密度泛函从平衡密度场学习（13506）跨温度/尺寸迁移；JANUS 统一离散原子身份与连续结构扩散（19116）；ESPResSo++ 粗粒化 MD 持续迭代（14911）。软物质领域正将"离散-连续耦合"采样作为核心竞争力。

## 三、最有价值 3 篇

**1. 18467｜WTe₂ 室温铁电可切换量子几何 → 互补存内计算（cond-mat.mtrl-sci）**

首次在室温（300K）、非易失、铁电极化可切换条件下演示量子几何（Berry 曲率/量子度量）的可编程控制。二阶与三阶非线性反常霍尔效应极性相反，构成物理层面的互补卷积核，MNIST 纹理识别达 98% 准确率。这篇论文的核心价值在于：**跨越了量子材料基础物理与后 CMOS 存算一体器件之间的鸿沟**——它不只是证明"量子几何存在"，而是证明"量子几何可在实际器件中可靠地写/读/保持"。对于生物质水凝胶/太阳能蒸发等涉及界面极化、离子输运的体系，其界面极化工程思路（铁电聚合物网络调制光-物质耦合）与水凝胶温敏相变存在概念映射可能。

**2. 20164｜中性原子阵列 qLDPC 乘积码架构+编译协同设计（quant-ph）**

在最有希望规模化的中性原子平台上，ONEX 框架将 2D 物理执行规划分解为独立 1D SMT 子问题，达到**深度最优且时钟率提升 3.7x~6.1x**，并推广到 zoned layouts 与 lifted-product 码族。这是 qLDPC 实用化路上最贴近硬件的体系级贡献，完美承接 19917（深度最优校验电路）与 20250（fan-out 压缩），构成"**qLDPC 实用化三引擎**"。对于 ML 材料预测方向，其 SMT 编码思想可迁移到"组合优化+约束满足"的材料结构预测问题。

**3. 19116｜JANUS 离散-连续耦合神经采样器（cond-mat.mtrl-sci）**

解决材料科学中最棘手的**离散-连续耦合采样难题**：组分（原子身份）变化与结构弛豫必须同时考虑，传统 MC 方法成本指数爆炸。JANUS 耦合连续扩散与离散遮蔽扩散，用等变图神经网络从能量评估直接学习，无需预生成平衡数据。在 NiCoFe 合金、Si 金刚石缺陷、乃至有机-无机复合材料上验证，**能量评估减少超过三个量级**，并通过 LLM evolutionary agent 实现逆设计。对用户技术栈的直接价值：水凝胶/生物质体系正是"聚合物组成 + 水化结构 + 相分离界面"的多变量耦合系统，JANUS 的离散-连续统一建模路径为该类材料的多尺度模拟提供了可直接使用的方法论框架。

## 四、跨领域授粉 3 点

**授粉点 1：量子几何工程 → 界面极化材料（来源：18467）**

WTe₂ 铁电极化切换量子几何的核心机制是**外场/极化可逆调制 Berry 曲率与量子度量**。这对于生物质水凝胶/太阳能蒸发体系的直接授粉在于：
- **潜在用途**：在温敏水凝胶中引入极化调制网络（如 PVDF 基、铁电聚合物），实现光-热-电多场耦合下的可切换吸收谱调控；太阳能蒸发器中极化可控的界面偶极子可增强局部电磁场提升光热转换效率。
- **方法借鉴**：量子几何张量的"驱动-响应"建模框架（ Berry 曲率梯度流 19770 已有理论工具）可移植到**聚合物偶极玻璃态**的迟滞/记忆效应建模。

**授粉点 2：主动学习+不确定性量化 → 生物质材料性能预测（来源：17742 + 14153）**

17742（主动学习 MBE）与 14153（MLIP 电化学静电基准）形成**"探索-验证-信任"闭环**：
- 17742 的 SMBO + 随机森林 surrogate 在 4 次主动学习迭代内将预测误差减半，展示了**不确定性驱动的实验设计**在材料体系中的高效性。
- 14153 的 EPhEct 基准揭示了 MLIP 对**镜像电荷吸引、介电屏蔽、电荷转移**等电化学相关物理量的定性预测失败——这对生物质水凝胶的电解质-聚合物界面建模至关重要。

**潜在流向**：将主动学习不确定性框架与 EPhEct 的**物理一致性检验**结合，用于生物质/水凝胶材料的电化学性能预测。具体地，对木质素/纤维素衍生物的电荷存储/离子传导进行 ML 预测时，先用 EPhEct 类基准检验 ML 模型对界面极化/双电层结构的物理合理性，再用主动学习筛选关键合成参数。

**授粉点 3：离散-连续耦合神经采样 → 软物质多组分体系（来源：19116 + 14451）**

19116（JANUS）处理的核心是**组分可变 + 结构可变形**的联合采样，这正是：
- **水凝胶网络**（交联点类型 + 网络拓扑 + 水化壳层）建模的难点；
- **生物质复合材料**（木质素/半纤维素/纤维素多组分 + 界面脱混合）的老化/自修复模拟核心。

14451（记忆驱动活性液滴）的**非马尔可夫反应记忆**理论与 JANUS 的"无需预生成平衡数据"学习框架结合，可为**生物质体系的非平衡自组装/凝胶化动力学**提供数据高效的新建模路径——无需穷举所有反应路径，用记忆核函数+神经采样器从有限实验数据学习动态演化规律。
