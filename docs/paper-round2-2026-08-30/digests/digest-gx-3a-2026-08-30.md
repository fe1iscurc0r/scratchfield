4. **Agent 系统化/图结构化**：Graph Engineering 综述、多智能体流量建模、零样本 VLA 任务生成、TSP 路由协同——单 Agent 能力见顶，转向系统级编排与结构显式化。

## 四、跨领域授粉 3 点（无线电/ESP32/SDR/机器人/Agent）

1. **Q-Planning 自改进范式 → 嵌入式/ESP32 机器人**（2608.21204v1）：用几十 KB 的小 Q 函数包裹已有策略，失败回滚数据直接吸收、推理时 Q 加权选动作——无需重训大模型即可让低成本边缘机器人持续自改进，天然契合 ESP32 端算力约束。

3. **形式化时序约束条件化 → Agent 与航路安全**（2608.20556v1 Logic-VLA + 2608.21156v1）：STL 规范作为推理期条件注入 VLA，一个模型适配多套安全要求；可与无人机/机器人 Agent 的任务约束（禁飞区、时间窗、编队保持）结合，把"自然语言任务+硬性时序要求"统一进同一策略。
