## 二、领域 Top 模式（4条）

**1. Agent 后训练的系统性失效被多角度系统揭示**
多条独立工作从不同角度指向同一结论：现有 Agent 训练方法存在结构性失效。TraceML（2608.26086）发现 Agent scaffold collapse 成窄循环，无法像专家一样交替做数据工作/验证/模型改动；SKILL.state（2608.26263）证明 append-only 历史是长 horizon Agent 的根本瓶颈；Repair or Resample（2608.25920）发现现有重采样方法 failure 再现率仅 67.97%、修复率仅 6.90%；WikiSkill（2608.27454）证明技能进化必须配合持久化知识积累。这些工作共同揭示：当前 Agent 后训练pipeline缺乏对执行轨迹的可靠记忆、可信赖的调试机制和真正的策略重评估能力。

**2. 世界模型与物理归纳偏置深度融合成为科学 AI 的主旋律**
本批次中多个方向同时推进：MPNO（2608.25744）通过构造性谱约束实现神经算子的自回归稳定性，将 PDE 求解误差从发散变为有界；TRACE（2608.26219）用 Kalman-style 时空先验在稀疏传感下完成流场重建；DAW（2608.22277）用动力学 aware 重加权解决混沌系统长期预报的 catastrophe；物理不变式作为数据表示（2608.25189）让 LLM 能像理论家一样读取场数据。这条脉络指向一个共同方向：已知物理结构（方程、约束、谱特性）必须作为 inductive bias 进入架构，而非仅作为 loss 正则项。

**3. 多模态融合的根本性问题被精准定位**
Strong-modality collapse（2608.26879）揭示对称融合会让主模态退化 18.5%——这解释了为何很多 multimodal 模型无法超越单模态基线；Inverted Asymmetric Fusion（IAF）通过保留主模态直通、让弱模态锚定主模态解决此问题。同时，ASIL（2608.26991）证明截图点击是软件操作 Agent 的低效接口，结构化 JSON + 语义动作可以将任务成功率从 6.6 提升到 80+。这两个工作共同指出：多模态系统的 failure 不是数据问题，是融合架构和接口设计问题。

**4. 评测文化开始从"答案正确率"转向"执行轨迹可靠性"**
多个工作从不同角度推动这一转向：Trace Integrity（2608.26036）提出 CAIT Rate 来衡量"答案正确但轨迹无效"的比例；FrontierChallenge（2608.24979）发现 75.5% 的失败轨迹以语言声称完成收尾；BekchiAI（2608.26867）提出行为指标（tool-call adherence、URL hallucination）超越准确率；Same Model Different Harness（2608.26218）证明同一模型换 harness 后 SWE-bench 结果从 43% 升至 72%。这波工作共同指向：AI 系统评估必须从 output grading 转向 process/execution evaluation。

## 三、本组最有价值 3 篇（含理由）

**① 2608.26069 — Group-Shared Low-Rank Approximation（大核 CNN 移动端部署）**
理由：指出 pointwise convolution 占大核 CNN 参数 87% 以上，是移动端部署的真正瓶颈，提出 CGS 低秩近似在 RepLKNet/ConvNeXt/SLaK 上实现 competitive performance + 大幅存储压缩。这直接解决 ESP32/嵌入式视觉模型的部署约束——参数量的压缩意味着可以直接在 MCU 级别跑大核 CNN，而非依赖剪枝或知识蒸馏等后处理。对在资源受限无线电/传感器节点上部署视觉模型的用户，这是目前看到的最直接有效的方案。

**② 2608.24069 — Poisoning Agentic Alpha（多 Agent 交易系统对抗投毒攻击）**
理由：首个系统性研究金融多 Agent 交易系统对抗投毒的论文，提出 Adversarial Signal Preservation Score（APS）衡量对抗信号在 Agent 链路中的存活程度，发现在 Analyst/Researcher/Trader/Risk Manager 四角色中没有一个架构天然鲁棒。对所有在生产环境部署多 Agent 系统的人（尤其是涉及财务/控制决策的系统），这是第一篇给出系统性威胁建模和防御设计方向的工作。

**③ 2608.27429 — MAELLE（离散流匹配预测化学反应机理）**
理由：将化学反应建模为电子占据向量的离散流匹配，而非生成产物分子或做启发式图编辑，可以预测副产物并给出机械论解释。对材料/生物质方向：燃烧和热解过程的化学反应机理预测一直是仿真难题，MAELLE 的离散 CTMC 框架直接建模电子重新分布——这与生物质热解中自由基反应机理建模高度类似，跨模态迁移价值高。

## 四、可跨领域授粉的 3 个点（结合无线电/ESP32/SDR/材料生物质/Agent 技术栈）

**① 自回归稳定性构造性设计 → 无线电信道建模 / SDR 实时信号处理**
MPNO（2608.25744）的核心贡献：将谱半径 <= 1 作为架构设计约束而非优化目标，实现构造性自回归稳定。TRACE-CRC（2608.27124）进一步提出 trajectory-level 不确定性量化，控制多步 CSI 预测中任意帧的覆盖风险。对 ESP32/SDR 应用：无线电信道预测（多径、衰落）在时域递归展开，现有 DNN 预测器缺乏不确定度量且误差累积导致发散。将谱约束编码进网络结构 + trajectory-level conformal risk control，可以实现可证明稳定的实时信道跟踪，并给出每步预测的置信区间——这对无线电资源管理和干扰规避直接有用。

**② 物理信息引导的剪枝 → 材料/生物质传感网稀疏部署**
PI-SAP（2608.25564）提出用 PDE 残差的敏感性来分配剪枝重要性，而非仅用 NTK 谱。对于材料/生物质传感器网络：节点能量有限，传感器数据有物理约束（能量守恒、物质平衡），在部署前就知道哪些权重对物理方程的残差贡献大。这可以直接指导 ESP32 等端侧设备的稀疏化——在感知物理量对应的参数上多留精度，在不影响 PDE 约束的方向上剪掉。结合无线传感网（2608.27152）超低功耗 RSS 定位的生物追踪应用，PI-SAP 的物理引导稀疏化可以延长端侧节点寿命。

**③ Agent 协作可靠性原语 → 多跳无线电频谱感知与分配**
Agent Mesh（2608.26225）和 SARA（2608.27146）从生产环境提炼出 Agent 可靠协作的最小原语：identity adequacy（身份必须能区分正确/错误答案）、evidence adequacy（可靠性决策必须有移动能力的证据）。将这些原语映射到认知无线电场景：多 SDR 节点协作感知频谱，每个节点对环境状态的"断言"必须可验证，错误的身份/证据会导致整个频谱分配出错。萤火虫的自适应路由协议（2608.27152）和 Multi-Agent RL 的 SIGMA 框架（2608.26683）中的结构化噪声效应分析，为多跳无线电网络的分布式协作提供了观测-决策闭环的设计参考。
