# R01 事件驱动频谱缓存

> 来源分组：group1-无线电

【SPEC】rf_brain 增加频谱事件缓存模块：把"逐帧 FFT"改为"检测信号出现/消失/突发干扰→固化事件记录"，支持"当前主干扰源是什么"类查询不问历史；验收=模块单测 ≥6 用例 + 模拟频谱流演示查询。
【工单】①定义频谱事件 schema（时间/频点/类型/持续/强度）②事件检测器（能量跳变/消失判定）③环形缓存实现 ④查询接口（最近 N 事件/当前活跃源）⑤测试与 MCP 注册。
【提示词】你是 rf_brain 组件开发 AI。实现频谱事件缓存模块：读 mcpserver/rf_brain/ 现有风格（demod_ref.py、schemas.py），新建 spectrum_events.py：事件检测（能量跳变判定）+ 固定预算环形缓存 + 查询 API（current_interferers/recent_events）。输出 NDJSON 兼容现有总线。验收：python -m pytest 新增测试全过；grep 断言事件类型字段；不碰 NEKO。推 trae/agent-r01 分支。
