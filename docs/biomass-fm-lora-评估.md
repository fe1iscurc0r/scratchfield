## 1. 授粉映射

两篇来源共同证明：**预训练视觉基础模型（DINOv2）+ LoRA 微调，可在「4M 参数级」低成本获得
医疗/农业场景的实用精度**。对陆墨的直接同构：生物质材料成分识别（热解产物图像、SEM 图像、
显微结构分类）同样面临「数据稀缺 + 需边缘部署」——用「冻结 DINOv2 主干 + 少量 LoRA 适配」
即可在 ESP32 级硬件上做本地化分类，不必从零训练或全量微调 22M 参数。

## 2. 模型选型

| 组件 | 选型 | 说明 |
|---|---|---|
| 主干（FM） | DINOv2 ViT-S（22M）| 冻结特征提取；ViT-B（86M）为可选更强主干 |
| 适配器 | LoRA（低秩 ΔW = B@A）| 加在分类头或注意力投影，rank r=4~16 |
| 分类头 | 线性 softmax | 映射冻结特征 → 材料成分类别 |
| 任务 | 热解产物/成分识别 | 8 类材料成分（本原型）|

## 3. 参数 / 内存预算（验收项）

| 方案 | 可训练参数 | 权重内存（int8） | 内存总量（含激活，估算） | ESP32 可行 |
|---|---|---|---|---|
| 全量微调 DINOv2-S | 22M | 22 MB | > 24 MB | ✗（超 PSRAM）|
| 冻结主干 + 全量微调头 | 4096（本原型）| ~4 KB | 主干 22MB(冻结)+头 | 边缘需量化主干 |
| **冻结主干 + LoRA(r=4)** | **2080（本原型）/ ~4M（真实 DINOv2 多层）** | **~4 MB** | 主干 int8 22MB + LoRA 4MB | ✓（int8 量化主干）|

> 真实 DINOv2 场景下 LoRA 加在多层注意力/FFN 投影上，可训练参数 ~4M（vs 全量 22M）；
> 本原型在单头上演示「冻结主干 + 低秩适配」机制，参数量缩放关系一致。

**ESP32 可行性**：主干必须 int8 量化（22M×1B=22MB 落 8/16MB PSRAM）；LoRA 适配器 ~4M×1B=4MB；
推理只跑冻结主干前向 + 低秩头，低分辨率输入下可达秒级/帧。fp32 全量不可行。

## 4. 精度评估（本原型，8 类合成材料成分）

| 方案 | 精度 | 可训练参数 |
|---|---|---|
| 零样本（随机头） | 2.8% | 0 |
| 冻结主干 + 全量微调头 | 100% | 4096 |
| 冻结主干 + LoRA(r=4) | **100%** | **2080（全量的 51%）** |

LoRA 在参数量减半下达到与全量微调头一致精度，验证「紧凑部署」范式；真实 DINOv2 多层的
节省幅度更大（~4M vs 22M，约 5.5×）。

## 5. 落地路径

1. **任务锚定**：选一个陆墨真实图像任务（热解产物 SEM 图 / 显微结构分类）冷启动。
2. **主干复用**：DINOv2 冻结特征（或 K27 的紧凑 DINOv2-LoRA 部署经验）作为特征层。
3. **LoRA 微调**：只训 LoRA 适配器 + 头，用陆墨小样本（几十~几百张）微调。
4. **int8 量化 + 边缘推理**：主干 int8 量化落 PSRAM，ESP32-S3 跑冻结前向 + LoRA 头。

## 6. 诚实降级与风险

- 本原型是 numpy 单头 LoRA 演示，未加载真实 DINOv2 权重；精度是合成特征空间的结果。
- 「4M 参数实用精度」是来源论文结论，需以陆墨真实图像数据复评。
- ESP32 上跑 DINOv2-S 主干仍偏重（22M 冻结前向），务实落点可能是「近边缘/轻主干蒸馏版」
  （承接 K14 蒸馏），本评估只到「LoRA 微调可行」这一层。
