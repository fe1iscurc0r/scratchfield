## 触发逻辑

木质素基多孔碳（lignin-derived porous carbon）是生物质材料线的高价值下游——活化造孔后的碳材料做 CO2 捕集/气体分离/超级电容器。该子域需要：孔结构表征、吸附模拟（GCMC）、MOF/沸石高通量筛分三类工具。此前扫货已覆盖 QMOF + gRASPA（agent79 清单 W78-06），本轮补齐垂直周边。

## ⚠️ 许可核实关键发现（本轮方法论增量）

1. **spdx 三重撒谎实证**：RASPA3 API 返回 NOASSERTION，但 `contents/LICENSE.md` 原文是标准 MIT（Dubbeldam/Calero/Vlugt/Snurr 2023）。若信 API 直接暂缓，会错过吸附模拟界最核心的活跃项目。**LICENSE 文件原文是唯一裁决**，再次验证。
2. **autografs 双许可文件陷阱**：根目录同时有 COPYING(GPL-2.0) + LICENSE.txt(LGPL-2.1) + COPYING.LESSER，API 报 NOASSERTION。实测 LGPL——copyleft 排除。多许可文件并存时必须逐个读。
3. gRASPA(100★ MIT) 上轮已立项（扫货-材料软件-2026-09-02 W438行），本轮 RASPA3 是其上游正统续作且更新更活跃，标注「同族补强」不算重复。
