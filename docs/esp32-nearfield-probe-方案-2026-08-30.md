# NICWhisper 电磁侧信道 → ESP32 近场探头设计（勘察点 2）

> 工单：09-02（智能体 09 · ESP32 侧信道/频谱勘察）

> 结论先行：**部分能做，但 ESP32 内置 ADC 是硬短板。** 探头 + 前置放大 + ESP32 ADC 只能做"设备网络活动有无/强度分级"的粗粒度探测；要复现 NICWhisper 论文粒度（8 类威胁行为分类），信号质量（ENOB、带宽、前端）与论文平台存在明显差距。

## 〇、一句话定位

**设计一个"线圈/磁棒近场探头 → 基带低噪放大 → ESP32 ADC 采样 → 频谱能量/包络特征 → 轻量分类"的采集链路，用来探测设备（网卡/SoC）网络活动产生的电磁泄漏指纹；与 TESLA 触摸屏电磁侧信道同方向，但目标对象是网络活动而非触摸。**

## 一、NICWhisper 方法调研（准确引用，已读原文）

**论文**：*What's Your NIC Whispering? Network Threat Behavior Recognition via NIC Electromagnetic Side-Channel Leakage*（Hongchao Wang, Linrui Li, Yunkai Zou, Zhenduo Hou, Yilin Zhang, Haoyang Pu, Wen Chen, Jierui Chen — 川大/南开/中科院信工所）。**arXiv:2608.22941**（2026-08-24 预印本，无会议），DOI:10.48550/arXiv.2608.22941，cs.CR/cs.AR。

**关键澄清（更正工单认知）**：这不是"哪个网站/App"粒度，而是**网络威胁行为类别**（8 类：Normal / Flood / PortScan / ServiceProbe / DirEnum / PathDisc / SQLi / XSS）的粗粒度识别；也不读包内容，只读"网卡活动 → EM 泄漏"的指纹。

### 1.1 NICWhisper 采集链路（原文 Section V-A）

| 环节 | 参数 |
|---|---|
| 目标设备 | USB 3.0 千兆网卡，Realtek RTL8153B 控制器 |
| 探头 | **磁近场探头（magnetic near-field probe）**，三维位移台贴网卡 |
| 放大 | **30 dB 低噪声放大器（LNA）** |
| 采集 | PicoScope 3000 系列示波器 |
| 采样率 | **1 MS/s**，每段 1s = 10⁶ 样本 |
| 频率范围 | **0–500 kHz**（Nyquist=500kHz，单边谱 1025 频点） |
| 特征 | log-power STFT 频谱图（2048 Hann 窗/FFT，无重叠），面积重采样 128×128 |
| 分类器 | CNN（3 卷积段 32/64/128 + GAP + 8 类线性层，94,152 参数，AdamW） |
| 信息频段 | 判别能量集中在 **约 75–200 kHz**（100–125k / 90–160k / 75–200k 三段） |
| 结果 | Accuracy 80.53%，Macro-F1 80.67%（Flood 90.51%，ServiceProbe 69.12%） |

### 1.2 与"TESLA"的对应关系（诚实说明 skill 不存在）

工单指认 `security/tesla-touchscreen-em-sidechannel` skill，**本仓不存在该 skill**（全仓 `find` 无此目录）。经 web 调研，"TESLA"实为 **Touchscreen Electromagnetic Side-channel Leakage Attack** 的缩写（非特斯拉汽车），对应论文：

**TESLA（实践版）**：*Capacitive Touchscreens at Risk: A Practical Side-Channel Attack on Smartphones via Electromagnetic Emanations*（Yukun Cheng 等 9 人）。**arXiv:2605.14633**。采集：**Fosttek NFP-One P1 近场探头 + STM32F407 MCU（12-bit ADC）@ 500 kHz** + PicoScope 5444D 辅助；距离 5–25cm；结果 PIN 99.3%、键盘 97.6%、App 95.0%、字符 76.8%。

### 1.3 触摸屏侧信道 vs 网络活动侧信道（采集参数对照）

| 维度 | TESLA（触摸屏泄漏） | NICWhisper（网络活动泄漏） |
|---|---|---|
| 泄漏源 | 触摸屏 TX 电极扫描激励（周期性特征频率=触摸采样率 120–180Hz 载在 100–500kHz 上） | 网卡 SoC 开关电流的基带包络 |
| 载波/信息频段 | 100–500 kHz（+120–180Hz 调制） | **75–200 kHz**（基带） |
| 采样率 | 500 kHz | 1 MS/s |
| 探头 | Fosttek NFP-One P1（商用近场探头） | 磁近场探头 |
| 放大 | MCU 直采（无明显 LNA 描述） | **30 dB LNA** |
| 分类器 | CNN / MLP / Transformer | CNN |
| 目标粒度 | PIN/键盘/App/手写轨迹 | 8 类网络威胁行为 |

**共同点**：两者都是**低频磁场泄漏**（不是 433MHz RF！），都是"近场探头 + 基带放大 + 亚 MHz 采样 + CNN/ML 分类"。这决定了下面 ESP32 探头设计是**基带（75–200kHz）方案，而非 433MHz 射频方案**——这是本单最容易踩的认知坑。

## 二、ESP32-S3 近场探头设计

### 2.1 信号链（文字图）

```
[磁近场探头 H-field loop / 磁棒天线]
      │ 感应 75–200kHz 磁场泄漏（微伏~毫伏级）
      ▼
[基带低噪前置放大 20–40 dB]（低噪运放，非 RF LNA——频段是基带）
      │ 可选无源 RC/LC 带通 50–300kHz
      ▼
[ESP32-S3 ADC1]（12bit，I2S-DMA 连续采样，~1 MS/s 标称 / 数百 kHz 实际可用）
      │
      ▼
[FFT 频谱能量/包络特征]（128/256 点，log-power，均值/峰度/频带能量）
      │
      ▼
[轻量分类]（ELM-LUT 起步；要复现论文用 CNN，放云端）
```

### 2.2 探头选型（线圈/磁棒）

| 方案 | 构造 | 频率特性 | 成本 | 建议 |
|---|---|---|---|---|
| **磁棒天线（首选）** | 铁氧体磁棒（如 10×140mm）+ 漆包线绕制（~50–100 匝，电感 ~100µH–1mH） | 对 75–200kHz 磁场灵敏，方向性强（可指向网卡） | ¥3–8 材料 | DIY，嘉立创/立创有磁棒与漆包线 |
| 环形线圈 H-loop | 铜导线绕成小环（直径 3–5cm，几匝） | 宽带，灵敏度低于磁棒但频响平坦 | ¥1–3 | 备选，配合磁棒对比 |
| 商用近场探头 | Fosttek NFP-One P1（论文同款） | 标定、宽带 | 较高（¥数百） | 仅当要复现论文精度时才买 |

**选型建议**：起步用**磁棒天线 DIY**（成本最低、方向性利于对准网卡），验证"能否采到 75–200kHz 包络"后再决定是否上商用探头。

### 2.3 前置放大器（基带低噪放大，关键环节）

**认知纠正**：NICWhisper 的"30dB LNA"针对的是**基带 0–500kHz**，不是射频 LNA（如 BGA2818/SPF5189Z 那种 GHz 低噪放大器）。所以前置放大器应是**低频低噪运放**：

| 运放 | 带宽/噪声 | 成本 | 备注 |
|---|---|---|---|
| **NE5532**（双运放，TI） | 10MHz 带宽，低噪通用 | ¥1–3 | 起步首选，两级各 20dB 即 40dB |
| OPA1612 | 高保真低噪 | ¥15–30 | 精度升级 |
| AD797 | 超低噪（0.9nV/√Hz） | ¥50–80 | 极限低噪，仅在微弱信号时考虑 |

**设计要点**：交流耦合（隔直，磁棒感应是纯交流磁场）、输入阻抗匹配磁棒（高输入阻抗运放即可，无需 RF 匹配）、单电源偏置到 ADC 中位（约 1.65V，适配 ESP32 ADC 0–3.3V）、可选 50–300kHz 带通限制带外噪声。

### 2.4 ADC 采样方案

| 方案 | 采样率/位深 | 能否覆盖 75–200kHz | 成本 | 结论 |
|---|---|---|---|---|
| **ESP32 内置 ADC1（首选起步）** | 标称 12bit，DMA 连续 ~1MS/s 上限，实际可持续 ~200k–500kS/s | **名义够、边缘**：Nyquist 需 ≥400kS/s 覆盖 200kHz | ¥0 | 先验证信号是否够大 |
| ESP32 I2S 并行 ADC | 8bit @ 高速 | 采样率够但位深更差 | ¥0 | 仅当需更高采样率 |
| 外置音频 ADC（PCM1808） | 24bit/96kHz | **不够**（96kHz Nyquist=48kHz < 75kHz） | ¥8–15 | ❌ 音频 ADC 覆盖不了 |
| 外置高速 ADC（AD9226 等） | 12bit/65MS/s | 远够，但过采样 | ¥30–50 | 需 SPI/并行接口 + MCU 带宽，复杂度高 |

### 2.5 特征提取

1. 分帧 FFT（128/256 点，Hann 窗），log-power 谱。
2. 特征：75–200kHz 频带总能量、峰均比、谱峰频点、包络均方根、包络过零率。
3. 归一化 → 8 维特征（复用 `firmware/elm_lut` 的"8 维特征 → 32 隐节点 → 3 类"范式）。
4. 起步分类：3 类（**无活动 / 低活动 / 高活动** 或 **空闲 / 传输突发 / 持续负载**）；复现论文的 8 类威胁行为识别留云端 CNN。

## 三、诚实评估：ESP32 内置 ADC 的带宽/采样率限制

| 维度 | 论文平台 | ESP32 内置 ADC | 差距结论 |
|---|---|---|---|
| 采样率 | PicoScope 1MS/s / STM32F407 500kS/s | 标称 ~2MS/s（DMA），**实际可持续 ~200k–500kS/s** | **名义够/边缘够** |
| 有效位数 ENOB | PicoScope ~8bit 干净 / STM32 12bit(ENOB~11) | 12bit 标称但 **ENOB 仅 ~6–9bit** | **主要短板之一** |
| 模拟带宽 | 覆盖 0–500kHz | **>100kHz 明显衰减**，削弱 75–500kHz 信息段 | **主要短板之一** |
| 输入阻抗 | 高阻探头输入 | **低输入阻抗，需 <100kΩ 源**，需运放缓冲 | 前置放大必配 |
| 前端 | 磁探头 + 30dB LNA / NFP 探头 | **无探头、无放大** | **真正的瓶颈（比 ADC 更关键）** |

**核心结论**：ESP32 内置 ADC 在"采样率"上对这两类任务**名义够用/边缘**；真正不可直接覆盖的是 **(a) 探头 + 前置放大模拟前端**（两篇论文都靠它拿到信号）、**(b) ADC 的 ENOB 与高频带宽**。所以本方案是"**探头 + 基带运放放大 + ESP32 ADC 粗采**"三段式，且**明确只能做到粗粒度探测**，不声称能复现论文 80% 的 8 类分类精度。

**何时需要外置 ADC/SDR**：若目标信号能量很弱、或需要覆盖 >200kHz 信息段、或要复现论文 CNN 精度——则换外置高速 ADC（AD9226 类）或直接 SDR（RTL-SDR），ESP32 只做 MCU 控制/数据搬运。这是 09-01 档B 的 RTL-SDR 可以共用的硬件。

## 五、可行性结论

| 目标 | 结论 | 卡点 |
|---|---|---|
| 探测"设备网络活动有无/强度"（粗粒度） | ✅ **部分能做**：磁棒 + NE5532 放大 + ESP32 ADC | 需验证信号强度是否高于 ADC 底噪 |
| 活动类型粗分类（空闲/突发/持续，3 类） | ⚠️ **边缘**：ELM-LUT 可行，但依赖真实泄漏数据重训 | 训练数据 + ENOB 限制 |

| 与 TESLA 触摸屏侧信道同向验证 | ⚠️ 参考其"探头+MCU 500kHz"思路，但 ESP32 位深弱于 STM32F407 | ADC ENOB |

## 六、诚实降级清单

1. NICWhisper 论文是**预印本、无同行评审会议**，且是 8 类威胁行为分类（非网站/App 指纹）——工单原始描述"流量指纹→哪个网站/App"有偏差，已如实更正。
2. TESLA skill 在本仓不存在，本单以 arXiv:2605.14633 论文为准，非 skill 内容。
3. ESP32 ADC 的 ENOB（~6–9bit）、>100kHz 衰减、输入阻抗等为**通用规格/常见实测**（非论文数据），需真机标定。
4. 磁棒 DIY 探头的电感/灵敏度为估算，绕制后需实测谐振与频响。
5. 所有"能否采到 75–200kHz 包络"的结论，**真机验证前不声称已实测**。

## 七、真机验证点（用户实测）

1. **探头灵敏度**：磁棒贴近 RTL8153B 网卡 / ESP32-S3 自身（跑密集 SPI 时），示波器/万用表看 75–200kHz 是否有可分辨包络。
2. **ADC 底噪**：ESP32 ADC 空载采 1s，FFT 看底噪谱，确认放大后信号 > 底噪 10dB 以上才可分类。
3. **放大增益标定**：NE5532 两级增益实测（是否真达 40dB、有无自激）。
4. **活动有无对比**：目标设备空闲 vs `iperf`/`ping` 压测时，频谱能量差异是否显著。
5. **粗分类**：ELM-LUT 训练"空闲/突发/持续"三类，用真实泄漏数据验证精度（合成 mock 不算）。
