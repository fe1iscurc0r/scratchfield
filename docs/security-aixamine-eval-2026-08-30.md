## 一、问题陈述

LLM 的安全失效是**跨维度**的：一个模型可以安全分 99，却在隐私/鲁棒/蒸馏维度崩溃。单一维度评估会漏掉关键失败模式。aiXamine（2608.20554）是 120+ LLM 的**跨维度统一安全评估平台**，关键发现：

- **安全强化 → 过度拒绝（safety tax）**：安全对齐的副作用是过度拒绝合法请求；
- **蒸馏导致鲁棒性崩溃**：鲁棒性从 56.9 骤降到 2.6；
- **隐私与其他维度近乎正交**：隐私表现与安全/鲁棒几乎无关。

## 二、评估方案设计

跨维度评估，量化各维度的独立表现与"安全税"：

| 维度 | 指标 |
|---|---|
| 安全 | 安全对齐质量 |
| 隐私 | 隐私保护能力 |
| 鲁棒性 | 对抗鲁棒性（含蒸馏后） |
| 蒸馏 | 蒸馏后鲁棒性保持 |
| safety tax | 过度拒绝率（安全强化的代价） |

### 流程
1. 接入 aiXamine 平台，对自家/目标模型跑跨维度评估。
2. 输出各维度分数 + 交叉关系（如"安全高但隐私低"、"蒸馏后鲁棒崩溃"）。
3. 量化 safety tax：安全提升 vs 过度拒绝的权衡曲线。
