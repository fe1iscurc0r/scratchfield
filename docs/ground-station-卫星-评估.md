# W69-07 ground-station 评估（浏览器卫星地面站）

> 上游：sgoudelis/ground-station · GPL-3.0 · ~4730★ · 2025-03 · JavaScript · 活跃
> 定位：浏览器卫星跟踪 + SDR 接收 + 硬件控制套件
> 结论：**可融合（吞）**——本仓 AGPL-3.0 与 GPL-3.0 兼容（AGPL ⊇ GPL），卫星跟踪/SDR/指向闭环可直接吸收代码

## 1. 项目定位与架构

ground-station 把「卫星地面站」做成浏览器套件：卫星过境跟踪（轨道计算 + 天线指向）、SDR
接收（浏览器内 WebSDR/USB SDR）、硬件控制（天线云台/rotator）。核心卖点是「浏览器内一站
式」——无需装桌面软件，浏览器里完成跟踪/接收/控制。

## 2. 与本仓对照

| 维度 | ground-station | 本仓 IC-705 卫星线 / 天线云台 / LoRaCanary |
|------|----------------|-------------------------------------------|
| 卫星跟踪 | 有（轨道算法） | 部分（IC-705 卫星模式） |
| SDR 接收 | 浏览器内 SDR | rf_brain/SDR 后端 |
| 硬件控制 | 云台/rotator | esp32-rotator 参考 |
| UI 形态 | 浏览器 | 前端 ConfigView/radio_suite |

本仓已有 IC-705 卫星线 + 天线云台（esp32-rotator 参考）+ LoRaCanary，硬件与控制层齐备；
ground-station 的差异化在「浏览器内 SDR + 卫星跟踪算法 + 一体化 UI」。

## 3. 可落地借鉴点（≥3）

1. **卫星过境跟踪算法**：轨道根数（TLE）→ 过境预测 → 方位/仰角/AOS-LOS 计算，可借鉴补 IC-705 卫星线的跟踪精度。
2. **浏览器内 SDR 形态**：WebSDR 式浏览器接收，是本仓 radio_suite 前端可借鉴的「远程频谱」交互。
3. **天线指向闭环 UI**：跟踪 → 指向 → 信号强度的可视化闭环，可借鉴到 esp32-rotator 的控制面板。
4. **硬件抽象层**：rotator/SDR 的多设备统一抽象，可借鉴本仓天线云台与 SDR 后端的统一接口。

## 4. 许可裁定与结论

- **许可**：GPL-3.0。**本仓为 AGPL-3.0，与 GPL-3.0 兼容（AGPL 是 GPL-3.0 的超集）→ 可融合代码**。
- **结论**：**可融合（吞）**。卫星跟踪算法、浏览器 SDR 交互、指向闭环 UI 均可直接吸收；融合后整体仍按 AGPL 发布（GPL 的源码公开义务被 AGPL 覆盖，无额外负担）。落地路径：直接复用其卫星跟踪 + 指向闭环逻辑，接入本仓 rf_brain/radio_suite 前端，而非从零重写。
- **注意**：仅 GPL-2.0-only 的代码与 AGPL-3.0 不兼容；本项是 GPL-3.0，无此问题。
