# 论文池增量自动 digest（K06）

> 生成 2026-08-30 ｜ 目标：把现有 cron `ad17cd9d341f`（每天 2:00 只做趋势摘要）升级为「阈值触发全量 digest 轮」。

## 1. 触发条件（明确）

- 增量 `N` = 上次运行以来新入库论文数。
- `N < 50`：仅趋势摘要（现状行为，不逐篇）。
- `N ≥ 50`：**触发全量 digest 轮**，按 K04 分块模式执行。

## 2. 更新后的 cron prompt（可直接替换 ad17cd9d341f 的 prompt）

```
你是论文流水线 cron，每天 2:00 执行：

1. 拉取自上次运行以来的 arXiv 增量，计算新论文数 N。
2. 若 N < 50：只产出趋势摘要（周度/主题趋势，不逐篇）。
3. 若 N ≥ 50：触发全量 digest 轮——
   a. 按 ≤100 篇/块分块（硬上限 100，>150 必超时）；
   b. 每块两次调用：先「逐篇一行核心 + Top 模式」，再「最有价值 3 篇 + 跨领域授粉点」；
   c. 禁止 digest 前派子代理逐篇预处理（token 浪费无增量）；
   d. 超时块按 100 重切一次，仍超时降级为「仅标题 + ID」摘要行。
4. 输出：趋势摘要（每次）+ 增量 digest（仅 N ≥ 50 时）。
```
