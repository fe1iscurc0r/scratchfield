## 一、问题陈述

嵌入式/边缘机器人想"从失败中持续学习"，但**重训大模型不现实**（算力、内存、数据都不允许）。Q-Planning（2608.21204）给出范式：**用几十 KB 的小 Q 函数包裹已有的大 BC 策略**，失败回滚数据直接吸收、推理时 Q 加权选动作——无需重训大模型即可持续自改进。实证：真实任务 **5 轮迭代 40% → 90%**。

## 二、核心机制

- **冻结大策略**：已有 BC（行为克隆）策略不重训，作为动作候选生成器。
- **小 Q 函数**：几十 KB 规模，包裹在大策略外层，负责"动作打分"。
- **推理时 Q 加权选动作**：大策略生成候选动作，小 Q 函数打分，选 Q 值最高的执行。
- **在线只微调 Q 函数**：失败回滚的 `(状态, 动作, 结果)` 直接吸收进 Q 函数，成本极低。

关键洞察：**把"学习"从大模型迁移到小 Q 函数**，让失败回滚成为可持续的学习信号，而不是重训成本。

## 三、原型设计

```python
class QPlanning:
    def __init__(self, base_policy, q_fn):   # base_policy 冻结，q_fn 几十KB
        self.policy = base_policy
        self.q = q_fn

    def act(self, state):
        cands = self.policy.propose(state)     # 大策略生成候选动作
        return max(cands, key=lambda a: self.q(state, a))  # Q 加权选动作

    def learn_from_failure(self, rollback):    # 失败回滚数据吸收
        for (s, a, r) in rollback:             # r<0 的失败样本
            self.q.update(s, a, r)             # 只更新小 Q 函数

    # 循环：执行 → 失败回滚 → learn_from_failure → 下一轮
```
