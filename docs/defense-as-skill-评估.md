# W73-12 Defense-as-Skill 运行时守卫评估

> 上游：arXiv 2609.01487（Defense-as-Skill）+ 2609.00546（运行时无关持久 Agent）+ 2609.01345（级联盲区）· 论文
> 安全类：只写防御。

## 1. 项目定位

恶意 skill 注入需要**运行时守卫**；跨运行时保持身份/记忆的持久 Agent；验证器盲区（级联盲区）。

## 2. 架构拆解

- **Defense-as-Skill**：把防御做成 skill，运行时监控 skill 行为（恶意 skill 注入检测）。
- **运行时无关持久 Agent**：跨运行时保持身份/记忆（连续性基底迁移）。
- **级联盲区**：验证器盲区基准——多级验证之间的盲区。

## 3. 与本仓对照

| 维度 | 上游 | 本仓 |
|---|---|---|
| skill 安全 | 运行时守卫 + 盲区基准 | Hermes skill 系统 + 双层管线（L1 本地/L2 云端）+ skill_gate（tools/skill_gate.py） |

## 4. 可落地借鉴点（≥3）

1. **Defense-as-Skill 运行时守卫**：把防御做成可挂载 skill，运行时监控其他 skill 行为——可增强 skill_gate 的行为监控。
2. **连续性基底迁移**：跨运行时保持身份/记忆的机制，可参考用于双层管线（L1/L2）的身份连续。
3. **级联盲区基准**：建立「多级验证之间的盲区」基准，作为 skill 安全评测口径。

## 5. 许可裁定 + 结论

- **许可**：arXiv 论文（无代码许可）→ **参考设计**（安全类只写防御）。
- **结论**：运行时守卫 + 盲区基准落到 skill_gate 的行为监控与 skill 安全评测；盲区基准建议纳入评测体系。
