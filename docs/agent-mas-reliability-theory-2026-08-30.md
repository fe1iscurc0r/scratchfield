## 一、问题陈述

多 Agent 社会依赖某些**社会机制**（互惠 reciprocity、共识 consensus、惩罚 punishment、gossip 流言传播）来维持协作与可靠性。但这些机制**有规模极限**：Agent 人口扩大时，某些机制会失效。若在设计 MAS 时默认"机制随规模扩展"，就会在规模达到阈值后突然崩溃。

论文（2608.22884）提供了**可预测的规模扩展审计方法**，覆盖互惠/共识/惩罚/gossip 四种机制，结论跨模型家族泛化。

## 二、规模极限理论笔记（何时失效）

| 机制 | 规模失效模式 | 关键变量 |
|---|---|---|
| 互惠 | 大群体中"搭便车"无人可惩罚，互惠链断裂 | 重复交互概率随规模下降 |
| 共识 | 意见收敛变慢，或收敛到错误共识 | 通信拓扑直径、消息往返 |
| 惩罚 | 惩罚成本被摊薄，威慑失效 | 惩罚者数量相对规模不足 |
| gossip | 消息覆盖范围和寿命决定失败阈值 | 传播范围、消息寿命、表达方式 |

**通用规律**：
1. **信息稀释**：规模越大，单个 Agent 获得的可靠信息占比越低。
2. **局部交互失效**：依赖"重复相遇"的机制（互惠、惩罚）在人口扩大、交互稀疏化后率先失效。
3. **gossip 的阈值由消息覆盖范围与寿命决定**——覆盖不足或寿命太短，流言机制失效。
4. **表达方式影响规模行为**：计数 vs 百分比等表达差异会改变大规模下的行为走向。

## 三、设计启示

1. **不默认机制可扩展**：任何依赖"重复交互 / 局部惩罚 / 短寿命消息"的机制，都要做规模审计。
2. **规模分档设计**：小规模用互惠/惩罚，大规模改为中心化信任 + 长寿命、高覆盖的消息协议。
3. **通信预算与机制绑定**：共识机制要配合"覆盖范围 + 消息寿命"的显式设计（对齐 A17 资源感知共识）。
4. **回归 A19**：规模放大时，错误传播（不确定性）会同步放大，需显式建模。
