# K26 神经形态数值求解→感知-推理一体 ESP32 勘察

> 来源：round3 digest-g4 2608.28387（神经形态架构作为数值求解器）+ 2608.28530（非光滑相对弱凸复合优化，Bregman 近端次梯度）
> 交付：勘察报告（本文档）。无真机，架构与资源预算为**纸上勘察**。

## 1. 授粉点核心

- **神经形态作"非尖峰"数值求解器**（2608.28387）：多比特包通信 + 高阶微分方程求解器
  优于传统尖峰网络，在精度受限的嵌入式传感场景有优势。
- **非光滑优化收敛保证**（2608.28530）：Bregman 近端次梯度，O(ε⁻⁴) 收敛，**不需要精确
  梯度**，适合噪声测量下的状态更新。

启发：前段用神经形态加速器做传感器**时序积分**，后段用 **Bregman 近端**做**状态估计**，
内部走事件驱动通信（而非全局内存访问）降功耗，在 ESP32 级功耗内做实时多传感器融合。

## 3. 资源预算（ESP32 级，纸上估算）

| 组件 | 计算模式 | 内存 | 功耗贡献 |
|---|---|---|---|
| 事件驱动传感 | 稀疏激活（无变化不算） | 事件队列（KB 级） | 低 |
| 神经形态时序积分 | 多比特包累加/ODE 步进 | 状态 O(通道数) | 中（相对尖峰网络更低） |
| Bregman 近端估计 | 无精确梯度的迭代 | O(状态维) | 低 |

- **内存**：全链路状态 O(通道数 × 阶数)，数十 KB 内，适配 ESP32-S3（512 KB SRAM）。
- **算力**：Bregman 近端每步只需近端算子（如软阈值/投影），无矩阵求逆，适合定点 DSP。

## 4. 可行性结论

- **架构可行**：事件驱动 + 时序积分 + 近端估计三段在 ESP32 级均可实现，关键是
  "感知-推理一体"省去"采样→上传→中心处理"的往返，降低功耗与延迟。
- **风险**：神经形态加速器需专用外设（或 CPU 模拟）；Bregman 近端收敛常数需按任务调参；
  ESP32 无原生事件驱动硬件，需用中断/RTOS 事件队列模拟。
- **建议**：先落地"事件驱动队列 + 软阈值/Bregman 近端状态估计"的 CPU 原型（对齐 K23
  的 PDM 前端 + 本报告后段），验证收敛与功耗收益后再上神经形态加速器。

## 5. 结论

感知-推理一体化 ESP32 架构**可行且方向正确**：用"神经形态时序积分 + Bregman 近端估计 +
事件驱动通信"替代"全量采样 + 中心推理"，能在 ESP32 级功耗内做实时多传感器融合。短期
用 CPU 原型验证，长期外接神经形态加速器。
