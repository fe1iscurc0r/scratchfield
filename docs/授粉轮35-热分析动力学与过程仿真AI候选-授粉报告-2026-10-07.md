## 二、授粉映射（源→目标域）

### 金果1：Kinetic-calculation + pyTGA → TGA 动力学 MCP（P0，立即可做）
- **源**：`src/`（C#，算法纯数值可直接 Python 移植）Vyazovkin/OFW 积分法；`Example Data/` 带真实 TGA 样例数据（已随包保留）。
- **共鸣**：TGA/DTG 曲线 → 生物质组分热解动力学三体（E、A、f(α)）——邵老师方向（木质素 NPs→碳化)表征环节的标准计算，实验室级刚需。
- **落点**：`tools/tga_kinetics.py`（pyTGA 解析多厂商原始文件 → 转换度 α(τ) → OFW/Vyazovkin 出 E(α) 分布）+ 后续 MCP 化。非侵入旁路，纯 Python+numpy。
- **验收**：`python tools/tga_kinetics.py --demo` 用 Example Data 出 E(α) 图；木质素 E≈100-160 kJ/mol 区间合理性校验。

### 金果2：CRNN → 机理硬编码物理约束网络（P1）
- **源**：`src/`（MATLAB）Chemical Reaction Neural Network：把 Arrhenius 形式 c^(1/T) 激活嵌进网络层，权重即动力学参数，训练=机理辨识。
- **共鸣**：lignet（轮101 W101-05 已立项）是黑箱 ANN 产物预测；CRNN 是**机理约束**辨识——同一批木质素热解数据的下一档处理。二者拼成「黑箱预测→灰箱辨识」两级台阶。
- **落点**：融合参考；SPEC 供 Trae 做 PyTorch 移植（`tools/crnn_probe.py`），不并入主仓核心。

### 金果3：RMG-Py(+database) → 机理生成引擎（P2，重量级）
- **源**：`rmgpy/` 核心包（5.1MB）+ `arkane/`（32MB→17MB 修剪后）参数估算 + database `families/` 反应模板。生物质热解（cellulose/lignin 模型化合物）机理自动生成的事实标准。
- **共鸣**：木质素结构（轮30候选）→ RMG 反应模板 → 热解产物分布预测。链条上接结构、下接动力学。
- **落点**：融合参考为主；database 的 `families/` 规则库是结构化知识（YAML 树），可拆出来喂 KG 线（qKnow 对照片）。

### 金果4：freeze-drying-optimization-agent-skill → Skill 架构模板（P1）
- **源**：`src/freeze_drying_optimization/` — skill registry（register/resolve/execute/validate + I/O JSON schema）+ 生命周期钩子 + 质量门（U1-U6+G1-G4 auto-fix）。
- **共鸣**：**冻干内容不重要，skill 骨架值钱**——这正是一个 Claude Skill 的工程化范本，与 Hermes skills/ 的 manifest 纪律互为对照。冻干物理引擎（无依赖纯 Python）本身对生物质干燥段也有直接参考价值。

### 金果5：dwsimopt + pyAspenPlus + dwsim-claude-integration → 过程仿真三件套（P1）
- **源**：dwsimopt（PyPI 在架，黑箱优化）/ pyAspenPlus（COM 读流股设备）/ dwsim-claude-integration（NL→flowsheet 的 agent 范本）。
- **共鸣**：process-sim-双引擎handler-SPEC-v1（已有）指定的 dwsim/aspen 两个 adapter 后端，**三个都是现成桥**——SPEC 从纸面走向可执行的路料全齐了。
- **落点**：`mcpserver/process-sim/` 的 adapter 参考实现；配合 SPEC-18 科研增强管线。
