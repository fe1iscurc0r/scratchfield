## 1. 项目定位与架构

ai-engineer-notebooks 是一组 Jupyter 笔记本，主题是「**无框架、手写**」AI 工程实践：不用
LangChain/LlamaIndex 等框架，直接手写 embedding / RAG / agent / 部署等核心环节，用于训练
「forward-deployed」AI 工程师。价值不在「生产代码」，而在「把黑盒框架拆开看原理」的教学/参考。

## 2. 与本仓对照

| 维度 | ai-engineer-notebooks | 本仓陆墨科研线 + Python 工具 |
|------|----------------------|------------------------------|
| 实现风格 | 无框架手写 | 多为 numpy/stdlib + 少量框架 |
| 主题 | RAG/agent/embedding/deploy | 材料计算/射频/记忆 |
| 形态 | 教学笔记本 | 生产模块 |

本仓陆墨线大量「numpy/stdlib 手写」的模块（rf_brain、材料线、RAG）与其「无框架手写」理念同源；
差异在本仓面向生产模块，笔记本面向教学。

## 3. 可落地借鉴点（≥3）

1. **无框架实现思路**：手写 embedding/RAG/agent 的「最小可懂实现」，是本仓「不引新依赖」铁律下的最佳参考——把复杂环节降成几十行 numpy/stdlib。
2. **forward-deployed 工程方法**：先跑通最小闭环再迭代，与本仓「原型→测试→验收」同构，可吸收其「最小闭环优先」的 notebook 组织方式。
3. **教学式拆解**：把黑盒（如向量检索、重排）拆成可读步骤，本仓新模块的 docstring/注释可借鉴这种「每步说人话」的写法。
4. **部署实践**：无框架下如何做 embedding 服务/本地推理部署，可参考陆墨科研工具链的部署简化。
