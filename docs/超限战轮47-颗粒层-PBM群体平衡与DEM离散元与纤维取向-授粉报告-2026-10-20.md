## §3 · 源码级证据（5 处，都是实读，不是读描述）

**3.1 `MOpS` 的 PBM 骨架（`src/mopsc/source/` 目录实列）**

```
mops_psr.cpp            18 KB   粒径表示（Particle Size Representation：abscissa + weights）
mops_gpc_sensitivity.cpp 31 KB  高斯过程（GPC）全局参数敏感度 —— 直接给"哪些工艺参数决定 PDI"
mops_simulator.cpp     135 KB   主循环（加权时间算法：采样"下一个发生的事件"）
mops_loi_reduction.cpp           失重（LOI）归约：实验 TGA 曲线 → 模型对标量
mops_reactor_network.cpp         反应器网络（沉淀釜 / 管式 / 混合器串联）
```

> **为什么值钱**：木质素 NPs 的 PDI 不是"调参调出来"的，是**成核速率 ∝ 过饱和度^m、生长 ∝ 扩散、聚并 ∝ 碰撞核**三者竞争的结果。PSR + 加权时间算法正好是"离散事件采样群体"，比连续矩法更容易塞进非线性的木质素自组装核。GPC 敏感度那一层，等于自动回答"温度/浓度/滴加速率哪个最影响 PDI"——这正是 `xtalyst` 设计文档里靠"领域常识假设"填的那格。

**3.2 许可实读：MOpS 是双口径，不能按 MIT 记**

- 根 `LICENSE.txt`：MIT 原文（Copyright C 2020 Markus Kraft）
- 但 `mops_psr.cpp` / `mops_reactor.cpp` / `mops_particle_solver.cpp` 文件头全是
  `GNU General Public License … either version 2 of the License, or (at your option) any later version`
- → **按 GPL-2.0-or-later 处理**（GPL-2.0+ 可升 GPL-3.0，与主仓 AGPL-3.0 兼容；保留文件头声明）。若只抄根 LICENSE 当 MIT，是把 copyleft 洗成宽松——和 stimm（badge MIT / 实为 AGPL）同一类坑，方向相反。

**3.3 `DEcalioc` 的两段式标定（仓库内 `DEcalioc.m` 实读）**

```matlab
:154  The desired DEM model result lies outside of the boundaries of the initial DEM results.
:184  costFunc = @(params) costFunction(params, @evaluateKriging, KrigingFunNames);
:201  userIntDEM = @(p,vals,state)userInt(p,vals,state,DEMflag);
:217  [p_DEM, resid_DEM, cvg_DEM, outp_DEM] = nonlin_residmin(costFunc, initParam, settings);
```

> 算法骨架：**先跑一小批 DEM 得到 DoE 边界 → 拟合 Kriging 代理面 → 在代理面上全局搜 → 只把最优几个点回灌真 DEM → `nonlin_residmin` 精修**。
> **为什么值钱**：这是"用实验室能测的三个数（休止角、堆密度、压缩/剪切）反演 DEM 微观参数（μs/μr/恢复系数 e/滚动阻力）"的标准解。生物质（木片、竹屑、蒸煮后浆料）的 DEM 参数没人给过库，标定是唯一出路；而单次 DEM 仿真几十秒到几分钟，没有代理面根本标不动。

## §7 · 许可纠正（4 条，全部实读原文）

1. **`PBM-Flocculation` 是"All rights reserved"，不是开源**。API 返回 `NOASSERTION`，LICENSE 657 B 原文写明"*No permission is granted to copy, modify, publish, distribute, sublicense, or sell the project-specific code. Access supplied for grant review does not itself grant redistribution or commercial-use rights.*" —— 这是本轮唯一一个"主题最贴、许可最死"的项目，**硬排除**。教训与 screenpipe 同类：NOASSERTION 既可能是"没写清"，也可能是"写清了但拒绝授权"。
2. **`MOpS` 双口径**：根 LICENSE.txt = MIT，`src/` 多数文件头 = GPL-2.0-or-later → 按 **GPL-2.0+** 处理（可升 GPL-3.0，与 AGPL-3.0 兼容）。若按 MIT 记，等于把 copyleft 洗成宽松。
3. **`SudoDEM` 97★ GPL-3.0 但已 archived**（2026-03）→ 可读不可跟；星数高不等于活着。
4. **`classproject-papermakingsimulator/papermaking-simulator`**：2★、900 MB、C#、无 LICENSE、无文档的课程作业 → 暂缓且低优先；"papermaking" 这个关键词的 GitHub 供给基本是艺术造纸与课程件，**不构成可融合候选**（这本身是差距清单第 1–5 行的旁证）。
