# TACAN 动态频谱接入 · 勘察与策略设计

> 日期：2026-08-30

---

## 1. 结论先行

TACAN 用「**信道 token 注意力**」替代「全信道扫描 + 固定阈值」：把频段占用历史编码成 token，Transformer 直接输出接入决策，PPO 训练，突发主用户流量下 92.5% 接入成功率。这一范式**可迁移到 rf_brain 的动态频谱接入**，核心收益是：

- 不再逐信道扫一遍再挑"最空"的（现有 `scanner.py` + `decision_layer.py` 思路），而是**从历史序列一步决策**；
- token 注意力天然建模"信道间占用相关性"与"突发模式"，比独立能量阈值更鲁棒。

**推荐形态**：rf_brain 决策层引入一个轻量「信道 token + 策略头」模块，训练在 PC 完成，端侧只跑冻结推理（策略查表/小网络）。

## 2. TACAN 要点

| 维度 | TACAN 做法 | rf_brain 映射 |
|---|---|---|
| 状态表示 | 频段占用历史编码为 channel token | `spectrum.py` 帧序列 → 每信道占用 token |
| 决策器 | Transformer 注意力 + PPO | 轻量注意力策略（冻结推理） |
| 训练 | 从贪婪策略 warm-start | 用现有 rule_engine 做行为克隆 warm-start |
| 指标 | 突发主用户下 92.5% 成功率 | 接入成功率 / 碰撞率 / 频谱利用率 |

## 3. MDP 定义

### 状态 S
把过去 `T` 个时隙、`K` 个候选信道的占用状态编码为 token 序列：
- 每个信道 i 每时隙 t 的观测：`[能量, 是否被主用户占用(检测), SNR]`；
- 时序聚合 → 每个信道一个 token `h_i`（可经轻量编码器 / 直接拼接）；
- 状态 = `{h_1, …, h_K}` + 全局上下文（当前时隙、待发数据优先级）。

### 动作 A
- 离散：`a ∈ {0, 1, …, K-1}`，选一个信道接入；可加 `a = K`（"本时隙不接入/等待"）。

### 奖励 R
- `+1` 接入成功且无碰撞；
- `-c_coll` 与主用户（或他认知节点）碰撞；
- `-c_scan` 每次接入前的额外扫描/切换代价（鼓励少动）；
- 可选：`+w·quality` 按接入信道 SNR 加权（鼓励高质量信道）。

### 折扣与目标
`max E[Σ γ^t R_t]`，γ≈0.95；训练用 PPO，策略 warm-start 用 rf_brain 现有贪婪规则（行为克隆）。

## 4. 三个模拟场景

| # | 场景 | 主用户模式 | 考察点 |
|---|---|---|---|
| **S1 突发主用户** | 主用户按随机 on/off 突发占用（占空比 ~20%，持续期随机） | 认知节点在间隙接入、避免碰撞 | 接入成功率 / 碰撞率 |
| **S2 多认知节点竞争** | 多个次用户共享 K 个信道 | 需学习共存/退避，避免互相踩 | 系统总吞吐 / 公平性 |
| **S3 慢时变信道质量** | 各信道 SNR 慢漂移（瑞利/慢衰落） | 在"占用 vs 质量"间权衡 | 平均接入质量 / 切换次数 |

> 验收口径：S1 接入成功率 ≥ 90% 且碰撞率低于固定阈值基线；S2 总吞吐优于随机接入；S3 平均 SNR 优于"只挑最空"策略。

## 5. 映射到 rf_brain 现状

| rf_brain 组件 | 现状 | 接入 TACAN 后 |
|---|---|---|
| `spectrum.py` | 逐帧 FFT | 帧 → 信道占用 token 序列 |
| `scanner.py` | 顺序扫描 | 由策略直接指向候选信道（按需探测） |
| `decision_layer.py` | 规则 + 特征 | 增加「策略头」分支，规则做兜底 |
| `spectrum_events.py`(R01) | 事件缓存 | 事件历史喂入 token 编码器 |

## 6. 模拟验证方案

1. 用 numpy 实现一个最小 gym 风格环境 `DynamicSpectrumEnv`：
   - `reset()` 生成 K 信道 + 突发主用户模型；
   - `step(action)` 返回 `(next_state, reward, done)`；
   - 观测 = 每个信道的能量 + 占用标签（含噪声）。
2. 基线：随机接入、固定阈值能量检测、贪婪"选最空"。
3. 训练：小策略网络（全连接 + 单头注意力），PPO 若干 episode。
4. 输出：接入成功率 / 碰撞率 / 频谱利用率对比表 + 学习曲线。
