## 四、授粉勘察（阶段 4）

### 4.1 核心数据结构共鸣：「一维传感器响应时间序列 → 多模态特征向量」

授粉价值的核心不在"我们做不做得来化学计量学"，而在 **「跨域映射：哪个上游范式能描述用户专业线的问题」**。本轮定位三个错位使用：

#### 范式 A：**IBM chemsense 的"数字指纹"范式**（最值钱）
- **源域**：电化学电子舌 16 电极 / 时长 80 秒 → 15 路差分电压时序信号
- **数据流**：raw time series → **Gramian Angular Field (GAF)** 编码为 RGB 图像 → **预训练 ViT/BeiT/MobileNet/ResNet** 提取特征向量 → 分类器（"数字指纹"）
- **目标域**：
  - **SDR I/Q 采样流** → GAF → 预训练视觉模型 → 协议指纹 → 同频段异常检测（**授粉到 rf_brain / Channel2World**）
  - **EMG/ECG/PPG 时序生物电** → GAF → 视觉模型 → 心理状态/手势识别（**授粉到 SDR-Agent 链路的生物信号侧**）
  - **多模态时序振动信号**（无人机电机、LoRa 信号衰落） → GAF → CNN → 故障模式识别
- **为什么值钱**：
  - **GAF 编码**把"一维序列"变成"二维图像"——预训练视觉模型（小海、无参 GPT-4V）的全部能力瞬间可复用，**等于免费获得 ImageNet 量级的视觉先验**应用到一维传感器。
  - **绕过"小样本"困境**——传统传感器分类需要数千条标注训练样本；chemsense 用迁移学习把样本需求降到 100-200 条/类。
  - **用户专业线"分子印迹电化学传感器"**正是这套范式的天然目标——15 路电信号 → 指纹 → 木质素/酚类/酯类识别。

#### 范式 B：**chemotools / pyChemometrics 的"模块化化学计量学"**
- **源域**：光谱数据 PLS 回归 + 11 种基线校正（AirPLS/ArPLS/AsLS/多项式/橡皮筋...）+ 5 种平滑（Savitzky-Golay/Whittaker/Mean/Median/Modified Sinc）+ 4 种缩放（MinMax/Norm/Pareto/Point）+ SR/VIP 特征选择
- **目标域**：
  - **授粉到 rf_brain**：频谱分析管线如 transformer — 基线 = 直流偏置消除 / 平滑 = 频谱泄露抑制 / 缩放 = 动态范围归一化 / 特征选择 = 频段选择
  - **授粉到 RamanSPy 链路**：chemotools 的 `baseline.AirPLS` + `smooth.SavitzkyGolay` + `scale.Pareto` 直接给 Raman 数据用，**比 RamanSPy 自带的 baseline/scale 模块更完整**。
  - **授粉到木质素/水凝胶测试数据**：NIR/IR 光谱分析 → chemotools 全套 → 棕纤维素含量预测
- **为什么值钱**：
  - **scikit-learn API 兼容性**——直接 `Pipeline([('baseline', AirPLS()), ('scaler', ParetoScaler()), ('plsr', PLSRegression())])` 串起来。
  - **Improved Kernel PLS (ikpls) 加速**——比 sklearn 自带 NIPALS 快 5-10×，对实时/批量均实用。
  - **完全 MIT 许可 + 2026-10-05 还在活跃**——直接并入 mcpserver。

#### 范式 C：**pyMCR 的"盲源分离"光谱解析**
- **源域**：混合光谱 = 多个纯组分光谱 × 浓度矩阵 → MCR-ALS 反演出纯组分光谱 + 浓度
- **目标域**：
  - **RF 频谱混合信号分解**：多电台混叠 → MCR-ALS 分解出单电台功率谱 + 占用时段
  - **电化学阻抗 EIS 多机制解混**：EIS 等效电路拟合前，可用 MCR 看是否存在多个时间常数的叠加
  - **生物质热解气相色谱-质谱联用**（GC-MS） → MCR → 各组分含量变化
- **为什么值钱**：
  - **NIST 官方维护**（US gov 公共领域）—— 长期可持续，几乎无法律风险。
  - **sklearn 风格 API**——可集成进光谱处理流水线。
  - **可复用 pyChemometrics 缩放器**——同一套预处理可喂给 PLS 和 MCR。
