# 自注入锁定（SIL）本振稳定 · ESP32 勘察

> 来源工单：R22 · 分组 group1-无线电
> 参考 digest：[digest-g8-1b-2026-08-30.md](../paper-round2-2026-08-30/digests/digest-g8-1b-2026-08-30.md)（授粉点 2 · 论文 2608.17476 sub-THz 自注入锁定测距）
> 日期：2026-08-30

---

## 1. 结论先行

自注入锁定（Self-Injection Locking, SIL）用「把振荡器输出的一部分延迟后反馈注入自身」来**锁窄本振线宽、压低相位噪声**，sub-THz 场景已实现 <0.002% 测距精度（亚毫米级）。这一原理**可降级迁移到 ESP32 射频前端的本振改进**——虽然 ESP32 用 PLL 而非自由振荡器，SIL 的「延迟自注入 → 相位噪声整形」思路仍给出三条可落地改进。

---

## 2. SIL 降噪原理分析

- **核心机制**：振荡器输出经一段**延迟线**（或高 Q 谐振腔）后注入自身，注入信号与振荡信号相关，锁定后等效于提高谐振腔 Q 值 → **线宽变窄、相位噪声下降**。
- **本质**：用「自身的相干延迟副本」做负反馈，抑制振荡器的随机相位游走（Leeson 模型里 Q 越高相位噪声越低）。
- **sub-THz 效果**：SIL + FMCW → 相位噪声大幅下降 → 测距精度到亚毫米（<0.002%）。

---

## 3. 三条可落地改进（ESP32 本振）

1. **提高参考晶振/环路 Q 值（间接 SIL）**：ESP32 本振由 PLL 从参考晶振合成，相位噪声受参考与环路带宽制约。用**高 Q 晶振**（TCXO/OCXO 替代普通 XTAL）等效于 SIL 的「高 Q 谐振腔」——最直接、零额外 RF 设计的改进。

2. **优化 PLL 环路带宽与分频比（噪声整形）**：SIL 的「相位噪声整形」启示：合理选择 PLL 环路带宽（在参考噪声与 VCO 噪声之间取平衡点）和分频比，把带内/带外噪声推到最低。ESP32 的 PLL 参数可在固件层调整。

3. **加外部延迟自注入（硬件级 SIL，选配）**：对高要求的接收链路，可在 PA/LNA 输出引一路**微带延迟线**回注本振/参考，实现真正的 SIL 锁窄。成本高、仅限高端变体，作为可选升级。

---

## 4. 落地建议

- **短期**：换 TCXO 参考晶振（改进 1）+ 调 PLL 环路带宽（改进 2），固件级、低成本。
- **中期**：对相干测距/测相应用（如 R18 指纹提取、R14 相位保持），评估硬件 SIL（改进 3）。
- **量化指标**：以单音相位噪声（dBc/Hz @ 偏移）与载波频偏稳定性为验收口径，目标相位噪声降 6–10 dB。
