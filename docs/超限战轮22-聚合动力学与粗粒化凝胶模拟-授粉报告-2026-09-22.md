## 授粉映射（源→目标域）

### 1. polykin（聚合动力学）→ 木质素-单体接枝共聚配方计算层
- **共鸣**: 活度系数模型（Flory-Huggins 与 NRTL）正是木质素NPs在共熔溶剂中分散/相容性预测的缺失件；ligpy给热解路径，polykin给**正逆聚合双向**能力
- **难度1×收益6** = 纯Python无C扩展，pip即用
- **落点**: `research/polykin-共聚配方/`，与ligpy/lignet构成木质素转化三件套（热解ANN→动力学ODE→活度系数）

### 2. martignac（Snakemake工作流引擎）→ 陆墨科研线的可复现管线模板
- **共鸣**: "可复现+可追溯+可组合"的仿真管线模式可直接套用到任何多阶段科研计算（木质素MD→分析→制图）；其Streamlit dashboard模式可授粉给科研线结果展示
- **难度2×收益4**（需Gromacs做生产运行，预处理只读架构）
- **落点**: `research/martignac-workflow-模板/`，架构授粉为主

### 3. DPDsim（介观模拟）→ 凝胶网络粗粒化模拟起点
- **共鸣**: DPD是连接分子尺度(All-atom MD)与连续介质(有限元)的中间层，共熔凝胶交联网络力学/溶胀行为正好落在这个尺度盲区——现有nequip(力场)/SOAX(图像量化)都没有介观模拟件
- **难度2×收益5**（教学级代码量小易读，生产需换Gromacs/edList后端）
- **落点**: `research/DPD-凝胶介观/`

### 4. MartiniGlass → 可视化辅助件
- **共鸣**: 与LigninBuilder(VMD插件)同一生态位，Apache-2.0可融合；暂列P2

## P0 优先级

1. **P0 polykin** — 唯一pip即用、直接命中木质素接枝/共聚配方的计算库，价值密度最高
2. **P1 DPDsim** — 凝胶介观模拟空白填补，教学级易吸收
3. **P1 martignac** — 管线架构授粉（不拉生产依赖）
4. **P2 MartiniGlass** — 可视化件，按需
