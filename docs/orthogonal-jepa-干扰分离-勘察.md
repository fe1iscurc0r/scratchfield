## 1. 结论先行

Orthogonal JEPA 的核心洞察：当多个物理过程（主导 + 次级）叠加时，**单一目标嵌入会让次级信号的梯度变弱甚至与主信号冲突**。SDR 接收信号正是这种场景——信号、多径、干扰同时叠加，若全部压缩进一个表示，弱干扰/多径会被强信号淹没。

**迁移思路**：把接收 IQ 分解为**正交的预测分量**，每个分量对应一个物理过程（信号 / 多径 / 干扰），正交性保证各过程互不污染。可行性：**高**——频率域天然正交（窄带干扰 vs 宽带信号），线性正交投影即可做最小原型；非线性学习版（真 JEPA）作为扩展。

---

## 2. Orthogonal JEPA 要点

| 维度 | Orthogonal JEPA | SDR 干扰分离映射 |
|---|---|---|
| 问题 | 单一嵌入导致次级信号梯度弱/冲突 | 弱干扰被强信号淹没，单表示不可分 |
| 做法 | 因子化正交预测分解 | 正交潜分量分别建模各物理过程 |
| 收益 | 表示质量/预测/长期稳定大幅提升 | 干扰/多径可分别重建与消除 |
| 验证域 | 细胞/心脏/分子/视觉 | 模拟 IQ 数据 |

## 3. 架构设计

```
IQ 接收 x = s(信号) + i(干扰) + m(多径) + n(噪声)
              │
   ┌──────────┼──────────┐
   ▼                      ▼
编码器 E_i（干扰子空间）   编码器 E_s（信号子空间）
   │ 正交约束 E_i ⊥ E_s     │
   ▼                      ▼
  î = P_i x              ŝ = (I-P_i) x
   └──────────┬──────────┘
              ▼
        正交性校验：⟨î, ŝ⟩ ≈ 0 + 与真值相关性校验
```

- **最小原型（本工单）**：线性正交投影。干扰子空间由窄带结构（sin/cos 基）张成，
  信号分量 = 正交补。闭式、零训练、可离线单测。
- **扩展（真 JEPA）**：非线性正交编码器 + 潜空间预测，多过程联合学习。

---

## 4. 可行性

- **高**：窄带干扰与宽带信号在频域正交，投影分解即分离，零硬件依赖。
- **限制**：线性投影假设干扰频点已知/可估；宽带干扰需非线性 JEPA 或自适应陷波（R03 已有）。
- **与 R03 的关系**：R03 是「检测+滤除」，本工单是「正交分解+分别重建」，二者互补。
