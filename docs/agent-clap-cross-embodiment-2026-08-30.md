# A14 CLAP 跨形态迁移（视频世界模型 → 零样本物理仿真）

## 一、问题陈述

机器人/Agent 的物理仿真迁移长期受困于**形态绑定**：为一个机器人形态训练的世界模型/仿真器，无法直接用于另一个形态。CLAP（2608.27406）的突破：

- **跨机器人形态**（人 / 机械手 / 人形 / 机械臂）统一物理视频生成；
- **打通互联网视频 → 具身仿真**迁移，**零样本泛化**；
- 发布大规模数据集。

核心价值：用一个**跨形态视频世界模型**充当"零样本物理仿真器"，让仿真→真机的迁移不再依赖逐形态标定。

## 二、核心机制：跨形态统一物理视频生成

- 把不同形态的物理交互统一到**同一个视频世界模型**的隐空间（形态条件化，而非形态绑定）。
- 用互联网视频的大规模分布 + 物理一致性约束训练，使模型学到"形态无关的物理规律"。
- 推理时给定目标形态条件，零样本生成该形态下的物理合理视频（作为仿真 rollout）。

## 三、迁移管线设计

```
互联网视频（多形态物理数据）
  → CLAP 视频世界模型（形态条件化的物理隐空间）
    → 零样本生成目标形态的物理仿真 rollout
      → 用 rollout 训练/评估目标形态的 Agent 策略
        → 真机零样本迁移（少标定 / 无标定）
```

### 管线要点
1. **形态条件化**：目标形态编码为条件，注入视频世界模型，无需重训。
2. **物理一致性**：生成 rollouts 需通过物理规则校验（对齐 A06 护栏）。
3. **仿真→真机**：用零样本仿真 rollout 做策略预训练，真机仅需少量适配。

## 四、验证指标

| 指标 | 说明 |
|---|---|
| 跨形态生成质量 | 生成 rollout 的物理合理性（FID / 物理一致性） |
| 零样本迁移成功率 | 目标形态策略在真机上的成功率 |
| 数据效率 | 相对逐形态标定方法的样本节省 |

**验收目标**：跨形态零样本仿真迁移跑通，真机成功率与逐形态标定方法可比或更优，且省去逐形态标定成本。
