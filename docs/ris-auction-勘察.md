# RIS 序贯拍卖勘察报告（R60）

> 2026-08-31 · 智能体 12 · 来源：digest-g3-2 2608.22169v1（MARL-Based Sequential RIS Auctions: A Physical-Layer Security Analysis）
> 状态：勘察（不写实现）

## 一、结论（TL;DR）

RIS（可重构智能表面）的相位配置在「多用户竞争」下是**稀缺资源**——单块 RIS 无法同时为所有用户最优。2608.22169 用**序贯拍卖**分配 RIS 相位资源，多智能体强化学习（MARL）建模用户的策略性出价，并在物理层安全（窃听者存在）下分析拍卖对保密速率的影响。对 R07（CS-AO 相位闭合解）的补充价值：**R07 解决「给定用户如何最优调相位」，R60 解决「多用户时 RIS 归谁用、怎么轮转」**——即相位解之上的资源分配机制。

## 二、拍卖机制

- **序贯拍卖**：用户按轮次对 RIS 相位配置（或 RIS 服务时段）出价，赢家获得 RIS 服务。
- **MARL 建模**：每个用户是独立智能体，学习「出价策略」以最大化自身速率/保密收益；拍卖方（RIS 控制器）按规则定价/分配。
- **物理层安全维度**：效用函数含**保密速率**（合法用户速率 − 窃听者速率），拍卖结果影响合法链路与窃听链路的相对增益——不是纯吞吐拍卖，而是「安全感知」拍卖。

## 三、机制对比

| 机制 | 分配方式 | 算力 | 安全性考虑 | 适配 MCU |
|------|---------|------|-----------|---------|
| R07 CS-AO | 单用户相位闭合解（交替优化） | 低（闭合解） | 无（只优化合法增益） | 高（numpy 已验） |
| 固定轮转（round-robin） | 时间均分 | 极低 | 无 | 高 |
| 序贯拍卖（R60） | 出价竞争 + 安全效用 | 中（MARL 训练重） | 有（保密速率入效用） | 低（训练重，推理轻） |

## 四、与 R07 衔接

- R07 的 CS-AO 是「单用户相位优化内核」；R60 的拍卖是「多用户资源分配外壳」。
- 组合路径：R07 内核为每个候选用户算好「最优相位 + 可达保密速率」，拍卖层据此定价/轮转——内核复用，外壳新增。
- 代价：MARL 训练需要仿真环境（信道 + 窃听者模型），端侧只跑训练好的策略，不承担训练成本。

## 五、可落地借鉴点（≥3 条）

1. **资源分配与信号处理分层**：把「相位怎么调」（R07 内核）与「资源归谁」（拍卖外壳）解耦，rf_brain 的频谱/波束资源也可套用「内核复用 + 外壳新增」。
2. **安全感知的效用设计**：分配决策不只看吞吐，把「干扰/窃听代价」折进效用函数——可直接借鉴到 rf_brain 的频谱仲裁（S16 分布式频谱仲裁同理）。
3. **竞争性出价建模**：MARL 出价是「策略性资源竞争」的通用抽象，可用于多 ESP32 节点竞争有限的 LoRa 时隙/频点。
4. **序贯（非一次性）分配**：资源按轮次分配，支持动态用户进出——契合 LoRa 自组网节点的间歇性在线。

## 六、离栈度

中高。拍卖/MARL 的抽象可直接借鉴；但 RIS 硬件与窃听者模型离 ESP32/LoRa 栈较远，落地需替换为「LoRa 时隙/频点」与「同频干扰」等价物。建议仅在 R07 内核落稳后再考虑外壳。
