# W73-11 端上 DSP 三件评估（multiplierless DFT + PCG 均衡）

> 上游：arXiv 2609.01115（multiplierless DFT 近似）+ 2609.00890（PCG 均衡器）+ 2609.01431（缩放律估计）· 论文

## 1. 项目定位

端上 DSP 三件：①无乘法 DFT 近似（multiplierless FFT，省乘法器）；②硬件流水 PCG 均衡器；③训练缩放律预估（训练预算分配）。

## 2. 架构拆解

- **multiplierless DFT**：用移位/加法近似 DFT 旋转因子，无乘法器，适配 FPGA/MCU。
- **PCG 均衡器**：硬件流水线的共轭梯度（PCG）均衡，低延迟。
- **缩放律估计**：训练前预估缩放律，指导预算分配。

## 3. 与本仓对照

| 维度 | 上游 | 本仓 |
|---|---|---|
| DSP | 无乘法 FFT + PCG 均衡 | 嵌入式 DSP + mcpserver/rf_brain 滤波链 + ESP32-S3 |

## 4. 可落地借鉴点（≥3）

1. **无乘法 FFT vs 现有 FFT 的精度/功耗权衡**：multiplierless DFT 用移位加法替代乘法，适配 ESP32-S3 整数运算，可作为 rf_brain 频域处理的前端。
2. **PCG 均衡器硬件化**：低延迟均衡器，可对照 rf_brain 滤波链的均衡实现。
3. **缩放律预估训练预算**：训练前预估预算，指导端上模型的训练/微调预算分配。

## 5. 许可裁定 + 结论

- **许可**：arXiv 论文（无代码许可）→ **参考设计**。
- **结论**：参考「无乘法 FFT」在 ESP32-S3 上的精度/功耗权衡，作为 rf_brain 频域前端的对照；PCG 均衡 + 缩放律预估作为训练预算参考。
