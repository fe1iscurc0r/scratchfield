# 跨模拟器基础模型迁移 · 方案

> 参考 digest：[digest-g6-2b-2026-08-30.md](../paper-round2-2026-08-30/digests/digest-g6-2b-2026-08-30.md)（授粉点 3 · 论文 2608.26354 ViT-JEPA 跨模拟器 SBI）
> 日期：2026-08-30

---

## 1. 结论先行

2608.26354 用「自监督 ViT-JEPA 预训练 → 21cm 宇宙学 SBI 零样本跨模拟器泛化」，解决 SBI（仿真推断）模型的**模型错误设定**核心问题。这一范式可迁移到射频域：在**仿真**上预训练基础模型，冻结编码器后**零样本**迁移到**真机**推理，跳过逐任务真机标注。

---

## 2. 迁移流程

```
 ① 仿真预训练（PC）
   射频仿真器（信道/干扰/调制）→ 大量无标签 IQ/频谱
   ViT-JEPA 自监督（预测潜表示，无需标签）
        │
        ▼
 ② 冻结编码器（真机部署前）
   ╰ 保留预训练编码器，仅接轻量下游头
        │
        ▼
 ③ SBI 零样本推理（真机）
   真机观测 → 冻结编码器 → 后验/分类（无真机标签微调）
        │
        ▼
 ④ 验证与校准
   覆盖率/校准/零样本精度（见 §3）
```

- 与 R02（Channel2World 频谱基础模型）同源：预训练 + 冻结 + 微调；区别在 R41 强调**跨模拟器零样本**（真机无标签直接推理）。

---

## 3. 验证指标

| 指标 | 定义 | 合格线 |
|---|---|---|
| 零样本精度 | 真机下游任务无微调准确率 | 接近仿真域精度 |
| 后验覆盖率（SBI） | 真机观测的后验是否覆盖真值 | 名义覆盖率（如 95%） |
| 校准误差（ECE） | 预测置信度与真实频率一致 | < 0.1 |
| 域漂移敏感度 | 真机 vs 仿真的表征距离 | 漂移 << 类间距离 |
| 小样本微调增益 | 用极少量真机标签微调后的提升 | 显著高于随机初始化 |

---

## 4. 落地建议

1. 预训练数据用射频仿真器（合成 IQ + 信道模型），复用 R02 的数据源路线。
2. 编码器用轻量 ViT/JEPA 变体（ESP32 只跑冻结推理，符合 R11/R38 的定点化产物）。
3. SBI 后端用于真机参数估计（信道参数、干扰类型），输出后验而非点估计。
4. 与 R02（频谱基础模型）、R41 互为补充：R02 定预训练任务，R41 定跨模拟器零样本迁移与验证。
