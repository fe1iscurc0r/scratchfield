# PCI 分配干扰管理勘察报告（R62）

> 2026-08-31 · 智能体 12 · 来源：digest-g1-3 2608.21485v1（Congruence Decomposition with Neural Block Solvers for PCI assignment）
> 状态：勘察（不写实现）

## 一、结论（TL;DR）

PCI（Physical Cell Identity）分配是稠密 5G 网络的邻区干扰管理核心：给每个小区分配标识，必须避免**冲突**（两相邻小区同 ID）与**混淆**（某小区的两个邻居同 ID）。这是个大规模图着色/约束满足问题。2608.21485 用「同余分解（congruence decomposition）+ 神经块求解器」把大网络拆成可并行求解的块。对 LoRa 自组网的直接借鉴：**节点 ID / 频点分配同样受「冲突 + 混淆」约束**，可套用同一套形式化 + 分解求解。

## 二、算法拆解

1. **约束形式化**：
   - 冲突（collision）：相邻节点不能同 ID。
   - 混淆（confusion）：一个节点的两个邻居不能同 ID（否则路由/识别歧义）。
   - 本质是带二阶约束的图着色（邻接约束 + 邻居对约束）。
2. **同余分解**：利用「标识空间模结构」（PCI mod 3 避免参考信号冲突等），把约束分解到若干同余类，降低耦合。
3. **神经块求解器**：大网络分块（块内精确求解 + 块间迭代协调），神经求解器替代穷举，保证大规模可扩展。
4. **目标**：最大化可用标识复用率（同 ID 远距离复用），同时零冲突/零混淆。

## 三、与 LoRa 自组网的映射

| 5G PCI 概念 | LoRa 自组网等价物 |
|------------|------------------|
| 物理小区标识 PCI | 节点 ID / 网络密钥 / 频点 |
| 邻区冲突（相邻同 ID） | 相邻节点同 ID / 同频点 |
| 混淆（邻居同 ID） | 一跳邻居 ID 歧义导致路由错乱 |
| 标识复用 | 大网内 ID 跨区域复用 |

LoRa mesh（mesh_layer 的邻居表/路由表）已有节点 ID 与「直达/多跳」拓扑，天然具备「冲突/混淆」判定所需的信息。

## 四、可落地借鉴点（≥3 条）

1. **冲突 + 混淆双约束形式化**：LoRa 自组网节点 ID / 频点分配显式写为「邻接不同 + 邻居对不同」约束，避免当前「随机 ID + 靠去重兜底」的冲突隐患。
2. **同余分解降耦合**：把频点/ID 分配按模结构（如 mod 跳频组）分解，减少全局耦合——对应 LoRa 的跳频组/扩频因子分组（SF 正交性天然是「同余类」）。
3. **分块求解 + 迭代协调**：大网按地理分块，块内精确分配、块间边界迭代对齐——契合 mesh 的分簇/多跳结构，避免全局重分配。
4. **可复用性最大化**：远距离节点复用同一 ID/频点，提升大网容量——直接指导 LoRa 频点规划与节点 ID 空间设计。

## 五、自建门槛

- 需要真实/仿真拓扑（节点位置 + 邻居关系），无真机时用 mesh_layer 的模拟网络即可。
- 神经求解器训练重；落地可用「贪心 + 局部搜索」替代（资源受限），保留「冲突/混淆」约束与分解思想。
- 标识空间有限（LoRa 节点 ID 位数），需评估复用率与混淆风险的权衡。

## 六、离栈度

低。图着色 / 约束满足 / 分解求解是纯算法，与 LoRa 自组网的节点 ID / 频点规划直接同构；无特殊硬件依赖，可直接指导 rf_brain 的 mesh 频点/ID 分配。
