2. 模块内部依赖（全部在包内，零第三方）
================================================================================

  mcpserver/kicad_mcp/
        __init__.py ──►（惰性）server.py
                          │
        ┌──────────┬──────┴───────┬────────────┬──────────────┬────────────────┐
        ▼          ▼              ▼            ▼              ▼                ▼
    sexpr.py   board.py    schematic.py  design_check.py  fab_bridge.py  capability_map.py
        ▲          │              │            │              │                │
        └──────────┴──────────────┘            │              │                │
          （board/schematic 都只经 sexpr 读写）  │              │                │
                                               ▼              ▼                ▼
                                        （对账两侧）    （用 board 的派生值）  （读夹具 JSON）
                                                                              │
                                                        tests/fixtures/upstream_capabilities.json
                                                        （机械抽取自上游 registry.ts，MIT）

  **真值源是 sexpr.py**：所有解析都走它，没有任何模块自己再写一份 tokenizer。
  **算法只在所属模块里**：`board.py` 只算板子的量、`fab_bridge.py` 只做阈值比对、
  `design_check.py` 只做差集 —— 三者都不重复解析。

  依赖方向**单向无环**：sexpr → {board, schematic} → {design_check, fab_bridge}；server 在顶层编排。
  （对照：本仓 `mcpserver/rf_brain/rlnc` 与 `mcpserver/esp32/rlnc` 是镜像关系；本模块**不**做镜像。）
