4. **静态** 的含义（本模块最容易被误解的一点）
================================================================================

  解析 entryPoint 的类**不 import 被盘对象**，而是：
    ① 按 module 路径拼出候选 .py 文件（module → path）
    ② ast.parse 读它，找 class 定义
    ③ 找 handle_handoff：先在类自身方法体找；没有则**沿基类递归**（同文件内）
    ④ 跨文件基类 ⇒ 标 handoff_uncheckable，**不算缺口**（"判不出" ≠ "没有"）

  为什么不用 import：盘存器 import 被盘对象 = 执行对方模块级代码（副作用/依赖/崩溃面）
  ⇒ 与上游 detection-only 纪律（"never executes a discovered binary"）冲突。

5. **它会扫到自己**（本模块的自指性质，不是 bug）
================================================================================

  mcpserver/agentic_inventory/agent-manifest.json 是它自己那张表里的**一行**
  （实测：66 行里的一行，且是 8 个带风险标记的行之一）。

  ⇒ 两个直接后果：
     ① 它记录的 8 条风险里，有一条是**它自己**；
     ② 收尾期就抓到过一次自伤假阳性 —— 它把自己的 README 令牌表里那串
        `` `npx`/`uvx`/`bunx`/`pnpx` `` 判成了"未钉依赖"。收紧包规格识别后消失
        （证据目录 README 的「两次生成」一节留了证）。

  这不是设计缺陷，是**必须留意的性质**：判据一宽，第一个误报的就是它自己的文档。
