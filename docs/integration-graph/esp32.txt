        │  from mcpserver.rf_brain.rlnc import *              ◄── 全量镜像真值源
        │  from mcpserver.rf_brain.rlnc import __all__ as _REEXPORTED
        ▼
  mcpserver/rf_brain/rlnc/__init__.py        ◄── **真值源（唯一实现）**
        │  只重导出 7 个模块，**不含** apc_mesh_routing（numpy 那支）
        ├──► .galois       （GF(2^8) 0x11B，生成元 0x03；纯标准库）
        ├──► .encoder      （系统式分层 RLNC；r = ⌊k×factor⌋）
        ├──► .decoder      （增量 RREF 高斯消元）
        ├──► .clustering   （链路可靠度三档 → 冗余率）
        ├──► .reliability  （EWMAReliability + LossWindow）
        ├──► .peer_state   （邻居可靠度表）
        └──► .packetize    （4B 头 + 打包/拆包 + dcp payload 切片）

  ✗ mcpserver/rf_brain/rlnc/apc_mesh_routing.py  ── import numpy ──► **不在上述链上**

  实测（子进程 sys.modules 探针，repo 根为 cwd）：
        import mcpserver.esp32.rlnc  ⇒  拉入 rf_brain 模块 9 个
                                        （2 个包初始化 + 上述 7 个）
                                        numpy 是否被拉入 = **False**
                                        兼容层 __all__ 长度 = **30**（28 镜像 + 2 新增）

  身份契约（防漂移，结构性而非约定）：
        tests/test_rlnc.py::test_compat_layer_symbols_are_the_truth_source_objects
              ── 14 个符号逐一断言 `esp.X is ref.X`（不是拷贝、不是重写）
        tests/test_rlnc.py::test_compat_layer_mirrors_whole_all_and_adds_only_two
              ── 断言 set(ref.__all__) ⊆ set(esp.__all__) 且新增恰好 2 个
        tests/test_rlnc.py::test_compat_layer_import_chain_has_no_heavy_dependency
              ── 静态解析 __init__ 的 `from .X import` 得镜像表，断言 apc_mesh_routing 缺席
        tests/test_rlnc.py::test_importing_compat_layer_does_not_pull_numpy
              ── 子进程实证（上表）
        ⇒ 任何一边改数学，另一边立刻同步：**公式漂移结构性不可能**。

4. 运行期数据流（dashboard 一次 build_dashboard() 的全过程）
================================================================================

  normalize_config(cfg 或 DASHBOARD_BASELINE)
        ▼
  generate(topology, n, …)           ◄── cluster_sim/topology.py
        ▼
  apply_failure(nodes, rate, seed)   ◄── cluster_sim/config.py
        ▼
  cluster_report(nodes, threshold, max_hops, margin, …)
        │   rssi_links ──► adjacency ──► bfs_hops ──► build_clusters
        ▼
  {clusters[]: {id, members, health, head, head_alive, size, alive_members, mean_hops, hops},
   unstable_pairs[], stats{…, uncovered_alive}}         ◄── 覆盖性自检必须为空
        ▼
  取**活成员最多**的簇 → 中继槽位 min(A, n) → 取跳数最近的活成员
        ▼
  encode_random(source_blocks, factor=…)  ◄── esp32/rlnc（→ rf_brain/rlnc 真值源）
        ▼
  每块沿 h 跳生存率 s^h 抽样 → 收到的块
        ▼
  decode_full(blocks, k=…)  ⇄  与源块**逐字节比对**  ⇒ 满秩且一致 = 重建成功
        ▼
  dashboard.json（UTF-8 + LF，无时间戳 ⇒ 同参数同结果）

  外部数据源：**无**。拓扑为程序生成（grid/random/lora_deployment，后者是合成样例）；
  不使用 LoRaCanary 真实布点表（本仓无该表，见交付报告 §9 第 6 项）。
