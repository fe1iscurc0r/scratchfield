================================================================================
1. 注册与路由链（本单**未修改**任何既有文件）
================================================================================

  mcpserver/mcp_registry.py::scan_and_register_mcp_agents("mcpserver")
        │  glob("**/agent-manifest.json")            ← 自动发现，无需登记表
        ▼
  mcpserver/rf_workflow/agent-manifest.json
        │  entryPoint = {module: "mcpserver.rf_workflow.server", class: "RfWorkflowBridge"}
        ▼
  mcpserver/rf_workflow/server.py::RfWorkflowBridge
        │  async def handle_handoff(task) -> str          （MCP agent 契约）
        │  instance.handle_handoff(tool_call)             （运行时调用形态）
        ▼
  mcpserver/mcp_manager.py::MCPManager.unified_call(service_name, tool_call)
        │  ① _auth_blocked              ② _agent_governance_block（工单241，默认旁路，未启用即 return None）
        │  ③ 熔断 allow               ④ ensure_hot 冷表转热
        ▼
  RfWorkflowBridge.handle_handoff  →  {start_workflow | step | explain | workflow_status | list_workflows}

  ⇒ 结论：新模块**零侵入**接入。无需改 mcp_manager.py / mcp_registry.py / mcp_assembly。

2. 模块内部依赖（在仓内 import）
================================================================================

  mcpserver/rf_workflow/
        __init__.py ──► server.py
                          │
        ┌─────────────────┼─────────────────┬──────────────────┐
        ▼                 ▼                 ▼                  ▼
  prompt_to_script.py  sim_runner.py   explainer.py        lora_phy.py  ◄── 真值源
        │                                  │                  ▲   ▲
        └──────────────► lora_phy.py ◄─────┘                  │   │
                          （公式 / 校验 / compute_metrics）    │   │
                                                              │   │
        lora_phy.py 是**唯一**算物理量的地方：ToA、能量、链路预算、FFT 占用带宽。
        prompt_to_script 只负责"规格 → 脚本文本"；sim_runner 只负责"跑 + 收"；
        explainer 只负责"读数 → 结论"，三个模块都不重算物理量。

5. 参数口径对齐（虚线，无代码耦合）
================================================================================

  rf_workflow  ······················► firmware/dcp_lora/sx1278_lora.cpp
     433.92 MHz / BW 125 kHz / SF 7 / CR 4/5 / 私有 sync word 0x12
     （本单 PoC 的起点参数；`in_ism_433` 用来校验频点是否落在 433.05–434.79 MHz 子带）

  rf_workflow  ······················► mcpserver/rf_brain/dcp/（frame.py / transmit.py）
     dcp 帧协议口径（magic 0xD0CC / CRC-16 MODBUS / 帧长 = 7 + N）；本单不改其接口，
     只把"发射功率/带宽/SF"这些参数放在同一坐标里核算。

  rf_workflow  ······················► mcpserver/antenna_sim/（结构先例）
     sim_runner 的"串行 / 路径收敛 / job_id 白名单 / 失败不静默"四件纪律照抄语义，
     但不共用代码（antenna_sim 面向 OpenEMS 全波求解，本模块面向 PHY 位级核算）。
