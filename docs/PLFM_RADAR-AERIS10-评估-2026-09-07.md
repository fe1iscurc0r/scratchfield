## 二、系统架构（实读 README + 目录）

- **FPGA XC7A50T**：PLFM chirp 生成（DAC）、ADC 采读、混合 AGC（FPGA/STM32/GUI 三层）、I/Q 基带下变频、抽取、滤波、FFT、**脉冲压缩、多普勒、MTI、CFAR**、USB
- **STM32F746xx**：上电/掉电时序、FPGA 通信、外设初始化（时钟/频综/相移器/电流监测 ADC/DAC）
- 射频链：AD9523-1 低抖动时钟 · 2×ADF4382 频综 · 2×LTC5552 混频器 · **4×ADAR1000 四通道相移器**（波束成形）· **16×ADTR1107 前端**（LNA/PA）· 电流感测（INA241A3 + 5mΩ 分流）
- 软件侧：**Python GUI + 地图集成**、GPS/IMU 实时姿态校正
- 目录：1_描述 / 2_功能图与互连矩阵 / 3_电源管理 / 4_原理图与版图 / 5_仿真 / 6_应用笔记 / 7_元件手册 / 8_工具 / 9_固件 / Licence

## 六、结论与建议
