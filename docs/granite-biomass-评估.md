# W70-01 · granite-geospatial-biomass 评估（生物质地理空间模型）

> 2026-09-02 · 第二十四期三榜单扫描批 · 勘察/评估（不写实现）
> 上游：ibm-granite/granite-geospatial-biomass（Apache-2.0，dl=120，likes=49，TerraTorch/图像特征提取，2026-08-24 活跃）

## 一、项目定位

IBM Granite 地理空间基础模型的生物量下游：以遥感影像（哨兵/卫星多光谱）为输入，做**地上生物量（Above-Ground Biomass, AGB）**的像素级/区域级估算。属于「地理空间基础模型 → 生物量回归」的微调产物，挂 TerraTorch（基于 Prithvi 家族地理空间 FM 的训练框架）。

## 二、架构拆解

- 主干：Prithvi 系列视觉 Transformer（掩码自编码预训练，多光谱 patch 嵌入）。
- 头：图像特征提取 → 生物量回归头（单通道/单标量输出）。
- 训练栈：TerraTorch（torchgeo 生态），支持 geospatial datacube 输入、多任务头。
- 尺度：**地理空间宏观尺度**（区域/地块 AGB 吨/公顷），非分子尺度。

## 三、与本仓对照

| 维度 | 陆墨现有 biomass（W59-01/02） | granite-geospatial-biomass |
|------|------------------------------|---------------------------|
| 尺度 | 分子/材料（分子势、流匹配） | 宏观地理空间（区域 AGB） |
| 输入 | 分子图/结构 | 遥感多光谱影像 |
| 输出 | 分子性能 | 生物量储量（t/ha） |
| 许可 | — | Apache-2.0（可借鉴） |

结论：**互补**——陆墨材料线做「微观材料」，本模型补「宏观生物质储量估算」视角，二者不冲突。

## 四、可落地借鉴点（≥3）

1. **基础模型 + 下游头解耦**：Prithvi 主干冻结 + 轻量回归头微调，是「地理空间 FM → 生物量」的标准范式，可复用于陆墨的「材料 FM → 性能预测」头设计。
2. **TerraTorch 训练栈**：torchgeo 生态的 geospatial datacube 抽象 + 多任务头，可借鉴其「数据立方体 → 任务头」接口设计到陆墨的多模态材料数据管线。
3. **多光谱 patch 嵌入**：把多波段遥感当作多通道 patch 输入 ViT，与「多模态材料表征 → 图/序列」有同构映射。
4. **生物量储量 vs 分子性能的跨尺度互补**：宏观 AGB 估算可作为陆墨材料线的「上游供给/储量」数据源，串成「储量→材料→性能」链路。
