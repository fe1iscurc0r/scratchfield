# Agent 攻击面防御对照表（中文 AI Agent · 只防御，不实现攻击）

> 2026-09-03 · 84号 A3 · 防御侧调研
> 授粉来源：DJAzzs/agent-red-team（Apache-2.0 ★2，中文 AI Agent 红队/安全评估框架）
> 纪律：**本表只做攻击面分类与防御建议，不实现、不演示任何攻击 payload。**

## 一、范围与方法

基于 OWASP LLM Top 10（2025）在中文 Agent 语境下的变体，结合 agent-red-team 的
攻击面分类思路，梳理 6 类主要攻击面。每类给出：威胁描述 / 危害 / 我方防御点 /
对应现有防线。仅防御，不实现攻击。

## 二、攻击面分类表

| 类别 | 威胁描述 | 危害 | 我方防御点 | 对应现有防线 |
|------|---------|------|-----------|-------------|
| 提示注入 | 恶意输入诱导模型无视系统指令、执行越权动作 | 越权操作、数据泄露、工具滥用 | 系统指令与用户输入分层；高危动作二次确认 | skill_gate 安全门（需求级） |
| 不安全输出处理 | 模型输出未经校验直接驱动工具或代码 | 命令执行、路径穿越、注入 | 输出结构化校验；工具参数白名单；拒绝裸执行 | feedback_sensor QualityGate（规划） |
| 工具滥用 | 模型调用超出授权范围的工具或参数 | 越权访问、资源破坏 | 工具调用白名单；最小权限；参数范围钳制 | skill_gate 工具门（需求级） |
| 记忆投毒 | 长期记忆被污染导致后续决策被误导 | 决策偏离、持久化后门 | 记忆写入校验；来源可信标记；异常记忆回滚 | memory_maas 记忆层（需求级） |
| 过度代理 | 授予模型过大的自主执行权 | 不可逆操作、资产损失 | 权限分级；不可逆动作需人工确认 | 决策门 DecisionGate（已有） |
| 敏感信息泄露 | 模型在输出或日志中泄露密钥、个人数据 | 密钥泄露、合规风险 | 输出脱敏；密钥不进提示词；日志审计 | 现有脱敏/审计链路（部分） |

## 三、防御落点（并入 skill_gate 安全门参考，文档级）

1. **提示注入防护**：系统指令与用户输入分层，高危动作二次确认。
2. **工具调用白名单**：仅允许注册过的工具，参数范围钳制。
3. **记忆投毒检测**：记忆写入校验 + 来源可信标记 + 异常回滚。

## 四、纪律声明

本报告只做攻击面分类与防御建议，不实现、不演示任何攻击代码或 payload。
安全线只写防御，不写攻击。
