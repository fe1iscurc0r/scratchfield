## 入选弹药（6 项）

### 1. PINNs-Torch ★950（BSD-3-Clause ✅）· rezaakb/pinns-torch

- **语言**: Python（PyTorch）
- **核心功能**: 物理信息神经网络（PINN）工程级实现——PDE 残差损失、自适应采样
  （RAR/GRADM）、硬约束（傅里叶特征/空间采样）。配套姊妹件 hPINNs（逆问题/参数辨识）。
- **授粉点**: [源→目标映射] 流变学的核心逆问题——从实测 G'(ω)/G''(ω) 或蠕变曲线
  **反演本构参数**（零剪切粘度/松弛时间谱/分数阶阶数）正是 PINN 反演的教科书场景。
  PyRheo（已有）是传统优化拟合路线；PINNs-Torch 提供深度学习对照路线——
  同一数据集双路线互验，是导师组论文的增量点。仓里卷122（antenna_sim）已有
  "数值仿真+回归验证"模式，PINN 层可挂 `mcpserver/material_science/`。
- 活跃度：2026-02 push；文档完整（ReadTheDocs）。

### 2. PINA ★793（MIT ✅）· PINA-org/PINA

- **语言**: Python（PyTorch，意大利 SISSA 数学组）
- **核心功能**: PINN 高级抽象层——`SolvingProblemProblem` 声明式 PDE 问题定义、
  多种求解器（PINN/监督/物理采样）、多任务（正问题+逆问题同训）、高效采样器。
- **授粉点**: [源→目标映射] 比 PINNs-Torch 更"框架化"——若流变反演要做多材料
  批量参数辨识（不同水凝胶配方 → 松弛谱批量提取），PINA 的声明式问题模板
  （`pina.problem` 子类化）能把"换材料=换配置"变成一行。设计上与
  Lumo 的 agent 工具面（参数化任务）同构。
- 活跃度：2026-09 仍在 push。

### 3. lbm（jviquerat）★213（MIT ✅）· jviquerat/lbm

- **语言**: Python（纯 numpy）
- **核心功能**: 全 Python 2D Lattice-Boltzmann 流体求解器——D2Q9 格式、
  圆柱绕流/多孔介质流经典算例、可视化管线。
- **授粉点**: [源→目标映射] 水凝胶的**介观流场**场景（蒸发对流、多孔脱水收缩）
  在连续介质 CFD 之下、分子动力学之上，正好是 LBM 的领地。
  纯 numpy 实现意味着 MCP 工具化零重型依赖；参数（Re/Da/孔隙率）直接
  对应水凝胶蒸发模型的量纲分析。小体量（教学级）恰是"授粉借设计"的
  理想尺寸——照其 D2Q9 kernel 结构写 gel-advection 模板。
- 活跃度：2023 停更——但 LBM 基础算法稳定，教学件无腐化风险。

### 4. DMA-analysis-suite ★4（MIT ✅）· MahdiTBT/DMA-analysis-suite

- **语言**: Python
- **核心功能**: 动态力学分析（DMA）数据处理——TTS（时温叠加）自动平移、
  主曲线构建、tanδ/储能模量/损耗模量导出。
- **授粉点**: [源→目标映射] 水凝胶力学表征的**实验侧标准流程**就是 DMA：
  温度扫描 → TTS → 主曲线 → 松弛谱。仓里 RHEOS/RepTate 偏"通用流变数据"，
  TTS 自动化是缺口。小星数但功能精确命中（TTS shift 算法可直接移植
  `spectra_tools` 同层级的 `gel_tools`），许可干净。
- 活跃度：2025-01 push。

### 5. viscoprony ★1（MIT ✅）· MrJSimon/viscoprony

- **语言**: Python
- **核心功能**: 粘弹性材料 Prony 级数本构参数拟合——蠕变/松弛数据 →
  广义 Maxwell 模型（Prony 级数）参数，FEA（Abaqus/ANSYS）可直接消费的
  本构卡片。
- **授粉点**: [源→目标映射] "实验数据 → 仿真可用本构"的最后一公里：
  水凝胶 DMA/流变数据最终要进有限元（脱水收缩应力模拟）就需要 Prony 化。
  viscoprony 的输出格式（归一化模量+松弛时间对）正是 FEA 输入标准——
  连接已有流变拟合件与未来结构仿真线的桥梁件。
- 活跃度：2025-07 push。

### 6. pyVBRc ★6（MIT ✅）· vbr-calc/pyVBRc

- **语言**: Python
- **核心功能**: 岩石/软物质粘弹性本构计算的"基准+封装"模式——Very Broad
  Rheology calculator：多本构模型（Andrade/Maxwell/Burgers）统一接口、
  参数扫描、与实验文献值的对账表。
- **授粉点**: [源→目标映射] 它的**多本构统一接口 + 对账（benchmark）设计**
  是可借的架构：把 G'/G'' 计算的多种模型（分数阶/广义 Maxwell/Andrade）
  挂同一接口 + 各自文献基准用例——这套"模型注册表+基准表"模式
  可移植为 lumo 的 `rheo_models` 模块骨架（与 rf_brain registry 同构）。
- 活跃度：2026-09 仍在 push（地球物理圈活跃维护）。
