## 1. 背景与授粉映射

uMOF（2608.28100）的贡献：为 MOF（金属有机框架）体系建立「**通用数据库 + 基准 + ML 原子间势
标准化评测**」——把「这个 ML 势好不好」从各自为政的论文口径，统一到一套可复现的评测集 + 指标上。

陆墨的缺口同构：生物质（木质素/纤维素/半纤维素/水凝胶）体系已有多个 ML 势可选（DPA4C、
UBio-MolFM、经典力场、ReaxFF），但**缺一套「生物质专用、可复现」的势评测基准**，导致选势靠
经验、不可比。本方案参照 uMOF 方法，建「生物质分子势基准」。

## 2. 评测指标（验收项）

| 指标 | 定义 | 说明 |
|---|---|---|
| 能量误差 | 预测总能 vs DFT 参考（meV/atom） | 势面精度核心 |
| 力误差 | 原子受力 RMSE（meV/Å） | MD 稳定性关键 |
| 晶格/密度 | 纤维素 Iβ 晶胞参数、材料密度 | 结构保持能力 |
| 氢键网络 | 氢键键长/角度分布 vs DFT | 生物质特有（糖苷键/羟基）|
| 键断裂顺序 | 热解升温中 C-C/C-O/β-O-4 断裂温度排序 | 反应性（承接 M29）|
| 稳定性 | NVT/NPT 长时间 MD 不发散 | 可用性门槛 |
| 外推鲁棒性 | 训练集外构型（新氢键/新构象）误差 | 迁移能力 |

## 3. 数据需求

- **DFT 参考集**（基准的「真值」）：覆盖
  - 纤维素 Iβ/Iα 晶胞 + 无定形纤维素快照；
  - 木质素模型物（愈创木酚 G、丁香酚 S、紫丁香基 H 二聚体/三聚体，含 β-O-4/β-5/5-5 连接）；
  - 半纤维素（木聚糖/甘露聚糖）低聚物；
  - 水凝胶（PVA/纤维素水凝胶）代表性团簇 + 界面水。
  - 用周期性 DFT（GIPAW/CP2K）或团簇高精度方法（DLPNO-CCSD(T) 标定）。
- **规模**：分 10²（小分子）、10³（低聚物）、10⁴（微纤丝片段）三级，与 M08 的性能预估表对齐。
- **本地缺口**：陆墨现有 ELN（`eln-biomass-case.csv`）是宏观 char_yield，无原子级数据——
  需新建 DFT 参考集或借用公开生物质势数据集，短期先以「纤维素晶格 + 氢键」最小集冷启动。

## 4. 候选势清单（验收项）

| 势 | 类型 | 生物质适配 | 优先级 |
|---|---|---|---|
| DPA4C（M08） | 通用 ML 势（图/等变） | C/H/O 覆盖需验证氢键/芳环 π | ★★ |
| UBio-MolFM（M09） | 预训练量子化学 FM | 10⁵ 原子、DFT 精度，主推 | ★★★ |
| ReaxFF | 反应力场 | 键断裂/热解反应性，但精度有限 | ★（反应线）|
| CHARMM/OPLS-AA | 经典力场 | 糖类/水凝胶成熟，但无反应 | ★（力学线）|
| GLYCAM | 糖类专用经典力场 | 纤维素/半纤维素糖苷键专门优化 | ★★ |
| ANI-2x 类 | 通用 ML 势 | C/H/N/O 小分子，生物质迁移需验证 | ★ |

**结论**：基准先覆盖「UBio-MolFM（精度主推）+ GLYCAM（糖类对照）+ ReaxFF（反应性对照）」三档，
分别代表「量子精度 FM / 领域经典 / 反应力场」，让陆墨在同一评测集上横向可比。

## 5. 落地路径

1. **最小冷启动集（≤2 周）**：纤维素 Iβ 晶胞（晶格参数 + 氢键）+ 愈创木酚二聚体（β-O-4 断裂
   能量），先跑通「DFT 参考 → 势预测 → 指标对比」闭环。
2. **扩充基准集**：加木质素 S/G/H 三聚体、半纤维素低聚物、水凝胶团簇，成正式基准。
3. **自动评测脚本**：一套脚本跑多势 → 输出统一指标表，接 M08/M09 的性能预估。
4. **与 M29/M33 协同**：键断裂顺序指标喂给 M29 反应机理；描述符库（M33）的聚合度/官能团
   描述符作为基准集的元数据标签。

## 6. 诚实降级与风险

- uMOF 是 MOF 体系，生物质（多糖氢键 + 木质素芳环）化学环境不同，评测方法「参照」而非「照搬」。
- 本方案给的是基准「设计」，未跑出实测指标；真实对比需先建 DFT 参考集。
- 各势的「DFT 精度 / 10⁵ 原子」为模型方声明，基准正是要验证这一点（承接 M08/M09 同一风险）。
