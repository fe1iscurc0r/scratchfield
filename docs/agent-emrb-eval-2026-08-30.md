## 一、问题陈述

LLM 能否"真正做科学推理"而非"拟合文字描述"？EMRB（2608.24086）用最直接的方式回答：**让 LLM 直接在原始 I/Q 数据上写代码做物理分析，不做预处理特征工程**。评测结果暴露了巨大能力鸿沟：

- 基础测量题：**84.9%** 正确率；
- 系统设计题（如 OFDM 设计）：**21.2%** 正确率。

这个 60+pp 的鸿沟说明：LLM 能做"描述性/单点测量"，但**无法把原始信号分析组织成系统级设计**——这对无线电/SDR Agent 是决定性的能力边界。

## 二、评测对象与规模

- **200 题 × 5 难度 × 27 类型**，覆盖从信号检测到 OFDM 设计。
- **14 个模型**参评。
- 关键设计：**原始 I/Q 输入**，禁止预处理特征工程——直接考验"从原始信号到代码"的物理推理链。

## 三、评测流程（搭自家 Agent 跑一遍）

### 3.1 环境准备
- 用 EMRB 题目集（或按同规范自建子集），每题为"原始 I/Q 数据 + 任务描述（分析/检测/设计）"。
- 被测 Agent 接口：`agent_solve(question) -> code`，输出可执行的分析代码。

### 3.2 评分维度
| 难度层 | 类型示例 | 论文参考正确率 |
|---|---|---|
| 基础测量 | 频率/功率/带宽估计 | ~84.9% |
| 中级分析 | 调制识别 / 干扰检测 | 中间梯度 |
| 系统设计 | OFDM / 链路设计 | ~21.2% |

### 3.3 流程
```
for q in questions:
    code = agent_solve(q)          # Agent 直接写代码
    result = execute(code, q.data) # 跑代码得到输出
    score(q) = match(result, q.answer)
```
汇总得到分难度的能力曲线，与论文 84.9%→21.2% 对照。

**关键结论**：定位自家 Agent 的"断崖点"——在哪一层从"能做"跌到"不能做"。对 SDR/无线电 Agent，这个断崖点直接决定它能被委派到什么复杂度的任务。报告中应附**失败模式分类**（物理单位错误 / 信号链理解错误 / 系统约束缺失 / 代码不可执行）。

## 五、能力鸿沟的修复方向（对齐其他工单）

- **ReconPilot**（论文提出，13/15 组合显著提升）：把"原始信号→代码"拆成"先重建成物理量 → 再写分析代码"的两段式，弥补 LLM 直接端到端推理的不足。
- 结合 **A06 护栏**：对生成的信号处理代码加物理规则恢复检查。
- 结合 **A01/A03**：用终端一致性（而非单次正确）衡量无线电 Agent 可靠性。
