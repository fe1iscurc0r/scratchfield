# S05 连续学习灾难性攻击防护（塑性攻击）

## 一、问题陈述

持续学习（CL）让模型边用边学新知识。但 Catastrophic Learning（2608.18976）揭示一种新攻击向量：**对抗数据可以选择性地阻止模型学习新知识，同时保留旧知识**——即"塑性攻击"（plasticity attack）。攻击者通过注入对抗性数据，让模型的**学习塑性（plasticity）丧失**：后续迭代学不进新东西，模型被"锁死"在当前状态。

对嵌入式 OTA 更新场景这是直接威胁：攻击者在更新数据里掺入对抗样本，使设备 OTA 后无法再学习新任务/新信号类型。

## 二、攻击模型

1. **目标**：让模型丧失塑性（无法学习新知识），而非直接投毒输出。
2. **手段**：在持续学习的数据流里注入对抗性样本，破坏模型对新数据的梯度方向，使其选择性"学不动"。
3. **隐蔽性**：保留旧知识 → 在旧任务上表现正常 → 常规检测难发现（不是"变坏"，而是"不再变好"）。

## 三、防护策略

1. **输入侧完整性校验**：OTA 数据流加流量完整性验证（对齐 FedGuard-DC 鲁棒聚合思路），拒绝可疑对抗样本进入训练。
2. **梯度层隔离**：借鉴 AEGIS 三通道梯度隔离，把"新知识学习"的梯度与"攻击干扰"隔离，防止塑性被对抗数据定向破坏。
3. **塑性监测**：持续监测"学习新任务的能力"（塑性指标）——若塑性异常下降，触发告警与回滚。
4. **回滚机制**：检测到塑性被攻击时，回滚到攻击前的检查点。
