# K21 Geometry-Constrained KAN 评估

## 0. 结论速览

KAN 用「可学习的单变量边函数」（B 样条）替代 MLP 的固定激活 + 线性权重；「几何约束」对边函数施加几何性质（原型用单调性）。原型（numpy）在单调目标 `log(1+3x)` 上、带噪拟合下对比：

| 方案 | MSE（无噪评估） | 参数量 | 单调保证 | 可解释 |
|---|---|---|---|---|
| KAN 无约束 | 0.001420 | 20 | ✗（过拟合抖动） | 系数即结点值 |
| **KAN 几何约束** | **0.000905** | **20** | ✓ | 系数即结点值 |
| OTA-ELM | 0.000329 | 30 | ✗ | ✗（黑盒） |

**结论**：几何约束让 KAN 在**参数更少（20 vs 30）**且**保证单调**的前提下，把无约束版的 MSE 降 36%（抑制过拟合）；ELM 原始 MSE 更低，但代价是更多参数 + 黑盒。**KAN 的核心价值是可解释 + 几何约束的稳健性，而非原始精度**。

## 1. 方法拆解

- **边函数**：`φ(x) = Σᵢ cᵢ · hᵢ(x)`，hᵢ 为线性 B 样条（hat）基，行和=1。
- **拟合**：最小二乘（闭式，无梯度，与 OTA-ELM/Bern2Edge 同思路）。
- **几何约束**：PAVA 把系数 c 投影成非递减 → φ 严格单调。单调性既是「可解释先验」，也起正则化作用（抑制噪声过拟合）。

## 2. ESP32 可行性

- 边函数是 hat 基的线性组合，hat 值可离线查表（同 Bern2Edge 的 LUT 思路）。
- 系数即函数在结点处的值（见 §3），量化后直接定点存储。
- 单调性约束是系数级线性约束，可离线求解、推理侧零开销。

## 3. 可解释性示例

hat 基在结点 `x = knots[j]` 处取值为 1，其余为 0，故 **系数 `cⱼ` 就是边函数在结点处的函数值**——`φ(knots[j]) = cⱼ`（测试 `test_explainability_coefficients_are_knot_values` 验证）。这意味着：

- 学完的 KAN 边函数可以直接「读出形状」：系数序列的升降 = 函数的升降；
- 对单调物理量（如功率-电压响应、SNR-误码曲线），几何约束保证学出的形状符合物理直觉，而非黑盒。

## 4. 与 OTA-ELM / Bern2Edge 的分工建议

| 场景 | 推荐 |
|---|---|
| 纯精度、特征维高 | OTA-ELM（随机隐层容量大） |
| 低维 + 参数/MACs 敏感 | Bern2Edge（Bernstein 基） |
| 需要可解释 + 物理先验（单调/有界） | **Geometry-KAN** |

## 5. 边界与待办

- 原型为单变量边函数（1 输入 1 输出）；多维 KAN 需多层/多边组合，未实现（诚实降级）。
- 几何约束只演示了单调性；其他几何约束（凸性、有界性、曲率）可同类实现。
