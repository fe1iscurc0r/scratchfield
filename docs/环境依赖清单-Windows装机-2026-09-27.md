# 实验田 (scratchfield) 环境依赖清单（Windows 全新人装机指南）

> 2026-09-27 盘点 · 依据 main@368b87a 实测。给「AI 拉库装机」场景兜底——AI 默认环境是齐的，人肉装机才知道缺什么。逐项装完再开工。

## 一、必装项（缺一不可）

### 1. Python 3.12（**严格 3.12.x，不是最新！**）
- `pyproject.toml`：`requires-python = ">=3.12,<3.13"` —— 装 3.13 会被拒
- Windows 安装包勾选 "Add python.exe to PATH"
- 验证：`python --version` → 3.12.x

### 2. uv（Python 包/锁管理器）
- 安装：`powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`
- 仓库用 uv.lock 锁版本，**不要用裸 pip install**（会绕过锁文件装出不可复现的环境）
- 验证：`uv --version`

### 3. Node.js（前端构建必需）
- frontend/ 是 Vue3 + Vite + Electron，需要 **Node.js ≥20 LTS**（engines 字段没写死，但 Vite 7 系要求 ≥20.19）
- 官网 LTS 安装包，自带 npm
- 验证：`node -v`（≥20）/ `npm -v`

### 4. Git
- 拉库用，略

## 二、按需安装（功能开关型）

| 功能 | 需要什么 | 怎么装 |
|---|---|---|
| **本地 LLM**（LawLLM-7B 等） | Ollama for Windows | ollama.com 下载，装完 `ollama pull <model>` |

## 三、安装顺序（照抄版）

```powershell
# 1. 拉
git clone <仓库地址>
cd scratchfield

# 2. 后端环境（uv 会自动装对 Python 3.12，本机没有也行）
uv sync                    # 基础组
uv sync --extra pdf2md     # 要判例/论文PDF功能才加

# 3. 前端
cd frontend
npm install                # 有 package-lock.json，别用 pnpm/yarn 混装
npm run build              # 或开发时 npm run dev

# 4. 启动
cd ..
python main.py             # 桌面端（托盘）
# 或纯 web 模式：uv run uvicorn apiserver.api_server:app --host 0.0.0.0 --port 8000
```

## 四、已知坑（实锤，别踩）

1. **CRLF 行尾**：仓库文件是 Windows 行尾（pyproject.toml 带 `\r`）。git 配置 `core.autocrlf=false` 克隆，或某些 grep/正则匹配不到内容时先想到这一层
2. **Python 版本陷阱**：uv 环境没问题，但如果有人手滑用系统 Python `pip install -e .`，3.13 直接报错，3.11 也拒——只有 3.12 開門
3. **websockets 死锁**（卷161 修复前）：`uv lock --upgrade-*` 会报 unsatisfiable——这是已知死锁不是你装错了，别自己折腾约束，等卷161 合并
4. **npm 混装**：frontend 有 package-lock.json → 锁 npm。装了 pnpm 会生成另一套 lock，CI/其他机器对不上
5. **ffmpeg 不在 pip 依赖里**：voice 模块直接调 ffmpeg 可执行文件，pip 装得再全也没用，必须是系统级安装
6. **⚠️ venv 被 safe-delete shim 损伤**（卷173 实测，2026-09-30）：WorkBuddy 会话的
   `node-safe-delete` shim 会损伤 venv 两类——① dist-info 缺 METADATA（实测一次
   31 个包）② 包目录被掏空（实测 `thermo` 仅剩 1 个 JSON）。症状：`uv pip install`
   报 `Failed to read metadata from installed package ... os error 2`；import 反而多数正常。
   **修复**：`uv pip install --reinstall <报错包>`（本机已验证有效）。
   该损伤会在每次 uv install 时新增，遇到即修，不要当成仓库依赖问题排查。
