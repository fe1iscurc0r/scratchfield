# W73-04 LightRAG 图增强检索评估

> 上游：github.com/HKUDS/LightRAG · MIT · 39K★ · Python · EMNLP2025

## 1. 项目定位

EMNLP2025 轻量图增强 RAG：在 RAG 之上加一个轻量图索引层（实体-关系图），比全量 GraphRAG 简单快速，提升多跳/关系型问答。

## 2. 架构拆解

- **图索引层**：文档抽取实体-关系 → 建轻量图（非全量知识图谱）。
- **检索**：图检索 + 向量检索融合，简单快速。
- **定位**：比 GraphRAG 轻一个量级的「图增强」，适合资源受限的知识库问答。

## 3. 与本仓对照

| 维度 | LightRAG | 本仓 |
|---|---|---|
| RAG | 图索引 + 向量检索 | rag/ 检索引擎 + rag-skill（W69-06）+ 知识库 |

## 4. 可落地借鉴点（≥3）

1. **轻量图索引层**：在现有向量检索上加「实体-关系轻量图」，多跳问答时用图检索补充，比全量 GraphRAG 便宜。
2. **图增强 vs 现有 RAG 的取舍**：LightRAG 证明「轻量图」即可覆盖多数关系型问答，不必上全量图。
3. **知识库问答基准**：可作为我们 rag/ 引擎的对照基准（多跳问答评测）。

## 5. 许可裁定 + 结论

- **许可**：MIT → 可借鉴代码。
- **接入建议**：**可参考/借鉴**。轻量图索引层值得在 rag/ 引擎上做增量（实体-关系图 + 图检索），不整体迁入；可抽取其图索引 + 检索融合思路。
