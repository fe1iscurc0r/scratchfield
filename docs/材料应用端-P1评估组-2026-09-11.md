## 二、逐候选评估

### 1. rgerum/saenopy —— 3D 牵引力显微（TFM）

- **定位**：由细胞/组织在 3D 胶原、纤维蛋白、Matrigel 等**非线性生物聚合物网络**中的位移场，反演细胞施加的牵引力。README 明确其材料模型专为组织仿生、高非线性生物聚合物基质设计。
- **架构**：Python 包 + 独立 GUI 双形态；流程为「珠粒位移追踪（PIV/粒子跟踪）→ 连续位移场 → 材料本构（非线性，含纤维网络增强模型）→ 力场反演（FEM 正则化）」。readthedocs 文档齐全，带测试与覆盖率徽标（工程成熟度高）。
- **对照**：本仓 `tools/network_probe.py`（W101-06）只做到「丝状网络骨架提取+拓扑统计」；saenopy 是它的下游——同一类凝胶网络的**力学反演**。两者正好串成「网络结构 → 位移 → 力」完整链。
- **借鉴点（≥3）**：
  1. 非线性纤维网络本构（胶原/纤维蛋白）建模路线——与 W101-03 流变学 RepTate 缠结理论同域呼应，可作网络力学模块的下一级本构；
  2. 「位移场 → 力场」FEM 正则化反演骨架——本仓无力学反演先例，这是新增能力方向；
  3. 独立 GUI + 脚本包双形态的工程组织——与 lignet/saenopy 同为「科研工具做 GUI」的可参考范式；
  4. 珠粒追踪的位移场构建（PIV 类）——可直接作为 `network_probe` 的时序位移输入来源。
- **许可裁定**：MIT，可借鉴融合。**唯一活跃维护 + MIT + 与本批 SOAX 线直接互补 → P1-1。**

### 2. lukasbaldauf/tga-kinetics —— TGA 动力学参数估计

- **定位**：由热重（时间、温度、样品质量）数据估计动力学参数；GUI + Excel 输入，内置模拟测试数据。
- **架构**：核心是 Arrhenius 型速率方程 `dx/dt = A·exp(-E/(R·T))·x^n` 的参数估计（频率因子 A、活化能 E、反应级数 n），数值求解后与实验曲线拟合。README 自述「简单脚本」并**推荐改用其 Julia 版 tga-kinetics.jl**（数值方法更稳健）。
- **对照**：本仓 `tools/lig_ann_probe.py`（W101-05）用 ANN 黑箱拟合木质素热解；tga-kinetics 是**物理白箱**（动力学方程）路线，两者互补：ANN 快但无参数物理意义，动力学方程慢但输出 E/A/n 可直接进工艺。
- **借鉴点（≥3）**：
  1. Arrhenius 速率方程的归一化质量建模（-dm/dt·1/c 表述）——可直接移植为 `tools/` 下的白箱拟合器；
  2. 「模拟数据自检 + 固定输入结构」的测试工程习惯——新工具应有自带验证数据；
  3. 白箱动力学（E/A/n）与 ANN 黑箱（W101-05）的双引擎对照评测——正是 lignet 报告预留的联动方向；
  4. GUI 屏蔽数据预处理差异（Excel 直接进）。
- **许可裁定**：MIT，可借鉴。注意作者已转向 Julia 版——立项时取**算法与数据协议**而非此 Python 代码库。**P1-2。**

### 3. michaelorella/lignin-kmc —— 木质素动力学蒙特卡洛

- **定位**：用 KMC 模拟木质素热解/解聚的分子尺度反应网络（4★，Jupyter 形态；配套 LianneGahan/LigninFit 拟合分析包，MIT）。
- **架构**：事件驱动 KMC——反应通道（键断裂类型 β-O-4/β-5/5-5 等）按速率常数抽样执行，产物分布随时间演化；LigninFit 负责速率常数拟合。
- **对照**：本仓 `tools/lig_graph_probe.py`（W101-04）建立了「单元/键型」图表示——正是 KMC 需要的输入结构；「图 → KMC 反应网络」是本卷最自然的下一步。
- **借鉴点（≥3）**：
  1. 键型→反应通道的映射（与 W101-04 `_LINKAGE_SYMBOLS` 直接对接）；
  2. KMC 事件抽样骨架（Gillespie 类）在木质素场景的参数化；
  3. 「模拟 + 拟合分离」（lignin-kmc + LigninFit 两仓分工）的模块边界设计。
- **许可裁定**：MIT，可借鉴融合。**P1-3（与 W101-04 联动优先级高）。**

- **对照**：本仓无任何材料配方/工艺类内容；若后续做「材料合成/配方知识库」或 LUMO 相关实体实验辅助，此仓是零成本样例。
- **借鉴点（≥3）**：

### 5. NOMspectra/NOMspectra —— 天然有机物质谱

- **定位**：天然有机物（NOM）高分辨质谱（FT-ICR-MS）数据批处理——分子式分配、van Krevelen 图分类等环境化学标准处理。
- **架构**：Jupyter 工作流：质荷比校准 → 分子式指派（含同位素规则）→ 化合物分类（类木质素/类蛋白等）→ 可视化。GPL-3.0。
- **对照**：本仓质谱/化学信息学暂无同类；与「木质素解聚产物分析」场景潜在相关（解聚产物质谱表征）。
- **借鉴点（≥3）**：
  1. van Krevelen 图（O/C-H/C）分类体系——木质素解聚产物族类判别的标准可视化；
  2. 高分辨质谱分子式指派的同位素/质量亏损校验规则；
  3. 批量谱文件→结果表的流水线组织。
- **许可裁定**：GPL-3.0——只参考设计不融合代码；若未来融合会传染本仓许可，需保持独立进程/库隔离。**P1-5。**

### 6. jvermaas/LigninBuilder —— VMD 木质素构建插件

- **定位**：VMD 插件 + 脚本：由**拓扑规格**（单元序列 + 键型连接）自动构建木质素分子三维结构（17★，Rich Text Format/Tcl）。
- **架构**：输入拓扑描述 → 单元库（G/S/H 构象模板）→ 按键型拼接、生成 PDB/PSF。与 W101-04 `build_lignin_graph` 的「单元+键型」输入协议同构，是图模型的三维升维。
- **对照**：本仓 W101-04 是抽象图；LigninBuilder 是**图 → 三维坐标**的生成器。互补而非重叠。
- **借鉴点（≥3）**：
  1. 「拓扑规格字符串 → 结构」的输入协议设计（可直接供 `lig_graph_probe` 增加解析器）；
  2. 单元构象模板库 + 键型拼接的生成流水线；
  3. 与 VMD/MD 生态的接口（PDB/PSF 输出）。
- **许可裁定**：无 LICENSE——仅蒸馏不融合；可借鉴输入协议与流程设计，不复制实现。**P1-6。**

### 7. procf/RhINNs —— 流变信息机器学习

- **定位**：Northeastern Jamali 组「流变信息机器学习」项目集（23★ Jupyter 仓）：把流变学物理先验嵌入 ML（物理信息神经网络路线）。
- **架构**：按项目分文件夹的研究代码集：流变实验/模拟数据 + 物理约束损失函数（如本构方程残差项）+ 网络训练。无 LICENSE。
- **对照**：本卷 W101-01~03（RHEOS 数据处理 / pyRheo 分数阶 / RepTate 缠结理论）已建立本仓流变基座；RhINNs 是「流变物理 → ML 约束」的上层，可作流变+AI 融合的路线图。
- **借鉴点（≥3）**：
  1. 本构方程残差进损失函数（物理约束正则）——RHEOS/pyRheo 模型的 ML 化路径；
  2. 实验/模拟双数据源的流变 ML 训练管线；

- **许可裁定**：无 LICENSE——仅蒸馏不融合。**P1-7。**
