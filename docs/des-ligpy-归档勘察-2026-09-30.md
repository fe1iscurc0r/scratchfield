## 一、martini3-DES：DES 专用 Martini 3 力场

### 1.1 是什么

DES 体系的**粗粒化（CG）分子动力学**力场库：Martini 3 bead 拓扑（`.itp`）+
GROMACS 输入模板（`.mdp`）+ 起始构型（`.gro`）。配套论文案例：
*"Competitive Interfacial Partitioning in CTAB Self-Assembly: A Coarse-Grained
Study Across Deep Eutectic Solvents"*（CTAB + Glyceline/Reline）。

### 1.2 itp 覆盖表（14 个分子，实测文件清单）

| 分子 | itp | gro | 角色 |
|---|---|---|---|
| cetyltrimethylammonium（CTAB） | ✅ | ✅ | 表面活性剂（案例主角） |
| glycerol | ✅ | ✅ | Glyceline 组分之一（HBD） |
| choline | ✅ | ✅ | Glyceline/Reline 组分（HBA 阳离子） |
| urea | ✅ | ✅ | Reline 组分 |
| menthol | ✅ | ✅ | 萜类 HBD |
| decanoic_acid | ✅ | ✅ | 脂肪酸 HBD |
| dodecyl_sulfate | ✅ | ✅ | 阴离子表面活性剂 |
| tetrabutylammonium | ✅ | ✅ | 季铵阳离子 |
| aliquat336（+ aliquat_336 变体） | ✅ | ✅×2 | 季铵盐萃取剂（萃取线关键） |
| imidacloprid | ✅ | ✅ | 农药客体（分配系数案例） |
| 2-methylthiophene | ✅ | ✅ | 含硫模型化合物 |
| benzothiophene | ✅ | ✅ | 含硫模型化合物 |
| dibenzothiophene | ✅ | ✅ | 含硫模型化合物（脱硫线） |

**注意**：14 分子中 **仅 glycerol+choline 覆盖 Glyceline、choline+urea 覆盖 Reline**
——不是通用 DES 体系库，而是**案例驱动**的分子集（表面活性剂/含硫/农药客体为主）。
我们的木质素衍生 DES 体系大概率需自行建 bead 拓扑。

### 1.3 能量最小化输入模板（md.mdp 关键段摘录）

```
integrator      = md
dt              = 0.02          ; Martini 3 标准时间步（0.02 ps）
nsteps          = 250000000     ; 5 μs
cutoff-scheme   = Verlet
coulombtype     = reaction-field
rvdw            = 1.1           ; Martini 3 推荐非键截断
tcoupl          = v-rescale
tc-grps         = SYSTEM
ref_t           = 350           ; 案例温度
constraints     = none
```
配套 `eq0.mdp ~ eq4.mdp` 五级平衡序列（力场松弛→逐步升温/密度平衡）。
⚠️ 摘录时发现 `md.mdp` 有**重复的 `constraints = none` 行**（上游小瑕疵，
拷贝使用时清理即可）。

### 1.4 与既有 MD 线（MACE/ASE）的衔接可行性

| 轴的对比 | martini3-DES（CG） | MACE/ASE（全原子 ML 势） |
|---|---|---|
| 尺度 | 粗粒化（~10× 加速） | 全原子 |
| 目标 | **介观自组装/界面分配**（胶束、相行为） | 电子级精度性质（能量/力） |
| 衔接点 | CG 无法给热力学量，但能给**介观构型**——可作全原子模拟的初始/边界构型来源 | 反之可用 MACE 校准 CG bead 参数（force matching） |
| 可行性结论 | **互补而非替代**：DES 介观相行为走 CG，关键局部相互作用走全原子；两者拼装的工程量在中（需 bead 映射表 + 参数校准），本轮不落地 | |

## 二、ligpy：木质素热解详细动力学

### 2.1 是什么

`ligpy.py` 模拟**完美混合批次反应器中木质素热解**的详细动力学模型：
**~100 物种 / 400 反应**（2016 IECR 论文 *Detailed kinetic modeling of lignin
pyrolysis for process optimization*），无拟合直接预测分子与官能团随时间的演化。

### 2.2 物种/反应清单的组织格式（实测——**纯文本 `.dat`，非 XML/dict**）

| 文件 | 格式实测 | 规模（实测） |
|---|---|---|
| `complete_reaction_list.dat` | 每行一条反应：**化学计量系数_物种名**（负=反应物，正=产物，逗号分隔），如 `-1_PLIGH,1_PRLIGH` | **406 反应 / 94 物种** |
| `complete_rateconstant_list.dat` | 每行对应上述反应，**"A n E"**（Arrhenius 指前因子/温度指数/活化能） | 406 行 |
| `faravelli_reactionlist.dat` + `faravelli_rateconstantlist.dat` | 同上格式（上游源机理） | **104 反应 / 89 物种** |
| `elemental_analysis.dat` | C/H/O 质量分数（**用户唯一需直接编辑的文件**——决定能模拟哪些木质素原料） | — |
| `compositionlist.dat` | 自动生成：木质素 → 伪组分（LIGC/LIGH/LIGO）摩尔数 | — |
| `rates_and_ODEs.txt` | 供人阅读的求解方程清单（程序不使用） | 45 KB |

### 2.3 动力学求解器接口

- **默认求解器：修改版 DDASAC——闭源**（README 明示；官方建议用
  `scipy.integrate` 替换 `ddasac_utils.py`）
- 接口层：`ligpy/ddasac_utils.py`（11 KB，可替换模块边界清晰）
- 其他模块：`ligpy.py`（主入口）/ `ligpy_utils.py`（18 KB）/
  `analysis_tools.py`（23 KB）/ `equivalent_compositions.py` /
  `revisions_to_faravelli.py`（机理修订）
- **运行环境老旧**：Python **2.7** + NumPy（2016 年代码）——移植到 3.x 需过
  `2to3` 级改造 + 求解器替换

### 2.4 双引擎差异表（白箱详细机理 vs ANN 代理）

> 工单原文"ANN 白箱双引擎"——**实测上游 ligpy 无 ANN**（它是纯白箱详细动力学）；
> 对照的 ANN 侧来自本仓已有线：`docs/lignet-木质素热解ANN-授粉报告-2026-09-11.md`。
> 下表为**跨仓对照**，如实标注来源。

| 维度 | ligpy（白箱详细动力学） | lignet（ANN 代理，本仓授粉报告） |
|---|---|---|
| 机理粒度 | 94 物种 / 406 反应（基元级，含自由基） | 端到端代理（输入条件 → 产物分布） |
| 可解释性 | 全白箱：每个物种演化可追 | 黑箱（靠 SHAP 类方法事后归因） |
| 速度 | 刚性 ODE 组（DDASAC 为刚度优化） | 推理毫秒级 |
| 外推能力 | 物理约束内可靠（Arrhenius 机理） | 训练域外不可信 |
| 数据需求 | 机理参数（文献/DFT） | 需样本（可拿 ligpy 生成） |
| **互补用法** | **ligpy 生成训练数据 → 训 ANN 代理 → 在线快速预测；ANN 无法解释时回退 ligpy 复核** | |

### 2.5 归档建议（照工单 C.3）

| 内容 | 建议 | 理由 |
|---|---|---|
| `complete_reaction_list.dat` + `complete_rateconstant_list.dat`（406 反应/94 物种） | **进 docs/ 索引引用**（不复制进仓，写引用卡） | 机理数据是文献成果（BSD-2），体量小但产权清晰；本次已实测格式，引用卡足够 |

| `sample_results/`（55 MB 结果） | **留 github_haul 长期档** | 体积大、可复算（ligpy 重跑即得），不进仓 |
| `ligpy/data/DFT/`（Gaussian .com/.o + modeled_reactions.pdf） | **留长期档** | DFT 原始数据，复算成本高、体积可控但不属代码资产 |
| ligpy 代码本体 | **不进仓**：Python 2.7 + 闭源求解器，移植成本高；机理数据已可引用 | 需要时按索引回上游 |
| martini3-DES 全库（60 KB） | **可轻量进仓或进索引**（体积极小） | Apache-2.0，itp/gro 是纯数据文本；但注意案例驱动、非通用库 |
