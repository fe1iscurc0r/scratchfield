## 全流程一页图

```
填 CSV（照 data_schema.md）
      │
      ▼
quick_import.py 校验+入库 ──拒绝的行会打印原因──→ 改 CSV 重跑
      │  自动生成 features_*.csv（回归就绪）
      ▼
loo_regression_template.py features_*.csv
      │
      ▼
读结果：LOO R²（预测力）+ 特征重要性（哪个变量最关键）
```

---

## 第 0 步 · 判断你该用哪张表

| 你做的实验 | 表 | 目标列（想预测什么） |
|---|---|---|
| 制备木质素 NPs + DLS 表征 | `lignin_np` | `diameter_nm` / `pdi` / `zeta_mv` |
| 水凝胶配性能测试 | `hydrogel` | `swelling_ratio` / `compressive_modulus_kpa` |
| 共熔凝胶 DSC | `deep_eutectic` | `t_peak_c` / `dh_j_g` |

## 第 1 步 · 填 CSV

- 列名**逐字照抄** `data_schema.md`（区分大小写；复制表头别手打）。
- 缺失写 `NA`；数值列必须是纯数字；日期 `YYYY-MM-DD`。
- **行数 ≥ 8 才有回归意义**（LOO 下限；建议 ≥ 15）。

## 第 2 步 · 入库（校验 + 生成回归文件）

```bash
# 文件名以表名开头可免 --table（如 lignin_np_2026-10.csv）
python quick_import.py lignin_np_2026-10.csv
# 或显式指定
python quick_import.py 我的数据.csv --table lignin_np --target diameter_nm
```

**看输出三行**：
1. `入库: N 行` —— 成功进库（同 sample_id+date 重复导入会**覆盖**，改错重跑即可）；
2. `⚠ 第 X 行拒绝: 原因` —— 按原因改 CSV 再跑；
3. `features_lignin_np.csv（N 行 × K 列）` —— **这是下一步的输入**。

## 第 3 步 · 跑回归

```bash
python ../lignin-np-regression/loo_regression_template.py features_lignin_np.csv
```

输出解读（两段都要看）：

```
LOO R²(Ensemble) = 0.71     ← 总预测力
  Ridge  R²=0.89            ← 各模型（哪个稳看哪个）
  ...
特征重要性:
  lignin_conc_mg_ml 0.44    ← 排最前 = 对粒径影响最大
```

| LOO R² | 含义 | 建议 |
|---|---|---|
| > 0.8 | 良好 | 可用于指导下一轮配比 |
| 0.5 ~ 0.8 | 可用 | 趋势可信，预测值当参考 |
| < 0.5 | 弱 | 数据量不足或噪声大 → 多攒数据 / 检查异常点 |

## 第 4 步（可选）· 换目标再跑

同一批数据想预测别的指标：`quick_import.py … --target pdi` 重新导出 → 再跑第 3 步。

## 常见问题

| 问题 | 处置 |
|---|---|
| `无法从文件名猜表类型` | 加 `--table lignin_np`（或 hydrogel / deep_eutectic） |
| `缺列 [...]` | 列名没对齐 schema；缺的列记为 NA，**必填列缺失会拒绝行** |
| features CSV 行数比入库少 | 有行缺必填数值被剔除（输出里有 `剔除 N 行含缺失`） |
| R² 是负数 | 数据信号弱/量太少（n<8）→ 正常现象，别硬解读；先攒数据 |
| 想删掉某次导入 | 告诉管理员（SQLite 表按 sample_id+date 覆盖式导入，重复导入自动更新） |

## 边界（如实说明）

- 模板是**线性/浅层集成 + LOO**：适合 n ≤ 50 的小数据；不是深度学习，不追求 SOTA。
- **不外传数据**：全部本地（lab_data.db + records.jsonl 都在本目录）。
- 回归结果**不替代实验**——是"下一轮实验往哪配"的导航仪。
