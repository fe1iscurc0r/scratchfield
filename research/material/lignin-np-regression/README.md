# 木质素纳米粒子 · 小数据回归模板（LOO）

> 来源：工单 206 任务三（physics.space-ph 2610.07547 —— 37 样本小数据集成回归，LOO R²=0.77 预测聚合物耐久性）
> 落地：工单 213 任务二（本科实验数据快通道共用水电）
> 用户：生物质能源与材料专业 · 邵长优惠组（木质素 NPs → 水凝胶/共熔凝胶 → 水下电子/太阳能蒸发）

## 1. 方法摘要（为什么是小样本 + 集成 + LOO）

邵长组典型场景：**一次课题攒 10~40 个实验点**（n ≤ 50）。这个量级：

- **不能**训练深度模型（必过拟合）；
- **不能**用普通 train/test 切分（切完训练集只剩几个点）；
- ✅ 正确姿势 = **leave-one-out（LOO）交叉验证**：每个点轮流当测试集，其余 n−1 个点训练——
  小数据下最稳的泛化估计；
- ✅ 模型用**集成**（多个简单模型投票/平均），比单模型稳（2610.07547 的核心结论）。

**输出**：LOO R²（模型对"没见过的实验点"的预测力）+ 各特征重要性（哪个变量最影响性能）。

## 2. 与木质素纳米粒子体系的变量映射表

| 论文语境 | 邵长组实验对应 | 快通道字段（见 ../bachelor-lab/data_schema.md） |
|---|---|---|
| 聚合物组成特征 | 木质素浓度 / 溶剂比 / 沉淀温度 | `lignin_conc_mg_ml`, `solvent_ratio`, `temp_c` |
| 加工参数 | 超声时间 / 搅拌速率 | `sonication_min`, `stir_rpm` |
| 微观结构观测量 | **粒径(DLS) / PDI / zeta 电位** | `diameter_nm`, `pdi`, `zeta_mv` |
| 目标性能（耐久性） | 分散稳定性（如 7d 沉降率）/ 凝胶压缩模量 | `target_*`（任务定义） |

**两条用法**（同一个模板都支持，靠 CSV 的列名区分）：

1. **配方 → 微观结构**：特征 = 浓度/溶剂比/温度/超声…，目标 = 粒径/PDI/zeta；
2. **微观结构 → 性能**：特征 = 粒径/PDI/zeta…，目标 = 溶胀率/压缩模量/稳定性。

## 3. 使用方法（本科生照单操作）

```bash
# ① 把实验数据填进 CSV（列名照 data_schema.md，或直接抄 example CSV 改）
# ② 跑 LOO 回归（特征列在前，最后一列是目标值）
.venv/Scripts/python.exe loo_regression_template.py 你的数据.csv

# ③ 输出示例：
#   LOO R²(Ensemble) = 0.71   ← 预测力（>0.5 可用，>0.8 良好）
#   各模型 R²: Ridge 0.68 / RF 0.66 / ...
#   特征重要性: lignin_conc_mg_ml 0.41 / sonication_min 0.33 / ...
```

**约束**：n ≤ 50 行；特征列全部为数值（分类变量先转 0/1）；缺失值填 `NA`（自动剔除该行）。

## 4. 依赖

`numpy` + `scikit-learn`（venv 已有）。**刻意不引**重型框架（XGBoost/PyTorch）——小数据用不上，
本科生环境好装。

## 5. 自测

```bash
.venv/Scripts/python.exe loo_regression_template.py --selftest
```
用合成数据（真实系数 + 噪声）验证管线，LOO R² 应 > 0.6（合成数据信号明确）。
