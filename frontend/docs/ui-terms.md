## 数据概念（API/文档/注释统一）

| 定词 | 不用 | 说明 |
|---|---|---|
| **五元组** (quintuple) | ~~记忆条目/记忆碎片~~ | subject + subjectType + predicate + object + objectType 的最小记忆单元 |
| **记忆** (memory) | | 五元组**全量**（MemoryView 管"记忆"，指全量列表/分页） |
| **知识图谱** (graph) | ~~思维图~~ | GRAG 可视化（MindView 画的**图**叫知识图谱） |
| **度** (degree) | ~~连接数~~ | 实体的五元组关联计数（`with_degree` 回填） |
| **会话** (session) | ~~对话记录~~ | 一轮起止的上下文单元 |
| **骨架屏** (skeleton) | ~~加载动画~~ | `SkeletonCard`：结构占位，非转圈 |
| **空态** (empty state) | ~~空页面~~ | `EmptyState`：引导 + 动作按钮 |

## 反馈语义（utils/feedback.ts）

| 级别 | 呈现 | 用于 |
|---|---|---|
| `success` | 行内徽章 ✓（淡入淡出） | 保存成功等不需要打断用户的确认 |
| `warn` | toast（4s） | 需要用户注意但可自行继续 |
| `error` | toast + 详情（7s） | 失败必须可见，附原因 |

> 视图层**不再直接 `toast.add`**，一律走 `feedback.*`。
