## 1. PapersView（文献）——toast 重灾区，14 处 → ≤5 处

**现状**：`toast.add` 15 处（含删除成功、导入成功等"成功也弹"）；无骨架屏；空态文案裸。

### 1a. toast 降频对照表（15 处逐条裁决）

| 场景 | 现状 | 改成 |
|---|---|---|
| DOI 导入成功 | toast success | `feedback.success('已导入 N 篇')`（行内） |
| 导入失败（DOI 无效/网络） | toast error | `feedback.error('导入失败', 'DOI: xxx — 10.xxxx 返回 404')` |
| 删除文献 | toast success | **ConfirmDialog**（见 1c）+ `feedback.success('已删除')` |
| 批量删除 | toast | **ConfirmDialog**（列出影响范围） |
| 刷新文献列表成功 | toast success | 删掉（列表本身可见，无需确认） |
| 刷新失败 | toast error | `feedback.error('刷新失败', detail)` |
| 标记已读成功 | toast success | 删掉（行内状态已变） |
| 导出成功 | toast success | `feedback.success('已导出')` |
| 导出失败 | toast error | `feedback.error(...)` |
| 保存笔记成功 | toast success | `feedback.success('已保存')` |
| 保存笔记失败 | toast error | `feedback.error(...)` |
| 关键词为空校验 | toast warn | `feedback.warn('关键词不能为空')` |
| 其余 3 处同模式 | | 按"成功→行内或删；失败→error"裁决 |

**目标**：`toast.add` 直接调用 ≤0（全部经 feedback），**弹出的 toast（warn+error）≤5 处**。

### 1b. 列表加载态（骨架）

### 1d. 响应 `lumo:quick-action`（DOI 导入直达）

  const kind = (e as CustomEvent<{ kind: string }>).detail?.kind

  }
