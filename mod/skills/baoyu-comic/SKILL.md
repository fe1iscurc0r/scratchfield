# 漫画生成技能 (baoyu-comic)

## 概述

本技能封装了 baoyu-skills 漫画生成能力，支持从自然语言描述自动生成完整漫画，包括分镜设计、角色设定、画面生成等全流程。

## 触发条件

- 用户请求"生成漫画"、"画漫画"、"制作漫画"、"comic"
- 用户提供了故事/脚本想要转化为漫画
- 用户需要将文本内容可视化为漫画形式

## 工作流程

### 第一步：故事理解与分镜设计

1. 解析用户输入的故事/脚本/描述
2. 自动拆分场景，确定每页的格子数量与布局
3. 生成分镜脚本（镜头描述、对话、旁白、特效指示）

### 第二步：角色与风格设定

1. 根据故事自动生成角色外观描述
2. 确定漫画风格（日式、美式、国风、简笔等）
3. 统一角色在不同分镜中的一致性描述

### 第三步：逐格生成画面

1. 按分镜脚本顺序逐格生成画面
2. 每格画面包含：构图描述、角色动作、背景、对话气泡位置
3. 支持对生成结果进行局部修改和调整

### 第四步：排版与输出

1. 将各格画面组装为完整页面
2. 添加对话气泡和文字
3. 输出最终漫画页面（支持多页）

## 支持的能力

- **多风格支持**：日式漫画、美式漫画、国风漫画、四格漫画等
- **多页漫画**：支持长篇故事自动分页
- **角色一致性**：跨分镜保持同一角色的外观一致性
- **对话气泡**：自动排布对话和旁白文字
- **特效处理**：速度线、集中线、网点等漫画特效

## 使用示例

```
用户: 帮我生成一个4格漫画，讲一个程序员debug的故事
→ 自动生成4格分镜脚本 → 逐格生成画面 → 输出完整漫画

用户: 把这段故事画成日式漫画风格
→ 解析故事 → 日式分镜 → 线稿+网点 → 日语拟声词 → 输出
```

## 注意事项

- 复杂故事建议先分成小节再逐节生成
- 角色数量建议控制在5个以内以保证一致性
- 生成前会先展示分镜脚本供确认
