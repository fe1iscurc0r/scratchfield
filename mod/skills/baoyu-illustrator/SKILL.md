# 插画生成技能 (baoyu-illustrator)

## 概述

本技能封装了 baoyu-skills 插画生成能力，支持从风格描述、主题关键词、参考图片等输入生成高质量插画作品。

## 触发条件

- 用户请求"生成插画"、"画插画"、"illustration"
- 用户描述了画面内容并指定了某种美术风格
- 用户需要书籍封面、海报、概念图等视觉素材

## 工作流程

### 第一步：需求解析

1. 解析用户描述中的主题、风格、氛围要素
2. 识别关键元素：主体、背景、色调、构图
3. 提取风格关键词（水彩、油画、扁平、赛博朋克等）

### 第二步：风格匹配

支持的主要风格类别：

- **传统美术**：水彩、油画、水墨、素描、版画
- **数字艺术**：扁平矢量、像素艺术、3D渲染、赛博朋克
- **商业插画**：扁平商务、2.5D等距、手绘涂鸦、极简线条
- **二次元**：日系赛璐珞、厚涂、Q版、治愈系
- **概念设计**：科幻概念、奇幻场景、角色设定

### 第三步：构图与细节

1. 根据描述生成详细的画面构图说明
2. 确定光源、透视、景深等视觉要素
3. 生成色彩方案和材质表达

### 第四步：生成与精修

1. 生成初始插画
2. 支持细节调整：修改局部、调整色调、增强对比
3. 可选添加文字/排版元素（适用于封面、海报）

## 支持的能力

- **丰富风格库**：50+ 预设艺术风格
- **参考图融合**：支持上传参考图进行风格迁移
- **高分辨率输出**：支持 2K/4K 分辨率
- **批量生成**：同一主题生成多个风格变体
- **后期调整**：局部修改、色彩调整、裁剪

## 使用示例

```
用户: 画一幅赛博朋克风格的未来城市夜景，有霓虹灯和飞行汽车
→ 风格:赛博朋克 → 构图:俯视城市 → 色彩:紫+蓝+粉 → 生成

用户: 帮我做一张书籍封面插画，主题是"星辰大海"，水彩风格
→ 主题提取 → 水彩风格 → 封面比例布局 → 生成 + 留白区域
```

## 注意事项

- 风格描述越具体，生成效果越精准
- 复杂场景建议先说明主体再说明背景
- 商业用途请注意版权合规性
