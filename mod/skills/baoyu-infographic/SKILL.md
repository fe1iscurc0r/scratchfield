# 信息图生成技能 (baoyu-infographic)

## 概述

本技能封装了 baoyu-skills 信息图生成能力，将结构化数据、统计信息、流程说明等转化为直观、美观的可视化信息图（Infographic）。

## 触发条件

- 用户请求"生成信息图"、"数据可视化"、"infographic"
- 用户提供了数据列表/统计数据需要展示
- 用户需要将文字说明转化为图解形式

## 工作流程

### 第一步：数据解析与结构提取

1. 解析用户输入的数据（JSON、CSV、自然语言描述的数据等）
2. 识别数据类型：对比数据、趋势数据、占比数据、流程数据、层级数据
3. 自动提取关键指标和核心信息点

### 第二步：图表类型匹配

根据数据类型自动选择最佳可视化形式：

| 数据类型 | 推荐图表 |
|---------|---------|
| 占比/构成 | 饼图、环形图、树图 |
| 趋势/变化 | 折线图、面积图、柱状图 |
| 对比/排名 | 条形图、排行榜 |
| 流程/步骤 | 流程图、时间轴 |
| 层级关系 | 思维导图、组织结构图 |
| 地理位置 | 地图可视化 |

### 第三步：视觉设计

1. 选择配色方案（自动或用户指定）
2. 确定布局方式（横向、纵向、网格等）
3. 添加图标、插图等视觉元素增强表现力
4. 生成标题、说明文字和标注

### 第四步：输出

1. 渲染最终信息图
2. 支持 PNG、SVG、PDF 等输出格式
3. 提供可交互版本（可选）

## 支持的能力

- **多图表类型**：饼图、柱状图、折线图、雷达图、散点图、热力图等
- **智能配色**：自动生成和谐配色方案，支持品牌色定制
- **图标库**：内置丰富图标资源，自动匹配语义
- **自适应布局**：根据数据量自动调整布局
- **多格式导出**：PNG、SVG、PDF、HTML

## 使用示例

```
用户: 把这份销售数据做成信息图
数据: Q1: 120万, Q2: 156万, Q3: 142万, Q4: 189万
→ 自动选择趋势图+柱状图组合 → 配色 → 输出信息图

用户: 生成一张展示公司组织架构的信息图
→ 组织层级数据 → 树状布局 → 输出
```

## 注意事项

- 数据量过大时建议先做汇总再生成
- 饼图切片建议不超过8个以保证可读性
- 配色会确保文字与背景有足够对比度
