# anything-llm 架构笔记

## 概述

AnythingLLM 是一个隐私优先的本地化全栈 LLM 应用框架，核心理念是"数据不出本地"，所有处理（嵌入、向量检索、LLM推理）均可在用户本地环境完成。

### 关键组件

| 组件 | 默认方案 | 可替换方案 |

## 本地嵌入

### 默认嵌入策略

AnythingLLM 优先使用本地嵌入模型，确保文档内容不出用户设备：

```
文档上传 → 文档解析(提取文本) → 文本分块
    → 本地嵌入模型 (all-MiniLM-L6-v2 / native)
        → 向量 → 存储到 LanceDB (本地嵌入式向量库)
```

### 嵌入流程要点

1. **零网络依赖**：默认配置下，嵌入过程完全离线
2. **LanceDB**：嵌入式向量数据库，无需独立服务进程，直接文件存储
3. **增量更新**：文档修改后仅重新嵌入变更部分
4. **工作区隔离**：不同工作区的向量数据物理隔离

## 多模型支持

### 模型接入层抽象

```
                      ┌─────────────────┐
                      │   Model Router   │
                      │  (统一接口适配)   │
                      └───────┬─────────┘
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
        ┌──────────┐   ┌──────────┐   ┌──────────┐
        │ 本地模型  │   │ 云端API  │   │ 自定义   │
```

支持的 LLM 提供商（40+）：
- **本地**：Ollama, LMStudio, LocalAI, KobaldCPP
- **云端**：OpenAI, Anthropic, Azure OpenAI, Google Gemini
- **开源**：Groq, TogetherAI, Perplexity, Fireworks

## 隐私优先设计

### 隐私保障层级

1. **默认本地**：安装即支持完全离线运行
2. **渐进式上云**：按需选择是否接入云端模型
3. **数据控制**：用户明确知晓哪些数据发送到了哪里
4. **无遥测**：默认不收集任何使用数据
5. **开源透明**：AGPL 协议，代码完全可审计

### 数据流向控制

```
本地模式（完全离线）:
  文档 → 本地嵌入 → LanceDB → Ollama 推理 → 回答

混合模式:
  文档 → 本地嵌入 → LanceDB ─┐
                              ├→ 本地 LLM   (敏感对话)
  用户问题 ──────────────────┘
                              └→ OpenAI API (非敏感对话)
```

## 与 scratchpad 的对比

| 维度 | AnythingLLM | scratchpad |
|------|-------------|------------|
| 定位 | 终端用户产品 | Agent 开发框架 |
| 部署 | 桌面应用 / Docker | Agent 运行时服务 |
| 隐私 | 默认完全本地 | 取决于工具配置 |
| 知识库 | 文档上传 + RAG | summer_memory 压缩 |
| 多模型 | Provider Router | 配置切换 |
| 多租户 | 工作区隔离 | 会话级隔离 |
| 用户界面 | 完整 Web UI | CLI / 对话接口 |
