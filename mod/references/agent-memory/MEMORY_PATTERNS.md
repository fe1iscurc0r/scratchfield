# agent-memory 记忆模式笔记

## 概述

agent-memory 是一个面向 AI Agent 的图记忆引擎，以知识图谱为核心数据结构，为 Agent 提供长期记忆和上下文检索能力。

## 核心设计

### 知识图谱构建

系统将 Agent 交互中的实体和关系自动抽取为图结构：

```
(实体A) --[关系]--> (实体B)

例：
(用户Alice) --[偏好]--> (深色主题)
(项目X) --[依赖]--> (Python 3.11)
(会议#42) --[发生于]--> (2024-03-15)
```

**抽取流程**：
1. 对话/文档 → LLM 实体抽取 → 实体节点
2. 共现/语义分析 → 关系发现 → 边
3. 新信息 → 图谱更新/合并 → 动态演化

### 记忆检索模式

#### 1. 语义检索（Semantic Search）
将查询向量化后在图嵌入空间中搜索最相关的实体和子图。基于向量相似度，适合模糊查询。

#### 2. 图遍历检索（Graph Traversal）
从已知实体出发，沿关系边遍历 N 跳（N-hop）获取关联信息：
```
查询: 用户Alice喜欢什么？
→ 定位(Alice) → 遍历[偏好]边 → 获取(深色主题)
→ 继续[曾使用]边 → 发现(Notion, VS Code)
```

#### 3. 混合检索（Hybrid）
结合语义搜索和图遍历，先语义定位入口实体，再沿关系扩展。

### 记忆管理

- **重要性评分**：根据访问频率、时间衰减、关系密度自动评估记忆重要性
- **记忆衰减**：长期未访问的记忆自动降权或归档
- **冲突解决**：新信息与旧信息冲突时的合并策略（以新为准 / 置信度PK）

## 与 scratchpad summer_memory 对比

| 维度 | agent-memory | scratchpad summer_memory |
|------|-------------|--------------------------|
| 数据结构 | 知识图谱（节点+边） | 分层摘要（DAG） |
| 检索方式 | 语义搜索 + 图遍历 | FTS5全文搜索 + 摘要展开 |
| 记忆粒度 | 实体级（细粒度） | 摘要块级（粗粒度） |
| 关系表达 | 显式关系边 | 隐式（通过摘要继承） |
| 更新策略 | 增量图谱更新 | 周期摘要压缩 |
| 优势 | 关系推理、多跳联想 | 对话保真度高、实现简单 |
| 劣势 | 构建成本高、噪音控制难 | 缺乏关系表达、碎片化 |

## 适用场景

- **agent-memory 擅长**：需要关系推理的长期知识管理、多实体关联分析
- **summer_memory 擅长**：对话历史保真、上下文窗口压缩、快速回溯
